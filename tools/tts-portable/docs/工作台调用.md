# tts-portable · 工作台统一调用

`G:\StudyCode\个人工作台\tools\tts-portable` 是共享语音工具的维护入口。这里集中放置：

- FastAPI 实时服务：VoxCPM2 → edge-tts；
- 前端 `client/voice.js`：再回退到浏览器 Web Speech；
- Edge TTS 配置、批量生成、VoxCPM2 诊断和移植文档；
- 幼儿英语词库生成器；
- 汉字、汉语组词、拼音、古诗和英语拼读内容音频生成器。

`G:\StudyCode\宠物积分系统\prj\tts-portable` 仍保留，作为旧项目的兼容副本；以后新增或修复优先改共享目录，再按需要复制到宿主项目。

## 一条命令入口

PowerShell 或 CMD 都可以从任意目录调用：

```powershell
$TtsPortable = 'G:\StudyCode\个人工作台\tools\tts-portable'

# 检查服务（服务未启动时会返回明确错误）
& "$TtsPortable\run.bat" health

# 启动实时 TTS 服务；默认 http://127.0.0.1:9885
& "$TtsPortable\run.bat" start

# 查看四套预设音色
& "$TtsPortable\run.bat" voices
```

也可以直接用 PowerShell：

```powershell
& "$TtsPortable\invoke.ps1" health
& "$TtsPortable\invoke.ps1" start
```

## 幼儿英语词库

默认项目根目录是 `G:\StudyCode\个人工作台`：

```powershell
# 不加载模型，只查看 597 条词库中哪些音频缺失
& "$TtsPortable\run.bat" dry-run

# 先生成一个词确认质量
& "$TtsPortable\run.bat" generate --word brown --device cuda

# 小批生成；已存在且大于 100 bytes 的 MP3 默认跳过
& "$TtsPortable\run.bat" generate --limit 10 --device cuda
```

生成器使用：

- VoxCPM2 Python：`D:\PythonEnvs\tts-voxcpm\Scripts\python.exe`；
- 模型：`D:\HuggingFaceCache\VoxCPM2`；
- 词库：`prj/data/preschool/英语/vocabulary-bank.json`；
- 输出：`prj/assets/audio/vocab/`。

也可以显式指定另一个宿主项目的词库与输出目录：

```powershell
& "$TtsPortable\invoke.ps1" dry-run `
  -Bank 'G:\StudyCode\个人工作台\prj\data\preschool\英语\vocabulary-bank.json' `
  -OutputDir 'G:\StudyCode\个人工作台\prj\assets\audio\vocab'
```

## 汉字、汉语、拼音、拼读、古诗

共享内容生成器直接读取工作台现有课程数据，不再另维护一套词表：

- 1,500 个汉字；
- 2,672 个去重后的汉语组词；
- 63 个拼音条目；
- 34 首古诗和 139 行诗句；
- 94 个英语拼读词、26 个字母卡、字母音和拆音；完整内容清单为 4,535 个音频目标。

先查看完整清单，不加载模型，也不联网：

```powershell
& "$TtsPortable\run.bat" content-dry-run
& "$TtsPortable\run.bat" content-dry-run --category hanzi --limit 10
& "$TtsPortable\run.bat" content-dry-run --category pinyin --limit 10
& "$TtsPortable\run.bat" content-dry-run --category poetry --limit 10
& "$TtsPortable\run.bat" content-dry-run --category phonics --limit 10
```

默认用 Edge TTS 生成普通话和古诗，音频落在：

```text
G:\StudyCode\个人工作台\prj\assets\audio\tts\
```

生成小批样音：

```powershell
& "$TtsPortable\run.bat" content-generate --category poetry --limit 3 --engine edge
& "$TtsPortable\run.bat" content-generate --category hanzi --text 山 --engine edge
# Edge 批量生成可以并发，带请求超时和重试；VoxCPM2 不并发加载多个模型
& "$TtsPortable\run.bat" content-generate --category hanzi --engine edge --workers 8 --edge-timeout 30 --edge-retries 3
```

确认样音后再批量生成。需要用 VoxCPM2 时：

```powershell
& "$TtsPortable\run.bat" content-generate --category poetry --engine voxcpm2 --device cuda
```

工作台运行时会按统一音频键先找 `prj/assets/audio/tts/` 的本地 MP3；APK 可以离线播放这些已打包音频，缺失项目再回退 Android 原生 TTS 或浏览器 Web Speech。全量 APK 会增加约 37 MiB（本次 Debug APK 约 93.11 MiB）；VoxCPM2 模型和虚拟环境本身不会进入 APK。

## 常用环境变量

```powershell
$env:VOXCPM2_PYTHON = 'D:\PythonEnvs\tts-voxcpm\Scripts\python.exe'
$env:VOXCPM2_MODEL_PATH = 'D:\HuggingFaceCache\VoxCPM2'
$env:TTS_PORT = '9885'
```

模型权重和 GPU 虚拟环境是机器级资源，不复制到任何项目目录；APK 只打包生成后的音频，不打包 VoxCPM2。
