# 智慧花园：植物大战僵尸式草坪战场背景提示词

## 目标

为 3-6 岁幼儿学习工作台生成一张横向游戏场景背景。背景只负责营造“阳光草坪、植物防守、僵尸入侵路线”的游戏氛围，网页文字、任务卡、按钮和交互角色由 HTML 叠加。

## GPT-IMAGE-2 提示词

Create a polished 2D illustrated landscape background for a preschool learning game dashboard, inspired by the visual language of a classic lane-based garden tower-defense game, but with original characters and no logos or copyrighted character designs. Wide 3:2 composition, bright cheerful daytime backyard garden, saturated green lawn with four clear horizontal planting lanes and soft perspective, a warm blue sky with fluffy white clouds, a small friendly garden fence and leafy bushes in the distance, a sunny warm color palette with fresh grass green, sunflower yellow, sky blue, tomato red accents and warm soil brown. The left and center of the lawn should stay relatively open and low-detail so HTML task cards and plant sprites can be layered on top. Keep a clear empty sky band across the top for a dashboard header. Keep the rightmost lane edge visually readable as an incoming path for playful cartoon zombie silhouettes to be layered later, but do not draw zombies or readable characters in this image. Add subtle hand-painted texture, soft rounded shapes, crisp clean outlines, playful preschool game art, high contrast, joyful and energetic, non-pixel-art, polished mobile game background, no text, no letters, no numbers, no UI panels, no buttons, no interface icons, no watermark, no border.

## 负面约束

No text, no Chinese characters, no English letters, no numbers, no logo, no watermark, no UI, no cards, no buttons, no menus, no people, no realistic horror, no dark mood, no fog, no blood, no scary zombie faces, no pixel art, no Minecraft blocks, no checkerboard transparency.

## 预期用途

- 作为幼儿工作台首页的场景背景。
- CSS `background-image` 或 `<img>` 铺底。
- 植物、僵尸、阳光、任务卡和导航由 HTML/CSS/透明 PNG 叠加。
