# 视觉评审记录

## 首版验收点

- 横屏一屏显示 HUD、Canvas、控制区和底部操作栏；`body` 不滚动。
- 天空、草地、方块地面、玩家和最终传送门均在 Canvas 中有稳定的 fallback 绘制，复制资产加载失败也不会出现空白关卡。
- 卡片使用高对比浅色面板，图片选项有 44px 以上触控面积；答错使用暖色提示，正确答案使用绿色高亮。
- `prefers-reduced-motion` 会缩短卡片落下和奖励等待，portrait 设备展示旋转提示。

## 待评审

真机 Android 横屏需要重点复核安全区、软键盘/地址栏抢占高度、触屏按钮误触和语音权限提示；原创角色与传送门资产替换后需要重新检查 Canvas 与卡片视觉焦点的层级关系。
