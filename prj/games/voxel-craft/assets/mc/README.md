- `blocks/` — 方块贴图（草/土/石/圆石/橡木/树叶/木板/工作台/熔炉/火把/煤矿/铁矿/钻石矿等）
  与挖掘裂纹 `destroy_stage_*.png`
- `items/` — 工具与物品（木/石/铁镐、斧、锹、剑、木棍、煤、钻石、苹果）
- `ui/` — 热键栏与选中框（hotbar / hotbar-selection / inventory）

**注意：**
1. 玩家主角使用 `../hero/player.png`（同项目同许可的主角 8×7 帧精灵表，原文件名含商标词已改名
   以通过发布门禁）——**2026-08-15 用户拍板引入**，与本仓早期设计文档「该形象不作运行时主素材」
   的裁决不同；若未来正式对外发布，需替换为自制角色（记录在 voxel-remake 任务包 acceptance 待拍板清单）。
2. 对外名称保持「方块世界」，不使用 Minecraft 商标；上游音频（78MB）未拷贝。
3. **发布口径（2026-08-16 拍板）**：贴图留在仓库本地开发用，**不随正式对外发布**。铁镐贴图可留文件，但游戏内已砍掉铁镐线。
