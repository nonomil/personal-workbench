# 视觉评审记录

## 首版验收点

- 横屏一屏包含 HUD、Canvas、触屏控制和底部操作栏，`body` 使用 `overflow: hidden`，Android 横屏不产生上下页面滚动。
- Canvas 有天空、平台、玩家、敌人、10 个检查点和最终旗帜；卡片覆盖层使用浅色高对比面板。
- 答案按钮触控高度不低于 44px；答错显式高亮正确图片并提供纠错继续按钮。
- portrait 设备展示旋转提示；`prefers-reduced-motion` 缩短卡片和奖励延时。

## 待真机复核

需要在 Android 横屏设备复核安全区、地址栏高度、连续按住奔跑的误触、不同语音实现的 Promise/返回值，以及素材替换后的角色与旗帜视觉层级。
