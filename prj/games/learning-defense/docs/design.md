# 知识花园保卫战 · 场景与玩法设计

## 产品边界

- 这是独立于 `garden-defense` 的新游戏，不把学习弹窗硬塞进旧游戏。
- 玩法使用原创“花园守卫”命名与 UI；首版复用资产仅用于验证玩法，后续逐批替换为原创角色和场景。
- Android 横屏是一等布局：一屏完成战斗和学习，不允许纵向滚动。
- Android/Web 竖屏只显示友好的旋转提示，不维护一套被压扁的塔防操作界面。
- 完成 10 张仅解锁本局最终波；答题尝试写回课程掌握度，但不得直接修改或完成 `dailyPlans`。

## 30 秒核心循环

```text
0–18 秒   植物攻击、敌人推进、孩子补种
18–20 秒  击败敌人后天空出现卡片预告
20–21 秒  卡片落下，战场进入安全冻结
21–29 秒  自动朗读、看图选择、必要时纠错
29–31 秒  卡片化为阳光，进度从 4/10 变为 5/10
31 秒后   3、2、1 恢复战斗
```

首版采用“每击败一名普通敌人掉一张卡”。累计 10 张后不再掉卡，按钮从“继续防守”切换为“开启最终波”。

## 学习闸门状态

```text
ready
  → battle
  → card-falling
  → learning
  → correction（仅首次答错）
  → card-reward
  → resume-countdown
  → battle / final-wave-ready
  → final-wave
  → settled
```

`card-falling` 到 `resume-countdown` 期间，敌人、植物、子弹、生成计时和技能冷却全部冻结。暂停按钮或应用进入后台时，卡片落地、奖励动画、恢复倒计时和最终结算使用的游戏时钟也会冻结。Canvas 可以继续绘制轻微环境动画，但不得推进游戏模拟。

## 学习判定

- 每张卡先自动朗读，也可重复点击扬声器。
- 每题提供 2–3 个大图片选项，按钮间距不小于 8px。
- 首次答对直接完成，记录 `correct=true`。
- 首次答错不扣游戏生命，显示正确图并重播；点击“我记住了”后完成，记录 `correct=false`。
- 10 张代表完成 10 次流程，不要求 10 张全对，避免幼儿无法返回游戏。
- 正确率影响结算星星和复习推荐，不影响最终波是否解锁。
- 胜利结算只允许从 `final-wave` 进入；普通 `battle` 阶段只能失败结算。

## 工作台入口

“植物大战”导航先进入一屏游戏选择页，不再直接跳旧游戏：

- “去花园游戏”：保留经典 18 关花园保卫。
- “知识花园 · 10 张卡”：进入本项目。

入口脚本和共享 bridge 使用独立缓存版本号，保证 APK 覆盖安装后不会继续执行旧的直跳逻辑。

```text
┌──────────────────────────────────────────────────────────┐
│ 第1关  波次 1/2     ●●●●●○○○○○ 5/10     声音  暂停  退出 │
├──────────────────────────────────────────────────────────┤
│                                                          │

│                         ┌──────────────┐                 │
│                         │ 图片 │ 文字   │                 │
│                         │      │ 3选1   │                 │
│                         └──────────────┘                 │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ 阳光 250   [阳光花] [种子炮] [护盾果]       开始/继续防守 │

```

在 800×360 矮横屏中，学习卡固定使用左图右题；在平板横屏中可以增加留白，但不改变触控位置。HUD 使用高对比深绿，卡片使用奶油白、阳光黄、湖水蓝和草地绿，边框和阴影保持玩具块感。

## 发音

运行时采用：本地 MP3 → Android 原生 TTS → Web Speech。`edge-tts` 只适合作为构建期批量生成本地语音的工具，不作为 APK 在线依赖。

## MVP 与后续

MVP：1 个关卡、3 种植物、2 种普通敌人、1 个最终敌人、5 张汉字卡、5 张英语卡、10/10 最终波、结算与掌握度写回。

第二阶段：课程引擎动态选题、错题优先、拼音和自然拼读卡、原创角色动画、更多关卡、APK 方向锁定与中断恢复。
