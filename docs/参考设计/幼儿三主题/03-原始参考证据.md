### 体素方块方向

本地参考笔记中“我的世界”方向的关键不是把页面做成普通 3D 场景，而是把以下元素贯穿 UI：

- 靛蓝侧栏 + 黄色高亮选项
- 草方块、泥土剖面、石砖、木箱、晶体
- 背包槽 / 物品栏式资源胶囊
- 方块地图或关卡路径
- 直角、等距、硬边阴影；不使用软绵绵的写实 3D 仪表盘

## 本轮生成的硬门槛

1. 先生成真实工作台壳：侧栏、顶部状态、科目卡、任务清单和奖励出口必须一眼可见。
2. 主题素材只进入对应区域：平台世界进顶部，科目卡保持可读空白，游戏场景进独立卡片。
3. 卡片比例、间距和层级接近参考截图；禁止单一巨型英雄插画占满页面。
4. 生成图不内嵌中文、英文、数字、Logo、水印或官方角色；网页文字由 HTML/CSS 叠加。
5. 马里奥方向使用原创小探险家；方块方向使用原创方块伙伴；植物方向使用原创植物和入侵者。
6. 优先 2D/2.5D 游戏 UI 质感。只有方块主题使用清晰的等距体素，不做泛化的高光 3D。
