# 幼儿三主题：组件级生图提示词 v4

更新时间：2026-08-06

## 共同规则

```text
Use case: ui-mockup and game-ui-asset-pack.
Create an original children's learning workbench visual system, not a poster and not a full-screen game key art image.
The web page is built in HTML/CSS. Generated images are only reusable components: transparent companion characters, isolated UI objects, or a shallow horizontal top-banner strip.
Preserve these layout facts when a reference UI is supplied: fixed navigation rail about 22% of desktop width, pale content surface, large readable cards, generous spacing, one primary today panel, a task checklist, and one game exit card.
Do not render readable Chinese/English text, numbers, logos, watermarks, browser chrome, fake UI copy, official characters, copied levels, or official game textures.
Use original characters and original shapes that communicate the requested visual grammar without reproducing a protected brand asset.
```

## 生成顺序

1. 先生成透明伙伴和 8～12 个主题物件的爆炸图，验证 alpha 后裁切。
2. 再生成一张 1536×768 的浅横幅，只覆盖网页顶部的 25%～30% 高度。
3. 最后用 HTML/CSS 组合侧栏、卡片和文字；不再生成一张包含所有页面元素的 1024×1536 海报。

## 平台冒险组件

```text
Create an original platform-adventure learning UI asset sheet for a preschool workbench.
Visual grammar: saturated tomato red menu panels, bright golden-yellow active state, cyan sky, white puffy clouds, rounded green hills, grass-topped brown platforms, chunky orange brick blocks, gold coin disks, a simple green pipe, a small finish flag, and an original child explorer companion wearing a warm orange scarf and a bronze explorer cap. The explorer must not resemble any famous plumber or use a famous logo.
Output a clean grid of isolated objects with generous spacing on a perfectly flat #00ff00 chroma-key background: explorer companion, cloud, grass platform, brick block, coin, pipe, flag, star badge, treasure chest, book, pencil, calculator, globe, palette, and music note.
No text, no numbers, no watermark, no scene background, no cast shadows, no overlap between objects. Use crisp 2D game UI illustration, strong dark outlines, simple controlled highlights, saturated red/yellow/blue/green palette.
```

## 体素方块组件

```text
Create an original voxel adventure learning UI asset sheet for a preschool workbench.
Visual grammar: orthographic hard-edged cubic geometry, stacked grass blocks with visible brown dirt cross-sections, square-leaf trees, stone stairs, a wooden chest, purple crystal cluster, small water channel, bridge, checkpoint flag, and an original cube companion with a simple friendly face. This must feel like a block-building adventure without copying any famous game's character, logo, or exact texture.
Output isolated objects in a clean grid on a perfectly flat #00ff00 chroma-key background: cube companion, grass block, dirt block, stone step, tree, chest, crystal, water tile, bridge, flag, book block, number-abacus block, globe block, potion flask, trophy, and gear.
No text, no numbers, no watermark, no landscape background, no blur, no soft toy-like rounded 3D. Use crisp orthographic voxel geometry with deliberate cube layers, limited indigo/cobalt/moss/stone/clay/gold palette.
```

## 草坪防守组件

```text
Create an original friendly lawn-defense learning UI asset sheet for a preschool workbench.
Visual grammar: warm cream cards, deep purple and forest-green menu panels, layered grass and brown soil, sunlight-gold resource token, shield badge, streak badge, friendly sunflower guardian, pea-shooting plant, protective nut-shaped wall plant, watering can, seed packet, harmless silly garden invader, treasure chest, book, calculator, English letter tile, and exercise star.
Output isolated objects in a clean grid on a perfectly flat #00ff00 chroma-key background. Objects must be original and friendly, not copied from any commercial tower-defense game. No horror, no official characters, no text, no numbers, no watermark, no background, no cast shadows, no overlap. Use chunky 2D game UI illustration, strong outlines, readable silhouettes, lime/leaf-green/purple/cream/sunlight-gold palette.
```

## 横幅参考图提示词

```text
Create a wide 1536x768 visual reference for one preschool learning workbench homepage, shown as a real web dashboard rather than a poster.
Keep a fixed navigation rail on the left, a compact shallow themed world banner across the top of the main area, a pale content surface, one companion/today card, a two-column subject/task card area, and a small game-progress exit card. Leave all labels blank for HTML/CSS overlay.
For the selected theme, change only the visual language: platform adventure uses red rail + yellow active item + sky/brick/coin/pipe strip; voxel adventure uses indigo inventory rail + hard cube terrain + crystal/chest strip; lawn defense uses purple-green rail + lawn/fence/sunlight strip + compact soil grid.
No readable text, no official characters, no logo, no watermark, no full-screen key art, no giant hero illustration, no generic SaaS charts.
```
