# 幼儿三主题：参考驱动 v3 生图提示词

更新时间：2026-08-06

用途：生成页面视觉参考图，不直接作为运行时页面。三张图必须保持同一个工作台信息架构，只更换主题皮肤。

## 共同约束

```text
Use case: ui-mockup
Asset type: portrait-first preschool learning workbench reference, 1024x1536
This is a real usable web-app dashboard screenshot, not a poster, not a landing-page hero, and not a single giant game illustration.
Preserve this exact information architecture: a fixed vertical navigation rail taking about 20-24% width; a compact game-world top banner; a warm white or very pale main content surface; a large companion/today panel; a two-column subject-card grid; a separate game-progress panel; a daily task checklist; and a reward-center exit card near the bottom.
All cards must have large blank areas reserved for HTML/CSS labels. Do not render any readable text, letters, numbers, Chinese characters, fake writing, logo, watermark, browser chrome, or screenshot frame.
Use clean 2D or 2.5D children's game UI illustration with strong outlines, controlled shadows, readable spacing, and large touch targets. Do not use generic SaaS charts, glassmorphism, photorealism, or a full-screen key art poster.
The same shell proportions and card hierarchy must be visible in all variants. Only the theme colors, world banner, game-progress panel, decorative icons, and companion character change.
```

## A. 平台冒险 / 马里奥语法方向

```text
Create the platform-adventure themed variant of the common workbench.
Use a saturated tomato-red vertical navigation rail with deep red inset panels, large rounded menu tiles, white simple pictograms, and one bright golden-yellow active tile. At the top of the rail place an original child explorer badge, not an official character.
The top banner is a wide cheerful side-scrolling world strip: vivid cyan sky, layered white puffy clouds, green rounded hills, grass-topped brown platforms, a row of orange brick blocks, a few golden coin disks, one green pipe, and a small finish flag. Keep the banner shallow like a web header, not a full-screen landscape.
The main companion panel is a large white card with a thin warm-gold border. Place an original small explorer companion on the left and blank label areas plus three or four chunky colored action buttons on the right. Below it place six clean subject cards in a two-column grid, each with a large simple icon, a colored top border, an empty title area, and a pill button.
Place a separate horizontal platform-progress card lower down: several grass-topped floating dirt platforms connected by a dotted path, coin markers, a question reward block without any readable mark, and a treasure chest. End with a task checklist and a purple-gold reward chest card.
Visual language: flat cheerful platform-game UI, crisp dark outlines, saturated red/yellow/sky-blue/leaf-green, warm white cards, limited soft shadows. Avoid shiny 3D dashboard treatment, realistic characters, official plumber/mustache/hat design, copied levels, official logos, and random game-poster composition.
```

## B. 方块世界 / 我的世界语法方向

```text
Create the block-building voxel adventure variant of the common workbench.
Use a saturated indigo-purple vertical navigation rail with large rounded inventory-like tiles and one bright yellow active tile. The rail should feel like a game menu, not a corporate sidebar.
The top banner is a shallow panoramic voxel world: bright blue sky, square clouds, orthographic block-built grass and dirt islands with visible dirt cross-sections, square-leaf trees, stone steps, a wooden chest, a crystal cluster, and one original small cube companion. Put crystal and streak resources in chunky item-slot capsules.
The main surface is cream-white. Below the banner show six subject cards in a two-column inventory/quest grid. Each card has a colored bookmark tab, one small voxel-built object, a blank label plate, and a clear empty area for HTML text. Do not fill the page with one large 3D scene.
Below the subject cards show a compact voxel mission map: block path, small cave entrance, water channel, bridge, signpost, checkpoint markers, chest at the end, and a four-row daily checklist with crystal rewards. Finish with a large golden treasure chest reward exit.
Visual language: crisp orthographic voxel, hard square silhouettes, visible stacked cube layers, limited cobalt/indigo/moss/stone/clay/gold palette, pixel-inspired bevels but not blurry pixel art. Avoid smooth rounded toy 3D, glossy generic game UI, official Minecraft textures, Steve, creeper, official logo, copied inventory screen, or random landscape poster.
```

## C. 草坪防守 / 植物大战僵尸语法方向

```text
Create the lawn-defense variant of the common workbench.
Use a deep purple and forest-green vertical navigation rail with large rounded garden-menu tiles. Add a bright lime or golden active tile and a small original sunflower guardian badge.
The top banner is a shallow sunny backyard: blue sky, soft clouds, rolling lawn, white fence, layered leaves, sunlight resource capsules, a shield capsule, and a streak capsule. Keep it as a header behind the dashboard, not a giant garden painting.
The main surface is warm white with a clear two-column subject-card grid. Each card has an original friendly plant or garden object, an empty text plate and a simple HTML label area. The central game panel is a compact lawn-defense card with a clearly readable 5 by 3 grass grid, brown soil planting holes, three original plants on the left, and a few harmless silly invaders approaching from the right. Include a separate daily checklist with sunlight reward chips and a reward chest exit.
Visual language: chunky outlined 2D game UI, layered grass and soil, green/lime/purple/cream/sunlight-gold, friendly expressive faces, strong hierarchy, large touch targets. Avoid official Plants vs. Zombies characters, logos, copied artwork, realistic zombie horror, glossy generic SaaS dashboard, and single giant illustration.
```
