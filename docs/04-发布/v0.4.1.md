# 个人工作台 v0.4.1

发布日期：2026-08-03

## 版本定位

这是“儿童冒险基地”版本。儿童首页负责把真实学习安排清楚、把完成证据留下来；成长地图、奖励中心和幼儿版花园继续承载游戏化反馈。

## 本版内容

### 儿童学习工作台

- 首页改为四段式冒险基地：身份伙伴、今日必做/选做、学习证据和成长地图。
- 必做任务默认展开，选做挑战默认折叠，保持首屏聚焦和低压力节奏。
- 语文知识森林、数学数字岛、英语探索湾根据现有课程进度派生状态；科学发现站作为任务探索支线，不生成虚假的课程数据。
- 首页点击计划继续使用现有 `toggle-plan`，完成一次任务只结算一次阳光；课程、阅读、奖励入口仍跳转到既有页面。
- 桌面端使用主内容 + 侧栏双栏，移动端在 375px 左右切换为单列并确保没有横向溢出。

### 资料与边界

- 参考小红书案例只转译信息架构，不复制人物、视频、截图或品牌资产。
- AI 自动排课、完整教材引擎和新的云端账本仍是后续规划，不在本版运行时实现。
- 自然拼读专项资料和 reference-only 素材保留在既有数据/文档目录，不改变儿童首页的轻量定位。

## 发布方式

- GitHub Pages：`main` 分支根目录直出，推送后等待 Pages 部署完成。
- APK：推送 `main` 自动触发 `.github/workflows/android-apk.yml`；推送 `v0.4.1` 标签时额外生成 GitHub Release Debug APK。
- `dist/`、`android/`、`tmp/` 和 `.worktrees/` 仍是本地/构建目录，不提交。

## 已知边界

- 儿童版首页是计划与成长反馈工作台，不替代语数英教材和真实学习过程。
- 科学发现站当前是任务探索入口，未新增科学课程数据。
- 正式签名 APK、MuMu 安装复验和自托管服务部署不在本版验证范围内。
