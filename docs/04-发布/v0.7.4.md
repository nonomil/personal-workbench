## 平板结论

工作台本身适合安卓平板，本版不另做布局大改。

- 幼儿版已有横屏常驻侧栏、竖屏抽屉、`viewport` 自适应；课程卡和今日练习按 768 宽屏收过。
- APK 仍只带三界：花园保卫、方块世界（`voxel-craft`）、横版闯关，以及英语课里的认词对战。
- 方块传奇要指针锁和键盘，不适合手指操作，继续不进 APK、不出现在启动页「进入 / 去玩」按钮。本地网页或独立仓可玩。
- 首页若再露出方块传奇入口，平板上会点进空页，本版已从今日冒险、三世界进度和周报里拿掉。

## 本版变化

- 英语 mastery 方案 A：新词走 6 小时到 28 天课表，存量词沿用旧间隔；英语专区置顶「今天练这个」。
- 跟读评测共享模块 `games/shared/speech-match.js` 入库，工作台与后续游戏共用同一套判定。
- 识字 / 拼音 / 拼读 / 口算词包 `core-*-2026.08.19` 接入 `packages.json`。
- 工作台启动页不再给方块传奇放入口，避免 APK 404。

## 安装

- 覆盖安装要求：同一包名、同一把签名钥匙、`versionCode` 只升不降。
- 机器上如果还装着以前的 Debug 包，签名不同，需要先卸载再装（这次会丢本地数据）。之后的正式包可以直接覆盖。
