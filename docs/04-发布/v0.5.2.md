# 个人工作台 v0.5.2

> 状态：根入口首页优化版；网页门禁与静态制品验收以本文件的实际记录为准。APK/MuMu 设备验收为 **PARTIAL**（部分完成），不是全功能通过。

## 本版变化

- 根入口采用明确的“两层五入口”结构：上方三个幼儿游戏世界，下方成人与少儿两个通用工作台。
- 三个幼儿入口分别传递 `garden-defense`、`voxel-adventure`、`platform-quest` 主题参数，仍进入同一个 `preschool-workbench/index.html` 和同一份本地成长快照。
- 幼儿世界卡使用更强的主题视觉，成人/少儿卡使用更紧凑的通用工作台展示节奏。
- 增加跳到入口的可访问链接、世界/通用卡语义标记、键盘焦点和 44px 触控区域。
- 修复 320px 手机宽度在存在竖向滚动条时由 `body min-width: 320px` 引发的横向滚动；手机标题改为可控断行。
- 不新增 localStorage key，不加载 60 日课程资料到根入口，不改变独立花园游戏规则。
- 2026-08-06 源码续接（尚未进已发 APK）：根入口冷启动不再因记忆选择自动跳转，打开即显示多工作台五入口；`shouldAutoRedirect` 恒 false，记忆选择仅用于最近徽章。
