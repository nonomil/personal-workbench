# 个人工作台 v0.7.3

> 状态：2026-08-18 网页随 `main` 推送到 GitHub Pages。APK 改为正式签名包。

## 版本号

- npm / 页脚：`0.7.3`
- Android：`versionName=0.7.3`，`versionCode=703`
- 上一正式记录：`v0.7.2`（2026-08-18）
- 不另开 localStorage key，包名仍是 `com.nonomil.personalworkbench`。

## 本版变化

- APK 改为 `assembleRelease`，用 GitHub Secrets 里的固定钥匙签名。
- 工作台实际打开的游戏保留：花园保卫、方块世界（`voxel-craft`）、横版闯关，以及英语课里的认词对战。
- 方块传奇没有启动页入口，已从工作台页面、APK 和远程仓库移除，只留在本地。
- 未用游戏目录和生图中间层从打包和远程仓库移除。

## 安装

- 覆盖安装要求：同一包名、同一把签名钥匙、`versionCode` 只升不降。
- 机器上如果还装着以前的 Debug 包，签名不同，需要先卸载再装（这次会丢本地数据）。之后的正式包可以直接覆盖。
