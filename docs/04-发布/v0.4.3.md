# 个人工作台 v0.4.3

发布日期：2026-08-06

## 版本定位

这是幼儿版任务交互修复版本。工作台继续保持“今日计划、打卡、简单测试、进度、阳光/奖励和去游戏出口”的轻量边界；60 日自然拼读和暑假资料仍是资料库，不会被全量加载到首页。

## 本版内容

### 幼儿学习工作台

- 每日任务使用“任务 ID + 本地日期”定位，解决跨日复用模板 ID 导致勾选错记录的问题。
- 首页、今日页、成长路线和学习任务页统一携带任务日期；勾选、编辑、删除均针对当前日期的具体任务。
- 任务卡的完成按钮与编辑/删除按钮分离，避免管理操作误触完成状态；自定义任务仍可改名和删除。
- 任务奖励幂等事件改为 `plan:{id}:{date}`，同一日期的任务不会重复领取阳光，跨日期记录互不串联。
- 花园基地继续使用成长进度、成就墙、收集记录和现有植物技能/棋盘交互，不新增第二套积分账本。

### 兼容与边界

- 保留现有 localStorage、本地优先、JSON 导入导出和旧快照迁移逻辑。
- 不把 60 日课程资料全量接入首页，不扩展复杂课程引擎或复杂游戏引擎。
- APK 仍由 `.github/workflows/android-apk.yml` 在推送 `main` 或 `v*` 标签后自动构建；产物是 Debug APK，正式签名和 MuMu 安装验收仍需单独进行。

## 发布方式

```powershell
git push origin main
git push origin v0.4.3
```

推送 `main` 后 GitHub Pages 使用仓库根目录更新静态站点；推送 `v0.4.3` 后 Android Actions 自动构建并将 Debug APK 附加到对应 GitHub Release。
