# 个人工作台 v0.4.0

发布日期：2026-08-03

## 版本定位

这是“轻量工作台 + 独立游戏”版本。工作台负责完成、记录和反馈；趣味动画、植物、僵尸和战场互动集中在独立的“花园保卫战”页面。

## 本版内容

### 工作台

- 今日 3 项核心任务 + 3 项可选任务，旧快照迁移时保留已完成状态。
- 简单测试、阳光奖励、进度记录和奖励出口继续使用现有本地优先链路。
- 60 日自然拼读资料保留在资料库，不全量读取到首页，不新增完整课程引擎。

### 花园保卫战

- 5 路 × 6 列独立棋盘。
- 可选择向日葵、豌豆射手和坚果墙，并通过放置改变实际行为。
- 普通、路障、铁桶僵尸具有不同生命值和移动节奏。
- 游戏状态写入幼儿版既有成长快照，刷新后恢复；离开 battle 页面停止自动 tick。
- 游戏失败不扣除打卡结果、已有阳光或学习进度。

### 自然拼读

- 幼儿英语入口提供 3 张轻量测验卡：字母音、首音识别和 CVC 拼读。
- 完成状态使用现有 `courseProgress.completedLessonIds`，奖励事件保持幂等。
- Open Source Phonics PDF、来源页和授权页放在 `docs/自然拼读/research/resources/`，仅作 reference-only 核对资料，不作为运行时依赖。

## 发布方式

- GitHub Pages：推送 `main` 后由仓库 Pages 配置发布根目录静态站点。
- APK：推送 `main` 自动触发 `.github/workflows/android-apk.yml`；推送 `v0.4.0` 标签时额外创建 GitHub Release 并附加 Debug APK。
- APK 仍是 Debug 包；正式签名包、MuMu 本轮安装复验和自托管同步不宣称已完成。

## 已知边界

- 不实现原版植物大战僵尸的完整关卡、复杂 AI、多人、联网排行榜或第三方 iframe。
- 课程资料完整不等于网页已接入全部课程；后续按需逐科接入。
- `docs/`、`data/` 和 `assets/` 是正式资料；`tmp/`、`dist/`、`.worktrees/` 不属于 Pages 发布制品。
