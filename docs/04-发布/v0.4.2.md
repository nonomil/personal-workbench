# 个人工作台 v0.4.2

发布日期：2026-08-04

## 版本定位

这是“暑假学习资料库”版本。幼儿版将打印资料整理成可浏览、可朗读、可继续使用的课程入口，同时保留植物大战、打卡和奖励的主路径。

## 本版内容

### 幼儿学习工作台

- “植物大战”前置为幼儿版主导航第二入口，学习专区默认折叠，避免左侧导航过长。
- 新增“暑假学习”课程，提供 6 张精选素材卡：晨读、识字、古诗、数学和每周复盘。
- 新增资料库分类浏览：60 天晨读、45 天识字、古诗、经典短句和 8 周复盘；支持下拉选择、前后翻页和浏览器语音朗读。
- 资料库只在暑假学习课程中出现，首页仍聚焦今日打卡、阳光、植物大战和奖励，不增加第二套积分账本。

### 资料与边界

- 暑假资料是项目原创学习内容，作为静态前端数据发布，不依赖网络和第三方教材运行。
- 资料展示与课程练习分离：资料用于阅读、朗读和复习，答题与阳光结算仍走现有课程事件链路。
- 保留 `localStorage` 本地优先、JSON 导入导出和现有自托管 API 预留；未重新引入 Supabase 运行时。
