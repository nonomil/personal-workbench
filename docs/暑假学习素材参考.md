# 幼儿版暑假学习素材参考

## 来源

主要参考：`G:\StudyCode\宠物积分系统\prj\暑假每日学习打印版`。

该项目的核心结构是“按天使用的一页学习单”，包含：

- 每日学习单：晨读、识字、古诗和睡前/复盘记录
- 60 天晨读：短句、拼音和朗读勾选
- 45 天识字：每天 10 个字、拼音和例句
- 古诗词：正文、拼音、解释和手写区
- 经典短句：礼貌表达和轻量晨读加餐
- 每周复盘：回看熟悉的句子、汉字和想继续的内容

## 幼儿版映射

幼儿工作台没有直接复制成人打印页面，而是把内容拆成“看得懂、点得开、读一遍就有反馈”的 `暑假学习` 课程：

| 参考内容 | 当前入口 | 幼儿版呈现 |
| --- | --- | --- |
| 每日学习单 | 暑假学习 | 一张学习节奏卡，晨读、识字、古诗分开看 |
| 60 天晨读 | 暑假学习素材 | “你好，暑假”短句和 5 分钟提示 |
| 45 天识字 | 暑假学习素材 | 山、水、火、木、日、月、石、田、人、口 |
| 古诗词 | 暑假学习素材 | 《咏鹅》正文和朗读按钮 |
| 经典短句 | 暑假学习素材 | “父母呼，应勿缓。父母命，行勿懒。” |
| 数学练习 | 数学专区 / 暑假学习 | 沿用 10 以内加减和乘法分级路线 |
| 每周复盘 | 暑假学习素材 | 说出喜欢的句子、熟悉的字和下周想看的内容 |

## 当前实现

- 左侧“学习专区”折叠区新增“暑假学习”入口。
- 暑假学习页保留 6 张“今天精选”素材卡，每张都能使用 Web Speech API 朗读，适合幼儿马上开始。
- 精选卡下方已接入独立静态资料库：60 天晨读、45 天识字、60 首古诗、8 组经典短句和 8 周复盘，共 181 份资料。
- 资料库按“每日学习单 / 60 天晨读 / 45 天识字 / 古诗词 / 经典短句 / 每周复盘”分类切换，可选择具体天数或周次，也支持上一份、下一份和朗读。
- “每日学习单”会把当天晨读、识字、古诗、经典短句和对应周复盘组合在一起；第 46 至 60 天继续提供识字复习内容，避免暑假后半段断档。
- 素材下方仍保留 4 张小练习卡，完成后进入现有阳光和成长路线。
- 原始数据放在 `preschool-summer-learning-data.js`，不扩张 `config.js`，便于未来替换版本或继续增加学习包。
- 素材和练习仍使用当前工作台的本地状态、课程进度和奖励机制。
