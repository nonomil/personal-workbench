# 五科低密页面 + 暑假「今日任务」汇总页设计

- 日期：2026-08-15
- 状态：**已实施**（缓存戳 `20260815-poem-full-v1`；古诗后按用户反馈改为全文页）
- 页面范围：幼儿工作台 `#courses` 详情页剩余五科（古诗/数学/专注/运动/暑假）
- 前置设计：`docs/01-方案/2026-08-15-学习详情页翻页卡片设计.md`（认读四科翻卡）

## 1. 决策记录（头脑风暴结论）

| 学科 | 形态 | 说明 |
| --- | --- | --- |
| 古诗 | **今日一首全文页** | 诗题/作者 + 全文一次给出，下方附「讲解」（诗库新增 meaning 字段，34 首全覆盖）+「听整首」朗读；页尾问一次「会背了吗」→ 整诗落账（会背 ready / 还没会 practicing） |
| 数学 | **口算闪卡** | 左算式（或数数/比多少图示）、右答案；按钮为「再练练 / 答对了」，点了自动翻下一题；复用翻卡族落账（math 通道） |
| 专注 | **单任务启动页** | 三个小游戏按日期轮换，一张大卡 + 大按钮直接进现有练习弹窗；不翻卡 |
| 运动 | **动作卡浏览** | 左动作名、右时长+安全提示；翻页浏览不标记；翻完「完成打卡」把今日动作记入运动进度 |
| 暑假 | **今日任务汇总页** | 资料库五栏目（晨读/识字/古诗/经典/复盘）每日一份，点栏直达完整资料库对应条目 |

统一原则：孩子视野只留一个主体动作；统计/分级/说明全部在「经典详情页」（底部小字入口进入），经典页保留「回到今日学习页」返回按钮。

## 2. 数据流

- **古诗**：诗库按当前级别（`getCourseTrackProgress`）筛未 ready 的诗，按日期轮换选一首；全文一页展示（`renderPreschoolPoetryToday`），不再逐句翻卡。落账 key = poem.id，走通用学科通道（`markSubjectReady` / practicing 手写 entry）。
- **数学**：`buildQuiz(bank, {level, band: getMathPracticeBand(), size: 8, salt: today})` 按日出题；L1 数数 / L2 比大小 / L3+ 口算（口算级别尊重设置）。落账 key = round.id。
- **运动**：`getLevelBanks().motion` 按级别过滤出卡；「完成打卡」`markSubjectReady(motion, 今日动作 ids)`。
- **专注**：`course.lessons` 按日期轮换（dayIndex % 3）。
- **暑假**：复用 `getSummerLibraryEntries('daily')` 的每日合集（已聚合晨读+识字+古诗+经典+复盘），按日期轮换取一天；每行点击 = 置 `ui.summerLibraryCategory/Item` + 打开经典详情定位到该条目，**零新弹窗**。

UI 状态仍只有 `ui.courseCards`（卡包快照/翻页下标/标记）与 `ui.courseClassic`（经典页开关），切学科自动重置，均不落盘。

## 3. 明确不做（本期）

- 古诗讲解来自诗库 `meaning` 字段（`poem-bank.json` 逐首人工撰写，`parseBank` 透传），不现场编造
- 暑假各栏不做打勾（完成状态由对应练习自身记录，不新造存储）
- 专注/运动不改小游戏与练习弹窗内部
- 数学卡包不按掌握度过滤（口算题为生成池，标记录入统计即可）
