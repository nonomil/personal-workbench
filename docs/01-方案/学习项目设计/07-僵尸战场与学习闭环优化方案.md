# 07 · 僵尸战场与学习闭环优化方案

> 源头：2026-08-29 场景战场落地后的整体分析（三列战场/豌豆射击/+3 阳光已上线，
> 见 `docs/plans/T20260816-literacy-uplift/test-report.md` 第四~六轮）。
> 执行包：`docs/plans/T20260829-pvz-learning-loop/`

## 1. 问题：闭环存在但孩子看不见

经济链已通（会了卡 +3 → 首次 +10 → 任务 +15 → 游戏返阳光 → 兑真实奖励），
反向也通（play pass 靠学习获得，耗尽提示去翻卡）。但三个断点让"学习=打僵尸"
的心智没有成立：

1. **僵尸是装饰**：场景页三只僵尸与学习数据无关，"击退"只是特效。
2. **努力无方向**：首页没有"今日目标"进度，孩子不知道多翻一张卡意味着什么。
3. **错题无叙事**：错题 due 只在家长摘要里，`garden.invader` 入侵状态机在
   `preschool-garden.js` 里已有但从未与错题数据接通。

## 2. 方案（按学习动机影响排序）

### S1 僵尸 = 复习进度（核心）

- 场景页僵尸列数量 = 本场卡中「复习卡」（`item.review`，来自错题/到期队列）数量，上限 3。
- 每会了一张复习卡 → 按顺序击退一只（退场动画：后仰倒地淡出），纯渲染派生
  （会了数 = `session.marks` 里 review 项 known 数），无新状态。
- 全部击退 → toast「复习清空，僵尸退散！」+ 一次性 +5 阳光
  （`awardSunlight('scene-clear:课程:日期', 5)`，awardedIds 幂等）。

### S2 首页「今日阳光目标」横幅

- 首页 hero 下加一条进度横幅：`今日会了 N 张 · 阳光 +M / 目标 6 张`。
- N 由 `courseProgress.literacy.mastery` 里 `dates` 含今天的字数派生（无新存储）；
  目标 6 张 = 今日识字卡批量上限（8 卡墙的软目标）。
- 达标后文案切换为「今日目标完成 ✓ 去花园守一局」+ 直达战斗页按钮。

### S3 错题入侵事件（激活既有状态机）

- 错题 due ≥ 3 时置 `garden.invader.active = true`（hp=due，上限 9），
  每日一次 `mistake-invasion:日期` 幂等；首页 pixel map 已有入侵者渲染（血条+形态）。
- due 清零 → 入侵解除 + `mistake-clear:日期` +10 阳光 + toast。
- 首页 home-top 加一行入侵警示（僵尸小图 +「错题入侵：去改错本清 N 题」）。

### S4 战场音效（WebAudio 合成，零素材）

- 豌豆"biu"（方波短滑音）、僵尸受击闷哼（低频锯齿衰减）、阳光"叮"（正弦泛音）。
- 合成器挂在 `firePreschoolScenePea` 与击退链路；音量 ≤0.15；
  尊重 `preschool-no-motion` 与 `prefers-reduced-motion`（该人群默认静音）。
- 不加新设置项（红线：无新 storage key）；后续若要开关走设置页增量。

### S5 多主题敌人一致性（后置）

- voxel/platform 主题场景页无敌人列（`renderPreschoolSceneZombieRail` 仅 garden 主题）。
- 方案：voxel 用 blocklegend mobs、platform 用障碍物贴图复用同一 S1 机制。
- 后置原因：需为两个主题选型素材，先验证 garden 主题的 S1~S4 心智成立。

### S5 拼音四声条（2026-08-29 已落地）

- 声母/韵母/整体认读卡新增四声条：`pinyinToneForms` 按标准标调规则
  （a 优先 → o/e → iu/ui 标后 → i/u/v）派生 bā bá bǎ bà；
  例字从识字字库（1500 字带调拼音）自动索引（八/拔/把/爸）。
- 点击读音（例字 hanzi 音频，缺失回退音节 TTS）；当前声调高亮。
- 声母呼读/韵母呼读/跟我拼三段播报同轮落地（见 T20260829 包 test-report）。

### S6 知识花园并入主战斗（设计稿，不实施）

- garden-defense 波次间隙弹字卡，答对才可种植物；learning-defense 保持独立入口。
- 工程量大（跨游戏核心循环），待 S1~S4 验收后单独立项。

## 3. 红线（沿用工作台既定约束）

- 无新 storage key；无新货币；奖励只走 `awardSunlight`（awardedIds 幂等）。
- 幼儿无惩罚：不会/答错不扣阳光不掉进度；入侵可忽略（不阻断任何页面）。
- `preschool-no-motion` / `prefers-reduced-motion` 下全部动画音效静止。
- 每片：先红测试 → 实现 → 绿 → 缓存戳 → dist 重建 → 浏览器 800×360 sim-android 走查。

## 4. 验收口径

- S1：复习卡 2 张的场次，会 1 张退 1 只、全退触发 +5 与 toast；非复习场次僵尸列退化为
  3 只装饰（现有行为不变）。
- S2：今日 0 张/3 张/6 张+ 三种状态下横幅文案与进度条正确；数据来自 mastery 派生。
- S3：due=4 时首页出现入侵者与警示；清完 due 入侵解除 +10；due<3 不触发。
- S4：会了时三音效触发且 no-motion 下无声；无控制台报错。
