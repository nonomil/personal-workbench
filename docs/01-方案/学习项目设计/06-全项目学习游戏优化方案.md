# 全项目学习游戏优化方案

日期：2026-08-24  
状态：P0 已完成并通过 Web / Android APK 验收；P1 待实施

## 产品目标

把当前“课程入口 + 卡片 + 若干小游戏”升级成一个连贯的儿童学习循环：

> 先复习需要复习的内容，再学少量新内容，在游戏中真正使用，最后把证据写回成长档案。

第一原则是学习证据可信；第二原则是儿童能理解下一步；第三原则才是奖励和装饰。

## 学习性

### 统一掌握合同

拼音、古诗、数学、拼读统一保存：

- `attempts`：真实作答次数。
- `correct`：真实正确次数。
- `dates`：发生学习的不同日期。
- `activityTypes`：字卡自评、听音选择、拼读、计算、下一句等活动类型。
- `accuracy`：`correct / attempts`。
- `nextReview`：按 1/3/7/14 天安排。
- `state`：`introduced / practicing / ready / maintenance`。

进入 `ready` 必须同时满足：至少两次活动、至少两个不同日期、准确率不低于 80%，且证据来自至少两种活动。答错后进入或回到 `practicing`，今天优先重试；不能因为最后终于点对就把整节内容全部算会。

### 每日内容

每科默认 4–7 分钟：

1. 到期复习 1–2 个。
2. 新内容 2–4 个。
3. 主动检索 2–3 题。
4. 游戏迁移挑战 1 次。
5. 结算给出“会了什么、还要练什么”。

达到掌握门槛再解锁下一等级；时间可以变化，目标不降低。

## 游戏性

### 内循环

学习动作直接改变游戏状态：

- 拼音星路：选择正确声母/韵母就是选择安全路线。
- 识字泡泡：听音后碰到目标字；相似字是障碍，不是答题弹窗。
- 英语网球：词义、搭配、语境决定回球方向和力度。
- 数学阵列：选择正确阵列或拆分方式直接完成攻击/建造。

### 外循环

- 阳光和宠物成长奖励“持续练习与真实掌握”，不奖励乱点。
- 一天一个清晰主目标，完成学习后开放 1–2 次短游戏。
- 难度只读取 `ready/maintenance`，并允许儿童主动选择“练习/标准/轻松”。
- 提示后答对与独立答对分开记录，提示有温和代价但不惩罚儿童。

## 关卡节奏

| 阶段 | 时长 | 目标 | 反馈 |
| --- | ---: | --- | --- |
| 热身 | 30–60 秒 | 1–2 个到期复习 | 明确、低压力 |
| 新知 | 2–3 分钟 | 2–4 个新内容 | 可回放语音与示例 |
| 检索 | 1–2 分钟 | 不看答案主动作答 | 错误立即给动作提示 |
| 游戏 | 2–4 分钟 | 在玩法中迁移 | 学习动作即游戏动作 |
| 结算 | 20–30 秒 | 展示证据与下一次复习 | 不用夸张弹窗打断 |

同一机制连续不超过约 3 分钟；连续两次错误后自动降低干扰项或进入示范，不降低学习目标。

## 显示与声音

- 800×360 横屏保留 176–208px 导航，主要内容至少约 560px。
- APK 横屏使用左侧儿童导航和横向单页，普通 Web 不重复计算侧栏偏移。
- 主要按钮最小 44×44 CSS px，文字和图标共同表达，不只靠颜色。
- 反馈句式采用“结果 + 下一步”，例如“这是二声，再听一遍后选上扬的声调”。
- 汉字、拼音、拼读、古诗和英语优先播放离线预生成音频；运行时 TTS 仅作缺失回退。

## P0 落地结果（2026-08-24）

- 拼音、古诗、数学、自然拼读已按真实逐题行为写入 `attempts / correct / dates / activityTypes / accuracy / nextReview / state`。
- 完成课程只保留完课奖励，不再把整课内容直接提升为 `ready`。
- 掌握需同时满足两个学习日期、两种活动类型和不低于 80% 的准确率；答错回到 `practicing` 并当天优先复习。
- 游戏难度只读取 `ready / maintenance`，游玩记录与阳光奖励在同一状态写入中保存，重复结算不重复发奖。
- 普通 Web 的 800×360 横屏侧栏与主内容不再重叠；Android 横屏 rail 固定在视口左侧，页面和文档均无横向或纵向溢出。
- 首页、课程 Tab、L1–L5、朗读、会了/还不会等当前可见高频控件均达到至少 44×44 CSS px。
