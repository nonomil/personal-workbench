## 0. 一句话

把识字专区从「翻卡 + 找字」升级为小书虫式的四件套：**识字量测评、错字本强化、成长档案、柔光首页**，全部长在现有引擎和存储上，不做新 App、不引入小书虫商标或毛毛虫形象。

## 1. 参考 App 有什么值得抄

| 小书虫功能 | 核心价值 | 我们现状 | 差距 |
| --- | --- | --- | --- |
| 识字量测试（25 题、自适应、置信度） | 家长最想要的一个数：孩子认识多少字 | 只有课时练习，没有测评和估算 | **全缺，最高优先级** |
| 阶段划分（字芽初萌/绘本启蒙/自主阅读） | 把数字变成有意义的段位 | L1–L5 级别墙（内部概念，家长无感） | 缺家长向的阶段命名与映射 |
| 错字本（按错次排序、专项复习、可打印） | 复习只看最需要的 | 错题本已有（B2 回流 + 1/3/7 复习），但是纯文字列表 | 缺字卡形态、错次排序、打印 |
| 成长曲线 + 月度小结 + 证书 | 进步可视化，家长愿意每周测 | 家长学情摘要（B4 C3）只有当前快照 | 缺历史曲线与阶段参考线 |
| 柔光黏土风 UI（大卡、吉祥物、周打卡条） | 观感直接拉开档次 | 纸感柔光已铺（38-paper-glow），识字首页仍是课时列表 | 缺「三大卡 + KPI 行」首页 |
| 家长可控时长、无广告 | 儿童合规 | 本来就无广告、无内购 | 无需动作 |

### 新增（本方案范围）

1. **识字量测评**：`preschool-literacy.js` 新增 `buildAssessment` / `scoreAssessment` 纯函数；25 题四选一（字→选拼音读音，复用现有 `pinyin` 字段），阶梯自适应：L1 起步，连对升级、连错降级；结束输出「估算识字量 + 置信度 + 错字清单」。
2. **测评历史**：写入 `courseProgress.literacy.assessments`（数组，封顶 24 条，字段：date/estimate/confidence/level/wrongChars）。**同一 storage key 内扩字段，不开新 key**。
3. **阶段映射**：0–250 字芽初萌 / 250–500 绘本启蒙期 / 500–750 自主阅读期 / 750+ 阅读进阶期（对齐课标第一学段 1600 字口径，命名自拟，不抄小书虫文案）。
4. **错字本字卡化**：错题本内「识字」科目的条目以田字格字卡渲染（大字 + 拼音 + 组词 + 错次徽标），按错次倒序；「专项复习」入口只出错字题，连对 3 次自动 mastered（复用现有 `markMistakeReviewed` 的 mastered 通道）。
5. **可打印字卡**：A4 打印页（2×4 = 8 卡/页：大字田字格 + 拼音 + 组词 + 5 个练写格），纯 print CSS + `window.print()`，无新依赖；入口在错字本与家长侧。
6. **成长档案**：识字专区新「档案」视图 + 家长学情摘要加曲线：X 轴测评日期、Y 轴估算识字量、虚线阶段参考线（250/500/750）、本月新增、最近/最高识字量；SVG 手绘折线，不引入图表库。
7. **证书**：每次有效测评（置信度 ≥60%）生成一张打印友好的成就卡（日期 + 估算量 + 阶段），走同一个打印页路线，不做图片分享。
8. **识字首页改版**：识字专区今日页顶部改为「KPI 行（会了 N 字 / 本周 +M / 阶段徽章）+ 三大卡（开始测评 / 错字本 / 成长档案）+ 周连续条（复用现有 streak）」。

### 禁止（红线）

- 不出现「小书虫」名称、毛毛虫吉祥物、App Store 元素；吉祥物用现有星芒/向日葵体系。
- 不新建 localStorage key；不加 SM-2；不做新货币；测评不发额外阳光（只算一次学习事件）。
- 不上传数据、不加登录、不加分享 SDK；打印即导出。
- 参考图只作风格参照；正式 UI 图另开生图会话（管线 `.cursor/skills/game-asset-pipeline`），**占位不阻塞**代码。

## 3. 测评算法（关键设计）

- **题型**：显示单字，四个拼音选项（1 正确 + 3 干扰）；干扰项优先取同声母/同韵母近音字的拼音（字库内检索），不足时取同级随机。语音朗读按钮读例词不读目标字（防白给）。
- **阶梯**：25 题分 5 段每段 5 题。起步 L1；段内答对 ≥4 → 下一段升一级（最高 L5），≤2 → 降一级（最低 L1）。已 ready/maintenance 的字不重复出（测「边界」，不测已知）。
- **估算**：每级取样命中率 × 该级字库容量，逐级累加：`estimate = Σ level_hit_rate(Li) × bankSize(Li)`；未触达级别按 0 计。四舍五入到 10。
- **置信度**：`confidence = 0.6×答题一致性 + 0.4×覆盖度`。一致性 = 1 − 段内波动（同段答对数方差归一）；覆盖度 = 触达级数/5。<60% 标记「参考值」，不进最高纪录。
- **防乱点**：单题作答 <1.5s 连续 5 次 → 本次测评标低置信；不惩罚、不打断。
