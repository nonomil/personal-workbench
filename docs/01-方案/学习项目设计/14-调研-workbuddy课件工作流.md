第 1 步：把你娃的课本 PDF 拖进 WorkBuddy 对话框（教材、练习册都行）。

第 2 步：把下面这段提示词整个复制进去。一个字都不用改——它自己会读你刚传的 PDF，提取知识点来出题。

第 3 步：回车发送。WorkBuddy 会生成一个 HTML 文件，下载保存到桌面。

第 4 步：双击这个文件，浏览器打开——娃就能玩了。学知识点、闯关攒星星、打 BOSS、翻错题本，预习变成了打游戏。

这段看着吓人，你完全不用懂——全选复制、粘贴、回车，AI 看得懂就行。

你是一位游戏化教育设计师。请根据我上传的课本 PDF 内容，生成一个超级玛丽风格的 HTML 互动学习闯关游戏。纯单文件，无需任何外部依赖。

【核心原则：一切从 PDF 出发】

✓
仔细阅读 PDF，提取所有知识点，按逻辑顺序分组

✓
每个知识组 = 1 个游戏关卡（World），总共 3 到 8 关，视内容量而定

✓
PDF 共有多少个自然知识模块，就设多少关；不要硬凑 6 关

✓
最后一关结束后，追加 1 个 BOSS 关作为综合挑战

【游戏结构】

✓
每关 = 教学阶段 + 答题阶段 教学阶段：2 到 4 个教学页，用游戏 NPC 对话的语言讲解知识点，配合 SVG 示意图、可交互计数器、对比表格、时间线等 答题阶段：3 到 6 道互动题（根据该关知识点数量决定），4 选项，选项随机打乱，错误选项基于常见错误设计有干扰性

✓
BOSS 关：3 道综合题，玩家 3 条命（♥），答错扣命，0 命需重打

✓
每道题第一次答对 = 1 颗星

✓
通关条件：该关全部答对（星星数 = 题目总数）

✓
若未全部答对：显示「闯关失败」，不给金币、不解锁下一关，需重新挑战

✓
全部常规关卡满星通关后，解锁 BOSS 关

【游戏剧情】

✓
根据 PDF 的学科/年级自动创造适配的世界观： 语文 → 汉字王国、成语秘境、诗词仙境 数学 → 数字王国、几何大陆、逻辑迷宫 英语 → 字母城堡、词汇森林、语法海洋 科学 → 实验基地、自然星球、元素实验室 历史 → 时光隧道、朝代城邦、文明遗迹 地理 → 地球探索局、山川大陆 其他学科同理类推，核心是「反派魔王破坏了该学科对应的世界，玩家通过答题来修复」

✓
剧情贯穿：开场引入 → 每关有 NPC 对话 → BOSS 有台词 → 胜利有结局

【BOSS 胜利动画】（五段式，必须全部实现） ① BOSS 爆炸 + 屏幕震动（0s，body 加 CSS screen-shake class） ② 「BOSS DEFEATED!」闪烁标题 ③ 公主/主角救出（1.5s 后，CSS 飘浮动画） ④ 放大旋转奖杯（2s 后，scale 0.05→1.35→1.15，金色 drop-shadow 光晕） ⑤ 烟花 + 彩色纸屑（三波：2s/2.5s/4s，固定定位粒子 + 星星爆发） ⑥ 统计面板（4s 后，显示总星数/金币/已掌握知识点列表）

【独立错题本】

✓
地图页顶部设「📝 错题本」按钮

✓
按关卡分组展示所有历史错题：题目、算式/原文、正确答案、解析

✓
空态显示鼓励文本

【技术要求】

✓
纯 HTML 单文件，CSS/JS 全内联

✓
Google Fonts：Press Start 2P（像素字体）+ Noto Sans SC（中文正文）

✓
8-bit 像素风格 UI：像素字体、马里奥配色体系（红/绿/金/蓝/棕）

✓
CSS 动画：角色跳跃(bounce)、云朵飘动(float)、页面淡入(fadeIn)、奖杯缩放旋转、震屏(shake)

✓
Web Audio API 生成 8-bit 音效：跳跃、吃金币、答对(success jingle)、答错(buzzer)、通关(fanfare)、BOSS 战

✓
localStorage 持久化：金币、星星、已解锁关卡(Array)、已通关关卡(Array)、错题记录(Object)、BOSS 击败状态

✓
移动端适配（max-width:680px 居中，-webkit-tap-highlight-color:transparent）

✓
页面固定 CSS 云朵背景装饰

【强制约束】

✓
❌ 绝对不允许「跳过此题」按钮

✓
❌ 重新开始必须用自定义确认弹窗（半透明遮罩 + 居中卡片），绝不使用 window.confirm()

✓
❌ 教学页翻页必须正确，不能死循环、不能跳回第一页

✓
✅ 所有随机选项在每次进入关卡时重新打乱

✓
✅ 状态变量需在 resetGame() 中完全重置

✓
✅ localStorage 读写需 try-catch 包裹

✓
✅ HUD 栏实时显示：金币数🪙、当前星数⭐/总星数、当前关卡

【输出要求】 生成完整的、可直接保存为 .html 文件打开的代码。不要分段、不要省略任何部分。代码中的教学内容必须根据 PDF 原文精准出题，不能杜撰知识点。
