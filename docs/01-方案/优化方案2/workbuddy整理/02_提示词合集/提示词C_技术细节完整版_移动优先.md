# 提示词 C：技术细节完整版（移动优先 + PWA，配小红书发布）

> 定位：用户明确要求"技术细节可以保留吧，反正就是复制粘贴，只要WorkBuddy能看懂，越详细越好，不容易出错"后产出的版本。相比B版，重点强化了移动端底部Tab导航、PWA配置、Web Speech API发音实现细节，是配合小红书发布的推荐版本（可再叠加"提示词D：生图能力补充"）。

```markdown
你是一位顶级全栈架构师兼儿童产品交互专家。请生成一个单页HTML应用，项目名"智慧花园工作台"，移动端优先适配，支持PWA添加到手机桌面。

## 一、技术约束（必须严格遵守）
- 纯前端，单HTML文件，所有CSS和JS内联
- 数据存储：localStorage（所有数据持久化）
- 语音：Web Speech API（window.speechSynthesis），不依赖任何第三方服务
- 兼容：Chrome / Edge / Safari 主流浏览器
- 适配：移动端优先（375px基准），同时适配PC

## 二、全局布局
- 移动端：底部5个主要Tab导航（首页/学习/练习/商城/我的），高度64px
- PC端：左侧导航栏，宽度220px，显示全部11个模块图标
- 主内容区：flex:1，内边距16px，背景毛玻璃效果
- 顶部状态栏：高度52px，显示当前时间、今日阳光余额、连续打卡天数

## 三、核心游戏引擎（植物大战僵尸机制）

### 3.1 阳光经济系统
- 完成任务获得阳光（5-20不等）
- 种植植物消耗20阳光，升级消耗30阳光
- 铲除植物返还50%（向下取整）
- localStorage键名：'sunBalance'

### 3.2 花园棋盘（首页核心）
- 4行×8列网格，每个格子80×80px（移动端60×60px）
- 点击空位种植（消耗阳光），点击已有植物升级
- 僵尸逻辑：昨日有未完成任务则今日右侧生成僵尸，每2秒左移一格
- 僵尸抵达第1列触发警告（红色闪烁+震动）

### 3.3 任务系统
- 每日从自定义任务中随机抽取5个
- 全部完成触发向日葵庆祝动画（全屏金色粒子）
- 日历自动打卡（绿点标记）

## 四、11个功能模块（每个模块必须独立可交互）

### 模块1：日历打卡
- 月历网格视图，每个格子显示日期
- 状态：打卡成功✅ / 漏卡❌ / 未到⭕
- 顶部统计：本月出勤率 = 已打卡天数 / 本月总天数 × 100%

### 模块2：花园基地
- 渲染4×8棋盘，展示已种植植物和僵尸
- 阳光面板（顶部显示余额）
- 僵尸入侵倒计时（若存在僵尸）
- 3个功能按钮：【收阳光】【快速种植】【护盾】

### 模块3：识字专区
- 内置300个常用汉字（按主题分类：自然🌿/动物🐼/身体🧍/数字🔢/颜色🎨）
- 每日分配：随机抽取10个新字 + 复习昨日错字
- 点击文字：Web Speech API发音（中文）
- 长按文字（>500ms）：弹出气泡显示3个词组

### 模块4：拼音专区
- 23个声母 + 24个韵母 + 16个整体认读音节
- 卡片网格，点击卡片发音
- 每个拼音配一句顺口溜（内置映射表）

### 模块5：古诗专区
- 内置20首经典古诗（含白话译文）
- 卡片翻页浏览，点击【朗读】整首发音
- 右上角【学会标记】点亮小红花

### 模块6：数学专区
- 10以内加减法（可扩展）
- 水果计数辅助（显示对应数量水果Emoji）
- 自定义数字键盘（0-9+退格+确认）
- 连续答对10题记录"闯关天数"

### 模块7：专注力训练
- 三种题型：找不同（左右图找茬）/ 迷宫（Canvas绘制）/ 数独（4×4初级）
- 切换题型按钮

### 模块8：每日英语
- 内置100个常用小学英语单词
- 每日推送5词（2新词+3复习）
- 点击单词发音（英文，Web Speech API）

### 模块9：每日运动
- 5项居家运动（开合跳/深蹲/原地跑/高抬腿/平板支撑）
- 每项15秒倒计时进度条
- 完成勾选获得5阳光

### 模块10：错题本
- 自动记录数学专区答错的题目
- 列表展示错题 + 正确答案
- 点击【复习重做】重新答题

### 模块11：奖励商城
- 植物商店：用阳光购买植物（向日葵/豌豆射手/坚果墙）
- 自定义奖励：家长入口（左上角齿轮长按3秒，密码8888）
- 增删奖励项（名称+阳光价格+Emoji图标）
- 兑换时播放"星星收集"特效

## 五、预设数据（开箱即用）
- 3个每日任务示例："背古诗《静夜思》" / "学5个新汉字" / "做10道数学题"
- 20个汉字示例（含拼音和分类）
- 5首古诗示例（含译文）
- 10道数学题示例

## 六、交互反馈
- 所有按钮有点击波纹效果（ripple）
- 完成任务飘字动画（"+10 ☀️"）
- 僵尸来袭：屏幕红色闪烁 + 震动API（navigator.vibrate）
- 卡片hover上浮2px（移动端点击态放大）

## 七、PWA配置（添加到手机桌面）
- 在<head>中添加：<meta name="apple-mobile-web-app-capable" content="yes">
- <meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
- <link rel="apple-touch-icon" href="data:image/svg+xml,...（生成一个绿色植物图标SVG）">

## 八、语音实现细节
- 使用 window.speechSynthesis.speak()
- 中文语音：优先选择 'zh-CN' 或 'zh' 语言代码
- 英文语音：优先选择 'en-US' 语言代码
- 降级方案：若语音不可用，显示"🔊 点击发音"按钮但不报错

现在请生成完整的HTML代码，确保所有功能闭环，可直接在浏览器中运行。
```
