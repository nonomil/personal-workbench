# 提示词 D1：视觉素材生成补充（无外部依赖 · 纯前端本地绘图版）

> 背景：用户发现提示词C里缺少"角色配图、奖励星星等配图"的具体要求。此为第一版补充——完全不依赖外部生图接口，全部用 Canvas/SVG/CSS 本地生成，保证"开箱即用"稳定性。
>
> 使用方式：插入到提示词C的"六、交互反馈"之前，作为新的一节。

```markdown
## 九、视觉素材生成要求（无外部依赖，纯前端实现）

### 9.1 角色配图（植物 + 僵尸 + 向导精灵）
所有角色不允许使用外部图片链接，必须由代码本地生成：

**植物角色（至少3种）：**
- 🌱 豌豆射手：使用 Canvas 或 SVG 绘制，绿色圆茎 + 深绿色圆头 + 白色圆眼 + 绿色管状嘴巴（可旋转）
- 🌻 向日葵：黄色圆形花瓣（8瓣，CSS transform旋转）+ 棕色花盘 + 微笑表情（用纯CSS或Canvas绘制）
- 🧱 坚果墙：棕色矩形 + 深色纹理线 + 坚定的表情（方块眼+平嘴）
- 所有植物需有"空闲摇摆动画"（CSS animation: 左右旋转2度，周期2秒）

**僵尸角色（至少2种）：**
- 🧟 普通僵尸：Canvas绘制，灰绿色身体 + 破烂西装 + 红色领带 + 呆滞表情
- 🧟‍♂️ 路障僵尸：普通僵尸基础上 + 头顶橙色三角锥路障（CSS绘制）
- 僵尸需有"行走动画"（身体上下浮动 + 手臂前后摆动）

**向导精灵（首页左上角辅助角色）：**
- 🦉 卡通猫头鹰：Canvas绘制，棕色圆身体 + 白色腹部 + 大眼睛（可眨眼）+ 小尖嘴
- 随阳光增多而左右扭动（rotation: -5deg ~ 5deg），身体从60px逐渐长大至80px

**技术要求**：所有角色绘制代码必须写在HTML中，优先使用Canvas 2D API，次选CSS + Div + SVG。

### 9.2 奖励特效（全屏动画）

**场景一：获得阳光飘字**
- 文字 "+10 ☀️" 从屏幕中央向上飘移，同时放大并渐隐
- 颜色：金色 (#FFD700) → 淡金色 (#FFF8DC)
- 持续时间：1.2秒，缓动函数 ease-out

**场景二：向日葵庆祝（全部任务完成）**
- 全屏金色粒子爆炸（Canvas实现，300-500颗粒子）
- 粒子形状：圆形 + 四角星形混合
- 背景短暂闪光（白色闪烁，opacity 0.3，持续0.5秒）
- 向日葵角色自动旋转360度并放大1.5倍

**场景三：星星收集（兑换奖励）**
- 5颗金色星星从屏幕四周飞向中央汇合
- 汇合后爆炸成彩色小星星（红/蓝/绿/粉/紫）
- 同时播放"叮叮叮"音效模拟（Web Audio API生成）

**场景四：僵尸来袭警告**
- 屏幕红色边框闪烁（border: 4px solid red，透明度0→0.8→0，周期0.5秒）
- 屏幕底部出现红色警示文字 "⚠️ 僵尸来袭！"
- 文字抖动动画（CSS transform: translateX(-5px) 和 translateX(5px) 交替）
- 手机震动（navigator.vibrate([100, 50, 100])）

### 9.3 古诗配图（降级方案）

由于外部生图API可能不稳定，采用**二级降级策略**：

**一级（优先）**：若 WorkBuddy 或混元3提供生图能力，调用生成古风插画：
- 接口假设：/api/generate-image
- 请求体：{"prompt": "古风山水画，水墨风格，意境宁静，描绘: {古诗标题或关键词}"}
- 超时时间：3秒

**二级（降级）**：若一级失败或不可用，自动切换为 SVG 简笔水墨画：
- 每个古诗配一幅纯 SVG 绘制的简笔风景画
- 元素包括：远山（波浪曲线）、近水（蓝色半透明弧线）、柳树（绿色垂直线条）、小船（三角形+矩形）
- 风格要求：极简、淡雅、留白充足
- 示例代码结构：内联在HTML中，每个古诗对应一个 `<svg id="poem-img-{id}">`

### 9.4 奖励商城图标

所有奖励和植物图标，使用 **Emoji + CSS 美化** 组合，不依赖外部图片：
- 例如：🏆 奖杯 → 加金色渐变背景 + 阴影
- 🎁 礼物盒 → 加红色丝带装饰（CSS伪类实现）
- 每个图标外层包裹一个圆形容器（48px），带毛玻璃背景

### 9.5 成长徽章（阶段性奖励）

累计获得阳光达到以下数值时，弹出徽章动画：

| 阳光值 | 徽章名称 | 徽章样式 |
|:---:|:---|:---|
| 100 | 🥉 青铜园丁 | 铜色圆形徽章，带🌱小苗图案 |
| 300 | 🥈 白银园丁 | 银色圆形徽章，带🌿绿叶图案 |
| 500 | 🥇 黄金园丁 | 金色圆形徽章，带🌻向日葵图案 |
| 1000 | 💎 钻石园丁 | 钻石蓝色圆形徽章，带👑皇冠图案 |

徽章用 Canvas 绘制 + CSS 3D旋转动画（弹出时从背面翻转至正面）。

### 9.6 技术实现约束
- **所有视觉元素不得引用外部图片、字体、CDN资源**
- 图标优先使用 Unicode Emoji
- 复杂图形使用 Canvas 2D 绘制
- 动画使用 CSS @keyframes + JavaScript requestAnimationFrame 混合实现
- Canvas 绘制代码需封装为独立函数，便于复用和调试
- 所有动画帧率控制在 60fps，移动端须流畅运行
```

## 实操建议
1. **先发"本地绘图版"，再迭代"AI生图版"**：本地版用 Canvas/SVG 绘图，保证所有用户打开即能看到完整画面，不受API影响；后续若WorkBuddy/混元3开放生图接口，再在代码里加 `if` 判断，有接口就调用，没有就用本地图。
2. **小红书文案可做对比**：贴"纯前端绘制角色" vs "AI生成精致角色"两张图，引发评论区讨论"你更喜欢哪种风格"，增加互动。
