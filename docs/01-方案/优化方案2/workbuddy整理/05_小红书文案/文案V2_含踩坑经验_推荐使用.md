⚠️ 你可能遇到的坑及解决办法：

❌ 坑1：生成的网页在浏览器里打不开？
✅ 解决：检查是否完整复制了提示词（包括所有标点和换行），WorkBuddy 对格式敏感。

❌ 坑2：添加到桌面后打开是空白？
✅ 解决：先用 Edge 浏览器打开一次，确认内容加载完整，再点"添加到主屏幕"。PWA 缓存需要首次加载完成。

❌ 坑3：文字点击没声音？
✅ 解决：先检查手机媒体音量是否开启。如果用的是 Edge，按一下音量键调大；如果用 Chrome，确认网页的"媒体自动播放"权限是开启的。

❌ 坑4：网址长按复制总选不全？
✅ 解决：不要长按网址本身！在地址栏 双击 选中全部，再点复制。或者在生成页面直接点"分享"→复制链接。

❌ 坑5：添加到主屏幕后，图标是浏览器的默认图标？
✅ 解决：这是正常的，不影响使用。如果想换图标，需要在代码里配 manifest.json，新手可以忽略。

- 微信（扫码登录用）
- Edge 浏览器（发音效果最好，后面会说原因）

✅ 安装到桌面（1分钟）：
1. 点"预览"打开网页
2. 长按网址 → 复制链接
3. 打开 Edge 浏览器 → 粘贴打开
4. 点底部菜单 → "添加到主屏幕"

✅ 发音支持说明（重点！）：
🔊 我用的方案是 Web Speech API（浏览器自带的语音合成），不是第三方服务。
- Edge 浏览器：语音引擎最成熟，中英文发音都自然，推荐！
- Chrome / Safari：也支持发音，但部分音色可能略有差异
- ⚠️ 不需要联网也能发音（离线语音包已内置）
- ⚠️ 如果没声音：检查手机侧边静音键 + 媒体音量是否打开

✅ 数据存储说明：
所有数据存 LocalStorage，就是存你自己手机里。
- 关掉网页再开 → 记录还在
- 清除浏览器缓存 → 数据会丢失（⚠️注意不要点"清除网站数据"）
- 换手机 → 数据不互通（适合个人专属）

✅ 能用到什么时候？
