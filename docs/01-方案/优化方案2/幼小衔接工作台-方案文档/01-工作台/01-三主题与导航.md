# 三主题与导航

## 主题表

| theme | 名称 | 主色 | 伙伴意象 | 主游戏 |
|:---|:---|:---|:---|:---|
| `garden-defense` | 花园工作台 | 绿 `#2d8748` | 向日葵 / 光之小兽 | 花园保卫战 |
| `voxel-adventure` | 方块工作台 | 蓝 `#3d9ee0` | 方块伙伴 | 挖矿 / 建造 / 背包 |
| `platform-quest` | 马里奥工作台 | 红 `#c23b32` | 奇诺比奥感 | 横版闯关 |

## 切换规则

- 右上角可切换：花园 / 方块 / 马里奥
- **选定后用该主题加载**，不要先渲染另一主题再切（避免叠层、错色）
- 任务与阳光等**共用同一份数据**

## 花园主题专项

- 侧边栏与整页 UI 用绿色系，避免和方块蓝/紫杂糅
- 趣味短局里 Canvas 保卫可合入「花园保卫战」
- 花园主题下**不必**展示马里奥闯关、像素建造入口
- 点击「开始守护花园」→ 右侧游戏全屏，左侧栏隐藏
- 僵尸节奏要慢、数量克制；可用花园背景图

## 方块主题专项（参考「12 岁小孩哥」视频与文档）

侧栏模块概念：

- 学习 / 生活 / 家务 → 赚经验
- **世界** — WASD 移动、跳跃、挖矿、打怪、血量提示
- **小卖部** — 原料与合成工具（镐、斧、剑等）
- **背包** — 格子存放物品
- **家长锁** — 锁定后孩子改不了关键配置

地面不要大片悬空；地表约 5 行即可，更深挖进入专门矿洞地图。  
工具、盔甲、收集物可逐步加；与学习完成发材料/阳光联动。

## 马里奥主题专项

- 横版过关，参考 `nonomil/mario-minecraft-game` 思路重做轻量版
- 主角图：透明底、单人、够大；跳跃时镜头不要乱抖上下
- 道具、灌木、地面等 tiles 用统一像素/清洁风格
- 与打卡/数学进度可弱联动（解锁关卡或体力）

## CSS 变量

各主题覆盖：`--seed-border`、`--canvas-border`、`--canvas-bg`、按钮与侧栏渐变等，避免只改 logo 色。
