# 素材工厂与语音

## 总策略

把 Grok / TTS 当 **内容工厂（预生成）**，不要当运行时依赖：

| 能力 | 用法 |
|:---|:---|
| Imagine 图 | 配图、场景、UI 插画 → 入库 |
| Imagine 视频 | 可选古诗/识字短片 → 预生成文件 |
| TTS | 字/词/句 mp3 批量 → `assets/audio` |
| Voice Agent | **独立**口语陪练，不焊进单页工作台 |
| Build | 用来写工作台本身，不是工作台内嵌功能 |

## 发音交互

- **统一**：点小乐或点主卡发音，而不是每个选项外再挂一排喇叭导致混乱
- 预录优先；失败再 Web Speech

## 音效事件

| 事件 | 感觉 |
|:---|:---|
| 点按 | 短促木琴感 |
| 答对 | 上升音调 |
| 答错 | 柔和提示 |
| 任务完成 | 短庆祝 |
| 升级/徽章 | 稍长庆祝 |

可用 Web Audio 合成，减少大文件。

## 生图纪律

- 默认 **透明背景**，禁止橘红/品红工作室底带进切图
- 角色一致性：同一小乐/主角用 edit 链，不每次重抽脸
- 生成后检查：半截人、双人、脏边

## 小乐

- 名称：小乐同学  
- 形象：儿童向，黄帽衫、星发卡、青短裤  
- 学习关吉祥物 + 发音入口
