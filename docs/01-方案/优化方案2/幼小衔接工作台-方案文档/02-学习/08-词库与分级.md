# 词库与分级

## 原则

**库要厚，每日要薄。**  
练习必须读库，禁止长期用演示手写题冒充内容。

## 汉字

- 目标承载：1000～1500
- 来源思路：通用规范汉字一级表 + 小学常用向筛选 + 主题分类
- 分级：按 L1～L5 或 rank 切片，设置切换

## 英语

- 目标：约 500
- Dolch + 儿童常用 + 课标核心合并去重
- 带 phrase / sentence

## 拼音 / 拼读

- 拼音：按 kind 字段分级
- 拼读：按 stageId；可与 Open Source Phonics 课程序列概念对齐

## 分级表示例（资料规划）

| 级别 | 汉字体感 | 英语体感 | 拼读体感 |
|:---|:---|:---|:---|
| L1 | 最常用生活字 | 具体名词为主 | CVC |
| L2 | 扩展常用 | 主题扩展 | short vowels |
| L3 | 再扩 | 再扩 | digraphs |
| L4 | 再扩 | 再扩 | blends |
| L5 | 综合复习 | 综合 | 综合 |

**界面不出现「一年级上」等年级标签。**
