# 认练测闭环

## 对标

参考「汉字乐园」路径：**主题感 → 闯关感 → 认 / 练 / 测**，  
用工作台轻量实现，不搬其后端、账号、SM-2 全家桶。

## 三步定义

| 步 | 孩子做什么 | 时长感 |
|:---|:---|:---|
| **认** | 大卡展示字/词/拼音，自动或点按发音，约 2 秒可进 | 15 秒内 |
| **练** | 对对碰（字配图 / 字配拼音 / 词配图） | 15～30 秒 |
| **测** | 听音点选（2～4 选） | 15 秒内 |

错了：温和提示，不扣分羞辱。  
对了：星星 + 短音效 + 自动下一问。

## 四科映射

| 世界 | 认 | 练 | 测 |
|:---|:---|:---|:---|
| 森林寻字 | 汉字大卡 + 图 | 字↔图对对碰 | 听音点字 |
| 单词岛 | 英文大卡 + 图 | 词图对对碰 | 听音点词 |
| 拼音坡 | 大拼音 | 字↔拼音 | 听音点拼音 |
| 拼读谷 | 大词 | 选词/配图 | 听音 |

## UI

- 顶条：`认` `练` `测`（当前高亮，已过变完成色）
- 世界小标题：如「森林寻字」
- 背景可按科换浅色渐变（绿/橙/蓝/紫）
- 吉祥物小乐固定角，点按读当前内容
