# 学习模块总览

## 八个模块

| 模块 | 世界名（示意） | 主玩法 | 资料目标 |
|:---|:---|:---|:---|
| 识字 | 森林寻字 | 认→练→测 | 字库约 1000～1500 |
| 拼音 | 拼音坡 | 闪卡 + 配对 + 听选 | 声母/韵母/整体认读分级 |
| 数学 | — | 排队 + 口算四选一 | 百内加减；乘法按积扩阶 |
| 英语单词 | 单词岛 | 闪卡 + 对对碰 + 听选 | 约 500 词 + 短语/短句 |
| 自然拼读 | 拼读谷 | 闪卡 + 听选 | stage 对齐可解码词 |
| 古诗 | — | 点句朗读 + 简单题 | 30～50 首可扩展 |
| 专注 | — | 舒尔特 / 4×4 数独 / 记颜色等 | 体验型，非词库量 |
| 运动 | — | 倒计时真做 + 完成 | 约 10 项居家动作 |

## 统一体验

- 全屏关，少列表长文
- 小乐同学可点发音（统一交互，不每个字旁堆按钮）
- 认 / 练 / 测 步条（识字、单词、拼音、拼读）
- 设置中切换难度级别，**不挂年级标签**
