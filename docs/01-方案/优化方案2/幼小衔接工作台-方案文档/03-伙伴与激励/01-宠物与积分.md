# 宠物与积分

## 理念（pet-bank）

> 把完成目标包装成积分增长，把坚持习惯包装成宠物养成。

积分更像「存款增长」的正反馈；饲料兑换可扣余额，但**累计获得**可统计展示。

## 轻量模型（抽取后）

```text
stage: 0蛋 → 1幼崽 → 2成长 → 3进化
exp / maxExp
hunger 0～100（时间衰减，如每小时 -2）
name / type（可按主题映射外观）
lastUpdate
```

可选维度（可只上饱食）：心情、亲密。  
**不做**死亡永久惩罚、班级排行、教师后台。

## 交互

| 操作 | 效果 |
|:---|:---|
| 点击 | 撒娇/短动画 |
| 喂食 | 饱食 +，消耗饲料 |
| 任务完成 | exp+；全天完成可额外 + |
| 升级 | 短庆祝 + 形象阶段变化 |

饥饿提示：饱食过低显示「好饿…」类文案（温和）。

## 饲料来源

学习完成 → 阳光/积分 → 兑换饲料（汇率简单，如固定比）。

## 小乐同学

- 学习伙伴形象：约 6 岁、黄帽衫、青短裤、发上小黄星（对话中定稿方向）
- 职责：学习关吉祥物、点按发音、鼓励语
- 与养成宠物可并存：小乐偏「讲解伴读」，蛋/兽偏「养成」
