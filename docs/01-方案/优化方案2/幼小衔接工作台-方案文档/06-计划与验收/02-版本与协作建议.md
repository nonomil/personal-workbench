# 版本与协作建议

## Git

建议正式工程：

- `main` 稳定可演示  
- 功能分支短生命周期  
- `CHANGELOG.md` 记用户可见变化  
- 版本号：如 `0.x` 玩法期，`1.0` 日闭环稳定  

## 文档与代码

- 方案在 `docs/方案/`（本包即该思路的导出）  
- 代码变更同步改「落地对照」  
- 大功能先改方案再写代码（用户曾要求）  

## 推送 GitHub

- 使用本地或 CI 登录，**不要把 PAT 发到聊天**  
- 若构建发布：保证 `npm run build` / typecheck 通过  
- 静态学前页可 GitHub Pages；注意资源路径  

## 本包说明

本 zip **仅文档**。  
完整源码需：旧沙箱仍在时打包，或按文档重实现，或从你已 push 的私有仓库拉取。
