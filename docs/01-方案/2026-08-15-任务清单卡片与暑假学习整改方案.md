# 任务清单卡片补全 + 暑假学习定位整改方案

- 日期：2026-08-15
- 状态：切片 A 已按选项 A 执行；并补了绘本/动画/熏听时长打卡（2026-08-15）
- 背景：首页已改版为「今天的任务」简卡 + 勾选，任务清单页（#plans）负责创建/编辑/删除。用户反馈：任务清单的卡片不合理不完整；暑假学习定位仍然奇怪。

## 一、审查结论

### 1. 任务清单页（#plans）当前问题

现状：`renderPreschoolPlanRows(items, { editable: true })` 直接复用了首页的 lane 卡片（`prj/app.js` 约 1151 行起），只是在卡片底部追加了编辑/删除两个小按钮。问题：

1. **职责矛盾**：页面文案写着「勾选完成请回首页」，但卡片主体仍是 `data-action="toggle-plan"` 的大按钮，点标题就会勾选/取消勾选——和文案自相矛盾。
2. **信息不完整**：管理页看不到任务的分类（识字/古诗/数学…）、预计时长、是否带练习，只有标题和「必做/选做」。要编辑一个任务前无法判断它是什么。
3. **形态不匹配**：lane 卡是为首页三列小方卡设计的（竖排、图案大、文字少），放到管理页里显得空、按钮挤在底部，观感"残缺"。
4. **重复元素**：管理页里还渲染「去练习」按钮，和首页功能重复。

### 2. 暑假学习当前问题

「暑假学习」实际是资料/素材库（视频、打印包等），但入口和内部文案叫「暑假 · 今日任务」，与首页「今天的任务」语义撞车——孩子分不清哪个是真正要做（可点亮、加阳光）的任务。方向未定，见第三节选项，等用户拍板后再排期。

## 二、切片 A：任务清单卡片改为完整管理行（可直接执行）

### 2.1 `prj/app.js` — 改 `renderPreschoolPlanRows(items, options)`

把 editable 分支拆出来单独渲染管理行；非 editable 分支（首页 `renderPreschoolHomeBattlefield` 与植物大战页共用）保持 lane 卡片不变，但删掉其中 `${editable ? …}` 的管理块（editable 已走新分支，不会再进来）。

editable 分支渲染结构：

```javascript
if (editable) {
    return `<div class="preschool-plan-list preschool-plan-lanes">${items.map(function (item) {
        const done = Boolean(item.done);
        const practice = item.practiceLessonId ? getPreschoolPlanPractice(item) : null;
        const minutes = getPreschoolPlanMinutes(item);
        const meta = [item.category || '学习', minutes ? `${minutes} 分钟` : '', item.required === true ? '必做' : '选做', practice ? '带练习' : ''].filter(Boolean).join(' · ');
        return `<article class="preschool-plan-row ${done ? 'is-done' : ''}">
            <span class="preschool-plan-row-art">${preschoolAsset(pixelQuestAsset(item), item.category || '学习')}</span>
            <div class="preschool-plan-row-copy"><strong>${escapeHtml(item.title)}</strong><small>${escapeHtml(meta)}</small></div>
            <span class="preschool-plan-row-status ${done ? 'is-done' : ''}">${done ? `${icon('check')} 已点亮` : '还没点亮'}</span>
            <div class="preschool-plan-manage" aria-label="调整任务"><button class="row-action" type="button" data-action="edit-plan" data-id="${escapeHtml(item.id)}" data-date="${escapeHtml(item.date)}" aria-label="编辑${escapeHtml(item.title)}" title="编辑任务">${icon('edit-3')}<span>编辑</span></button><button class="row-action danger" type="button" data-action="delete-plan" data-id="${escapeHtml(item.id)}" data-date="${escapeHtml(item.date)}" aria-label="删除${escapeHtml(item.title)}" title="删除任务">${icon('trash-2')}<span>删除</span></button></div>
        </article>`;
    }).join('')}</div>`;
}
```

要点：

- 状态列是**纯展示**的胶囊（已点亮 / 还没点亮），不可点击——勾选只在首页做，与页面文案一致。
- 图标用 `pixelQuestAsset(item)`（按分类给 task-book-icon / task-sun-icon 等），比轮换植物图更有信息量。
- 管理页不渲染「去练习」按钮。
- 依赖的 `getPreschoolPlanMinutes`、`getPreschoolPlanPractice`、`pixelQuestAsset` 都已存在于 app.js。
