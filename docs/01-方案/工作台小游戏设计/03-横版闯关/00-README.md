## 现状事实（2026-08-15）

- **玩法**：跑跳吃金币冲旗，10 关（`data/levels.js`），单关 1–2 分钟；有检查点（`checkpoints`）、问号/砖块（`blocks`，出金币）、水管装饰；掉坑/被撞回检查点或重开，无命数惩罚。
- **手感目标**（落地方案定义）：GRAVITY 0.55、JUMP_VY -11、coyote 与 jump buffer 各 100ms、按住跳减重力——**方案写明但落地状态待验证**。
- **美术**：Paper-MC 像素家族已统一（§8 落地）：`pixel-tiles.js` 代码地砖、探险家主角三态、蘑菇仔/史莱姆敌人、视差山丘云；商标马里奥贴图已删。
- **账本**：通关 `awardSunlight(eventKey:'clear-level-<id>')` + `grantProgressPoints(3+星)`；金币吃冒险等级 `platformCoinBonus`；进度存 `growth.worldGames.platform-quest`（含 `coinsTotal/bestTime`）。
- **主要缺口**：未接 `getPlayMods`；手感三件套无测试断言兜底；`bestTime` 存了但玩家看不到；星芒零出场。
