# 横版闯关 · 落地改造方案

> **给实施者：** 这个世界循环是对的（跑、跳、金币、旗）。不要换成 Super Mario 源码。把成熟平台游戏的物理与关卡表手法抽进来，角色和贴图继续用本仓素材。

**目标：** `prj/games/platform-quest/index.html` 手感稳定（落地可跳、边缘可跳）、10 关仍 1–2 分钟一关，通关阳光写回 bridge。

**架构：** 保留现有 Canvas 页与 `data/levels.js`。从参考项目抽 **tile 碰撞 / coyote time / jump buffer**，不抽角色图与关卡几何。

**技术栈：** Vanilla JS + Canvas。不引入 Vite、ECS 框架、FullScreenMario。

成长节奏（不要扩到 32 关）：

| 关 | 已有意图 | 本轮只调 |
|---|---|---|
| 1–2 | 平地跳跃 | 缩短宽度、减少间隙 |

## 5. 从参考抽到本仓的最小物理

建议常量（可微调，先写进 `game.js` 顶部）：

```javascript
var GRAVITY = 0.55;
var JUMP_VY = -11;
var MAX_FALL = 14;
var RUN_SPEED = 4.2;
var COYOTE_MS = 100;
var JUMP_BUFFER_MS = 100;
```

规则：

1. 离地后 `COYOTE_MS` 内仍可跳（bros）
2. 提前按跳，落地 `JUMP_BUFFER_MS` 内起跳
3. 按住跳且 `vy < 0` 时重力改为约 `0.28`（可变跳高）
4. 水平、垂直分轴碰平台，避免抖动（ZeroDayArcade / 通用 tile 分离）
5. 踩怪：玩家从上方且 `vy > 0` 则怪消失、小跳；侧面碰则重置本关

现有 `levels.js` 的 `platforms[]`、`coins[]`、`enemies[]`、`flag` 结构保留，避免重做 10 关数据。
