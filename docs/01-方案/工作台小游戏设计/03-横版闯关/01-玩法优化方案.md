# 横版闯关 · 玩法优化方案

- 日期：2026-08-15，状态：方案（未改代码）
- 原则：10 关固定不扩，优先把**手感**做扎实、把**重玩理由**（时间挑战）做出来。执行力游戏的核心体验是"操作听话"。

## 1. 问题定义

1. **手感三件套只是方案**：coyote 100ms / jump buffer 100ms / 可变跳高写在落地方案里，但没有纯函数测试锁住，是否生效、参数是否漂移无从判断。幼儿玩家对"明明按了跳却没跳"的挫败极其敏感。
2. **无学习难度联动**：`getPlayMods` 未接，怪速对识字 20 字和 250 字的孩子一样。
3. **通关即终点**：`bestTime` 静默存储，孩子看不到"这关我上次跑多快"，10 关通完就没有回头理由。
4. **检查点反馈弱**：碰到检查点只改数据，无视觉/音效确认，孩子不知道"安全了"。

## 2. 手感验证与锁定（P0）

- 把跳跃判定抽为纯函数 `canJump(state, now)`（输入：着地时刻、离地时刻、按键时刻、coyote/buffer 常量），`game.js` 调用它。
- 测试断言四种边界：离地 80ms 内按跳=成功（coyote）；落地前 80ms 按跳=落地即跳（buffer）；离地 150ms 按跳=失败；按住跳与点按跳高差 ≥30%。
- 参数常量集中到文件顶部并加注释来源（落地方案 §手感），防止后续调参不同步文档。

## 3. 学习难度联动

- 开局读 `getPlayMods()`：`enemySpeed` 乘敌人巡逻速度；`sunMult` 乘通关阳光；困难档敌人巡逻范围 `minX–maxX` 扩 20%（更难绕）。
- 简单档额外宽容：coyote 放宽到 140ms。把"识字多 → 更快的怪 + 更多阳光"写在关卡选择页。

## 4. 时间挑战：给 10 关重玩价值

- 结算页显示本次用时 vs `bestTime[level]`，破纪录弹"新纪录！"帧。
- 关卡选择页每关节点下显示最好成绩与星数；3 星（`bestTime ≤ parTime`）未达的关卡标"可挑战"。
- 全 10 关 3 星 → 本地成就"闪电探险家"（走 bridge 里程碑机制评估是否新增 `ms-platform-speed`，需同步 `MILESTONES` 与测试）。

## 5. 关卡微调（二期）

- 按落地方案复查 1–2 关时长（目标 ≤60 秒）与 9–10 关 ≤2 分钟，超时就删平台段，不加检查点数量。
- 检查点反馈：碰到时旗子升起动画 + 短音效 + 星芒喊"存好啦"。
- 每关金币总数在 HUD 显示 `12/18`，让 2 星（收齐金币）目标可视。

## 6. 不做清单

蘑菇变大/火球、二段跳、Shift 跑（DS 候选已否决）、32 关、地下/水下关、命数、Boss。
