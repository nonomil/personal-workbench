## 3. 生图与制作规范

- 像素资产统一 32×32（图标 64、卡片 512），白底或品红幕布生成后抠底；提示词模板沿用 `DS--我的世界--生图.md` 的 `cute 2D pixel art, children's game asset, flat colors` 结构，**删除 Minecraft/Steve 措辞**。
- 色板锚定：草顶 #7CB342、土 #8D6E63、石 #90A4A8、晶体 #AB47BC、矿洞底 #263238。
- 平铺纹理必须在提示词写明 seamless tile 并在落地前拼 3×3 目检接缝。
