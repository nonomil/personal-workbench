## 1. 结论

**已经落地。** 词库覆盖、同关复习、成对题型、主题成批、主题材料奖励都在工作台游戏目录里，刷新页面即可手玩。尚未同步到独立 GitHub / APK。

设计原则只有一句：**主动性来自「同一批词成对练，答完能换到我要合成的材料」，不是再堆题型或再发成品剑。**

## 2. 玩家能感觉到的环

```text
进关 → 本章约 50 词（关卡主题优先，十二关盖满 597）
     → 第一波史莱姆：英文选中文
     → 后几波提示「这一波 · 颜色」：同一主题成批
     → 错过 / 只做过选择题的词，后几波再见到
     → 再见到：中文选英文 → 句子对译 → 缺字母
     → 同一主题凑满 4 / 8 / 12 个不同的词：金币 + 原木/棍/板/煤/火把/矿
     → 自己合成装备，不白送剑
```

任务按「不一样的词」计数，同一词答对两次只算一次。

## 3. 题型（按遇见次数，不乱抽）

| 遇见次数 `seen` | 模式 | 玩家看到的 | 函数 |
| --- | --- | --- | --- |
| 0 第一次 | `choice` | 英文词 → 选中文 | `pickQuizMode` / `makeQuiz` |
| 1+ 再见到（≤5 字母） | `spell` | 看中文，拼出英文 | `recallProduceMode` |
| 1+ 再见到（长词） | `enpick` | 跟读或选英文 | 同上；麦克风仍可选 |
| 错过 ≥3 次 | 强制 `spell` 或 `fill` | 必须产出英文 | `needsHardMode` |
| 可选 | `listen` / `picture` / `phrase` | 听音、看图、整句听写 | 有音频/图/例句才启用 |

`seen` 记在本关 `session.seenByWord`。旧测试不传 `seen` 时，仍走 `stage` / 回合轮换，互不破坏。

**没做成随机题库的原因：** 第一次必须能打下去；第二次才翻转方向；第三次才上句子。乱抽会让孩子觉得「又换规则了」。

## 4. 词库与主题对齐

- 词包：`prj/assets/vocab/core-english-2026.08.15`，597 张，都有例句中英。
- 无主题配置时：按 `CAT_ORDER` 切 12 份，互不重复。
- 游戏内：先按 `climateWords` 锁定本关世界词（沙漠 `hot/warm/wind`，星空 `snow/cold/white`，海洋 `water/fish/boat/swim`），再按 `wordThemes` 补齐。词库没有 sand/fire/stone，只绑实际存在的词。最后一关收尽剩余，**十二关并集仍是 597**。
- 每一波：`pickWaveTheme` 选本关还没用完的主题，`bindCastWord({ theme })` 让这一波怪绑同一主题。复习位（最多 3 只）仍优先错过的词。
- 金色词块最多 48：近处新词，远处复习词（`layoutWorldWords`）。本关答错或只做过选择题后，远处未挖的金块会改绑这些词（`rebindWorldReviewWords`）。

关卡主题写在 `data/levels.js` 的 `wordThemes`，例如第 1 关 `自然 / 物品 / 动物`。

## 5. 奖励（材料，不发成品）

同一主题、本关不同的熟悉词达到阶梯时，`dueThemeAwards` → `grantThemeAwards`：

| 阶梯 | 金币 | 材料 |
| --- | --- | --- |
| 4 | 8 | 原木 ×2、木棍 ×2 |
| 8 | 12 | 木板 ×2、煤 ×2 |
| 12 | 16 | 火把 ×3、铁矿 ×1 |

不发木剑/铁剑。孩子要装备必须合成，所以会主动去打这一主题。金色词块另有 +3 金币、+4 血（`commitWordBlock`）。

## 7. 手玩验收

1. 硬刷新（脚本须带 `bl-learn2`）。
2. 第一波史莱姆：英文选中文。
3. 答错或只点中文后，后几波应再见到该词，且题型变成中文选英文。
4. 第二波起顶部提示「这一波 · ××」。
5. 同一主题凑满 4 个不同的词：弹出金币和材料，背包能合成。
6. 任务条显示「熟悉 N 个不同的词 / 重复不算」。
7. 往外走：金色词块明显多于 8 个。
