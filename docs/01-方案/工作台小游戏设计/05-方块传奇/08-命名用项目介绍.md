# 命名用项目介绍

> 产品名已锁定（2026-08-19）：中文 **我的方块学园**，英文短名 **blockschool**，副标题 **地下城闯关，边打边学**。
> 不用「战学园」：副标题已经负责「打」，多一个「战」字不顺口。
> 工程目录 / 存档键 / Android `appId` 仍是 `blocklegend`，避免已装测试包装不上。仓库改名以后另做。
> 游戏目录：`prj/games/blocklegend/`；独立仓 `github.com/nonomil/blocklegend`。

把本文从「一、一句话」复制到文末，交给取名模型即可。

## 一、一句话

一款给儿童和家长的 **3D 第一人称英语冒险**：在方块世界里砍挖、合成、打怪；关卡按地下城一层层推进；每个单词有记忆状态，到期的词会再拦路。说对、拼对、选对，世界才往前走。

## 二、给谁玩

- 主用户：大约 6–10 岁，跟家长共用一台安卓平板或电脑。
- 家长要一眼看懂：这是学英语，不是又一个沙盒建造游戏。
- 孩子要一眼想玩：能砍、能挖、能打、能开口，不是闪卡 App。

## 三、三个来源，各借什么

| 来源 | 借 | 不借 |
| --- | --- | --- |
| 我的世界 | 第一人称、方块手感、挖放合成、气候地图 | 无限生存、红石、官方角色名与商标 |
| 我的世界地下城 | 一关一局、波次、Boss、装备成长、重玩加难 | 动作游戏操作密度、付费赛季 |
| Anki 单词学习 | 每词一个盒子、到期再见面、难词降级、重玩=消复习债 | 桌面抽卡界面、完整 FSRS、把游戏做成复习软件 |

叠在一起的核心画面：

> **往下走一层（地下城），复习一盒到期的词（Anki），用方块世界的身体去做（挖、砍、说）。**

## 四、玩家实际在干什么

```text
进营地 → 今日优先打「到期的复习门」，否则推进新气候关
      → 384 格第一人称世界：走、挖、放、合成、打怪
      → 第一次见面：英文选中文，能打下去
      → 再见到：短词拼出来，长词跟读或选英文
      → 说对 / 拼对：伤害、破盾、掉材料，自己合成装备
      → 同一主题凑一批词：金币 + 原木/煤/火把等，不白送剑
      → 错的词后几波和远处金色词块还会出现
      → 通关花金币解锁下一气候；重玩可选默认 / 冒险 / 天启
```

已有内容（取名时当事实，不必写进名字）：

- 12 个气候关，597 张生活英语词卡（中英例句）。
- 词级记忆：Leitner 五盒 +「词力」；关级还有七轮「复习之门」。
- 营地 Hub、词卷轴、词灵回廊（隐藏关入口，是功能名不是游戏名）。
- 电脑 / 网页拖视 / 平板摇杆 三种操作；Android 独立 APK 已能装。
- 跟读评测、练一句、难词本、给家长看的听说统计。

和家里另一款游戏的分工：工作台里的「方块世界」负责建造家园；本游戏负责 **打怪 + 开口学英语**，只借方块手感，不做完整沙盒。

## 五、产品北极星（名字要能对上）

> **看见英文、听见英文、说出或拼出英文，让魔法立刻改变世界。**

主动性来自「同一批词成对练，答完能换我要合成的材料」，不是再堆题型，也不是再发成品剑。

## 六、必须避开的名字

- 不要用：**我的世界、Minecraft、Dungeons、Anki、ANKI、闪卡、SuperMemo**。
- 不要再用：**方块传奇、BlockLegend、Block Legend**。小红书参考作也叫方块传奇；工作台里已有「方块世界」。
- 不要像又一个 MC 套皮：方块冒险、我的单词、MineWord、CraftEnglish、DungeonAnki。
- 已试过、委托人觉得不合适，请换方向，不要微调：  
  词灵 / Wordling，开口世界 / Speakworld，言灵 / Wordspell，念咒岛 / Spellisle，说中 / SayHit，词牢 / Wordkeep，词渊 / Worddeep，掘词 / Wordmine，词塔 / Wordspire。
- 「词灵回廊」是游戏内功能名，可以留在游戏里，不要拿来当产品名。

## 七、名字要完成的工作

好名字应同时让人感到这三件事（不必每个词都写出来）：

1. 身体在 **3D 世界里行动**（不是坐着翻卡片）。
2. 关卡是 **一层层地下城**，可以重打、可以加难。
3. 学的是 **单词记忆**：今天该复习的词会再拦路。

还要：

- 中文 2–4 个字，小孩能叫、家长不尴尬。
- 英文短名 1 个词或两个短词，能当仓库名、包名、图标下文案（小写无空格更好）。
- 遮住副标题，仍不像「学习软件」，也不像「我的世界盗版」。
- 可以有一句不超过 12 个字的中文副标题。

## 八、请模型输出的格式

请给出 **8 个候选**，按推荐排序。每个候选只写：

```text
中文名：
英文短名：
副标题（≤12字）：
一句话理由（为什么同时像世界、地下城、单词记忆，又不是套皮）：
主要风险（谐音 / 像别的产品 / 太软或太硬）：
```

最后单列 **1 个首选** 和 **2 个备用**。不要解释过程，不要重复第六节里已否决的名字。
