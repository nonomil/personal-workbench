## 0. 开始前

1. 工作台根目录打开终端。
2. 用 **Chrome 或 Edge**（要测开口时）。
3. 进入游戏后 **Ctrl+F5 硬刷新**，确认地址栏脚本带 `?v=20260819-bl-side7`（或更新）。
4. 只打 **第 1 关**。不要为了测配菜去后面关。
5. 左侧 Listening 里记两行：
   - `My English: N words` → 下面称 **F**
   - `#side-due` → 如 `还欠 识字2 · 本局 0/6`

建议准备：空档（没刷过识字）最容易看见欠账。若工作台已经会很多字，欠账会被抵掉，石碑可能不出现——这是合同行为，不是坏了。

| 顺序 | F（不一样的英语词） | 应看见 | 不应看见 |
| --- | --- | --- | --- |

## 3. 分步操作

### 3.1 主车道没被抢走（每一步都要回看）

1. 打一只史莱姆或爬行者，等暴击题。
2. **必须是英语词**（四选一 / 拼写 / 跟读）。
3. Boss 蓝罩若出现，机制仍是该关英语，不是识字。

任一步暴击出汉字或口算 → **失败，停测。**

### 3.2 F=0–3：前几分钟只英语

1. 硬刷新进第 1 关。
2. 熟悉 1～3 个**不同**英语词。
3. 看远处金色词块：看向牌应是英文（如 `tree`），不是「识字」。
4. HUD `#side-due` 应为空（或没有「还欠」）。
5. 按 F 找商人：直接开店，没有口算题。
6. 点「练一句」：英语场景句（点餐/问路），不是 CVC。

### 3.3 F=4：识字石碑

1. 再熟悉到 **4** 个不同英语词。
2. 应 toast：`远处金块变成石碑了 · 看向挖开认字`。
3. 走到**远处**金块（不是脚边），准星看向：
   - 大字：**识字**
   - 下面：汉字（如「的」）
   - 一行：`挖开认字`
4. 左键挖开，四选一认字。
5. **答对：**
   - toast 类似 `识字 · +3金币`
   - 金币 +3，**血量不涨**
   - HUD `本局 1/6`，欠账少 1
   - 图鉴 / `My English` **不** +1
6. **答错一次：** 石碑还在，可再挖同一字。
7. **同一道再错一次：** toast `换一道`，金块改绑下一个字。
8. 打开「给家长看」：有一行如 `还欠 识字1 · 识字已练1`，没有新开单独科目页。
9. 帮助第 2 页能看到「石碑」一行。

### 3.4 F=8：拼音加入队列

1. 熟悉到 8 个不同英语词。
2. 远处石碑按欠账排：先识字，再拼音。
3. 看向拼音块：大字 **拼音**，说明 `挖开认音`。
4. 挖开是声母选择题，**不要**出现英语暴击牌。
5. 应听到中文 TTS（声母例词），下一句英语战斗应立刻回英文发音。
6. 练一句 / 拼读石碑题干应是 CVC 词（如 `sat`），不是单个字母 `a`。

### 3.5 F=12：练一句出拼读

1. 熟悉到 12 个不同英语词。
2. 点顶栏「练一句」。
3. 若还欠拼读：卡片标题 `练一句 · 读出这个`，题干是 CVC（如 `sat`），不是点餐句。
4. 麦克风按钮应可见。说对或点对都算一题配菜。
5. 说对后 **My English 不增加**（拼读写 `phonics`，不写 `minecraft`）。
6. 若本局已满 6 道，或拼读欠账为 0：练一句应回到英语场景句。

### 3.6 F=16：商人口算（数数/比较）

1. 熟悉到 16 个不同英语词。
2. 走到商人，按 **F**。
3. 先出 1 道口算（静题，像数数/比较），再开商店。
4. **算对：** toast `算对了 · 本单九折`，商品价约九折（如 40→36）。
5. **算错：** toast `原价也能买`，商店仍能开。
6. 关掉商店再按 F：若还没拿到九折，可以再问一道；已九折则不再问。
7. 口算 **不** 进英语图鉴。

### 3.7 F=20：商人改 20 以内加减

1. 熟悉到 20 个不同英语词。
2. 新开一局或关店后再找商人（本局还没满 6 道、还欠口算）。
3. 题目应是 `3 + 5 = ?` 这类加减，选项是数字。
4. 网络面板：这时才请求 `preschool-math-bank.js`，**首屏 HTML 里没有这个脚本**。

### 3.8 本局 6 道封顶

1. 连续做石碑 / 拼读 / 口算，直到 HUD `本局 6/6`。
2. toast：`配菜先到这儿 · 继续打英语`。
3. 远处金块看向应变回**英语词**。
4. 再按 F：直接开店，不再口算。
5. 再点「练一句」：英语场景句。
6. **刷新页面（新坐下）：** `本局` 归零，若仍欠账，石碑应再出现。欠账本身留在工作台掌握度里，不会因刷新白刷。

### 3.9 欠账清零

1. 把当前欠的识字/拼音都答对（或工作台里已经会）。
2. 远处金块全部恢复英语词，不再粘着汉字。
3. HUD「还欠」消失（若本局做过，可仍留 `本局 n/6`）。

## 4. 失败与边界

| 操作 | 期望 |
| --- | --- |
| 同一英语词打 10 次 | F 不涨，不会变出 5 道识字 |
| 识字目录 404（可在开发者工具屏蔽 `core-literacy-*.json`） | toast `识字板暂时没有`；拼音/英语仍可用 |
| 拼音目录 404 | toast `拼音板暂时没有`；识字石碑仍可出 |
| 口算目录 404 | 商人直接开店，英语战斗正常 |
| 工作台已会 ≥ 配额的字 | 该科欠账为 0，不重复刷 |
| 已会字 ≥ 80 | 新识字石碑应是 L2 带，不再只出最开头几个 L1 字 |
| Esc / 关商店 | 没拿到九折时可再问口算；英语主车道不受影响 |
| 中国大陆 Chrome 开口 `network` | 拼读可改点选；不要因此改主车道 |
