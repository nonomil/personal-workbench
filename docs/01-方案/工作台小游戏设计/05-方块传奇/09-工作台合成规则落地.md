> 产品名：我的方块学园。界面不新写商标名；机制对齐公开 Wiki，方便孩子「按形状摆、看缺什么」。

## 2. 原版规则（本项目采用）

1. **2×2**：原木→木板、木棍、合成台、火把、2×2 羊毛。3×3 台上也能做。
2. **3×3**：镐/剑/斧/铲、箱子、熔炉、门、梯子、弓、盾、床等。
3. **有序**：相对位置不变时可平移；**可左右镜像**（弓弦左右都行）；不上下翻转。
4. **无序**：只数材料，位置随便。本项目留给打火石简化、箭简化、TNT 简化。
5. **熔炉**：玻璃、铁锭、金锭。沙子+煤不该当工作台配方。
6. **展示**：配方书看出物 + 3×3 形状 +「有/要」数量；结果格显示个数；Shift 拿走可连做。
7. **一键合成**：保留（接近旧主机/触屏）。点配方仍走「拼英文 → 从背包扣材料」。格子摆放是第二条路。

## 6. 手玩

1. 砍树 → 原木摆任意格出木板 → 2×2 木板出合成台。
2. 3 木板横顶 + 中间两棍出木镐；同一图案往右挪一格仍出镐。
3. 3 棍 + 3 线摆成弓；弦改到左边仍出弓。
4. 配方书上看木镐应是 T 形；缺棍时数字发红。
5. 沙子+煤不能在台上做出玻璃，熔炉可以。
6. 结果格按住 Shift 连拿，直到格子空。

## 7. 更多可挖可合成方块（2026-08-20）

孩子要能挖到新材料、装进背包、合成后再放回去。本轮只加这条可见环，不搬盔甲/下界合金。

| 方块 | 怎么来 | 怎么用 |
| --- | --- | --- |
| 砂砾 | 浅层土里、石头缝；铲快 | 3 砂砾 → 燧石；可放回 |
| 粘土 | 平原/森林/海边浅土；铲快 | 熔炉烧成砖；可放回 |
| 砂岩 | 4 沙子 2×2 | 可放 |
| 石砖 | 4 圆石 2×2 | 可放 |
| 砖块 | 粘土+煤熔炼 → 砖，4 砖 2×2 | 可放 |
| 地毯 | 2 羊毛横排 → 3 地毯 | 可放 |
| 燧石箭 | 燧石+棍+鸡毛竖排 → 4 箭 | 圆石箭简化配方仍保留 |
| 剪刀/桶/钓竿/碗/船 | 配方书可见 | 船可合成；剪刀剪羊毛、桶挤奶 |

镐挖砂岩/石砖/砖块更快；铲挖砂砾/粘土更快。看方块卡有英文 gravel / clay / sandstone。

## 8. 配方书给孩子看的：床、工具、常用物品（2026-08-20）

第一次合成仍是 **看中文、选英文** 四选一。答对才做出并记住。台阶、按钮、石英块和面包饼干蛋糕不进配方书。

| 给孩子看 | 材料 | 用 |
| --- | --- | --- |
| 床 | 3 羊毛 + 3 木板 | 右键放到地上，再右键睡觉回满 HP |
| 木/石/铁锄 | 2 材料 + 2 木棍 | 对着草右键锄成泥地 |
| 拴绳 | 4 线 + 史莱姆胶 | 对着猪牛羊右键，它跟着走 |
| 剪刀 / 桶 / 钓竿 / 船 / 门 / 梯子 / 栅栏 | 已有配方 | 门能开关；梯子能爬；船能坐着划；钓竿对着水能钓鱼 |

剑镐斧铲、弓盾、箱子熔炉火把仍在配方书。
