## 现状事实（2026-08-15）

- **玩法**：点草坪种植物 → 点"来一波" → 植物自动战斗（规则在 `preschool-garden.js` 的 `tickDefense`），守住波次过关，单局 ≤3 分钟。僵尸破左线判负，重来不扣阳光。
- **关卡**：`data/stages.js` 12 关；波次 1→3，parSec 45→90，开局能量 2→8，通关阳光 12→35。
- **植物 5 种**：向日葵+豌豆（第 1 关）、坚果（3）、寒冰豌豆（4）、樱桃炸弹（6）；**第 6 关后再无新解锁**。
- **僵尸素材 5 种**（v4 批次）：普通、旗帜（波次首领）、路障、铁桶、橄榄球，见 `assets/manifest.md`。
- **账本**：通关 `awardSunlight`（eventKey `clear-<stage>` 去重）+ `grantProgressPoints(3+星)`；开局阳光吃冒险等级加成 `gardenStartSun`；进度存 `growth.worldGames.garden-defense`。
- **主要缺口**：未接 `getPlayMods` 学习难度联动；7–12 关只是波次微调、无新内容感；星芒零出场；徽章解锁无游戏内庆祝。
