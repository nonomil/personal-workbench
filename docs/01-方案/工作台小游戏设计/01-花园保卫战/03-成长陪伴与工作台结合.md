# 花园保卫战 · 成长陪伴与工作台结合

- 日期：2026-08-15，状态：方案（未改代码）
- 账本合同：只用 `workbench-bridge.js` 现有 API，不改 localStorage key，不加新货币。

## 1. 已接通的部分（保持不动）

- 通关发阳光：`awardSunlight({gameId:'garden-defense', eventKey:'clear-<stage>'})`，去重 + 日限 80。
- 冒险点：`grantProgressPoints('garden-defense', 3+星)`；里程碑 `ms-garden-3/8/12` 与 `ms-stars-20` 自动判定。
- 每日打卡戳：打开即 `recordPlaySession`，+3 阳光、计周目标与三界同日。
- 元反哺：开局阳光吃 `gardenStartSun`（冒险等级 2 级 +10 → 7 级 +60）。

## 2. 陪伴层（本册核心增量）

按总纲第 4 节规范落到花园：

- **星芒观战席**：HUD 右上角小头像。开局按识字档说话（"今天的僵尸有点快，先多种向日葵哦"）；通关庆祝姿势 + 夸奖文案；失败打气（"差一点点！下次把坚果种前面试试"——文案要**给策略提示**，不是空安慰）。文案池 12 条，`petLevel≥3` 解锁称呼"小园长"。
- **里程碑庆祝卡**：`recordPlaySession`/`grantProgressPoints` 返回的 `awards` 数组里有 `kind:'milestone'` 时，游戏内弹全屏卡（徽章名 + 星芒庆祝 + 阳光数），点按关闭。当前这些奖励是静默入账的，孩子完全感知不到。
- **结算页三行**（总纲规范）：本局所得（阳光×倍率、星数）；长线进度（冒险等级进度条 `getMetaSummary().adventurePoints/nextRank`）；下一个目标（如"再通 2 关点亮【八关防线】"，从 `MILESTONES` 计算最近未解锁项）。

## 3. 与学习闭环

- 难度联动（01 册 §3）：识字量 → playMods → 僵尸速度/阳光倍率，HUD 明示"多认字 → 更强敌人 + 更多阳光"。
- 周报增强：`getWeeklyReport()` 的 tips 已会提示"花园先通 3 关"；本游戏侧要在关卡选择页顶部展示同一条 tip，让工作台和游戏说同一句话。
- 工作台成长页的花园进度（n/12 关）与游戏内进度必须同源（都读 `clearedStages`），不许各算各的。

## 4. 长线节奏设计

- **短**（单日）：1–2 局 ≤3 分钟短局 + 每日打卡戳。
- **中**（单周）：周目标 4 天 + 三界同日；配合 01 册"每关一个新面孔"，一周推 2–3 关。
- **长**（一至两月）：12 关通关 → `ms-garden-12` 终章徽章 + "花园守护者"称号；之后进入三期内容（新关卡批次 / 三星全收集）。
- 防疲劳：日限 80 阳光 + 单局短，天然限制时长；不做断签惩罚。
