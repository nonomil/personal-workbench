# 花园保卫 · 落地改造方案

> **给实施者：** 不要新建游戏目录，不要 iframe，不要第二套阳光。把独立页接回已经验收过的自动塔防循环。

**目标：** 打开 `prj/games/garden-defense/index.html`，点草坪种植物，点「来一波」，植物自动打、僵尸自动走，清波或守住即过关，阳光经 `WorkbenchGameBridge.awardSunlight` 写回工作台。

**架构：** 规则继续放在 `prj/preschool-garden.js`；独立页只负责画、点、播 `tickDefense`。关卡表仍用 `data/stages.js` 的 12 关进度键，但把 `needKills` 改成波次/生存目标。

**技术栈：** Vanilla JS + Canvas；已有 `preschool-pvz-2d` 原创素材；不引入 Phaser / Vite。

## 1. 第一性原理：哪个更好

| 选项 | 孩子看见什么 | 代价 | 裁决 |
|---|---|---|---|
| A. 继续独立页「点技能击退 N 只」 | 不像保卫战 | 已存在，但手感差 | 否 |
| B. 整仓 fork `plantsvszombiesjs` / Azure 魔改版 | 像原版 PVZ | 原作图、第二套存档、体积 | 否 |
| C. 把 2026-08-03 的 `tickDefense` 接到独立页，再抽参考项目的波次/阳光掉落 | 种、自动打、僵尸走路 | 改 `game.js` + 少量规则 | **是** |

C 不是从零造轮子。轮子在：

- `placeDefensePlant` / `spawnDefenseWave` / `tickDefense`（`prj/preschool-garden.js`）
- 工作台 `#battle` 每 720ms 调一次 `tickDefense`（`prj/app.js` `ensurePreschoolDefenseLoop`）
- 任意种植坐标 `plant.x`（已落地，须保持）

独立页缺的是：**用这套规则驱动 Canvas**，而不是 `spawnInvader` + `usePlantSkill`。

## 3. 成长型怎么接（不改 key）

沿用已有进度，不新增 `localStorage`：

```text
growth.worldGames.garden-defense
  unlockedStage
  clearedStages[]
  stars{ stageId: 1-3 }

通关：
  bridge.awardSunlight({ gameId:'garden-defense', eventKey:'stage-'+id+'-clear', amount, energy:1 })
  bridge.grantProgressPoints('garden-defense', 3+star, 'clear-'+id)
```

关卡语义从「手动击退 N 只」改为：

| 关 | 标题可沿用 | 目标 | 开局植物 | 波次 |
|---|---|---|---|---|
| 1 | 第一天的阳光 | 清 1 波（约 2 只）或守 45s | 向日葵+豌豆 | 1 |
| 2 | 豌豆练习 | 清 1 波 3 只 | 同上 | 1 |
| 3 | 坚果报到 | 清 1 波，含路障 | 解锁坚果 | 1 |
| 4–6 | 寒冰/樱桃 | 2 波 | 按现 `unlockPlants` | 2 |
| 7–10 | 稳定输出 | 2–3 波 | — | 2–3 |
| 11–12 | 终章 | 3 波，含铁桶 | — | 3 |

星星：通关 1 星；无一株植物阵亡 2 星；在 `parSec` 内清完 3 星。  
失败：任一僵尸 `column < 0`（走到最左）→ 本关重来，不扣学习阳光。

一局目标 **≤ 3 分钟**。阳光只在通关发一次（`eventKey` 去重），局中种植继续扣 `growth.sunlight`。

**改：**

**素材：** 只用 `prj/assets/generated/preschool-pvz-2d/published/`。缺图用色块，不从参考仓拷 PNG。

## 5. 独立页循环（可落地）

```text
boot
  → loadProgress / loadAll
  → 关卡地图（已有）
enterStage(id)
  → garden.startDefenseGame(growth)
  → 按 stage.unlockPlants 并入 unlockedPlantIds
  → 给 startEnergy（可保留，但自动塔防不再消耗「点技能能量」）
loop (rAF)
  → 累积 dt，每 720ms tickDefense(growth, 1)
  → 画草坪、plant.x、僵尸 column 插值、豌豆
  → defense.status==='won' → 结算阳光
  → 若规则补 lost：提示重开
pointerdown
  → lawnFromEvent → placeDefensePlant(..., { x })
「来一波」
  → spawnDefenseWave（已有，同屏最多 3 只）
```

删除或停用本页：`useSkill`、`spawnInvader`、`peaAnim` 手动飞豆。豌豆由 `defense.projectiles` 画。

僵尸画面位置：`x = left + (zombie.column / 5) * width`（或按 6 列），不要固定画在最右侧一只「入侵者」。

## 6. 任务切片

### 任务 1：规则层失败态（若尚无 lost）

**文件：** `prj/preschool-garden.js`，`tests/preschool-garden.test.mjs` 或 `tests/preschool-defense-game.test.mjs`

1. 写失败测试：僵尸 `column` 减到 0 且再走一步 → `defense.status === 'lost'`
2. `node --test tests/preschool-defense-game.test.mjs` 先红
3. 在 `stepDefense` 末尾：僵尸 `column < 0` 或到达 0 仍存活 → `lost`
4. 再跑测试至绿

无 `lost` 时也可先用「僵尸还在最左且 plants 被吃光」做局内提示，但通关必须有明确 won。

### 任务 2：独立页改接 tick

**文件：** `prj/games/garden-defense/game.js`

3. 改 `game.js` 如上循环
