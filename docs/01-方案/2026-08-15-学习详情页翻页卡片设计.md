- 上游方案：`docs/01-方案/2026-08-15-学习专区卡片墙布局方案.md`（总览卡片墙已实施）

## 1. 决策记录（头脑风暴结论）

| 问题 | 结论 |
| --- | --- |
| 翻页卡片出现在哪 | **详情页整个变成翻页卡片**：从卡片墙点学科后直接进入，不再显示仪表盘式大卡 |
| 翻卡时是否标记 | **会了/不会两个大按钮 + 自动翻下一张**，一次点击 = 一张卡，翻页快且进度可追踪 |
| 卡片从哪里来 | **今日卡包**：今日到期复习 + 当前级别新字（如 L1 接下来 8 个），翻完即完成今日认读 |
| 覆盖学科 | **本期只做识字 / 英语 / 拼音 / 拼读**四科；古诗、数学、专注、运动、暑假保持现有详情页 |

## 2. 页面流程

```text
卡片墙点「识字」
   ↓
┌─────────────────────────────┐
│ ← 返回    识字 · 今天 8 张    │  顶条：返回 + 进度
│   第 3 / 8 张  ●●○○○○○○      │
│  ┌───────────┬───────────┐  │
│  │           │ 组词：大山  │  │
│  │    山      │      上山  │  │
│  │   shān    │ 解词：……   │  │
│  └───────────┴───────────┘  │
│      🔊 点字朗读             │
│  [✗ 还不会]      [✓ 会了]    │  点了自动翻下一张
└─────────────────────────────┘
   ↓ 翻完一包
┌─────────────────────────────┐
│  今天的小卡翻完啦！🎉         │
│  会了 6 · 明天再认 2          │
│  [练一练：组词开花] [测一测]  │  接现有练习（lesson dialog）
└─────────────────────────────┘
```

要点：

1. 详情页是**一本翻得完的小册子**，不是仪表盘。掌握统计、分级带、示例、参考说明从孩子视野移除；数据照常记录。
2. 翻完一包弹出鼓励页，把现有练习/测试接在末尾，老练习逻辑（lesson dialog）全部保留复用。
3. 页面底部放一个小的文字按钮「看看资料和其他练习」，切换回经典详情页（英语专区的儿歌视频、打印资料等资源入口不丢）。
4. 每科卡面：
   - **识字**：左 = 大字 + 拼音；右 = 组词（2 个）+ 解词/句子（有数据才显示）
   - **英语**：左 = 单词；右 = 中文 + 例句 + 例句中文
   - **拼音**：左 = 声母/韵母；右 = 例字 + 例字拼音
   - **拼读**：左 = 单词；右 = 字母拆分（s · a · t）
5. 朗读按钮复用现有 `speakLiteracy(text, lang)`：识字/拼音 zh-CN，英语/拼读 en-US。

## 3. 数据流

**今日卡包** `getPreschoolCourseCardPack(course)`：

- 识字：识字引擎复习队列（到期）+ 当前级别下一批新字（规则同"今日闪卡"，默认 8 张）
- 英语：英语引擎复习队列 + 当日新词批（同"今日 5 词"规则）
- 拼音/拼读：当前级别（track.maxUnlocked）内未掌握条目，取前 N 个（默认 8）

**落账**（全部走既有引擎，不新造存储）：

- 识字 `engine.markFlash(progress, char, known, today, rules)` → `saveLiteracy`
- 英语 `engine.markKnown(progress, word, known, today, rules)` → `saveEnglish`；点"不会"同时记错题本（沿用 `recordPreschoolLessonMistake`）
- 拼音/拼读：按现有 subject mastery 口径落账（实现时以引擎 API 为准）

**UI 状态**：`ui.courseCards = { courseId, index }`，仅记录翻到第几张，不落盘；切换学科/页面时重置。进度点、掌握统计全部由引擎进度派生，翻卡页不产生新数据结构。

## 4. 明确不做（本期）

- 不改古诗 / 数学 / 专注 / 运动 / 暑假五个学科的详情页
- 不改 lesson dialog 内部练习交互
- 不新增 localStorage key、不改 `dailyPlans` / `courseProgress` 数据结构
- 不做卡片翻面动画、不做滑动手势（按钮翻页已满足"翻页快"）

## 5. 验收标准

- `node --check prj/app.js` 通过；`npm test` 全绿（含更新后的合同测试）
- 浏览器层：卡片墙点识字 → 直接进翻卡页；点会了/不会自动翻下一张；翻完出鼓励页；练一练能打开现有练习；「看看资料和其他练习」能切回经典详情页；390px 下卡面左右改上下排布，按钮 ≥ 44px
- 点"不会"的字，第二天出现在复习队列（识字/英语）；拼音/拼读不会项计入"练过/还不会"统计
