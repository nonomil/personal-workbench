## 3. 执行纪律（继承仓库惯例）

1. 动手前先跑 `npm test` 记基线；先只读侦查、把实录写进 test-report，再改代码。
2. 合同测试先红后绿；文案改动同步更新断言中文文案的既有测试。
3. 不 commit，改完汇报等确认。
4. 红线自查（每阶段）：无新货币 / 无惩罚 / 无排行 / 无手动打卡按钮 / 不动 bridge 上限 / 奖励幂等零放松。
