## 1. 问题定义（2026-08-15 用户反馈）

卡片墙改版后学习专区呈三层，问题是**两头极端、中间缺失**：

| 层 | 现状 | 问题 |
| --- | --- | --- |
| 第一层：卡片墙（`renderPreschoolCourseWallCard`） | 插图 + 两字标题 + 3 个进度点 + 开始/继续/完成 | **太简单**。3 个点表达总完成度 33/66/99，看不出"今天这科要做什么、量多少"。卡片成了零信息的纯导航按钮 |
| 第二层：今日学习页（`renderPreschoolSubjectTodayPage`，`prj/app.js:3315-3323`） | 翻卡 / 今日一首 / 运动跟做 / 专注训练 / 暑假清单 | 这层是好的，不动 |
| 第三层：classic 详情（`ui.courseClassic = true`） | "看看资料和其他练习"按钮（`data-action="flashcard-classic"`，`prj/app.js:5432`）落到**原封未动的旧版完整大卡** `renderPreschoolCourseCard(course, true)`（`prj/app.js:3400`） | **特别复杂**。一张卡叠 8 层：长描述、进度条、L1–L5 分级带、掌握统计、参考说明、徽章、示例词、媒体资源、完整路线。复杂度只是被藏到按钮后面，没有被消化 |

## 2. 目标

```text
第一层 墙卡（加一行今日预览）        第三层 classic 改为「更多练习」菜单
┌──────────┐                      ┌────────────────────────────┐
│   插图    │                      │ ← 卡片墙   识字 · 更多练习    │
│   识字    │                      │ [▶ 回到今日学习页]           │
│ 今天认8个字 │  ←新增一行            │ [▶ 识字课 · 第3课]（今日课）  │
│  ●●○     │                      │ [🔊 听一听] [📖 看资料]      │
│   继续    │                      │ ▸ 家长看详情（默认折叠）       │
└──────────┘                      │   （原完整大卡整体收在这里）    │
                                  └────────────────────────────┘
```

设计原则：

1. 孩子路径上任何一屏的信息层 ≤ 5 个；家长密度内容（掌握统计、分级带、参考说明、媒体资源）默认折叠。
2. 零新 localStorage key、零数据结构改动；预览与菜单全部从既有确定性数据派生。
3. 旧完整大卡**不拆不删**，整体包进"家长看详情"折叠区——实现成本最低、回滚最容易，后续再评估是否移家长报告区。

## 3. 实施设计

### 3.1 墙卡今日预览行（A 项）

新增 `getPreschoolCourseTodayPreview(course)`，返回一行短字符串，插入 `renderPreschoolCourseWallCard` 的标题与进度点之间（`<small class="preschool-course-wall-preview">`）。各科派生来源（全部是既有确定性函数，禁止新造第二套"今天该学什么"逻辑）：

| 课程 | 预览文案（示例） | 数据来源 |
| --- | --- | --- |
| 识字/拼音/拼读/数学/英语（翻卡科） | `今天认 8 个字` / `今天 5 个单词` / `今天 8 道口算` | `PRESCHOOL_FLASHCARD_SIZE`（`prj/app.js:3061`）+ 各科翻卡 session 的今日张数口径 |
| 古诗 | `今日一首 · 静夜思` | 今日诗推导（`getPreschoolPoetryTodaySession` 同款 day-index，注意不要在墙卡渲染时污染 `ui.courseCards`，抽纯派生） |
| 专注 | `今日训练 · {lesson.title}` | `renderPreschoolFocusToday` 同款 todayIndex 推导 |
| 运动 | `跟做今天的动作` | 静态 |
| 暑假 | `今天五样小事` | 静态 |

已完成态：当日该科完成（翻完/背完/打卡完）时预览变 `今天做完啦 ✓`。完成判定复用各科已有口径（实施时侦查后定，禁止新造）。

### 3.2 classic 详情拆两层（B 项）

改 `renderPreschoolCourses` 的 classic 分支（`prj/app.js:3416-3419`）：

1. **删掉** `preschool-course-library-note`（REFERENCE LIBRARY 英文抬头那节）。
2. **新增** `renderPreschoolCourseMenu(course)` 作为 classic 落点主体，从上到下：
   - 顶部条：`← 卡片墙` 返回 + `{短标题} · 更多练习`（复用 `preschool-flashcard-top` 样式语言）。
   - `回到今日学习页` 主按钮（现 `classicSwitch` 的 `flashcard-cards` 行为升级为主按钮）。
   - 今日课程大按钮：`course.lessons` 映射 `open-lesson`（复用翻卡完成屏 `preschool-flashcard-lesson` 的样式）。
   - 资源快捷行：`听一听`（该科有 TTS 资源时）与 `看资料`（`renderPreschoolCourseResources` 的条目改为大按钮行，条目 > 3 时只显示前 3 + "全部资料"展开）。
   - `<details class="preschool-course-parent-detail">`：`<summary>家长看详情</summary>` + **原样调用** `renderPreschoolCourseCard(course, true)`。默认折叠。
3. 孩子层菜单按钮总数控制在 3–5 个（lessons 多于 3 个的科只显示今日课 + "全部课程"展开）。

## 4. 验收标准

Node 层：`npm test` 全绿；`node --check prj/app.js` 通过。

浏览器层（390px 竖屏 + 桌面）：

1. 卡片墙每张卡有今日预览行；完成的科显示"今天做完啦 ✓"；不同日期预览内容随 day-index 变化。

5. 从菜单进课程、进翻卡、返回卡片墙，全链路无死路。
