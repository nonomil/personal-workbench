# 2D 草坪战场参考图提示词

```text
Create an original children's learning dashboard reference image for a horizontal lane tower-defense garden game. The visual language should be a hand-painted 2D cartoon with thick dark ink outlines, warm paper-like highlights, expressive but friendly plant defenders, and silly undead intruders. It should feel like a classic 2D lawn defense game without copying any existing protected character, logo, UI, or screenshot.

Viewport: 1440x900 desktop web app. Composition: a narrow top HUD with a sun counter and a horizontal row of six blank seed packets; below it, a large five-lane green lawn with subtle horizontal mowing stripes and clear square planting spaces; plants stand on the left half; three different full-body original zombies approach from the right edge on separate lanes; a small soil strip and backyard fence sit behind the lawn. Use sunflower-like, pea-shooter-like, wall-nut-like silhouettes and conehead/buckethead-like equipment, but make every character newly designed. Keep all cards and panels blank for HTML overlay.

Palette: leaf green, fresh lawn green, warm sun yellow, soil brown, sky cyan, zombie sage gray, warning orange. Characters must be large enough to identify at a glance. Use flat 2D painted shapes and crisp outlines, not 3D render, not photoreal, not clay, not voxel, not pixel art, no purple dashboard, no glassmorphism.

No text, no letters, no numbers, no Chinese characters, no pinyin, no fake writing, no logos, no watermark, no branded UI.
```
