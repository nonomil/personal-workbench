# 总资料计划

## 资料包最小闭环

每个学科先生产一周可运行资料，而不是先追求 60 天数量：

| 资料 | 每周数量 | 交付格式 |
| --- | ---: | --- |
| 核心活动 | 6 | JSON 条目 + 1 个原创主图/图标 |
| 复习活动 | 3 | JSON 复习队列模板 |
| 家长提示 | 6 | 1-2 句短提示 + 观察选项 |
| 打印/离线活动 | 2 | HTML 打印页或项目原创 SVG/PNG |
| 花园反馈 | 3 | 状态文案、动画状态、备用静态图 |

## 生产顺序

1. 先定目标和题型，再生图；不先批量生图后硬找用途。
2. 先用项目原创文字和 CSS fallback 跑通，再替换合格素材。
3. 每批资料都记录来源、许可证、生成提示词、人工检查人和发布日期。
