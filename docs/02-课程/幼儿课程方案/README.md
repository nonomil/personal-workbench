# 幼儿课程方案

> 当前方案版本：`v1.0-research-backed`
> 对应研究：`../../03-研究与参考/幼儿学习工作台研究/`

这是幼儿学习工作台的总控课程目录。各科目的长期资料包已经拆到 `docs/02-课程/识字/`、`docs/02-课程/数学/`、`docs/02-课程/古诗/`、`docs/02-课程/英语/`、`docs/02-课程/自然拼读/`、`docs/02-课程/运动与专注/`、`docs/02-课程/成长游戏/`；本目录负责跨科目合同和实施索引，不替代各科目文件夹。它不是代码实现清单，也不是“以后再细化”的空目录；每个文件都要回答目标、活动、数据、奖励、资料和验收中的至少一项。

## 使用规则

1. 先读 `00-总控/总方案.md` 和 `00-总控/数据与奖励合同.md`，再读对应学科的分方案。
2. 分方案决定“教什么、怎样才算会”；分计划决定“哪一天做什么”；资料计划决定“需要生产哪些条目”；实施验收决定“代码做到什么才可合并”。
3. 研究目录中的外部资料只提供依据，不直接成为课程内容。课程内容默认项目原创。
4. 改动运行代码时，要把对应的方案文件和数据合同一起核对；改动奖励、日期、localStorage、路由或发布边界时，必须同步检查 `docs/data-model.md`、`docs/api-contract.md` 和项目 AGENTS 维护说明。

## 当前范围

- 各科资料库可以覆盖 60 天，适配幼儿园大班到小学低年级过渡，不承诺替代学校课程；工作台运行时先只验证轻量打卡 MVP，不把资料库当成已接入的网页课程。
- 每天六项今日任务（识字/古诗/数学/英语/运动/专注，`prj/storage.js` `PRESCHOOL_DAILY_ITEMS`），每项 5-15 分钟，其中识字/古诗/数学为核心必做，英语/运动/专注为可选；趣味动画和沉浸互动放到独立游戏入口。
- 课程结果用活动证据记录，花园和奖励只做反馈，不把动画或积分当学习能力证明。
- 先稳定工作台的打卡、简单测试、奖励和独立游戏出口，再按真实使用需求选择性接入课程资料；60 日资料存在不等于网页课程已经完成。
