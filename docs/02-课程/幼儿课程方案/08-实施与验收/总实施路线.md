# 总实施路线

## Milestone 1：数据合同

冻结活动条目、四段式字段、复习队列、reward event 和导入导出兼容规则。

## Milestone 2：学习活动

先实现英语自然拼读、数学和识字三条最小闭环；每条完成后再扩展古诗、运动和专注。

## Milestone 3：花园反馈

接入阳光、植物、豌豆能量和入侵者；动画只订阅状态变更，不参与结算。

## Milestone 4：家长与同步

实现家长观察和奖励确认，运行自托管 API 的离线/冲突/恢复演练。

## Milestone 5：发布

运行静态回归、Pages 制品门禁、APK Actions，下载并在 MuMu 安装验证。
