# 自然拼读资料计划

每条 lesson 必须包含：

`lessonId/day/stageId/skillIds/newPatterns/reviewPatterns/phonemes/examples/activityTypes/decodableTexts/durationMin/source/license`。

每个 `decodableText` 必须包含：`text/allowedPatterns/trickyWords/decodabilityPercent/source`。项目原创短句例子：`Sam sat.`、`A cat sat.`、`The fish is in a dish.`，只有在规则已教或被标为高频词后才能进入对应阶段。

每周资料包：3 个新课、2 个复习卡、1 个短句/小书、1 张音素格打印页、1 个家长观察提示。
