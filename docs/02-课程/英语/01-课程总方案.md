# 英语课程总方案

英语采用“听说热身 → 自然拼读/绘本精读 → 情景口语 → 阶段复习与应用”。三条路线互补：听说建立意义，拼读建立音-字关系，绘本建立理解和兴趣。

自然拼读不新增顶层导航，课程入口通过 `subroute: phonics` 挂在英语下；60 日专项细节以 `docs/02-课程/自然拼读/` 为准。

日定量闭环：英语专区顶部「今日 3 词」只从 `docs/02-课程/英语/06-80词溯源表.md` 的 80 词取词；点「会了」进入「我的词库」；到期复习标黄。597 词运行库仍在，不替换。掌握记录写在已有 `courseProgress.english.mastery`。

今日 3 词课内流程：听读自评 → **客观题（听音选图 / 看图选词）** → 中英配对 → 字母拼写。客观题干扰项只用词库真词，不用假词。无配图的词自动跳过客观题，流程不断。客观答对记入 mastery 条目内 `quiz` 分桶；答错写入通用错题本并带 `errorType`（listen/read/spell）。英语专区另有错词本（三分类 + 专项复习）、词汇档案（`masteredAt` 曲线 + 80/300 参考线）、单词BOSS（`prj/games/wordboss/`，金币仅局内，阳光走 bridge）。80 词日闭环配图 80/80。
