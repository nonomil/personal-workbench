# 60 日课程表

| 日 | 主目标 | 练习产出 | 复习 |
| ---: | --- | --- | --- |
| 1-5 | 词/音节/押韵/首音/口头合成 | 听辨配对、动作节奏 | 当天口头复述 |
| 6-8 | `s a t` | 字音匹配、`at` 合成 | 音素意识 |
| 9-12 | `p i n m d` | `sat/pat/pin` 等短片段 | `s a t` |
| 13-16 | 短 a CVC | `sat/pat/mat/map` | 第一组字音 |
| 17-20 | 短 i CVC | `sit/pin/tip/dip` | 短 a、首中尾音 |
| 21-24 | 短 o 词族 | `-ot/-op/-og` | 短 a/i |
| 25-28 | 短 e/u 词族 | `-et/-en/-ug/-un` | 混合短元音 |
| 29-32 | `sh/ch` | `ship/chip` 等定位 | 词族 |
| 33-36 | `th/ck/ng` | 词尾和组合拼图 | `sh/ch` |
| 37-40 | `st/sp/sl/sk` | 连缀读词 | 组合音 |
| 41-44 | `nd/nt/mp/ft` | 词尾连缀 | 首尾音 |
| 45-48 | 2 句短文 | 先读词后开图 | 混合 CVC |
| 49-52 | 4 句迷你故事 | 排序、回答意义题 | 连缀/组合 |
| 53-56 | 易错音复习 | 个人错音卡 | `+1/+3/+7` |
| 57-60 | 个人小书和亲子朗读 | 选择、跟读、展示 | `+14` 和迁移 |

日级运行数据允许把一个区间拆成多日活动；不得为了显示 60 格而生成没有目标和证据的占位课。
