# 自然拼读自研课程

> 本目录采用 `00-README.md` 到 `05-资料生产与版权规范.md` 的专项资料包形式；本 README 保留为历史入口兼容页，新的执行入口从 [00-README.md](00-README.md) 开始。

本目录是个人工作台英语专区的自然拼读课程设计与研究入口。课程以 60 日路线为长期资料框架，资料底座已经落地；网页工作台本轮只保留轻量英语测试入口，不把 60 日内容全量接入首页或课程引擎。

## 目录边界

- `猿编程-自然拼读项目-计划.md`：外部课程方案，仅作需求背景和对照资料。
- `自然拼读自研课程方案-v1.md`：本项目采用的教学与实施方案。
- `课程决策与家长执行建议.md`：是否报班、四周试运行和家庭执行标准。
- `research/`：联网调研、教材摘要、来源和许可证证据；不作为运行时数据。
- `research/source-matrix.md`：已核验来源、许可证证据、用途和发布状态。
- `../../data/preschool/english/phonics/`：程序读取的规范化课程数据。
- `../../assets/generated/preschool/phonics/`：通过版权审核后可发布的图片、音频和打印素材。

## 当前状态

- 课程入口仍属于英语专区，不新增顶层导航。
- 60 日课程、词库、短句库和复习规则已建立，并通过自然拼读专项数据 QA。
- 运行时边界：工作台只记录简单测试/活动完成证据和幂等奖励；完整 60 日路线留在资料库，按真实使用需要再选择性接入。
- 所有第一版文字内容标记为 `project-original`。
- 外部绘本、音频、图片只记录来源和授权，不直接复制到运行数据。
- 原始下载缓存位于 `tmp/phonics-downloads/`，不作为运行时资源。

## 使用原则

先完成数据和孩子实际使用验证，再批量生成素材和接入页面。课程浏览不发奖励，只有真实完成的活动才复用工作台现有奖励链路。
