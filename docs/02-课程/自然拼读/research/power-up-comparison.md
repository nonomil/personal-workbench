# Oxford Phonics World 与 Cambridge Power Up 对比

更新时间：2026-08-02

## 结论先行

两套产品不是同一类教材：

- `Oxford Phonics World` 是自然拼读专项课程，适合回答“孩子如何系统学音素、字母音、合成、解码”。
- `Power Up` 是 Cambridge University Press & Assessment 的小学综合英语课程，适合回答“孩子如何在听说读写、词汇、语法、任务和考试路线中持续学英语”。

如果当前目标是自然拼读，优先选择 `Oxford Phonics World` 作为家庭参考，或直接执行个人工作台的原创 60 日路线；不建议把 `Power Up` 当作自然拼读主教材。若目标是完整的校外英语课程，再考虑 `Power Up Start Smart` 或相应级别，但通常不需要两套都作为主教材。

官方页面核验到：纸质课程为 5 个 Level，产品页称覆盖 44 个英语音；包含 Phonics Friends、动作歌曲、chant、游戏、图片词典和 Phonics Readers。Level 1 学生站还提供视频、图片词典、Class CD、卡片和书写页。官方应用页面标注 3 岁以上、3 个应用 Level 和 200+ 单词；应用的 3 Level 不等同于纸质课程的 5 Level。

### Cambridge Power Up

- [Power Up 第一版官方目录页](https://cambridgelatamcatalogue.org/product/powerup/)
- [Power Up Second Edition 官方目录页](https://cambridgelatamcatalogue.org/product/power-up-second-edition/)
- [Cambridge English 少儿课程入口](https://www.cambridgeenglish.org/learning-english/parents-and-children/primary/)

官方目录页核验到：第一版为 7 个层级，包含 Level 0 `Start Smart`（标为 pre-literacy）和 Level 1-6，CEFR 为 Pre-A1-B1，适用对象标为 Primary，建议每周 5-8 小时。课程定位是 general English 与 Cambridge English Qualifications 综合路线，包含 Pupil's Book、Activity Book、Teacher's Book、Home Booklet、数字教材、音频、视频、任务项目和测评资源。

Second Edition 官方目录页同样列出 `Start Smart` 和 Level 1-6，并强调 real-world Missions、Cambridge Life Competencies、视频/歌曲/rap/dialogues、家庭复习册和 Cambridge One 数字资源。官方页面没有把它描述为独立的、按音素递进的自然拼读课程；早期层级可承担 pre-literacy、初始字母音和读写启蒙，但不能据此替代专项 phonics sequence。

## 对比

| 维度 | Oxford Phonics World | Cambridge Power Up |
| --- | --- | --- |
| 产品类型 | 自然拼读专项 | 综合英语课程 |
| 官方覆盖 | 5 个纸质 Level，44 个英语音 | Start Smart + Level 1-6，Pre-A1-B1 |
| 核心目标 | 音素意识、字母音、合成、解码和早期阅读 | 听说读写、词汇、语法、项目任务、学习能力和考试准备 |
| 拼读地位 | 主线能力 | 早期读写/拼读活动的一部分，不是产品主线 |
| 兴趣设计 | 朋友、动作、歌曲、chant、游戏、图片词典、Phonics Readers | Jim/Jenny 任务、故事、视频、歌曲、rap、对话、协作任务 |
| 适合当前幼儿自然拼读目标 | 高 | 中低；应选 Start Smart/低级别并确认当地版本内容 |
| 家庭执行负担 | 可拆成短时专项练习 | 更像完整课程，官方建议 5-8 小时/周，通常需要较完整的教材与数字资源 |
| 对个人工作台的可用方式 | 购买后家庭参考；借鉴活动节奏 | 购买后作为综合英语课程参考；不导入教材内容 |
| 发布版权 | Oxford University Press 版权，无开放再发布授权 | Cambridge University Press & Assessment 版权，无开放再发布授权 |

## 给个人工作台的决策

### 保留

- 保留原创 60 日自然拼读路线、原创词库、可解码短句和复习规则。
- 保留开放授权绘本候选库，但绘本用于兴趣、听力、理解和复述，不强行当作 phonics 解码材料。
- 保留英语专区内的单个自然拼读任务入口，不新增顶层导航、第二套积分或第二套课程账本。

### 可以购买参考

- 当前若只想补自然拼读：优先看 `Oxford Phonics World Level 1`，先确认纸质版本、音频/数字资源和孩子是否愿意跟读。
- 当前若要完整英语课程、课堂节奏和 Cambridge 考试路线：再看 `Power Up Start Smart` 或当地教师根据真实水平推荐的级别。
- 不建议同时购买两套并行推进。一个主线负责系统进度，另一套最多作为听说、故事或课堂补充。

### 明确不复制

- 不复制 Oxford 或 Cambridge 的教材页、音频、视频、卡片、角色、故事、题目、答案、数字资源或品牌视觉。
- 不把商业教材的章节、单词表或任务名称写入运行时课程数据库。
- 不把没有单项许可证证据的网盘 PDF、盗版音频或截图放入 `Data`、`assets` 或发布制品。

## 与 60 日路线的映射

个人工作台继续以原创路线为事实来源。商业教材只用于家庭对照，不作为运行时依赖：

1. 第 1-5 天：听音、音节、押韵、首音和口头合成。
2. 第 6-20 天：`s a t p i n m d`、短 `a/i`、CVC 合成和分解。
3. 第 21-36 天：短 `o/e/u`、词族和 `sh/ch/th/ck/ng`。
4. 第 37-52 天：辅音连缀、可解码短句和短文。
5. 第 53-60 天：混合复习、迁移、亲子共读和学习证据回顾。

如果家庭使用 Oxford：每天从对应 Level 选一个听音/合成/读本活动，再在工作台记录原创 lessonId；不要导入 Oxford 原文。如果家庭使用 Power Up：把其中的歌曲、故事、对话作为综合英语输入，phonics 任务仍由工作台原创路线提供；不要用 Power Up 的综合课时替代每日专项解码练习。

## 采购与试听判断

购买前只检查三件事：

- 孩子是否能接受声音模仿、字母卡和短时跟读，而不是只喜欢动画。
- 教材是否明确示范 blending/segmenting，并让孩子读已教规则的词，而不是依赖图片猜词。
- 资源是否来自正版渠道，音频、数字账号、纸质书和售后范围是否说清楚。

当前建议是先用个人工作台原创路线执行 4 周；如果家长希望有现成的声音示范和读本，再购买 Oxford Phonics World Level 1 作为家庭辅助。只有当家庭还需要完整的听说读写课程、课堂任务和考试路线时，才考虑 Power Up。

## 许可证边界

两套商业教材的官方产品页能证明出版方、产品结构和可购买的资源形态，但没有给个人工作台提供开放再发布许可。因此本项目将二者标记为 `reference-only`：可引用事实和外链，不将教材内容、音视频和插图纳入发布制品。
