以下是针对 **1500 汉字 + 500 英语单词**学习目标，整理的全部开源项目、数据资源与整合方案。所有资源均可在工作台中直接引用或改造。

## 一、1500 汉字：数据资源

### 1.1 字表来源（国家标准）

| 字表 | 字数 | 说明 | 适用场景 |
|------|------|------|----------|
| **《通用规范汉字表》一级字** | 3500 字 | 教育部2013年颁布，基础教育和文化普及用字 | 从3500字中取前1500高频字 |
| **《义务教育语文课程》常用字表** | 3500 字 | 2022年版课标 | 与一级字表基本重合 |
| **《现代汉语常用字表》** | 3500 字 | 老版常用字表 | 备选参考 |

**取字策略**：从《通用规范汉字表》一级字（3500字）中，按使用频率取前1500个，覆盖小学1-2年级全部生字 + 3年级大部分生字。

### 1.2 开源数据仓库（可直接引用）

**① Make Me a Hanzi**（最核心的数据源）

- **地址**：`github.com/skishore/makemeahanzi`
- **数据量**：9000+ 常用简繁体汉字
- **包含字段**：character、definition、pinyin、decomposition（字形结构）
- **图形数据**：`graphics.txt` 包含所有汉字的**笔顺矢量图形**，可生成 SVG 笔顺动画
- **格式**：每行一个 JSON 对象
- **协议**：数据来源 Unihan + CJKlib + 开源字体
- **配套**：提供 `svgs.tar.gz` 动画 SVG 包

**② ben-hua/general_standard_chinese**（结构化最完整）

- **地址**：`github.com/ben-hua/general_standard_chinese`
- **数据量**：8105 字（含全部三级字表）
- **包含字段**：拼音、**声母/韵母/声调**、笔画、部首、繁体、五行、五笔
- **文件**：`gsc_pinyin_with_tone.csv` 含多音字第一个拼音的声韵调拆分
- **分级文件**：`gsc_level_1.txt`（3500字）可直接提取

**③ chinese-dictionary**（最全解释库）

- **地址**：`gitcode.com/gh_mirrors/ch/chinese-dictionary`
- **数据量**：超 20000 汉字
- **包含**：`char_common.json`（3500常用字）、`char_common_base.json`（拼音+笔画）、`char_common_detail.json`（解释）
- **分类**：最常用字（500）+ 较常用字（2000）+ 次常用字（1500）

**④ @xiee/zdict**（NPM 包，最易集成）

- **地址**：`npmjs.com/package/@xiee/zdict`
- **数据量**：7000 通用汉字
- **来源**：从汉典网站抓取，**初衷是辅助小朋友识字**
- **格式**：`js/data-chars.js`，直接 import 使用
- **优势**：无需处理 CSV/JSON 文件，直接 NPM 安装

**⑤ cnchar**（功能最全面的 JS 工具库）

- **地址**：`github.com/gong19861217/cnchar`
- **功能**：拼音（含多音字）、笔画、偏旁、**组词**、成语、语音、可视化
- **在线试用**：`theajack.github.io/cnchar`
- **应用案例**：汉字打字游戏、打字弹钢琴、成语接龙等
- **优势**：一个库解决拼音、组词、笔画全部需求

## 二、500 英语单词：数据资源

### 2.1 词表来源（国家标准）

| 词表 | 词数 | 说明 | 适用场景 |
|------|------|------|----------|
| **《义务教育英语课标》二级词汇** | 505 词 | 2022年版课标，小学阶段应掌握的基本词汇 | **核心词表，直接使用** |
| **课标拓展词汇** | 100-300 词 | 各地可根据实际情况增加 | 补充至500+ |
| **数字/月份/星期等** | ~60 词 | 课标要求掌握的附属词汇 | 额外补充 |

**取词策略**：以课标505词为基础，补充100-300拓展词，总词汇量达到500-600词。

### 2.2 开源词库（可直接引用）

**① PEP Words**（最匹配小学教材）

- **地址**：`github.com/lizliz404/pep-words`
- **数据**：人教版 PEP 英语词汇，**小学/初中分库**
- **功能**：查词、浏览、收藏、卡片复习、小测验
- **数据文件**：`src/data/primary_school.json`
- **在线体验**：`pep-words.lizliz.xyz`
- **优势**：直接对应小学英语教材，与工作台定位高度匹配

**② Dolch Sight Words**（220 高频词）

- **地址**：搜索 GitHub `dolch-sight-words` 或 `sight-words`
- **词数**：220 个高频词
- **分级**：Pre-primer(40) → Primer(52) → Grade1(41) → Grade2(46) → Grade3(41)
- **覆盖率**：占儿童读物文本的 50-75%
- **适用**：作为课标词的补充，覆盖高频视觉词

**③ 英语词汇库（47万词条）**

- **地址**：搜索 GitHub `english-vocabulary`
- **数据量**：466,000+ 英语单词
- **覆盖**：基础词汇到专业术语
- **用途**：可从中提取小学阶段词汇

**④ Vocabulary Flash Cards 项目**

- **地址**：`github.com/jonny50905/VocabularyFlashCards`
- **功能**：自訂單字庫、統計追蹤、智慧複習
- **格式**：可导入自定义单词库

**⑤ GPT 生成的字典库（含 SVG 单词卡）**

- **地址**：`github.com/Tofu-Xx/dictionary`
- **数据量**：10万单词
- **特色**：每个单词含2个 SVG 单词卡
- **附带**：生成单词卡的 prompt 和自定义生成网站

## 三、整合方案

### 3.1 数据层整合（工作台直接引用）

```
工作台数据层
│
├── 汉字数据（1500字）
│   ├── 字表：从 gsc_level_1.txt 取前1500字
│   ├── 拼音/笔画：从 ben-hua/gsc_pinyin_with_tone.csv 读取
│   ├── 组词：调用 cnchar.getWords(char) 动态生成
│   ├── 笔顺：从 Make Me a Hanzi/graphics.txt 读取矢量数据
│   └── 配图：kids-learning-cards 生成或 Grok Imagine 批量生成
│
└── 英语数据（500词）
    ├── 词表：PEP Words primary_school.json 为基础
    ├── 补充：Dolch 220高频词（去重后补充）
    ├── 释义：从英语词汇库（47万词）提取
    └── 配图：GPT字典库的SVG单词卡或Grok Imagine生成
```

### 3.2 代码层整合（NPM 包直接安装）

```bash
# 汉字工具
npm install cnchar              # 拼音、笔画、组词、成语
npm install @xiee/zdict         # 7000字拼音释义

# 笔顺动画
npm install hanzi-writer        # 笔顺动画JS库

# 英语数据（直接复制 JSON）
# 从 PEP Words 仓库复制 primary_school.json
# 从 Dolch 列表复制 220 高频词
```

### 3.3 内容生成流程

**汉字内容（1500字 × 5项）** ：

| 内容项 | 生成方式 | 工具/来源 |
|--------|----------|-----------|
| 字表 | 从一级字表取前1500 | ben-hua 仓库 |
| 拼音+声调 | 从 CSV 读取 | ben-hua/gsc_pinyin_with_tone.csv |
| 组词（每字3-5个）| 动态调用 API | cnchar.getWords() |
| 笔顺 SVG | 从数据文件提取 | Make Me a Hanzi/graphics.txt |
| 配图 | 批量生成 | kids-learning-cards + pollinations |

**英语内容（500词 × 4项）** ：

| 内容项 | 生成方式 | 工具/来源 |
|--------|----------|-----------|
| 词表 | 课标505词 + Dolch补充 | PEP Words+ Dolch |
| 释义 | 从词库提取 | 英语词汇库（47万词） |
| 例句 | 从词库提取或生成 | GPT字典库 |
| 配图 | SVG生成或Grok Imagine | GPT字典库的SVG单词卡 |

## 五、实施建议

### 第一阶段：数据准备（2-3天）

1. 从 `ben-hua/general_standard_chinese` 提取前1500字 → 生成 `chars_1500.json`
2. 从 `PEP Words` 复制 `primary_school.json` → 生成 `words_500.json`
3. 补充 Dolch 220高频词（去重）→ 合并到英语词库

### 第二阶段：内容生成（3-5天）

1. 用 `cnchar.getWords()` 为1500字生成组词 → 存入数据文件
2. 用 `Make Me a Hanzi/graphics.txt` 提取笔顺数据 → 生成 SVG
3. 用 `kids-learning-cards` 或 Grok Imagine 批量生成配图

### 第三阶段：工作台整合（2-3天）

1. 识字模块改为从 `chars_1500.json` 读取数据
2. 英语模块改为从 `words_500.json` 读取数据
3. 笔顺动画接入 `hanzi-writer` 库

**总计工作量：约 7-11 天**，即可完成 1500 汉字 + 500 英语单词的完整数据建设。
