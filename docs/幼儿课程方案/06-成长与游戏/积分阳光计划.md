# 积分阳光计划

| 账本 | 来源 | 消耗/用途 | 是否学习能力 |
| --- | --- | --- | --- |
| `sunlight` | 活动完成、首次行动、日闭环 | 植物、浇水、家长奖励 | 否，只是反馈货币 |
| `totalSunlightEarned` | 阳光累计 | 阶段解锁和统计 | 否 |
| `defenseEnergy` | 唯一活动事件 | 发射豌豆 | 否 |
| `growthPoints` | 花园种植/升级规则 | 植物阶段 | 否 |

任何新模块先提交 reward event 设计，不能直接读写 `petbank_points` 或另造 `sunBalance`。
