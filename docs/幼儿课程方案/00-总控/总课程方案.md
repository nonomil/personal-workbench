# 总课程方案

## 1. 60 日阶段

| 阶段 | 天数 | 课程结果 | 花园表现 |
| --- | --- | --- | --- |
| 认识与热身 | 1-10 | 能听、看、数、模仿和完成简单配对 | 太阳芽发芽，开放基础工具 |
| 形成技能 | 11-25 | 在引导下完成学科核心动作 | 解锁豌豆能量和第一条防守路线 |
| 组合应用 | 26-45 | 在新情景中迁移已学技能 | 植物可升级，出现不同友好入侵者 |
| 复习与表达 | 46-60 | 能展示作品、朗读、解释或完成亲子任务 | 解锁成长徽章和家长奖励确认 |

## 2. 四段式模板

每个学科的每日活动必须填充以下字段：

| 字段 | 含义 |
| --- | --- |
| `warmup` | 复习一个已经见过的音、字、数量、动作或画面 |
| `teach` | 只引入一个主要目标，给出示范 |
| `practice` | 让孩子至少操作两次，允许重试 |
| `apply` | 用新情景、生活物品、短句或作品收尾 |
| `evidence` | 记录可观察行为，不记录“打开过页面” |
| `reviewTags` | 指向下一次复习内容 |

## 3. 每日配比

- 语言/阅读：1 项核心，8-12 分钟。
- 数学/探索：1 项核心，8-12 分钟。
- 身体/表达：1 项核心，5-10 分钟。
- 可选：最多 3 项，默认折叠，完成不改变核心三项的完成判定。
- 每日新内容占互动时间不超过约一半，其余为回顾、混合或应用。
