# 幼儿课程总控

本目录只维护幼儿版课程的共同约束。项目级范围、当前进度、工作树和发布状态统一由上级 [项目总控](../../00-总控/README.md) 管理。

学科可以有自己的题型和顺序，但不能自行新增积分账本、日期格式、课程完成 ID 或同步协议。

阅读顺序：项目总控 → 当前状态 → 总方案 → 总课程方案 → 数据与奖励合同 → 总计划 → 总资料计划 → 总实施计划。

## 当前范围

- 当前优先验证幼儿版 14 天 MVP，不把 60 日全学科资料当作已完成目标。
- 课程完成必须能进入今日活动、留下可观察证据并通过统一奖励事件结算。
- 花园、植物、入侵者和动画只提供反馈，不决定学习正确性，也不扣除学习资源。
