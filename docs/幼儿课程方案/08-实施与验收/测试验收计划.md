# 测试验收计划

## 数据测试

- 课程 ID 唯一、必填字段完整、复习日期正确。
- 可解码文本规则检查、数学答案计算、奖励 event 幂等。
- v1-v5 快照导入导出和 Profile 隔离。

## 浏览器测试

- 入口和深层路由：`overview`、`garden`、`checkin`、`courses`、`mistakes`、`rewards`。
- 视口：320、375、390、441、768、1440px。
- 交互：展开学习专区、进入课程、答错/重试/完成、领取阳光、发射豌豆、家长确认。
- 环境：无语音、无图片、离线、减少动效、刷新和后退。

## 发布测试

运行项目 AGENTS 维护说明中的 smoke、回归、Pages 制品和 APK 构建命令；测试产物只放 `tmp/`。
