# 小红书案例拆解

## 案例摘要

用户提供的公开笔记以 WorkBuddy 为工具背景，展示了一个面向孩子暑假的学习工作台。它的亮点不是单纯的待办清单，而是把“学习计划”转成了连续反馈：任务完成、阳光积累、植物成长、语音鼓励、奖励中心和家长互动。

## 可迁移结构

| 公开案例结构 | 本工作台的抽象 | 当前状态 |
| --- | --- | --- |
| 语数英日常任务 | 语文、数学、英语课程目录与今日计划 | 已实现 |
| 完成任务获得阳光 | 儿童版阳光账本、完成率、连续天数 | 已实现；每个事件只奖励一次 |
| 植物成长/僵尸入侵 | 阳光、植物阶段、漏打卡僵尸状态和完成行动后的驱散 | 已实现原创规则，不使用原案例角色素材 |
| 语音暖心夸奖 | 操作成功 Toast 与浏览器 `speechSynthesis` | 已实现开关；浏览器不支持时仍保留文字反馈 |
| 错题本 | 儿童版独立错题记录、错因、正确思路和复习状态 | 已实现基础闭环 |
| 奖励中心 | 儿童版阳光兑换页、成长目标和里程碑 | 已实现基础领取闭环；线下兑现仍由家庭约定 |
| 打卡统计 | 7 天专注柱状图、完成率、连续天数 | 已实现 |
| 亲子互动 | 独立家庭互动 feed、家长鼓励、孩子成长分享 | 已实现本地 feed；云端实时协作仍未实现 |

## 不照搬的内容

- 不使用植物大战僵尸角色、关卡、音效、文案或截图。
- 不把小红书图片下载进产品素材。
- 不把 WorkBuddy、Supabase 或第三方图片描述成当前工作台运行依赖；账号和同步使用现有自托管 API。

## 设计判断

工作台应先让用户完成一个真实动作，再让数据产生意义。因此首页的行动按钮直接围绕“添加今日计划、开始专注、记录阅读、推进目标”，而不是只展示装饰性的等级或积分。
