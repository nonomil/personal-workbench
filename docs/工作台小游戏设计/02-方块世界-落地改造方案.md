# 方块世界 · 落地改造方案

> **给实施者：** 方块世界的成长任务已经写好（挖、放、收集），但运行页被改成了史蒂夫横版。这是身份错误，不是缺引擎。把它改回 2D 点挖点放，接到现有任务表。

**目标：** 打开 `prj/games/voxel-adventure/index.html`，点击挖方块、放进热键栏、再点空地放下；完成 `data/quests.js` 里一条任务即发阳光。一局 3–5 分钟。

**架构：** 保留文件夹与 `GAME_ID = 'voxel-adventure'`。用二维网格世界替换当前横版 `player/vx/vy`。任务判定读 `quests.js`，进度仍写 `growth.worldGames.voxel-adventure`。

**技术栈：** Vanilla JS + Canvas 或 Canvas 网格；已有 `preschool-theme-assets/voxel-v1`。不要 Three.js、Eaglercraft、Docker 服务器。

## 3. 成长型怎么接

进度键保持兼容（`workbench-bridge` 已认两种）：

```text
growth.worldGames.voxel-adventure
  questsDone[]          // 优先
  clearedLevels[]       // 兼容旧横版；本轮可停写，勿删读取
  rank / minerLevel     // 按 quests.js RANKS
```

发奖：

```text
bridge.awardSunlight({
  gameId: 'voxel-adventure',
  eventKey: 'quest-' + questId,   // 生涯任务只领一次
  amount: quest.reward
})
每日挑战：
  eventKey: 'daily-' + today + '-' + daily.key
```

`quests.js` 已覆盖成长曲线，**不要另写 10 关破坏计数**。短局目标 = 当前未完成的生涯任务或今日挑战。

建议 HUD：「当前任务：铺一条小路 3/8」而不是「第 1 关晶体 0」。

矿工等级：完成 `needQuests` 后升 rank，只改显示与可挖层（rank2 可挖石，rank3 更深），不新开货币。

## 5. 玩法循环（从参考抽来的最小集）

```text
world[y][x] = { kind: 'grass'|'dirt'|'stone'|'wood'|'crystal'|'bedrock'|'air' }

工具：
  hand  — 挖草/土
  axe   — 挖木
  pick  — 挖石/晶体（rank 不够则提示「先完成前面的任务」）
  place — 把热键栏选中物放到 air

点击格子：
  place 模式 → 库存>0 则放下，quest 计数 +1
  其它 → 按工具能否挖，进库存

过关/完成：
  对照当前 quest.type
    build / build_total / collect / collect_total / blocks_alive / build_any
  满足 → awardSunlight + questsDone.push
```

地图不要无限生成。固定一块「家园」+ 往下 2～3 层矿，适合幼儿，也方便任务「世界中同时有 25 个方块」。

操作：鼠标/触控点击即可；可选 WASD 移动相机，不要做成平台跳跃。

一局建议：进入页后直接是世界，顶部一条当前任务，完成后 toast + 阳光，不必先选 8 张关卡卡。关卡地图可改成「任务墙」。
