好，既然游戏内容丰富程度不是限制条件，那重点就放在 **“如何让这些游戏成为工作台长期成长的一部分”** 。核心是建立 **游戏券 → 时间限制 → 奖励反馈 → 工作台账本** 的闭环。

## 一、整体架构：游戏作为工作台的“成长引擎”

把三个游戏定位为：
- **阳光花园**：策略 / 资源管理 → 对应“规划力”
- **方块世界**：创造 / 探索 → 对应“创造力”
- **横版闯关**：反应 / 操作 → 对应“执行力”

> 每个游戏都是工作台的一个“成长维度”，不是独立小游戏。

```
工作台与游戏的接口层：
┌─────────────────────────────────────────────────────────────┐
│  【工作台 → 游戏】                                         │
│  游戏券余额 → 游戏前消耗                                    │
│  每日剩余时间 → 游戏时长限制                               │
│  已解锁关卡 → 游戏内容开放                                 │
│  宠物饱食度/心情 → 游戏内增益/减益                         │
├─────────────────────────────────────────────────────────────┤
│  【游戏 → 工作台】                                         │
│  通关记录 → 阳光入账 (每日上限80)                          │
│  游戏内收集 → 经验值 → 宠物成长                           │
│  里程碑达成 → 徽章解锁                                     │
│  游戏总时长 → 专注力统计                                   │
└─────────────────────────────────────────────────────────────┘
```

## 五、游戏难度与学习进度联动（核心成长机制）

这是把游戏和工作台绑定的关键——**游戏难度随学习进度动态调整，学习越好，游戏越有挑战（但奖励也更多）**。

| 学习进度 | 游戏变化 | 奖励加成 |
|---------|---------|---------|
| 识字 < 100 字 | 游戏为“简单模式”（敌人慢、关卡短）| 基础奖励 |
| 识字 100-200 字 | 解锁“普通模式”（敌人速度 +30%）| 奖励 ×1.5 |
| 识字 > 200 字 | 解锁“困难模式”（额外敌人 + 隐藏关卡）| 奖励 ×2 |
| 英语 > 100 词 | 方块世界解锁新方块类型 | 奖励 ×1.5 |
| 数学闯关 > 10 关 | 花园解锁新植物 | 奖励 ×1.5 |
| 全部打卡完成 | 当日游戏券 +1 | — |

### 8.1 游戏券发放

```javascript
// 在任务完成回调中发放游戏券
function onDailyTasksComplete() {
  // 原有阳光奖励逻辑

  if (state.gameTickets.balance < 20) {
    state.gameTickets.balance += 3;
    state.gameTickets.totalEarned += 3;
    showTicketEarnedAnimation(3);
  }
  saveState(state);

```

### 8.2 游戏时长限制

```javascript
// 游戏启动时检查
function canStartGame(gameId) {
  const today = new Date().toDateString();
  if (state.gameTime.todayDate !== today) {
    state.gameTime.todayTotal = 0;
    state.gameTime.todayDate = today;
  }
  if (state.gameTime.todayTotal >= 30) {
    showToast('今天已经玩够啦，明天再来吧！');
    return false;
  }
  if (state.gameTickets.balance < 1) {
    showToast('游戏券不够啦，先去完成今日任务吧！');
    return false;
  }
  return true;
}
```

### 8.3 游戏奖励结算

```javascript
// 游戏结束时调用
function onGameEnd(gameId, result) {
  const state = loadState();
  
  // 1. 扣除游戏券
  state.gameTickets.balance -= 1;
  
  // 2. 阳光入账（每日上限80）
  const today = new Date().toDateString();
  if (!state.sunDaily) state.sunDaily = {};
  const earned = Math.min(result.sun, 80 - (state.sunDaily[today] || 0));
  state.sunBalance += earned;
  state.sunDaily[today] = (state.sunDaily[today] || 0) + earned;
  
  // 3. 宠物经验
  state.pet.exp += result.exp || 0;
  checkPetEvolution(state.pet);
  
  // 4. 徽章检查
  checkGameAchievements(gameId, result);
  
  // 5. 更新游戏时长
  state.gameTime.todayTotal += result.duration || 0;
  state.gameTime.totalMinutes += result.duration || 0;
  
  saveState(state);
}
```

## 十、一句话总结

游戏和工作台的关系从“学完→奖励玩一下”升级为 **“游戏是工作台成长的一部分”** 。三款游戏分别对应三个成长维度（规划/创造/执行），通过游戏券控制节奏、时间限制防沉迷、奖励反馈驱动长期参与，最终形成 **“学习→游戏券→玩游戏→阳光/经验/徽章→宠物成长→解锁更多→继续学习”** 的完整闭环。
