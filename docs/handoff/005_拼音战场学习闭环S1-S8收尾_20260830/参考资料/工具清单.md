# 工具清单

| 工具 | 用途 | 入口 |
| --- | --- | --- |
| `python -m http.server 8642` | 本地预览服务器（仓库根起） | 手动起，走查所有页面 |
| `npm run android:prepare` | prj→dist 同步（APK 资产） | scripts/prepare-mobile.mjs |
| `npm run android:build` | APK 重打包 | android/gradlew assembleRelease |
| `node --test tests/<file>.mjs` | regex 合同式单测 | 本包 9 套件 46 项（见 测试分析报告） |
| `python scripts/build-literacy-quiz-bank.py` | 知识门题库再生成（400 字三选一） | `--count` 可调 |
| `pinyin-pronunciation-kit/scripts/bake_call_audio.py` | edge-tts 音频重烤（`--force` 全烤） | 需 `pip install edge-tts` |
| ZCode 内置浏览器 + `?sim-android` | APK 模式走查 | hash 路由 #overview / #battle / #courses |
| 浏览器 CSSOM 规则追踪 | 层叠冲突定位 | evaluate 遍历 document.styleSheets + el.matches |
| `node --check <file>` | JS 语法门禁（补丁后必跑） | — |
| `python -m json.tool` / ast.parse | JSON / Python 脚本校验 | — |
