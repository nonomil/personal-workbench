## 模拟 APK 环境的三种途径

1. URL 加 `&sim-android`（launcher.js / 游戏端 game.js 识别）——最常用
2. 真机/模拟器 Capacitor 运行时自动探测
3. MuMu 模拟器 + ADB（历史验收用过，见 002 包与 T20260816 test-report）

## 已知环境坑

- `npm run android:prepare` 在 Windows 偶发 `ENOTEMPTY rmdir dist\...`：先 `rm -rf dist` 再跑
- Git Bash heredoc 内嵌长 python 脚本偶发截断：改用 `Write` 工具落盘 `tmp/*.py` 再执行
- 中文路径（仓库名"个人工作台"）：curl/浏览器访问用 percent-encoding 或直接走 127.0.0.1 根相对路径
