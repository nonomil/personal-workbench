# 解决方案（按问题索引的"一行修法 + 落点"）

详细根因见 [根因分析](./根因分析.md)。此处供快速检索。

| 问题 | 一行修法 | 落点 |
| --- | --- | --- |
| 识字页 web 横屏堆叠 | 解锁视口高度锁死 → min-height + 自然滚动 | `40-literacy-uplift.css` @media(max-width:860px,landscape) |
| 识字页 APK 舞台裁切 | 舞台行定高 `minmax(0,1fr) 72px` + 卡宽 `min(360px,68%)` + 纸底不透明 | `56-phone-landscape-focus.css` 主题块 |
| 首页任务卡溢出 | `width:min(400px,64vw)!important + height:auto!important` 收口 | 同上（home-top 收口注释处） |
| 数学/拼音卡被 56px 行裁切 | 场景页走道统一 64px + 卡簇 rows:none 内容自增 | 同上 `:not(.is-card-wall)` 块 |
| 古诗卡 27px 细条 | tone-pink 专属：走道 64px + 自评一行 + 诗头插画 44px | 同上 |
| 发音读例字 | 烘焙呼读字 22 mp3 + 运行时呼读表 + 顶层字段读取 | 烘焙脚本 / `app.js` / `preschool-pinyin.js` 契约 |
| 特效被重渲染抹掉 | `setTimeout(80)` 后挂新 DOM | `app.js` mark 分支 |
| 跳转游戏小窗 | URL 追加 `&sim-android=1` | `app.js openPreschoolWorldGame` |
| 走道伙伴下半身被裁 | rail/list/cell/art 四层 flex 定高链 + img height:100% | `56` 主题块 |
| 学习↔游戏权闭环验证 | `bridge.grantPlayPass` 可在控制台模拟学习奖励 | 走查辅助手段 |
| 知识门打断节奏 | 门频率 5 + 庆祝降级 + 答错仍种 | `game.js QUIZ_GATE_INTERVAL` + `suppressSceneCelebration` |

