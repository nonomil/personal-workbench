## 2. 知识门时序（每关首棵 + 每 5 棵）

```mermaid
sequenceDiagram
    participant K as 孩子(点草坪)
    participant P as placeAt
    participant Q as maybeQuizThenPlace
    participant D as bridge.drawLiteracyQuiz
    participant O as quiz-gate 弹层
    participant R as doPlace(种植)
    K->>P: pointerdown 草坪
    P->>Q: point
    Q->>Q: quizPlantsThisStage % 5 != 0 ?
    alt 非门点
        Q->>R: 直接种
    else 门点(0,5,10...)
        Q->>D: count=1
        alt 有动态题库
            D-->>Q: {char, pinyin, options[3]}
            Q->>O: 「字」怎么读? 三选拼音 + 朗读
        else 题库缺失
            Q->>O: LearningDefenseCards 图配字卡
        end
        K->>O: 点选项
        alt 答对
            O->>O: is-correct → 250ms 关
        else 答错
            O->>O: is-wrong + 高亮正确答案 → 850ms 关
            O->>B: recordLearningOutcome(wrong)
        end
        O->>R: doPlace(pendingPoint)
        R->>R: 成功则 quizPlantsThisStage += 1
    end
```
