# 关键发现（接手必读的六条硬事实）

全部为【已验证】（浏览器实测 / 定向测试 / 构建产物核对），来源路径随条目给出。

## 1. 两套渲染模式必须分开验证

同一 URL 加不加 `&sim-android` 走完全不同的 CSS 合同：

| 模式 | 触发 | 布局特征 |
| --- | --- | --- |
| 纯 Web | 无参数 | 文档自然滚动；识字页横屏 ≤860px 有专用规则 |
| APK 模拟 | `?sim-android`（真机走 Capacitor 探测） | `html.is-android-app`；场景页三列战场；页面锁 100dvh 不滚动 |

`prj/launcher.js` 与 `prj/games/garden-defense/game.js` 都有 `wantsSimulatedAndroid()`。
**验证任何布局必须两模式都截**，否则会出现"本地好了真机坏"或反之。

## 2. 场景战场的规则几乎全在一处

`prj/css/preschool/56-phone-landscape-focus.css` 的
`@media (orientation: landscape) and (max-height: 480px)` 块内，
主题作用域前缀：

```
html.is-android-app body.variant-preschool:is([data-world-theme="garden-defense"], [data-world-theme="platform-quest"], [data-world-theme="voxel-adventure"])
```

三列网格在 `.preschool-flashcard-page.is-scene-focus`（`auto 1fr auto` 单行三列）；
文件**末尾有一条基线 `.preschool-scene-zombie-rail { display: none; }`**——
56 块内的主题规则负责在安卓场景页把它打开。新增敌人/布局规则放在该 media 块**末尾**，
否则会被 40~53 号层的同名属性反压（踩过一次，已把整块挪到块尾）。

## 3. 拼音数据的真实形状（最容易踩的坑）

`prj/preschool-pinyin.js parseBank()` 返回的行是**拆平后**的：

```js
{ id, text:'b', initial:'b', sample:'爸', pinyin:'bà', kind:'initial', group:'lips',
  level:'L1', homophones:[], nearPhones:[], art, media }
```

**没有 `extra` 字段**。呼读表/拼读/转盘全部读顶层字段；`tests/pinyin-pronunciation.test.mjs`
里有 `doesNotMatch(item.extra)` 回归锁，不要移除。

## 4. 拼读三件套的联动点

- 呼读表：`prj/app.js` 搜 `PINYIN_INITIAL_CALL` / `PINYIN_FINAL_CALL`
  （同名表在 `pinyin-pronunciation-kit/data/pinyin-call-table.js` 与烘焙脚本
  `tools/tts-portable/generate-content-audio.py PINYIN_CALL_TEXT` 有第三份拷贝——
  **三处必须同步改**，套件测试 K1 只守 kit 那份）。
- 转盘合法音节：`prj/app.js PINYIN_LEGAL_SYLLABLES`（403 个）与
  `pinyin-pronunciation-kit/data/pinyin-legal-syllables.js` 两份。
- 四声条：`pinyinToneForms`（标调规则 a→o/e→iu/ui 后标→i/u/v）+
  `pinyinToneCharIndex`（从识字库 1500 字自动索引例字，如 bà→爸）。
- 转盘激活依赖卡片条目带 `initial` 字段——曾漏透传导致转盘点击无效（已修）。

## 5. 知识门的三个组成（garden-defense）

- 抽题：`prj/games/shared/workbench-bridge.js drawLiteracyQuiz({count})` ——
  读 `globalThis.LiteracyQuizBank`（400 字，由 `scripts/build-literacy-quiz-bank.py`
  从识字库生成，干扰项同声母带调）+ 工作台 mastery（练习中/到期优先→已会→未学，
  日期种子轮换）。
- 门节奏：`prj/games/garden-defense/game.js` `QUIZ_GATE_INTERVAL = 5`，
  `quizPlantsThisStage % 5 === 0` 时弹（首棵必弹）；`doPlace` 成功才计数；
  `enterStage` 重置为 0。
- 兜底：抽题返回空时回退 `LearningDefenseCards`（知识花园固定 10 卡图配字）。
- 回流：答题走 `bridge.recordLearningOutcome`（garden-defense 需要加载
  `shared/workbench-memory.js` 才真正持久化，已挂）。

## 6. 独立套件 pinyin-pronunciation-kit/ 的三份拷贝关系

呼读表在仓库里有**三份**：`prj/app.js`（运行时）、烘焙脚本（生成音频）、
`pinyin-pronunciation-kit/data/pinyin-call-table.js`（对外套件）。
改呼读口径必须三处同步；`tests/pinyin-kit.test.mjs` 只守 kit 那份
（K1 断言波/坡/知/啊/凹/儿/翁），另两份靠
`tests/pinyin-pronunciation.test.mjs` S1/S2 守。
