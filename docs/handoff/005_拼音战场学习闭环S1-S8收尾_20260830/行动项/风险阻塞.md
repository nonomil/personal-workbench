# 风险阻塞

（与 待做实验.md 的风险表互补；这里只列"会卡住接手者"的硬阻塞与口径冲突）

## 口径冲突（必须知道）

1. **呼读表三份拷贝**：`prj/app.js` / `tools/tts-portable/generate-content-audio.py` /
   `pinyin-pronunciation-kit/data/pinyin-call-table.js`。当前内容一致。
   任何修改三处同步，否则出现"页面读对了、重烤音频错了"的音文漂移。
2. **合法音节表两份**：`prj/app.js PINYIN_LEGAL_SYLLABLES` 与
   `pinyin-pronunciation-kit/data/pinyin-legal-syllables.js`（403，一致）。
3. **"S6"编号复用**：方案 07 的 S6 = 知识花园并入主战斗；计划包 steps 的
   S6 = 拼读转盘（已落地）。引用编号时写清楚来源文件，避免歧义。
4. **全量测试基线**：`npm test` 全仓 1061 项中约 43 项失败是**并行工作遗留**
   （blocklegend / play-mods / 50 号 CSS 戳 / wishes 等）。本包门禁只看定向
   46 项套件。不要试图"修绿全仓"——会踩进其他人的工作区。

## 硬阻塞

- 无。所有 P0 项都可立即开工（不依赖外部资源）。
- edge-tts 需要网络（微软在线服务）；离线重烤音频会失败，但**不影响运行时**
  （运行时三级兜底）。

## 敏感点（改前三思）

- `prj/app.js` 是 79 万字符单文件，多处使用 python 正则替换补丁；
  任何替换务必先 `assert s.count(old) == 1` 再替换，替换后 `node --check`。
- `prj/preschool-workbench/index.html` 的缓存戳被并行工作频繁追加
  （曾出现 `&wishes=v1`、`&courses-sun=v1` 半途插入），bump 戳时用精确子串替换，
  不要整行重写。
- `docs/handoff/` 历史包（001~004）只追加不修改。
