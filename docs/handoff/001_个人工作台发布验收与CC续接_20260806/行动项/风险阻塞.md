# 风险阻塞

## 卡点 1：总控与发布文档滞后

- **影响**：接手者可能误判 APK/MuMu 尚未开始，或反过来把局部设备证据误写成全部通过。
- **需要的帮助**：CC 先按 P0 做事实 reconciliation。
- **临时绕过方案**：以本交接包的测试报告和本轮命令输出为当前 APK/MuMu 证据，保留文档历史。

## 卡点 2：完整 APK 路线尚未覆盖

- **影响**：不能宣称三主题、轻量练习、返回和刷新持久化全部通过。
- **需要的帮助**：在已有 MuMu 设备上逐项操作并截图。
- **临时绕过方案**：发布状态写“已下载/已安装/已启动/首个花园已验证，核心全路线待验收”。

## 卡点 3：Chrome CDP 授权未完成

- **影响**：需要浏览器 CDP 的后续线上 UI 操作可能无法执行。
- **需要的帮助**：用户在 Chrome 远程调试授权弹窗中允许连接，或 CC 使用已有 HTTP/本地证据完成不依赖 CDP 的任务。
- **临时绕过方案**：不把 CDP 失败与 APK/MuMu 安装故障混为一谈。
