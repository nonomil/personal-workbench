# 总路线图

路线图按“可运行、可验证、可回滚”推进。未达到退出条件，不进入下一阶段。

## 阶段 0：基线收敛

**目标：** 让项目知道自己当前是什么状态。

**交付：**

- 项目总控、当前状态、进度看板和决策记录。
- 统一正式文档入口为 `G:\StudyCode\个人工作台\docs`。
- 测试失败项有明确原因、负责人和修复任务。

**退出条件：** 文档链接可达，当前任务不超过一个主目标，测试基线可重复。

## 阶段 1：幼儿工作台 14 天 MVP

**目标：** 验证孩子是否愿意每天打开工作台完成短打卡。

**范围：** 首页、今日 3 项、简单测试入口、阳光、奖励、花园状态、本地备份和“去游戏”出口。

**不做：** 60 日全量课程引擎、复杂战斗、云同步、完整家长后台和首页沉浸式动画。

**退出条件：** 连续模拟 14 天，活动不重复发奖，刷新和导入导出不丢进度，移动端无横向溢出。

## 阶段 2：独立游戏 MVP

**目标：** 验证游戏是否能提供额外趣味，而不是把工作台变复杂。

**范围：** 独立植物大战小游戏入口、植物选择、少量敌人类型、简单回合/波次、动画、结束反馈和重新开始。

**退出条件：** 游戏可独立进入和结束，失败可重来，不修改打卡结果，不重复发放奖励。

## 阶段 3：资料按需接入

**目标：** 在工作台和游戏闭环稳定后，按真实使用需求接入古诗、拼音、英语口语、专注和暑假打印资料。

**交付：** 每科有课程表、每日活动、成功证据、复习安排和授权清单。

**退出条件：** 只接入经过试用的内容；新内容不依赖页面硬编码，能够被测试检查并进入今日打卡。

## 阶段 4：家长与同步

**目标：** 让家长看得懂孩子完成了什么，并能在需要时跨设备恢复。

**交付：** 家长观察、待确认奖励、自托管登录、快照 revision、冲突提示和离线降级。

**退出条件：** 本地优先流程不依赖网络，登录、恢复、冲突和失败重试均有测试。

## 阶段 5：发布

**目标：** 发布网页和可安装 APK。

**交付：** Pages 深层入口、Actions APK、下载记录、MuMu 安装验收和版本说明。

**退出条件：** `npm test` 全绿，Pages 制品门禁通过，APK 在模拟器完成核心路线。

## 冻结规则

- 未完成阶段 0，不增加新的大功能。
- 未完成阶段 1，不把课程资料库全量接入工作台。
- 未完成阶段 2，不扩展第二套战斗机制或远端服务。
- 未完成阶段 3，不批量生成未经 QA 的课程和图片。
- 未完成阶段 4，不在 README 中宣称“多设备云同步已完成”。
