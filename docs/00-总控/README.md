# 项目总控

这里是“个人工作台”项目的唯一项目级总控入口，负责三套运行工作台、根入口五种选择、共享技术边界、当前阶段、发布节奏和跨模块决策。

## 阅读顺序

1. [项目总控](项目总控.md)：项目做什么、不做什么，以及什么算完成。
2. [当前状态](当前状态.md)：截至最近一次核对，代码、资料、测试和工作树实际是什么状态。
3. [总路线图](总路线图.md)：当前阶段只能推进哪一条路线，以及每个阶段的退出条件。
4. [进度看板](进度看板.md)：唯一的进行中任务列表，任务必须带证据和下一步。
5. [决策记录](决策记录.md)：已经做出的范围、架构和文档组织决定。
6. [变更与同步规则](变更与同步规则.md)：修改代码、资料、课程和发布配置时如何同步。

## 两级总控

- `docs/00-总控/`：管整个个人工作台项目，包括成人、儿童、幼儿三套运行工作台，以及根入口的三个幼儿主题、测试、发布和工作树。
- `docs/幼儿课程方案/00-总控/`：只管幼儿课程的内容结构、活动证据、奖励和学科接入。

幼儿课程总控不能替代项目总控；项目总控也不展开具体学科教案。

## 维护规则

- 当前事实以代码、数据、测试结果和发布脚本为准，文档不能反向宣称功能已经实现。
- 每次只允许一个“当前主目标”，其他工作进入待办或冻结。
- 日期型 `docs/plans/` 是历史设计和实施记录，不是当前进度来源。
- 没有证据链接、测试命令或文件路径的“完成”不计入完成。
