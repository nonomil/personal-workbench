## 2. 主应用：模块、打卡、学习、存储

### 2.1 入口与变体

根启动器 `prj/index.html` 五入口：

1. 花园保卫战 → `preschool-workbench/?theme=garden-defense`
2. 方块世界探险 → `?theme=voxel-adventure`
3. 横版闯关 → `?theme=platform-quest`
4. 成人成长工作台
5. 儿童学习工作台

三套幼儿主题 共享同一 localStorage，仅换视觉/`preschoolTheme`。

页面元数据定义在 `prj/config.js`。

### 2.2 各变体页面清单

成人（`adultPages`）：概览、今日计划、成长任务、阅读、长期目标、生活分区、归档统计、家庭互动、每周复盘、账号同步、偏好设置。

儿童（`childPages`）：今天、成长地图、今日打卡、学习任务、错题本、语数英课程、阅读、成长目标、奖励中心、家长互动、账号同步、成长日记。

幼儿（`preschoolPages` + 侧栏）：首页、日历打卡、花园保卫战（battle，可外链独立游戏）、花园基地、学习任务、课程资源（9 专区）、改错本、奖励商城、家长互动、设置。

幼儿侧栏学习专区（`preschool-workbench/index.html`）：暑假学习、识字、拼音、古诗、数学、专注力、英语、自然拼读、每日运动。

### 2.3 打卡如何实现

| 变体 | 机制                                                         |
| :--- | :----------------------------------------------------------- |
| 成人 | `adult.habits[].checkedDates` + `dailyPlans` 勾选；生活分区习惯打卡 |
| 儿童 | `dailyPlans` 勾选 → `child-growth.recordAction`；当日首次有效行动写入 `growth.checkinDates`，额外 +10 阳光 |
| 幼儿 | 每天自动种子化 6 项 `dailyPlans`（`storage.js` `PRESCHOOL_DAILY_ITEMS` v3）：完成今日识字、朗读一首古诗、数学闯关一关、学习今日英语、做一项运动、专注力训练一题；多项带 `practiceLessonId` 可「去练习」；完成走同一 `recordAction` / 阳光幂等 |

核心：`prj/child-growth.js` 的 `recordAction` — `awardedIds` 去重；`daily-checkin:YYYY-MM-DD` 每日只奖一次；连续天数由 `checkinDates` 倒推。

日历页：按 `dailyPlans` / `checkinDates` 渲染绿点。

## 3. 游戏部分

### 3.1 `prj/games/` 清单

| 游戏            | 玩法概述                                                     | 规模                    |
| :-------------- | :----------------------------------------------------------- | :---------------------- |
| garden-defense  | PVZ 式：选种子种植物、波次僵尸、点阳光；Canvas 战场          | 约 12 关                |
| voxel-adventure | 方块挖放/背包/任务/走到出口；工坊 overlay；识字量影响难度（playMods） | 约 8 关                 |
| platform-quest  | 横版跑跳、金币、旗子、星条件；触控板                         | 约 10 关                |
| `shared/`       | `workbench-bridge.js` + `growth-hud.css`                     | 生产桥接                |
| `ref/`          | 三游戏参考实现 + 旧 bridge                                   | 对照/素材参考，非主入口 |

工作台内 battle 页仍有 HTML/CSS 防守棋盘（`preschool-garden.js`），与独立 Canvas 游戏并存；独立游戏「返回工作台」链到对应 theme。

### 3.2 `workbench-bridge.js` 做什么

路径：`g:\StudyCode\个人工作台\prj\games\shared\workbench-bridge.js`

- 读写幼儿同一 key
- `getProgress` / `saveProgress` → `growth.worldGames.<gameId>`
- `awardSunlight`：事件幂等 + 每日游戏阳光上限 80
- `grantProgressPoints`：冒险点 → `ADVENTURE_RANKS`（开局阳光/金币/晶体加成）
- 三界今日打卡戳、周目标、里程碑徽章 `MILESTONES`
- `getPlayMods()`：识字掌握数 → easy/normal/hard

### 3.3 `growth-hud.css`

三世界共用 HUD：`.growth-hud` 阳光/等级 chip、`.stage-map` / `.stage-card` 选关、`.toast-game` 提示。纯样式，无业务逻辑。

## 4. 徽章 / 奖励 / 成长现状

### 4.1 已实现机制

| 机制           | 位置                          | 结构                                                    |
| :------------- | :---------------------------- | :------------------------------------------------------ |
| 阳光货币       | `child-growth.js`             | `sunlight`, `totalSunlightEarned`, `awardedIds`         |
| 奖励兑换       | config `childRewards` + claim | `claimedRewardIds`；线下约定奖励，非虚拟道具库          |
| 连续打卡奖励   | `STREAK_REWARDS`              | `claimedStreakRewardIds`；阳光或解锁造型                |
| 独角兽「星芒」 | `growth.unicorn`              | `xp/level/styles`；100 XP/级                            |
| 植物阶段       | `growth.plant`                | 累计阳光阈值                                            |
| 幼儿花园/贴纸  | `preschool-garden.js`         | `garden.*`, `collection.*`                              |
| 成就徽章 19 枚 | `preschool-achievements.js`   | `growth.achievements.{unlocked,history,lastShown,seen}` |
| 主题宠物       | `preschool-pet.js`            | `growth.pet`；喂食扣 5 阳光                             |
| 成长世界三视图 | `preschool-growth-world.js`   | 花园花/地图停/小镇砖（派生自真实进度）                  |
| 世界游戏元进度 | bridge                        | `growth.worldGames.meta` + 分游戏进度                   |

徽章类别：花园铜银金（识字数）、地图铜银金（全日任务完成天数）、建造铜银金（英语/拼读课节）、识字/英语 L2–L5、三域统一银金。

没有独立「券/coupon」运行时；方案文档有「徽章与券」，代码侧是阳光直兑线下奖励。
