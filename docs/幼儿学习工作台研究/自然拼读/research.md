# 自然拼读研究结论

## 已核实事实

1. UFLI 官方说明其课程是显式、系统并有 scope and sequence，材料包括可解码段落。
2. Reading Rockets 说明系统拼读要按有组织的字母-音关系推进，并提供大量累计应用；可解码文本使用已学音-字关系和有限高频词。
3. Open Source Phonics 的公开页面展示了 review、phoneme awareness、概念呈现、读写练习、听写和 repeated reading 组成的课节结构。
4. `phono-storyforge` README 展示了“每个孩子的掌握模型、目标选择、可解码文本生成、确定性 QA、下一次自适应”的工程闭环；它是开源项目设计，不是教育标准。

## 设计推断

- 低龄自然拼读不能从一套字母表静态展示开始，必须让孩子尽早体验合成一个词。
- “会了”至少要有两个不同活动的证据；一次点对不够。
- 图片用于理解和动机，不能替代词形解码；先读词再开图可以减少猜图。

## 本项目采用

- 60 日八阶段路线，内容和奖励映射到英语核心活动，不新增导航和积分。
- `reviewQueue` 使用 `+1/+3/+7/+14`，错题插队。
- 内容采用项目原创短句，规则检查失败则不进入 `data/`。
- 语音只作为示范和可选反馈，不作为完成判定的唯一证据。

## 待补证据

- UFLI 具体课件和印刷页的再分发边界未确认，不复制。
- Open Source Phonics 站点完整许可证未确认，不下载教材。
- 需要在真实幼儿试用后校准每节时长、按钮文字和题目难度；成人研究不能替代用户测试。
