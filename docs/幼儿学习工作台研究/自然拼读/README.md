# 自然拼读专项研究

该目录是自然拼读的研究证据和内容 QA 资料，和 `docs/幼儿课程方案/04-英语/自然拼读/` 的执行合同配套。

## 证据来源

- UFLI Foundations：系统、显式、顺序和工具箱结构。
- Reading Rockets：显式拼读、累计练习和可解码文本原则。
- Open Source Phonics：复习、音素意识、听写和重复朗读结构；授权未核清，只作参考。
- `phono-storyforge`：Apache-2.0，参考“掌握证据驱动下一次内容”和确定性可解码 QA 的软件思想。

## 研究产出

- `research.md`：把证据转为课程判断。
- `sources.md`：来源、访问状态和使用边界。
- `60日路线与内容合同.md`：日级课程和数据字段。
- `可解码文本QA.md`：文本进入发布数据前的检查规则。
