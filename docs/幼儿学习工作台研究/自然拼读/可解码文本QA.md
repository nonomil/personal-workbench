# 可解码文本 QA

## 规则

1. 先把文本分词，标出每个词的允许模式和高频词。
2. 未出现在 `allowedPatterns` 或 `trickyWords` 的词标为 violation。
3. 计算 `decodabilityPercent = 可按已教规则处理的词数 / 总词数 × 100`。
4. 低龄短句优先达到 80% 以上；目标规则练习文本可允许少量已明确教过的高频词。
5. 图片不能替代解码，意义题必须在读词后进行。

## 失败处理

- 构建测试失败，条目停在草稿目录。
- 内容作者选择替换词、提前引入高频词或调整阶段，不能只把 violation 从报告里删掉。
- 通过后保留 QA 报告、内容版本和来源字段，便于复核。
