# 幼儿学习工作台研究资料包

> 研究日期：2026-08-02（Asia/Shanghai）
>
> 本目录是长期资料的唯一来源。代码 worktree 只保留实现所需的方案副本、测试和运行代码，不作为研究档案库。

## 研究目标

把“完成学习任务 → 立即获得反馈 → 在花园里看到成长 → 下一次知道做什么”做成一个能落地的幼儿学习循环，同时保证：

- 每天可以在 20-35 分钟内完成，不把孩子锁在网页前；
- 每个学科有清楚的学习目标、活动证据和复习安排；
- 阳光、成长、豌豆能量是不同概念，事件只结算一次；
- 外部资料有来源和许可证记录，不能把商业教材或来源不明图片打包进网站/APK；
- 页面所有功能都能从现有 Vanilla JS、localStorage、静态 JSON 和自托管 API 边界实现。

## 证据标记

- **已核实事实**：可在来源正文或本地代码中定位。
- **设计推断**：根据多个事实和本项目约束得出的设计判断。
- **本项目采用**：已经写进课程、数据或验收合同的决定。
- **待补证据**：没有足够的一手来源、动态页面未访问或授权尚未确认。

## 当前结论

1. 成人版、儿童版、幼儿版仍是三个入口；本研究只服务幼儿版课程与成长闭环，不重写成人工作台。
2. 幼儿版首页以花园战场和今日三项核心行动为主，学习专区折叠在课程入口中，不把十几个学科卡片堆在首屏。
3. 所有学科共用“热身 → 新知/示范 → 游戏化练习 → 应用/复习”四段式，但每个学科的成功证据不同。
4. 课程、今日计划、首页推荐、奖励结算统一通过 canonical activity event；打开页面、浏览卡片和重复点击不产生奖励。
5. 外部素材默认只做研究链接。进入网站或 APK 的内容必须是项目原创、许可证允许再分发且已经通过内容/版权 QA 的资源。
