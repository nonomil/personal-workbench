先完整读取：

## 单卡写任务

```text
只执行任务卡 <ID>。
先读取任务卡总表、对应分计划、数据/验收文档。

必须：先失败测试，后最小实现；只改白名单文件；运行定向和全量测试；检查 diff。
禁止：回滚用户改动、批量清理、改变存储 key、建立第二账本、越过 USER-GATE、自动推送发布。

最后报告：修改文件、失败测试、通过测试、浏览器/设备实际执行项、未执行项、风险和下一张 READY 卡。
```

## 里程碑验收

```text
只读验收 <NODE>，不修改项目。
对照 docs/优化方案/07-验收/01-里程碑验收节点.md 逐项判定 PASS/FAIL/BLOCKED/NOT-RUN。
附真实命令、输出摘要和证据路径。不要把 NOT-RUN 当 PASS。
```

## 只读代码审查

```text
只读审查指定 diff/commit，不修改文件。
重点检查：范围漂移、数据丢失、重复奖励、旧路由、页面生命周期、CSS 继续叠加、禁止素材进入 artifact、测试等级夸大。
按 P0/P1/P2 输出文件、行号、证据和最小修复建议。
```
