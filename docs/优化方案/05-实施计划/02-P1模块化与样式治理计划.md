# 02 P1：模块化与样式治理分计划

## 范围

覆盖 M3 和 CSS 迁移部分。产品结构在本阶段冻结。

## 分批

1. 建 runtime/adapter 合同和失败测试。
2. 抽纯函数、素材 resolver、路由 helper。
3. 按 today、learning、games、rewards、profile 抽页面。
4. 让课程资料按需加载。
5. 抽成人和少儿 adapter。
6. 建 tokens/shell/workbench/game-entry/themes 六层。
7. 页面逐个迁移 CSS；旧层只在 GATE-3 后移除。

## 约束

- 不同时重写 DOM 和抽逻辑。
- 不把旧 `app.js` 复制成三个大文件。
- shared 只收真正共享能力。
- 每个页面明确 onEnter/onLeave。
- 每个抽取提交都能独立回滚。

## P1 完成

- 三模式只加载当前 adapter。
- 幼儿首页不加载完整课程数据。
- `app.js` 只保留装配/兼容代理。
- CSS 新结构接管全部页面；旧导入显著减少并有删除证据。
