# 03 P2：制品治理与发布分计划

## 范围

建立 runtime asset manifest、统一 Pages/APK artifact、完成远端和设备证据。P2 不等于低重要性；其中“禁止中间素材发布”属于发布 P0。

## 顺序

1. 从真实消费者生成素材清单。
2. 建禁止路径和许可证合同测试。
3. 修改 `prepare-mobile.mjs` 只复制清单。
4. 用同一 artifact 发布 Pages。
5. 比较修改前后 dist/APK 体积。
6. Actions、Pages 深层路径、APK 下载哈希、MuMu 安装和冷启动验收。

## 禁止

- 不在 manifest 建立前删除 `prj/assets`。
- 不把研究 docs 直接复制到 artifact。
- 不因为 Debug APK 能安装就宣称正式包完成。
- 不自动打 tag 或替换 Release 资产。
