# 个人工作台 v0.4.4

发布日期：2026-08-06

## 版本定位

这是“游戏化学习工作台闭环优化”版本。幼儿首页负责今日任务、完成证据、阳光/成长反馈和出口；60 日自然拼读及其他学科资料继续保留在资料库；复杂课程和花园战斗留在独立页面。

## 本版内容

- 首页增加专属伙伴、等级进度、连续行动、豌豆能量和下一步提示。
- 今日草坪战场继续使用现有可编辑任务与幂等奖励链路，不新增第二套积分账本。
- 增加“今天留下了什么”学习证据区，课程资料通过独立学习专区进入。
- 修复首页设置按钮图标缺失；发现旧浏览器缓存仍显示 `v0.4.3` 后，将幼儿入口资源缓存版本更新为 `20260806-game-study-loop-v3`。
- 成人、儿童、幼儿三个入口统一显示 `v0.4.4`。

## 边界

- 60 日课程 JSON 仍是资料库，不等于网页课程引擎全部完成。
- 花园保卫战仍是独立 MVP，不扩展为完整原版塔防复刻。
- Supabase、正式签名 APK、MuMu 安装验收和自托管生产同步不在本版自动宣称完成。

## 验证证据

- `node --test tests/preschool-workbench-refresh.test.mjs`：40/40 通过。
- `npm test`：95/95 通过。
- `node --check app.js`、`node --check config.js`、`node --check storage.js`：通过。
- `npm run android:prepare`：发布资源准备通过。
- `git diff --check`：通过。
- 浏览器：本地页面可打开首页、学习专区、自然拼读入口和独立 `#battle` 页面；`#battle` 实际显示五路六列棋盘、植物卡、僵尸和守护记录，设置按钮实际生成 SVG，首页无横向溢出。390px/320px 响应式规则由专项合同覆盖，真实设备尺寸验收仍待后续发布验收。

## 发布方式

```powershell
git push origin main
git push origin v0.4.4
```

推送 `main` 后等待 GitHub Pages 更新；推送 `v0.4.4` 后 Android Actions 自动构建 Debug APK 并附加到 GitHub Release。APK 下载、安装和 MuMu 核心流程需要以 Actions 产物和设备验收记录为准。
