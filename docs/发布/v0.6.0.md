# 个人工作台 v0.6.0

> 状态：学习模块扩展与小游戏重构版。网页门禁与静态制品验收以本文件的实际记录为准。APK/MuMu 设备验收为 **PARTIAL**（部分完成），不是全功能通过。

## 本版变化

### 新增学习模块（9 个）

- 识字专区：240 字生活字库，闪卡（会了跳过）→ 组词开花 → 找字闯关；掌握度状态机（introduced/practicing/ready/maintenance）与复习调度。
- 拼音专区：按汉语拼音方案三课分列 23 声母、24 韵母、16 整体认读音节，听字音选拼音。
- 古诗专区：小学必背诗库，听上一句选下一句的连句模式，一关一首。
- 自然拼读：字母听音辨认 + 词库听音选短词（CVC），口语词库合入 Dolch 高频词（340 词）。
- 英语词汇：每日 5 词听句子认词，答错不扣阳光。
- 数学专区：三关题库（数一数 / 比大小 / 10 以内口算），从本地题库出题。
- 成就徽章系统：徽章解锁、展示与领取流转。
- 宠物养成：小向日葵等宠物喂养、经验与阶段成长。
- 成长世界：地图站点、小镇等级与花园地标的成长视角总览。

### 小游戏重构（3 个世界）

- 花园保卫：12 关多波次关卡表（1-3 波渐进）、失败态（僵尸进家判负）、连续 x 坐标种植、僵尸节奏放缓（幼儿难度）。
- 方块世界：40×18 岛屿世界、挖放方块、合成（木材→木板）、晶体收集、生命与躲避怪。
- 横版闯关：独立 `data/physics.js` 物理模块（跳跃/无敌帧/二段跳）、缩短后的关卡、本地英雄与敌人素材。

### 修复与治理

- 修复花园保卫多波次卡死：清场后 `status='won'` 被 `spawnWave` 守卫误拦，第 4-12 关第二波永不刷新；守卫改为只拦 `'lost'`（`prj/games/garden-defense/game.js`）。

- `.gitignore` 增补 `.cursor/`、`__pycache__/`。
