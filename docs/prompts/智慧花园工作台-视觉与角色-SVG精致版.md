> 适用场景：独立使用，或在主项目提示词中引用此文档的「角色绘制任务」部分

## 一、前置任务：SVG 绘图技能调研

**在绘制任何图形之前，请先执行深度调研，学习以下资源：**

### 1.1 必读书籍与技能库
| 资源 | 内容 | 核心学习点 |
|:---|:---|:---|
| **Monet 艺术指南**（github.com/genneth/monet）| SVG 绘图艺术方法论 | 渐变、透明度、模糊、光影营造「绘画感」|
| **SVG Animations Skill** | SVG 动画技能库 | 坐标系统、Path 绘制、@keyframes 动画 |
| **unDraw SVG 集合**（github.com/balazser/undraw-svg-collection）| 开源精美 SVG 插画 | 扁平插画风格、配色方案、构图技巧 |

| **Pok Pok 设计哲学** | 极简色彩+极致质感 | 仅用11种颜色打造顶级儿童产品质感 |
| **Sago Mini 角色设计** | 圆润造型+丰富表情 | 大圆角、腮红、夸张眼睛、柔软感 |

### 1.2 调研目标
从以上资源中提取并总结：

1. **绘制精美 SVG 的核心原则**：
   - 用 **4层径向/线性渐变** 代替纯色填充（高光→主色→阴影→边缘暗部，营造球体感）
   - 用 **drop-shadow 滤镜** 增加深度，但阴影颜色用物体暗部色，禁用纯黑
   - 用 **feGaussianBlur** 增加质感，特别是高光层
   - 用 **feTurbulence** 模拟纸张/皮肤纹理
   - **分层绘制**：地面阴影 → 背景装饰 → 主体 → 细节 → 高光 → 腮红

2. **儿童插画风格要点**：
   - 色彩饱和明亮，但用渐变增加层次（非塑料感）
   - 造型圆润可爱，线条流畅，大圆角
   - 表情夸张丰富：**大眼睛 + 红腮 + 微笑**（三者缺一不可）
   - 每个角色必须有「地面阴影」层，让角色「站立」而非漂浮

3. **让 SVG 动起来的方法**：
   - **呼吸动画**：scale 1↔1.04，周期 2.5s，配合轻微旋转
   - **摇摆动画**：rotate ±2deg，周期 1.5s
   - **浮动动画**：translateY ±4px，周期 2.5s
   - **组合动画**：呼吸 + 部位微动 + 周期性眨眼（每 3-5 秒）
   - **扫光动画**：高光层横向移动，模拟光线变化

### 1.3 输出要求
先输出调研总结（300-500 字），说明你学到了哪些技巧，以及你计划如何应用这些技巧来绘制「智慧花园」的角色。
重点强调：**「精致感来自层次，而非复杂度」**——用4层渐变+高光+阴影+腮红，让简单形状变得立体生动。

#### 植物阵营（5 个基础款）

**1. 豌豆射手**
- **风格**：可爱卡通，绿色系，水润光泽材质

  - 炮管微转：rotate 0→-5deg→0，周期 3s，transform-origin 在炮管根部
  - 周期性眨眼：scaleY 1→0.1→1，每 4 秒一次，持续 0.2s
- **绘制要求**：
  - 身体：4层径向渐变（高光 `#A8E6CF` → 主色 `#6BCB77` → 阴影 `#4CAF50` → 边缘 `#388E3C`）
  - 炮管：线性渐变（顶部亮 → 底部暗）
  - 必须有椭圆高光层（`feGaussianBlur` 模糊，白色，透明度 0.25）
  - 必须有地面阴影（椭圆，暖灰，透明度 0.1）

**2. 向日葵**
- **风格**：温暖明亮，黄棕色系，花瓣水润感
- **关键特征**：12 片花瓣围绕花盘 + 微笑表情 + 大眼睛 + 腮红 + 绿色花茎
- **材质**：花瓣=半透明水润，花盘=粗糙纹理
- **动画组合**：
  - 整体呼吸：scale 1→1.03→1，周期 2s
  - 花瓣轻摇：每片花瓣独立轻微 rotate ±3deg，错开相位
  - 花盘微转：rotate ±2deg，周期 4s
  - 眨眼：每 3 秒一次
- **绘制要求**：
  - 花瓣：线性渐变（根部深黄 `#F4C430` → 尖端亮黄 `#FFE066`）
  - 花盘：径向渐变（中心深棕 → 边缘浅棕）+ 网格纹理（小圆点模拟葵花籽）
  - 花茎：线性渐变（左亮右暗，模拟圆柱）

**3. 坚果墙**
- **风格**：坚固可靠，棕色系，粗糙哑光材质
- **关键特征**：圆角矩形主体 + 裂纹纹理 + 坚定表情（浓眉）+ 小短手
- **材质**：坚果=粗糙纹理（用 `feTurbulence` 模拟），无强烈反光
- **动画组合**：
  - 呼吸（轻微）：scale 1→1.02→1，周期 3s（缓慢沉重感）
  - 裂纹微动：偶尔轻微抖动（模拟坚固感）
- **绘制要求**：
  - 主体：3层径向渐变（无强烈高光，偏哑光）
  - 裂纹：深棕色线条，带轻微阴影
  - 地面阴影：较宽较淡（体现沉重感）

**4. 土豆雷**
- **风格**：呆萌搞笑，土黄色系，泥土哑光材质
- **关键特征**：椭圆身体 + 引线 + 紧张表情（瞪大眼睛）+ 小短腿
- **材质**：泥土=粗糙无光泽，引线=纤维感

  - 引线冒烟：粒子特效（3-5 个小圆点向上飘动，透明度衰减）

  - 眼睛左右看：translateX ±2px，周期 2s
- **绘制要求**：
  - 身体：径向渐变（顶部亮土黄 → 底部深褐）

**5. 辣椒**

### 2.4 通用规则（精致版，必须遵守）
- **尺寸**：200×200px，viewBox="0 0 200 200"
- **风格**：扁平插画 + 强烈立体感（靠4层渐变+高光+阴影实现）
- **配色**：明亮、饱和，但用渐变增加层次（非塑料感）
- **表情**：所有角色必须有 **眼睛（眼白+瞳孔+高光）+ 嘴巴 + 腮红**（三者缺一不可）
- **动画**：每个角色至少有 **3 种组合动画**（呼吸 + 部位微动 + 周期性眨眼）
- **材质区分**：
  - 植物 = 水润光泽（强高光，半透明质感）
  - 僵尸 = 哑光皮革（弱高光，灰绿色系）
  - 坚果 = 粗糙纹理（feTurbulence）
  - 金属 = 强烈反光（高光条+闪烁动画）
  - 布料 = 柔软褶皱（路径变形）
- **代码规范**：使用 `<defs>` 定义渐变和滤镜，代码整洁，添加中文注释
- **地面阴影**：每个角色底部必须有椭圆阴影，让角色「站立」而非漂浮
