## 四、触发逻辑

每次学习任务完成时，自动执行检查：

```javascript
function checkAchievements() {
  // 1. 从localStorage读取当前数据
  const stats = getGrowthStats();  // { garden: { flowers: 23 }, adventure: { days: 12 }, builder: { bricks: 45 } }
  const existing = loadAchievements();  // ['GARDEN_BRONZE', ...]
  const newUnlocked = [];

  // 2. 依次检查所有徽章条件
  const rules = [
    { id: 'GARDEN_BRONZE', check: () => stats.garden.flowers >= 10 },
    { id: 'GARDEN_SILVER', check: () => stats.garden.flowers >= 50 },
    { id: 'GARDEN_GOLD', check: () => stats.garden.flowers >= 100 },
    { id: 'MAP_BRONZE', check: () => stats.adventure.days >= 3 },
    { id: 'MAP_SILVER', check: () => stats.adventure.days >= 15 },
    { id: 'MAP_GOLD', check: () => stats.adventure.days >= 30 },
    { id: 'BUILDER_BRONZE', check: () => stats.builder.bricks >= 10 },
    { id: 'BUILDER_SILVER', check: () => stats.builder.bricks >= 50 },
    { id: 'BUILDER_GOLD', check: () => stats.builder.bricks >= 100 },
    { id: 'UNIFIED_SILVER', check: () =>
      existing.includes('GARDEN_SILVER') &&
      existing.includes('MAP_SILVER') &&
      existing.includes('BUILDER_SILVER')
    },
    { id: 'UNIFIED_GOLD', check: () =>
      existing.includes('GARDEN_GOLD') &&
      existing.includes('MAP_GOLD') &&
      existing.includes('BUILDER_GOLD')
    }
  ];

  // 3. 只触发新解锁的
  rules.forEach(rule => {
    if (rule.check() && !existing.includes(rule.id)) {
      newUnlocked.push(rule.id);
    }
  });

  // 4. 如果有新徽章 → 弹窗庆祝 + 保存
  if (newUnlocked.length > 0) {
    showAchievementCelebration(newUnlocked);
    saveAchievements([...existing, ...newUnlocked]);
    // 宠物心情+5（正向联动）
    if (window.petSystem) window.petSystem.addHappiness(5);
  }
}
```

### 触发时机
在以下事件发生后自动调用`checkAchievements()`：
- 识字任务完成
- 拼音任务完成
- 英语任务完成
- 自然拼读任务完成
- 每日打卡完成（全部任务完成时）

## 十一、方案总结

| 设计原则 | 实现方式 |
|----------|----------|
| 数据唯一真实 | 徽章解锁直接从现有学习进度判断，不另建假账本 |
| 即时反馈 | 每次学习完成自动检查，新徽章立即弹窗庆祝 |
| 仪式感 | 弹出动画+徽章图标+名称展示 |
| 可收集 | 徽章收集箱展示已解锁和未解锁的徽章（灰色占位） |
| 低耦合 | 新增独立模块，不侵入现有学习/游戏逻辑 |

这个方案可以直接在现有代码上增量实现，不需要修改已有数据模型以外的部分。徽章解锁的检查逻辑挂在`onLearningComplete`或`saveGrowthData`里即可。
