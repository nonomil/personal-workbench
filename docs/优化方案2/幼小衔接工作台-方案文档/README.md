## 一句话定位

把「每日学习打卡」做成孩子愿意长期打开的成长伙伴：  
**做任务 → 得阳光/积分 → 照顾伙伴 → 短游戏奖励**；  
游戏与学习可联动，但不另建假进度账本。

## 三主题外壳

| 主题参数 | 风格 | 主游戏感 |
|:---|:---|:---|
| `garden-defense` | 花园 / PVZ 绿 | 花园保卫 |
| `voxel-adventure` | 方块 / 我的世界蓝 | 挖矿建造 |
| `platform-quest` | 马里奥红 | 横版闯关 |

学习内容共用同一套数据；主题主要换视觉与游戏外壳。
