# 落地对照与缺口

> 依据长对话中「已实现/已设计」的记录整理。

## 模块对照

| 模块 | 设计状态 | 实现侧记录（对话） | 主要缺口 |
|:---|:---|:---|:---|
| 识字 | 认练测 + 字库 | 闪卡/配对/听选、笔顺约 50、配图部分 | 配图与读音覆盖率、动画精致度 |
| 拼音 | 分级 + 认练测 | 闪卡/配对/听选 | 读音全覆盖、难度 UI 打磨 |
| 数学 | 百内 + 积阶乘 | 排队 + 四选一 | 题目手感与级别校验 |
| 英语 | 500 词目标 | 认练测、部分音频 | 词到 500、图与短语 |
| 拼读 | stage 词库 | 闪卡+听选 | 游戏感、stage 内容量 |
| 古诗 | 点句读 | 数十首级 | 整首预录、插画 |
| 专注 | 真小游戏 | 舒尔特/数独/Simon 等 | 美术与关卡包装 |
| 运动 | 真计时 | 大圆倒计时 | 动作示意图 |
| 伙伴 | 轻量养成 | 喂食/阶段模型 | 手感与主题外观 |
| 成长世界 | 三视图 | DOM 可视化 | 动画与今日高亮 |
| 花园保卫 | 主题主游戏 | Canvas 短局 | 节奏/美术/全屏打磨 |
| 方块世界 | 复刻向 | 挖放背包向 | 贴图、地图、合成深度 |
| 马里奥 | 横版 | 平台原型 | 角色与关卡资产 |
| 语音 | 工厂 | 汉字/英语 mp3 一批 | 继续补量 |
| 主题切换 | 三主题 | 参数切换 | 无闪切、无叠层 |

## 量级缺口（对话中的数量级）

- 汉字读音：已生成一批（约 300+），字库目标 1000～1500  
- 英语读音：约 100+，目标约 500  
- 配图：数十级，远小于字词量  

## 建议续做优先级

### P0

1. 源码恢复或按本文档重搭可运行骨架  
2. 主题切换无叠层  
3. 认练测四科稳定  
4. 奖励幂等与券规则  
5. 运动倒计时、专注真游戏可玩  

### P1

1. 音频/配图工厂继续补  
2. 成长世界今日高亮 + 徽章  
3. 花园保卫节奏与全屏  
4. 方块矿洞与合成  
5. 家长导出/报告  

### P2

1. 古诗插画与整首音频  
2. 马里奥关卡包  
3. 轻量复习调度  
4. PWA  

## 验收句（家长向）

- 孩子能否不读长文完成今日必做？  
- 做完是否一定有阳光/证据（且不重复刷）？  
- 切换主题后是否仍是同一份进度？  
- 无券时是否仍能看成长世界？
