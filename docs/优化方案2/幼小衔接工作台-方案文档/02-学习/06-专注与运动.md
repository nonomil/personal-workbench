# 专注与运动

## 定位

二者核心不是「词库量」，而是 **体验、习惯、每天坚持**。

## 专注力

### 已纳入设计的轻量玩法

| 玩法 | 说明 | 参考思路 |
|:---|:---|:---|
| 舒尔特方格 | 3×3 起，点 1…n | Schulte / freefocus 之轻量 |
| 4×4 数独 | 无笔记压力，大数字盘 | LibreToybox Mini-Sudoku |
| 记颜色 Simon | 序列从短开始 | Simon 经典 |
| 找不同 / 记忆翻牌 | Emoji 即可 | LibreToybox 等 |

### 整合原则

- **抽玩法，不嵌整站**（避免 Next/Vue 重项目）
- 统一工作台色板与完成回调（用时、完成 → 证据/积分）
- 不做 Dual N-Back 等成人认知向

## 运动

### 动作库示例（居家）

开合跳、深蹲、原地跑、高抬腿、平板支撑（短时）、摸高、侧跳、弓步压腿、肩绕环、踏步等。

### 交互（落地形态）

- **倒计时真做**（大圆数字），不是三道「先做什么」选择题
- 开始可语音报动作名
- 「做完了」可提前结束；到 0 自动完成
- 成人在旁的安全提示放 tip，不挡主流程

### 可选激励

连续完成 → 徽章；与阳光/伙伴心情弱联动。
