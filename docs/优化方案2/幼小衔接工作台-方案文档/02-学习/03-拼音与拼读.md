# 拼音与自然拼读

## 拼音

### 难度维度（设置里选）

- 声母
- 单韵母
- 声调
- 复韵母
- 前/后鼻韵母
- 整体认读

### 玩法

- 认：大号拼音闪卡 + 发音
- 练：例字 ↔ 拼音对对碰
- 测：听音选拼音 / 选例字

## 自然拼读

### Stage 结构（与词库字段对齐）

示例 stage：

- CVC blending
- short vowels / families
- common digraphs
- consonant blends

出题走 `word-bank` 的 `stageId`，不手写永久样例表。

### 玩法

- 认：目标词大卡
- 练/测：听选、看图选词（有图用图）
- 可参考 minecraft-phonics 的「主题包装」，不必复刻其工程

### 与单词模块边界

| 模块 | 重点 |
|:---|:---|
| 单词 | 意义 + 短语/短句 + 主题词 |
| 拼读 | 解码规则与可拼词 |
