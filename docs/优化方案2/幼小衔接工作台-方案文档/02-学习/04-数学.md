# 数学

## 范围

### 加减

- 主范围：**100 以内**
- 较小进位/简单题可减少「过易刷题」；重点练有思考量的题（按级别调）

### 乘法

- 孩子会用加法想乘法，但未记牢 → 用**积的上限**扩阶更符合认知：
  - 积 ≤ 20
  - 再 → 40、60、80…
- 也可从「5 以内因数」起步，再与积上限策略合并
