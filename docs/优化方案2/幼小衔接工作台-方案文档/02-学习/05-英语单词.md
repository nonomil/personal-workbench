# 英语单词

## 目标量

约 **500 词**（贴近小学核心词汇体量，启蒙可先用前 100～200）。

## 词源策略（资料层）

合并去重思路：

- Dolch 高频（pre-primer → 中低年级）
- 课标/常用儿童词
- 主题：颜色、动物、食物、自然、学校、家居等

**避免**幼小阶段硬塞 because / beautiful / together 等偏难抽象词作为主练。

## 字段

每个词尽量具备：

- `text` / `phonetic` / `meaning`
- `phrase` / `sentence`（短语、短句）
- `theme` / `rank` / 级别

## 玩法

- 认：词 + 图 + 发音
- 练：对对碰
- 测：听音选词  
展示短语/短句作「再说一次」即可，不必另开重玩法。
