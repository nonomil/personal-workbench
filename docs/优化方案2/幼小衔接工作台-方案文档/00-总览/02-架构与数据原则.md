# 架构与数据原则

## 技术栈（沙箱实现时）

| 层 | 方案 |
|:---|:---|
| 前端 | 以工作台单页/多页 + 纯 JS 模块为主（可挂在 TanStack/Vite 工程旁） |
| 存储 | `localStorage`，版本化快照，导出/导入 JSON |
| 游戏 | Canvas / DOM+SVG，不引入重型游戏引擎（除非主题明确需要） |
| 语音 | 预生成 mp3（edge-tts 等）+ Web Speech 回退 |
| 音效 | Web Audio 合成短音 + 可选预录 |

## 数据原则

1. **一份完成账本**  
   课次完成、打卡日期、练习证据共用现有存储；成长世界直接读取，不复制第二套「游戏进度」。

2. **奖励幂等**  
   同一任务/同一日门槛只发一次阳光、券、XP；用事件 id 或「日期+任务 id」去重。

3. **主题切换**  
   URL `?theme=garden-defense|voxel-adventure|platform-quest`  
   选定后按该主题加载样式与游戏入口，避免「先方块后花园」的闪切与叠层。

4. **学习级别**  
   口算 / 识字 / 拼音 / 拼读 / 单词等在设置中切换 L1～L5（或等价档位），**不挂年级标签**。

## 导航结构建议

| 优先级 | 入口 | 说明 |
|:---|:---|:---|
| 高 | 首页今日任务 | 孩子 3 秒知道今天做什么 |
| 高 | 伙伴 | 喂食 / 状态常驻 |
| 高 | 主题游戏（保卫/世界/闯关） | 核心反馈，非边角 |
| 中 | 课程/学习地图 | 一科一个圈 |
| 中 | 成长世界 | 不耗券的成果可视化 |
| 低 | 设置 / 家长 / 导出 | 可收纳 |
