# 产品定位与用户

## 用户画像（豆豆）

| 项 | 说明 |
|:---|:---|
| 年龄 | 近 7 岁，约 9 月入一年级 |
| 识字 | 约 200+，目标工作台承载到约 1000～1500 字资料库 |
| 拼音 | 中阶，需难度可选（声母 / 单韵母 / 复韵母等） |
| 数学 | 100 以内加减；乘法从结果 20 以内起，再扩到 40/60/80 |
| 英语 | 生活主题词 + 自然拼读；词库目标约 500 |
| 古诗 | 入门，可扩展到 30～50 首小学向篇目 |
| 使用方式 | 孩子记路径打开即可；家长可看说明与报告 |

## 日闭环（产品）

```text
打开工作台
  → 看三步路径（做任务 → 照顾伙伴 → 玩游戏）
  → 完成今日必做（可含「去练习」）
  → 自动留下证据 + 阳光/能量
  → 照顾伙伴（可选但推荐）
  → 短游戏奖励（有券再玩）
  → 结束（导出/备份由家长完成）
```

## 设计原则

1. **游戏是壳，学习是核** — 每关约 15～30 秒，不沉迷。
2. **错误不惩罚** — 温和提示「再想想」，不羞辱。
3. **完成动作单一** — 真正做完才到账，不空点。
4. **进度看得见** — 成长世界读真实完成数据，不另建假账本。
5. **儿童界面简** — 大字、大按钮、少说明；说明留给家长区。
6. **离线优先** — localStorage；可导出/导入备份。

## 明确不做

- 公开排行榜、社交、班级竞争
- 复杂积分经济
- Voice Agent 实时对话焊进工作台
- 打开页现算 Imagine / 现算 TTS
- 整仓 fork 重型框架项目（Next/Vue 全站）
