# 信息层级与文案

## 问题（审查结论）

首页曾同时堆：进度、能量、券、伙伴、任务、证据、专注、周节奏、徽章等 8+ 区块。  
5～7 岁无法在 3 秒内找到「今天做什么」；长说明句对孩子无效。

## 目标信息层级

| 层级 | 内容 | 呈现 |
|:---|:---|:---|
| 1 | 今天要做的事 | 大任务卡，少字 |
| 2 | 伙伴状态 + 阳光/能量 | 一卡看懂 |
| 3 | 游戏券（有才强调） | 小角标 |
| 4 | 徽章 / 证据 / 周报 | 次级或家长区 |

## 文案原则

- 孩子区：**短词、指令**（「去识字」「喂一喂」）
- 家长区：可保留规则说明（阳光真实到账、主题切换共用数据等）
- 删掉靠文字补 UI 缺陷的长句

## 任务描述

从「完成今日识字」改为可感知内容，例如：

- 识字 · 认 6 个字
- 古诗 · 读一首
- 数学 · 闯一关
- 英语 · 学几个词
- 运动 · 做一项
- 专注 · 练一题

## 响应式

- 桌面：侧栏 + 主区
- 约 390px 宽：无横向溢出，主按钮可点，游戏全屏可用
