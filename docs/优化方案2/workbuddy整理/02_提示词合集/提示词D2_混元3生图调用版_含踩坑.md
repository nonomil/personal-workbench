# 提示词 D2：充分利用混元3生图能力版（含调用规范 + 踩坑提醒）

> 背景：用户追问"要充分利用混元3模型可以生图的特点吧，生图肯定比SVG效果好？"——本节整理了WorkBuddy/混元3生图能力的调研结论、已知的坑，以及包含"生图优先、SVG/Canvas降级"完整机制的提示词模块。

---

## 一、生图能力使用前必须了解的3个坑

### 坑1：并发槽位只有2个，容易排队失败
混元图片生成服务（hy-image-v3）的并发槽位上限仅为2个，同时最多2人能生成图片，第3个人就会失败。有用户实测连续尝试30+次，成功率0%，报错为"concurrent slot limit exceeded"。
- **解决办法**：提示词里必须加入重试机制和降级方案——生图失败时自动切换为SVG占位图，保证页面功能不受影响。

### 坑2：生图可能消耗积分
WorkBuddy的图片生成会消耗积分（约10-30积分/张）。混元3模型本身限时免费，但生图功能走独立的ImageGen工具链路，积分消耗需留意。
- **解决办法**：控制生图数量，只在关键位置调用（如古诗配图、角色形象），其他装饰性元素用CSS/Emoji替代。

### 坑3：角色形象需要"稳定化"
AI生图做角色（豌豆射手、向日葵等），每次生成风格可能不一致，同一植物今天这样明天那样，体验割裂。
- **解决办法**：为每个角色固定详细描述词（颜色、比例、风格、视角），确保每次生成结果一致。

## 二、AI生图调用规范

### 2.1 调用方式
WorkBuddy 内置 ImageGen 工具，在对话中直接描述图片需求即可自动调用。
在HTML代码中，通过以下方式触发：
```javascript
// 调用 WorkBuddy ImageGen 生成图片
async function generateImage(prompt) {
    try {
        const response = await fetch('/api/imagegen', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ 
                prompt: prompt,
                style: 'illustration',  // 儿童插画风格
                aspect: '1:1'           // 正方形，适配卡片
            })
        });
        if (!response.ok) throw new Error('生图失败');
        const data = await response.json();
        return data.imageUrl;
    } catch (error) {
        console.warn('AI生图失败，降级为SVG占位图:', error);
        return null;  // 触发降级
    }
}
```

### 2.2 重试与降级机制（必须实现）
- **重试**：生图失败时自动重试3次，每次间隔2秒
- **降级**：3次重试全部失败后，自动切换为内联SVG占位图（保证页面不缺失任何视觉元素）
- **超时**：单次生图请求超时时间设为8秒（考虑并发排队因素）
