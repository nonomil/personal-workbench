# 提示词 A：简化开箱即用版（11模块，去除复杂技术细节）

> 定位：适合快速生成、发小红书传播的"轻量版"提示词，聚焦功能完整+视觉惊艳+移动端适配。

```
你是一个顶级前端工程师。请帮我生成一个"智慧花园学习工作台"的完整HTML单页应用，纯前端+localStorage存储，移动端优先适配。

## 一、整体风格
- 毛玻璃质感（glassmorphism）风格，背景动态渐变色
- 左侧导航栏（移动端折叠为底部tab栏），共11个图标
- 主色调：#4CAF50（植物绿）+ #FFD700（阳光金）
- 每个模块都要有对应的Emoji图标

## 二、核心游戏机制
- 主页是"花园基地"：4行×8列网格，可种植植物
- 完成任务获得"阳光"（数值），消耗阳光种植植物
- 未完成任务触发"僵尸来袭"警告动画
- 全部任务完成→向日葵庆祝🎉 + 自动打卡

## 三、11个功能模块（每个模块都需独立可交互）

1. 日历打卡：月历视图，显示每日打卡状态，统计出勤率
2. 花园基地：种植棋盘，阳光余额显示，僵尸入侵动画
3. 识字专区：内置300个基础汉字，点击发音，按主题分类（自然/动物/身体/数字）
4. 拼音专区：声母韵母卡片，点击发音，带顺口溜
5. 古诗专区：内置20首经典古诗，卡片翻页，显示译文
6. 数学专区：10以内加减法，水果计数辅助，数字键盘
7. 专注力训练：找不同/迷宫/数独三种题型
8. 每日英语：内置100个常用单词，每日5词，点击发音
9. 每日运动：5项居家运动，15秒倒计时进度条
10. 错题本：自动记录数学错题，支持复习重做
11. 奖励商城：用阳光兑换奖励，家长可自定义

## 四、交互与反馈
- 所有按钮有点击波纹效果
- 完成任务播放"✨"飘字动画
- 僵尸来袭有屏幕闪烁警告
- 数据实时保存到localStorage

## 五、移动端适配
- 在手机上自动隐藏左侧导航，改为底部5个主要Tab
- 所有卡片点击区域不小于44px（适合手指触控）
- 支持添加到手机桌面（PWA兼容）

## 六、语音支持
- 点击文字调用 Web Speech API 发音（不依赖任何外部服务）
- 在代码中标注"如需更高音质，可使用Edge浏览器打开"

## 七、预设数据
- 3个每日任务示例
- 20个汉字+拼音示例
- 5首古诗示例
- 10道数学题示例

现在请生成完整的HTML代码，包含所有CSS和JavaScript，确保在手机上打开即用。
```
