# 提示词 B：V3.0 极致细节版（像素级布局锁定）

> 定位：第一次被用户质疑"太简单了"之后产出的版本。核心思路是"受控自由发挥"——架构、交互逻辑、数据结构、API对接方式100%锁死，避免AI瞎编；视觉风格、动画缓动、色彩搭配则交给AI自由发挥。用户实测认为很有价值，之后的所有版本均在此基础上迭代。

## 为什么这份提示词能"落地可用"（设计原理）
1. **锁死架构，释放视觉**：布局尺寸（72px导航、80px格子）、数据模型（JSON结构）、API调用方式（`/api/tts`）全部硬性规定，AI没法跑偏；具体的毛玻璃`backdrop-filter`数值、渐变色值、扭动动画的`@keyframes`交给AI自由发挥，每次生成都有新鲜感。
2. **算法明确**：例如"每日10字"抽取逻辑（新字+复习错字）、"机器人对战"80%概率判定、"僵尸移动"2秒间隔——不写死AI会用随机数糊弄，写了就是严谨逻辑。
3. **降级方案**：给混元生图加了"3秒超时切SVG"补丁，避免接口不稳定导致页面白屏。
4. **成长闭环**：把"阳光"贯穿始终（赚取→消耗→回收→兑换），用"成长绿藤"和"勋章"把碎片化学习串成一条主线。

预计生成代码量：约800-1200行。若运行报错（如某API 404），可把报错信息反馈以微调接口路径。

## 二、核心游戏引擎（植物大战僵尸机制 - 详细数据流）
### 1. 阳光经济系统
- **获取**：每完成一个任务，获得该任务设定的阳光值（5-20不等）。
- **消耗**：种植植物消耗 `20阳光`；升级植物消耗 `30阳光`（二阶） / `50阳光`（三阶）。
- **回收**：铲除植物返还 `50%` 消耗值（向下取整）。
- **存储**：`localStorage.setItem('sunBalance', 数值)`。

### 2. 花园棋盘（首页核心）
- **布局**：4行 × 8列 网格。每个格子 `80x80px`，间距 `8px`。
- **僵尸逻辑**：
  - 若昨日有未完成任务，今日登录时，从棋盘右侧（第8列）随机生成僵尸，僵尸每 `2秒` 向左移动一格。
  - 僵尸抵达第1列则触发"花园受损"动画（屏幕红色闪烁），并扣除 `10阳光`。
- **植物逻辑**：
  - 点击空位种植（消耗阳光）。种植后植物每 `3秒` 发射一颗子弹攻击当前行最右侧的僵尸。
  - 植物有"摇摆空闲动画"（CSS `transform: rotate(2deg)` 循环）。

### 3. 任务清单与打卡
- **每日任务**：从所有自定义任务中随机抽取 `5个` 作为当日任务。
- **全部完成**：触发"向日葵庆祝动画"（全屏金色粒子特效），且**日历自动打卡**（标记绿点）。
- **漏卡统计**：若当日24点前未完成，日历标红叉，出勤率实时计算（`已打卡天数/本月总天数`）。

## 三、11个功能模块的详细交互细节

### 模块1：日历打卡
- **UI**：月历视图，每个日期格子下方显示"全勤⭐"、"漏卡❌"或"未到⭕"。
- **统计**：顶部卡片展示"本月出勤率：XX%"。

### 模块2：首页花园基地
- **即上述第二点的棋盘渲染**，必须包含：阳光面板（顶部）、僵尸入侵倒计时（若存在僵尸）、3个功能按钮（【一键收阳光】【快速种植豌豆】【花园护盾】）。

### 模块3：识字专区（1500常用字）
- **字库来源**：对接GitHub上的 `chinese-standard-characters` 一级字库（3500字中取前1500个高频字）。
- **分级**：按"启蒙（1-200）"、"进阶（201-600）"、"提高（601-1500）"三档，下拉切换。
- **每日分配**：算法随机抽取 `10个` 新字 + 复习昨日错误率最高的 `5个字`。
- **交互**：
  - **点击**：调用 Edge-TTS 发音（`voice=zh-CN-XiaoxiaoNeural`）。
  - **长按（>500ms）**：弹出气泡窗口，显示该字的 **3个常用词组** + 组词发音。
- **筛选**：顶部标签按钮（自然🌿/动物🐼/身体🧍/数字🔢/颜色🎨）。

### 模块4：拼音专区
- **内容**：23个声母、24个韵母（含单/复/前后鼻）、16个整体认读音节。
- **展示**：卡片网格，每个卡片点击发音。卡片背面显示"发音方式讲解"（如"舌尖前音，气流从舌尖挤出"）。
- **顺口溜**：每个拼音下方自动匹配一句顺口溜（内置映射表）。

### 模块5：古诗专区（100首）
- **关卡制**：每10首为一关，解锁下一关需上一关全部标记"学会"。
- **UI**：左半屏显示古诗原文（楷体大号），右半屏显示白话译文（灰色小字）。
- **操作**：【朗读】（显示录音动效）、【跟读】（高亮当前句子）、【学会标记】（点亮右上角小红花）。
- **配图**：若调用混元生图API，使用 `prompt: "古风山水画，风格淡雅，描绘古诗意境"`；若不可用，则自动生成 SVG 简笔水墨画（代码内联）。

### 模块6：数学专区
- **难度分级**：🌱10以内加减 → 🌿20以内进退位 → 🌳5以内乘法 → 🌲10以内乘除法。
- **水果计数辅助**：做题时，下方自动显示对应数量的水果Emoji（如 3+2，显示 🍎🍎🍎 + 🍎🍎）。
- **数字键盘**：自定义大按钮键盘（0-9，退格，确认），禁用系统键盘。
- **闯关与对战**：
  - 每日闯关：连续答对10题记录"闯关天数"。
  - **机器人对战**：每道题AI机器人（BOT）有80%概率答对。若玩家答对且BOT答错，玩家得双倍积分；若BOT答对且玩家答错，扣除1条命（每日3条命）。

### 模块7：专注力训练
- **5类题型**：找不同（左右两张图，点击不同处）、迷宫（Canvas绘制）、数数（点击正确数量）、规律（ABAB/ABB等）、逻辑（谁不是同类）。
- **新增硬核题**：
  - **舒尔特方格**：5x5数字随机排列，要求从1按顺序点击到25，计时并记录历史最快。
  - **数独**：4x4初级宫格（仅填1-4），提供"提示"功能（高亮唯一解）。

### 模块8：每日英语（GB标准）
- **词库**：内置500个小学PEP人教版核心词汇 + 200个常用短语/短句。
- **每日5词**：算法根据艾宾浩斯遗忘曲线推送（新词2个 + 复习3个）。
- **交互**：点击单词发音（`voice=en-US-JennyNeural`）。点击词组发音，且例句自动朗读。

### 模块9：每日运动
- **10项动作**：开合跳、深蹲、平板支撑等。每个动作搭配 `15秒` 语音播报（TTS合成）和 `进度条` 倒计时。
- **完成**：勾选即获得 `5阳光` 奖励。

### 模块10：错题本

- **复习模式**：每日推送最多 `5道` 错题，连续答对3次则从错题本移除。

### 模块11：奖励商城
- **植物商店**：用阳光购买不同品种的植物（向日葵、豌豆、坚果墙、土豆雷）。

- **兑换**：点击奖励弹出"确认兑换"，消耗阳光并播放"星星收集"特效。
