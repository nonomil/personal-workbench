# 普通人如何学习胡楚靓制作出自己的第一个个人工作台

## AI 总结
这篇文章以"用 WorkBuddy 做个人学习工作台"为例，解释为什么很多人虽然照着教程生成了网页，最终效果却和参考图差距很大。作者认为，问题通常不在工具，而在提示词过于模糊：只说"帮我做个学习工作台，深色主题，好看一点"，AI 就只能自行猜测"好看"的含义。

文章提供两份可复制的提示词：第一份生成纯本地版单页应用，使用 HTML、CSS、JS 和浏览器 `localStorage` 保存数据；第二份生成基于 Supabase 的云端版，支持邮箱登录、多设备同步和 Vercel 部署。两份提示词都把布局、颜色、组件、数据结构、交互和技术约束写得很细。

文章的核心方法是把"视觉参考图"翻译成可执行规格：明确像素尺寸、颜色色号、卡片结构、按钮行为、数据存储方式和移动端适配，而不是只描述一个模糊的产品愿望。

## 关键信息
- **工具定位**：WorkBuddy 是腾讯的 AI 办公助手，文章称其入口位于 `codebuddy.cn`，可用微信扫码登录。
- **本地版**：单文件 HTML，数据保存在浏览器 `localStorage`，无需后端，适合直接打开使用。
- **云端版**：使用 Supabase 的 PostgreSQL 和 Auth，部署到 Vercel，支持多设备登录和数据同步。
- **工作台功能**：首页总览、每日计划、学习任务、阅读记录、长期规划。
- **提示词重点**：明确桌面端和移动端布局、配色、卡片样式、交互行为、预设数据和存储键名。
- **普通人的学习方式**：不需要先学会写代码，先学会把需求拆成足够具体的规格，再让 AI 负责实现。
- **云端安全提醒**：云端版需要自己配置 Supabase 项目、Auth、数据库表和 RLS 策略，不能只复制前端代码就认为数据层已经安全可用。

## WorkBuddy 是什么
WorkBuddy 是腾讯出的 AI 办公助手，挂在 `codebuddy.cn` 下面。微信扫码就能登录，目前原生的大模型是：`hy3`。

还是免费的，不用折腾 API Key、不用绑信用卡。你给它一段足够详细的提示词，它能直接生成完整的网页应用。

## 提示词做出来的是什么
一个深色主题的学习工作台，左侧边栏 + 右侧主内容区，五个功能 Tab：

- 📊 首页总览：四个数据卡片（学习时长、章节数、累计天数、页数）+ 柱状图。
- 📋 学习任务：任务列表 + 进度条 + 截止日期，增删即时生效。
- 📖 阅读记录：本周/本月时长卡片 + 7 天趋势折线图。
- 🎯 长期规划：目标管理卡片，自由增删。

本地版数据存浏览器，关了再打开还在。手机端打开布局自动适配。

## 使用流程
1. 打开 WorkBuddy（`codebuddy.cn` → 微信扫码登录）。
2. 复制下面提示词，完整粘贴到输入框。
3. 回车，等它生成完。
4. 代码复制到桌面，改后缀为 `.html`，双击打开。

## 第二份提示词：云端版

想多设备同步的用这份。先看使用说明，再把提示词复制到 WorkBuddy。

### 使用说明
1. 去 `supabase.com` 注册，创建项目。
2. 在 SQL Editor 执行建表 SQL（AI 会写在代码注释里，拿出来用）。
3. `Authentication` → 开启 Email 登录。
4. 代码生成后，把 Supabase URL 和 anon key 填入对应位置。
5. 部署到 Vercel，完成。
