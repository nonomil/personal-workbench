## 使用建议（落地路径）

1. **先读**：01目录，了解整体设计思路和演进逻辑
2. **执行生成**：复制 02目录中的「提示词C」+「提示词D1或D2」组合，粘贴到 WorkBuddy（codebuddy.cn，微信扫码登录），生成完整HTML应用
3. **部署到手机**：按 04目录 步骤，用Edge浏览器打开生成的网页，添加到主屏幕
4. **决定是否上云**：如需多设备同步，参考 03目录 的迁移路径，引入Supabase
5. **发布传播**：使用 05目录「文案V2」直接发布小红书，评论区置顶完整提示词
