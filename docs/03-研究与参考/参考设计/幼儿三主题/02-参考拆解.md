# 参考图拆解与第二轮生成方向

更新时间：2026-08-06

## 结论

第一轮 `garden-defense / block-adventure / storybook-quest` 生成的是“完整插画式桌面面板”，与参考项目的真实使用感不一致。参考项目的核心不是把所有内容画进一张海报，而是：

> 一个可读的学习工作台壳，套一层明确的游戏世界皮肤；学习卡片和任务文字仍由 HTML 负责。

## 从本地参考图提取的视觉合同

| 层级 | 参考图事实 | 下一轮必须保留 |
| --- | --- | --- |
| 壳层 | 移动端/窄屏优先，左侧固定导航，右侧可滚动主内容 | 纵向工作台截图构图，不做纯横向海报 |
| 导航 | 高饱和主题色整条侧栏，图标 + 大字号栏目，当前项有亮色描边/底色 | 侧栏要成为主题识别点 |
| 顶部 | 主题背景横幅，角色/砖块/云朵/资源胶囊与连续天数同处一行 | 顶部状态区必须有游戏世界，而非普通白色工具栏 |
| 内容 | 白色或奶油色大卡片，圆角、浅阴影、清楚的分组标题 | 保持空白区域给 HTML 叠字，卡片不能被 AI 文字占满 |
| 学习 | 科目卡片采用两列网格，各自有主题色顶边/按钮，学习专区可继续下钻 | 课程不是六条横向任务塞在一张图里 |
| 游戏 | PVZ 是草坪棋盘 + 泥土种植格；马里奥是天空/砖块/金币；方块世界是体素地形/背包槽 | 每个主题必须有独立的场景隐喻 |
| 反馈 | 完成后阳光/金币/蘑菇/徽章进入资源胶囊，任务卡出现绿色完成状态 | 即时反馈位置要在任务卡和顶部资源条之间形成闭环 |

## 第二轮主题边界

- `garden-defense`：参考植物大战僵尸式草坪战场，但只使用原创植物、原创软萌入侵者和自己的图标；不复制官方角色、Logo 或截图。
- `voxel-adventure`：参考我的世界的体素/方块建造语法：草方块、泥土截面、石砖、木箱、背包槽、方块地标；不使用官方方块纹理、苦力怕、Logo 或 UI。
- `platform-quest`：参考马里奥类平台冒险的色彩和构图语法：蓝天、云、砖块、问号奖励块、金币、管道、旗杆和横向平台；主角使用原创小探险家，不使用官方人物、Logo 或关卡截图。

## 为什么第一轮不合格

1. `block-adventure-reference.png` 与 `storybook-quest-reference.png` 的 SHA-256 完全相同，说明输出没有形成独立主题。
2. 方块 v2 虽然有体素元素，但仍是“高光 3D 仪表盘”，没有参考图里的轻量白卡片、侧栏和科目网格。
3. 故事书 v2 更像地图插画，缺少任务工作台结构；它只能作为素材氛围参考，不能作为页面参考。

## 生成执行规则

- 第一张先做“页面参考图”，不直接生成透明角色资产。
- 先锁定壳层、侧栏、顶部世界背景、科目网格和游戏区，再单独生成角色/图标爆炸图。
- 生成图中的文字全部禁止，真实文字由网页 HTML/CSS 叠加。
- 每次串行请求并记录请求尺寸、实际 PNG 尺寸、SHA-256；重复输出直接拒收。
