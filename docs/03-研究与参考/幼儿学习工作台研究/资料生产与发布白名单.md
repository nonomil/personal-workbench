# 资料生产与发布白名单

## 1. 内容生产流水线

```text
课程目标 → 内容条目 → 人工编写/生成草稿 → 结构校验 → 学科 QA → 版权 QA → 进入 data/ → 页面验收 → Pages/APK
```

任何一步失败都只能停在研究或草稿目录，不能通过“页面能显示”绕过质量门禁。

## 2. 内容条目最低字段

```json
{
  "id": "preschool-math-day-001",
  "subject": "math",
  "stageId": "quantity-compare",
  "title": "找出更多的水果",
  "objective": "能比较两组 1-5 个物品的多少",
  "activityType": "manipulate-and-choice",
  "durationMin": 8,
  "prompt": "哪一盘水果更多？",
  "options": [],
  "success": "你发现了更多的一盘！",
  "reviewTags": ["compare-quantity"],
  "source": { "kind": "project-original", "license": "project-original" },
  "assets": { "image": "", "audio": "", "printable": "" }
}
```

## 3. 质量门禁

### 内容门禁

- 每条内容有唯一 ID、学科、阶段、目标、时长和成功条件。
- 题目有正确答案或明确的家长观察结果；不能只有“点击开始”。
- 文字长度符合幼儿界面：按钮优先 2-6 个汉字，长说明放家长页。
- 所有错误都有可恢复反馈，答错不清空已完成进度。

### 自然拼读门禁

- `newPatterns`、`reviewPatterns`、`trickyWords` 不为空且字段合法。
- `decodableTexts` 的规则覆盖由脚本计算，不接受人工填写的假比例。
- 未教规则必须标为 `trickyWords`，并在前一节或本节明确引入。
- 每个技能至少有两种活动、跨两个日期的证据，才允许变为 `ready`。

### 版权门禁

- `project-original`：记录作者、生成日期和是否使用外部参考。
- CC BY/Apache/MIT：记录来源 URL、版本、许可证文本、署名和修改说明。
- CC BY-NC/SA、未知、商业教材：只进研究目录，不进默认 Pages/APK。
- 生图素材必须保存提示词、模型、生成日期、人工筛选结果和透明背景处理记录。

### 工程门禁

- 课程、今日计划、首页下一节使用同一个 `activityId`。
- 奖励结算使用稳定 `rewardEventId` 幂等；刷新、后退、重复点击不重复发阳光。
- JSON 解析失败有默认值和用户提示；静态资源加载检查 `response.ok`。
- 桌面与 320/375/390/441px 移动端无横向溢出，弹窗按钮不被底部导航遮挡。

## 4. 目录白名单

| 目录 | 可放内容 | 是否进入发布 |
| --- | --- | --- |
| `data/preschool/` | 已通过内容/版权 QA 的 JSON | 是 |
| `assets/generated/preschool/` | 已人工筛选并登记 manifest 的原创素材 | 是 |
| `docs/03-研究与参考/幼儿学习工作台研究/raw/` | 搜索结果、正文、许可证和研究下载 | 否 |
| `docs/03-研究与参考/幼儿学习工作台研究/assets/` | 研究截图、参考图和待审核下载 | 否 |
| `tmp/` | 测试截图、APK、构建产物 | 否 |

## 5. 生成式素材规则

生图只生成原创的花园、植物伙伴、友好入侵者、奖励徽章和无文字 UI 元素。不得要求模型生成原版植物大战僵尸角色、游戏截图、品牌 Logo 或可读中文/英文。最终页面文字由 HTML/CSS 渲染，图片只承担氛围和角色识别。
