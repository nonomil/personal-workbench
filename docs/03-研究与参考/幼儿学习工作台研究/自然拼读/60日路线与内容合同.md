# 60 日路线与内容合同

## 日级合同

每一日有一个主课条目，最多两个复习条目。主课不能只写“学习字母”，必须包含目标、示范、互动、应用、错误反馈和复习标签。

```json
{
  "id": "preschool-english-phonics-day-013",
  "day": 13,
  "stageId": "cvc-blending",
  "skillIds": ["short-a", "blend-cvc"],
  "newPatterns": ["a"],
  "reviewPatterns": ["s", "t", "p", "i"],
  "examples": ["sat", "pat", "tap"],
  "activityTypes": ["sound-discrimination", "blend-track", "decodable-read"],
  "durationMin": 12,
  "decodableTexts": [],
  "source": { "kind": "project-original", "license": "project-original" }
}
```

## 复习和掌握

技能状态：`introduced`、`practicing`、`ready`、`maintenance`。达到 `ready` 需要至少两次不同日期、不同活动、约 80% 准确率；若错误连续出现，回到 `practicing` 并进入队列。
