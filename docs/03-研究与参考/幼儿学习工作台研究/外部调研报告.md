## 2. 阅读与自然拼读

### 已核实事实

1. UFLI Foundations 官方页将课程描述为 explicit、systematic，并强调 scope and sequence、automaticity 和 confidence；工具箱包含 lesson slide decks、decodable passages 等实施材料。
2. Reading Rockets 的 phonics 页面明确建议显式、系统、按组织好的字母-音关系教学，并要求大量累计练习；其 decodable text 说明强调文本要使用孩子已学的音-字关系，同时只允许有限的高频/特殊词。
3. Open Source Phonics 页面列出 review、phoneme awareness、concept presentation、reading/writing practice、dictation 和 repeated reading 等课节元素，但该站点的再分发许可证在本次抓取中没有得到清晰确认。

### 设计推断

- “认识字母”不等于“能读词”；每个新音/组合必须尽快进入合成、分解和短文本应用。
- 可解码文本需要由规则检查器验证，而不是凭成人直觉判断“看起来简单”。
- 复习要有累计性，不能每天只展示新的卡片。

### 本项目采用

- 自然拼读 60 日路线：音素意识 → 第一组字音 → CVC → 短元音/词族 → 常见组合 → 连缀 → 可解码短句 → 复习迁移。
- 每节包含“回顾 2-3 分钟、当日新知 3-5 分钟、引导练习 5-7 分钟、应用 3-5 分钟”；幼儿不要求一次完成完整成人课时。
- 课程内容使用 `newPatterns`、`reviewPatterns`、`decodableTexts`、`trickyWords`、`decodabilityPercent` 字段，未通过 QA 的短文不能进入发布数据。

## 3. 英语听说与家长互动

### 已核实事实

British Council LearnEnglish Kids 的家长支持页建议使用短活动，孩子可以独立完成或只需要有限指导；家长不必能说英语，可以用自己的语言说明，活动过程中让孩子使用英语。网站导航把 listen/watch、read/write、speak/spell、games、print/make 分开。

### 本项目采用

- 英语首页只显示“今天一小步”，内部按听说热身、自然拼读、绘本/短故事三条路线组织。
- 口语任务记录“尝试过/跟读/自己说/家长观察”，不因为浏览器语音识别失败而阻断奖励。
- 家长页面显示下一次陪伴动作，而不是把儿童页面变成家长表格。

## 4. 幼儿数学

### 已核实事实

NAEYC 文章将早期数学描述为可以通过有意义、愉快、游戏化的学习经验形成；Tavily 找到的 IES 研究机构文章也把 play-based learning 与语言、数学和社会情绪发展联系起来，但该文章正文在本次抓取中已失效。

### 本项目采用

- 先用实物/图片/动作，再显示数字符号；每道题有“看一看、摆一摆、说一说、选一选”中的至少两个环节。
- 难度不是单纯增加题量，而是按可观察技能分级：数量对应 → 5 以内合并/取走 → 10 以内加减 → 乘法作为重复分组的体验，不在幼儿版强行做笔算口诀。
- 答错只进入复习队列，不扣阳光；连续答对只解锁“更有趣的下一关”，不制造失败惩罚。

## 4.5 跨学科复习

### 已核实事实

Australian Education Research Organisation 的 spacing and retrieval practice 指南把间隔学习定义为把同一内容分散到两次或更多课程，并把提取练习定义为主动从记忆中回想；指南同时强调反馈、低风险练习和跨情景应用。正文快照见 `raw/firecrawl/aero-spacing-retrieval.md`。

### 本项目采用

所有学科都保留 `reviewTags` 和 `nextReviewDate`：新知当天短回顾，之后按 `+1/+3/+7/+14` 或错误插队复习；复习不单独制造第二份课程完成 ID。识字是看字/组词，数学是混合数量题，古诗是听画面/排序，英语是旧音/旧词，运动是旧动作/规则，成长游戏是旧花园操作。

## 5. 运动与专注

### 已核实事实

Tavily 找到的美国 Physical Activity Guidelines 摘要写明 3-5 岁儿童应在一天中保持身体活动并由成人鼓励多种活动；NHS 页面建议 3-4 岁儿童每天累计至少 180 分钟不同强度的身体活动，并避免长时间不活动。

### 本项目采用

- 网页只提供 30-90 秒的动作卡和亲子小游戏，不宣称网页计时等于全天运动量。
- 每日运动任务以动作完成/家长观察为证据，提供跳、走、平衡、投掷、伸展五类轮换。
- 专注训练采用短回合：找相同、听指令、路线记忆、呼吸/停走；不使用长时间静坐作为“专注力”唯一指标。

## 6. GitHub 项目

### `tanner-griffith/phono-storyforge`

仓库 API 元数据显示 Apache-2.0。README 的可借鉴点不是直接接入，而是“每个孩子有掌握模型 → 选择下一技能 → 生成严格可解码文本 → 确定性 QA → 根据朗读错误更新下一次内容”。该模式适合转化为本项目的 `patternStates`、`reviewQueue` 和短文 QA。

### `dmccreary/reading-for-kindergarten`

README 标注 CC BY-NC-SA 4.0，GitHub API 的 `license` 字段为空但 README 有明确授权说明。它可用于研究前置技能、概念依赖图和章节分层；因为包含 NonCommercial/ShareAlike 边界，不进入当前商业/不明用途的发布制品，也不复制其文本。

## 7. 不从研究直接复制的内容

- UFLI、Reading Rockets、British Council、Open Source Phonics 的课程原文、卡片、音频和绘本。
- GitHub 仓库的教材内容、图片、音频和数据集；Apache 许可只覆盖仓库中受其许可覆盖的代码/文件，不能推断第三方素材也同样授权。
- 商业绘本扫描页、原版游戏角色、搜索图片和没有清楚许可证的 SVG/音频。

## 8. 结论等级

| 结论 | 证据等级 | 是否进入方案 |
| --- | --- | --- |
| 系统、显式、累计的拼读教学 | 官方教育机构正文 + 多源交叉 | 是 |
| 可解码短文必须受已教规则约束 | Reading Rockets/Open Source Phonics 正文 | 是，项目原创实现 |
| 短活动、有限家长指导、孩子自主完成 | British Council 官方正文 | 是 |
| 数学嵌入游戏和具体操作 | NAEYC 官方文章 | 是 |
| 全天运动不能由网页打卡代替 | 官方指南摘要/NHS | 是 |
| 依据每次错误自动生成内容 | GitHub 项目设计，非教育标准 | 只采用“证据驱动推荐”思想，不自动生成未经 QA 的教材 |
