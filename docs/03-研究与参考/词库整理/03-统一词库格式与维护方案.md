# 03 统一词库格式与维护方案

> 目标：英语/汉字/拼音/拼读四类词库统一为"公共字段 + 学科扩展字段"的对象行格式，走同一条校验-构建-消费链路，方便长期维护。**不扩充词量**。

## 1. 统一卡片 Schema（草案 v1）

所有词库的每一行都是对象，公共字段固定，学科特有内容放 `extra`：

```json
{
  "id": "en-apple",
  "kind": "english",
  "text": "apple",
  "zh": "苹果",
  "theme": "食物",
  "level": "L1",
  "phrase": "I eat an apple.",
  "phraseZh": "我吃一个苹果。",
  "media": {
    "image": "assets/img/vocab/apple.png",
    "art": "emoji:🍎",
    "audio": ""
  },
  "source": "base-597",
  "extra": {}
}
```

字段约定：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | `{kind前缀}-{slug}`，全库唯一 |
| `kind` | 是 | `english / literacy / pinyin / phonics / poem / math / motion` |
| `text` | 是 | 卡面主内容（单词/汉字/音节/字母组合） |
| `zh` | 英语类必填 | 中文释义（统一叫 `zh`，废弃 `chinese/translation` 等别名） |
| `theme` / `level` | 是 | 主题分组 + L1–L5 分级（对齐 `levels.json`） |
| `media.image` | 否 | 本地位图相对路径；**禁止 http(s) 外链**（twemoji.maxcdn 教训） |
| `media.art` | 否 | 兜底矢量图描述，`emoji:X` / `color:#xxx` / `dots:N`，由 card-art 渲染 |
| `media.audio` | 否 | 本地 mp3 相对路径，空则回退 Web Speech |
| `extra` | 否 | 学科扩展：识字放 `{pinyin, words[], explain}`，拼音放 `{initial, homophones[], nearPhones[]}`，拼读放 `{graphemes[], phonemes[], stageId}` |

配套一份清单文件 `prj/data/preschool/banks-index.json`：列出每个库的 `path / kind / count / schemaVersion / levels 分布`，脚本和文档都以它为入口，不再靠读代码盘点。

## 2. 统一链路

```
源 JSON（统一 schema） ──▶ scripts/validate-banks.mjs（新增：字段校验/唯一性/外链检查）
                              │ 校验通过
                              ▼
                     scripts/build-preschool-banks.py（既有：生成 JS 全局变量）
                              ▼
                     prj/preschool-*-data.js ──▶ 各课程引擎（接口不变）
```

- 校验脚本挂进 `npm test`，改错列、丢字段、写外链在提交前就报错。
- 引擎消费接口不变（仍是全局变量），迁移对页面零感知。

## 3. 迁移路线（按优先级）

### P1 英语配图回填（收益最大，先做）

1. 从 WordQuest 包按词名筛出 108 个重叠词的 semantic PNG（含 fallback 共约 200 张，<10MB），拷入 `prj/assets/img/vocab/`。
2. 回填 `vocabulary-bank.json` 的 `image` 字段；无图的 489 词继续走 `media.art` 的 emoji-SVG。
3. `.gitignore` 加 `prj/assets/vocab/wordquest-vocab-2026.08.15/`，84MB 原包不入 git。

### P2 格式统一

1. 写一次性脚本把 `character-bank.json` 从数组行转成统一对象行（`[字,拼音,主题,组词,讲解,level]` → `{id,kind:'literacy',text,extra:{pinyin,words,explain},theme,level}`）。
2. 其余各库做字段改名归一（`chinese→zh` 等），生成 `banks-index.json`。
3. 更新 `build-preschool-banks.py` 读新格式；生成产物保持不变，页面不用改。

### P3 外部数据反哺（不加词，只补字段）

- 识字：用外部 800 字库比对，补 `character-bank.json` 里空缺的组词/讲解。
- 拼音：把外部 180 条的 `homophones/nearPhones` 合入 `extra`，练习题干扰项从写死改为按数据生成。

### P4 发音升级（可选，验收后再定）

- 默认维持 Web Speech API。
- 如需真人级音质：用 Piper TTS（MIT）本地对 597 词 + 1500 字高频词批量生成 mp3，落 `assets/audio/`，`media.audio` 有值时优先播文件、无值回退 Web Speech。不引入 AGPL 音频包。

## 4. 日常维护守则

1. **改词库只改源 JSON**，然后跑 `python scripts/build-preschool-banks.py` + `npm test`，禁止直接编辑生成的 `preschool-*-data.js`。
2. **素材本地化**：图片、音频一律入仓（或走 assets 目录），不允许任何 http(s) 热链。
3. **词量冻结**：英语 597 词为基线，新增词需要单独立项评审，不随素材接入顺带扩张。
4. **改动留痕**：批量修数据的一次性脚本放 `scripts/` 并保留，方便追溯每轮修复做了什么（现有 `repair-english-kid-gloss.mjs`、`repair-isee-phrases.mjs` 即此模式）。
