# 01 当前词库现状

> 统计时间 2026-08-15，来源 `scripts/inventory-vocab-banks.mjs` 实测。

## 1. 词库清单

源数据统一放在 `prj/data/preschool/`，按学科分目录：

| 学科 | 文件 | 条数 | 行格式 | 关键字段 |
| --- | --- | --- | --- | --- |
| 英语单词 | `英语/vocabulary-bank.json` | 597 | schema v1 对象 | `id / kind / text / zh / theme / level / phrase / media / extra`；主题序列，全 L1 |
| 识字（汉字） | `识字/character-bank.json` | 1500 | schema v1 对象 | `extra:{pinyin,words,explain}`；L1–L5 各 300 |
| 拼音 | `识字/pinyin-initial-bank.json` | 63 | schema v1 对象 | `extra:{initial,sample,kind,group,homophones,nearPhones}` |
| 拼读（词） | `english/phonics/word-bank.json` | 94 | schema v1 对象 | `extra:{graphemes,phonemes,stageId}` |
| 拼读（字母） | `english/phonics/letter-bank.json` | 26 | schema v1 对象 | `extra:{letter,sound,keyword,group}` |
| 清单 | `banks-index.json` | 5 库 | 索引 | 条数 / schemaVersion / levels 分布 |
| 古诗 | `古诗/poem-bank.json` | 34 | 对象 | 题目/作者/诗句/释义（meaning 已补全） |
| 数学 | `数学/problem-bank.json` | 50 | 对象 | 题型模板 |
| 运动与专注 | `运动与专注/motion-bank.json` | 16 | 对象 | 动作卡 |
| 汉字笔顺 | `prj/preschool-literacy-strokes-data.js` | 165 字 | JS 全局 | hanzi-writer 格式笔顺数据 |

分级由 `prj/data/preschool/levels.json` 定义（L1–L5），各库条目带 `level` 字段，引擎侧支持按级过滤。

## 2. 构建与消费链路

```
prj/data/preschool/*.json          源数据（人工/脚本维护）
        │  scripts/build-preschool-banks.py
        ▼
prj/preschool-*-data.js            生成的 JS 全局变量（浏览器直接 <script> 加载）
        │
        ▼
prj/app.js + preschool-literacy.js / preschool-poetry.js / …   课程引擎
```

- 页面无打包器，靠 `index.html` 里 `?v=` 版本号做缓存刷新。
- 修改源 JSON 后必须重跑构建脚本并更新版本号，`npm test` 有断言把关。

## 3. 配图现状

- 英语 101 词有本地 PNG（`media.image`），495 词 `media.art=emoji:X`，102 虚词 `art=none`。
- 运行时唯一入口：`resolvePreschoolCardMedia`（位图 > emoji-art > 纯文字）。
- `preschool-card-art.js` 支持 `emoji:X` / `color:#xxx` / `dots:N` / `none`。
