# 02 外部词库与素材分析

> 覆盖两个本地外部源 + 开源资源调研。重叠度均以工作台现有 597 个英语词为基准实测。

## 1. WordQuest 词库包（重点）

位置：`prj/assets/vocab/wordquest-vocab-2026.08.15/`（已拷入本仓库，**当前未被 gitignore**）。

### 1.1 包内容

| 项 | 实测值 |
| --- | --- |
| Schema | `wordquest.vocab-runtime.v1`（`manifest.json` + `catalog.json` + `chapters.json`） |
| 卡片数 | 2289（全部唯一词） |
| 媒体 | 2592 个文件，共 **84MB**，全部本地路径（semantic 图 2289 + fallback 图 612 + 音频 282） |
| 卡片字段 | `word / translation / phonetic / example / exampleZh / phrase / category / stage / difficulty / gamePolicy / image / imageFallback / audio / distractors / sourceIds / quality` |
| 章节结构 | 5 个 difficulty 章节 → 232 组 × 10 卡 |

按 stage 分布：**minecraft 1978（86%）**、kindergarten 249、junior_high 40、elementary_upper 14、elementary_lower 7、extension 1。

### 1.2 与工作台 597 词的匹配度

- 全包 2289 词中与我们重叠 **108 个**（18% 覆盖我方词表）。
- kindergarten 子集 249 词中重叠 **104 个** —— 即它的幼儿园层几乎是我方词表的子集，但只覆盖我们六分之一。
- 例句质量：463 条 phrase 是 "use the X" 之类的游戏指令风格，不是学习例句；`example/exampleZh` 稍好但仍偏游戏语境。
- 音频只有 282 条 mp3（12% 覆盖率），不成体系。

### 1.3 结论（2026-08-15 修订：Minecraft 词按兴趣词库接入）

- **重叠 108 词**：本地 PNG 直接回填核心词库的 `image` 字段，33 条 mp3 一并接入。
- **Minecraft 1978 词**：用户确认娃对 Minecraft 感兴趣，**作为独立兴趣词库分批接入**（不混入核心 L1–L5，详见 1.4 质检与 `docs/plans/T20260815-vocab-unify/` S5 阶段）。
- **不接入**：WordQuest 的章节/闯关结构（服务于 `wordquest.game.v2` 协议）；junior_high 等其余 stage。
- **仓库卫生**：84MB 原包 `.gitignore`，按批次只拷需要的媒体进 assets。

### 1.4 Minecraft 子集字段质检（1978 卡实测）

| 字段 | 覆盖率 | 质量结论 |
| --- | --- | --- |

| `phrase` 词组 | 1978/1978 | 17 个模板，403 张是 "use the X" 游戏指令风；兴趣词库场景可接受，也可模板级重写 |

| `phonetic` 音标 | 463/1978（23%） | 幼儿卡不展示音标，可忽略不补 |

难度与类别分布：difficulty 5 占 53%（1057 张，多为方块/物品量产变体）；趣味类别 mob 154 / biome 146 / tool 72 / effect 33 / food 30 / structure 29 / weapon 5，plant 202、block 538、item 461、color 277。

**接入建议**：第一批取 difficulty 1–2（324 词，适龄，图 24.2MB）；第二批按趣味类别补 mob/biome/tool/food；block/item/color 的量产变体（如各色羊毛）不进学习流，可留作游戏词池。

## 3. 开源素材调研（图片 + 发音 + 汉字）

### 3.1 图片（emoji 图库，均可离线自托管）

| 库 | 许可 | 说明 |
| --- | --- | --- |
| Noto Emoji | Apache-2.0 | 许可最宽松，Google 维护，SVG/PNG 齐全 |
| Twemoji | CC-BY 4.0 | 需署名；官方 CDN 已死，用 jsDelivr 或下载 GitHub release 自托管 |
| OpenMoji | CC BY-SA 4.0 | 风格统一好看，但 SA 传染性需注意 |

现状的 emoji-in-SVG 方案（系统字体渲染 emoji）已经零依赖可用，只有追求跨平台渲染一致时才需要引入上述图库的本地 SVG。

### 3.2 发音

| 方案 | 许可/成本 | 结论 |
| --- | --- | --- |
| Web Speech API（现状） | 免费、离线、零维护 | **维持**，覆盖中英全部内容 |
| PronounceHow 数据集 | CC BY-SA 4.0，34,805 词 IPA+音频 | 备选，体积大，只在需要真人音时按词筛取 |
| Early Reader 音频包 | AGPLv3 | **不用**，许可传染风险 |
| Piper TTS 本地生成 | MIT，本地跑模型出 mp3 | 若 Web Speech 音质不满意，可对 597 词一次性批量生成，产物入 `assets/audio/` |

### 3.3 汉字与拼音

- 笔顺/字形：`hanzi-writer` + makemeahanzi 数据（Arphic 许可，可再分发），我方已用其格式存了 165 字，扩到 1500 字只是数据量问题。
- 拼音标注：`cnchar`（已在 devDependencies）可批量校验 `character-bank.json` 的拼音列。
