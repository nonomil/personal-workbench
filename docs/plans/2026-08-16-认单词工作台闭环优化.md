# 认单词工作台闭环优化实施计划

> **给 Claude:** 必需子技能：使用 `superpowers:executing-plans` 来逐任务实施此计划。

**目标：** 在幼儿工作台的英语专区内，把现有“今日 3 词、客观题、错词本、词汇档案”整理成一条清晰、可操作、适合儿童与家长共同查看的首页闭环。

**架构：** 继续使用现有 `preschool-english-vocab.js` 引擎、`courseProgress.english.mastery` 和本地素材，不新增第二套学习状态。新增一个纯函数摘要和一个英语专区首页视图：摘要负责计算已会、练习中、待复习、本周新增、连续学习与当前阶段；视图负责渲染参考方案中的成长摘要、今日测评、错词本、词汇档案和学习连续卡片。闪卡和弹层题型流程保持原有入口，只由首页 CTA 触发。

**技术栈：** Vanilla JS、现有本地存储与课程引擎、HTML/CSS、Lucide 图标、本地 SVG/PNG 词汇素材。

**素材策略：** 优先复用仓库现有 project-original 词汇插画、`storybook-token` 与 `star-companion`。本次不读取或写入外部 API key，也不直接复刻参考图中的角色；若后续出现确实缺失的透明装饰，再按 `transparent-image-generator` 流程单独生成并做透明度校验。
