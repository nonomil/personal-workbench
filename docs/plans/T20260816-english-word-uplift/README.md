> 状态：in-progress（S1–S5 代码已绿，浏览器已走关键路径，未标 accepted）| 优先级：P1 | 前置：T20260815-B3（英语日定量已落地）、T20260815-vocab-unify（词库/素材 schema 已统一）

## 为什么有这个包

工作台英语专区的认单词目前是「今日 3 词 → 听词自评会了/不会 → 中英配对 → 拼写」。两份外部参考指出了明确缺口：

1. **DS 认单词参考方案**（`docs/01-方案/学习项目设计/DS--认单词--参考方案.md`）：
   - 缺客观题型（听音选图 / 看图选词），自评"会了"无法反映真实掌握；
   - 错词只进通用错题本，没有按错误类型（听力误判/含义混淆/拼写错误）分类的英语错词本；
   - 没有词汇量档案与成长曲线，家长看不到"离目标还有多远"。
2. **打BOSS单词游戏**（外部小红书笔记）：拼对单词=放技能打 BOSS 的强反馈玩法，是把"背单词"变成孩子主动请求的关键——工作台三世界游戏目前没有单词向的。

另外 80 词日闭环的配图覆盖不全（597 库仅约 101 张图），需要生图补齐。
