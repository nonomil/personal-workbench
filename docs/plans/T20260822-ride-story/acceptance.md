# 手玩验收

## D1

- [ ] A1 新档进营地，出生点旁能骑上龙，能飞、能喷。
- [ ] A2 约 20 秒后自动落地，toast 含「商人摊」或「龙鞍」。
- [ ] A3 落地后再按 F / 右键，不起飞，提示去商人摊。
- [ ] A4 练习房或词块攒到 ≥40 金，商人摊能看见「龙鞍 / Dragon Saddle / $40」。
- [ ] A5 购买后金币 −40，再骑不再倒计时落地。
- [ ] A6 刷新页面，龙鞍还在，仍能长骑。
- [ ] A7 未买鞍进第 1 关，对龙按 F 不飞。
- [ ] A8 HUD 攻击/防御数字不因买鞍改变。
