# 幼儿暑期作业台 2.0 刷新方案

日期：2026-07-31
范围：幼儿学习工作台；成人版、儿童版保持隔离。

## 复审结论

当前版本已经具备阳光、成长、收集、宝箱和豌豆防守闭环，但与新增参考帧相比仍有三处明显差距：

1. 默认首页只有 3 项今日任务，参考版是 6 项左右的暑期小任务密度。
2. 奖励中心是平铺卡片，没有把低、中、高和亲子奖励组织成清晰的阳光商城层级。
3. 防守场目前只有一条视觉 lane；参考帧通过多行棋盘、植物列和入侵者列强化“完成任务后立即守护”的反馈。

## 本轮设计决策

### 首页信息架构

保留当前已经验证过的顺序：顶部 HUD -> 今日任务 -> 花园防守 -> 宝箱/收集 -> 课程/家长。将今日默认任务扩展到 6 项，桌面端三列两行，移动端一列，所有卡片仍是大触控目标。

### 视觉方向

继续使用原创像素方块世界，不直接复制参考图的紫色界面或任何官方游戏素材。页面底色维持天空蓝，导航保留森林绿和阳光黄，以参考帧的紫色反馈状态作为“完成态/提醒态”辅助色，而不是主色；任务文字和交互状态由 HTML/CSS 渲染。

### 防守场

防守棋盘固定为 3 路、6 列：左侧是植物列，中间是可视网格，右侧是友好云朵入侵者。每次发射豌豆只消耗 1 点防守能量，短动画展示豌豆飞行和命中闪光；减少动效时保留生命值、按钮文案和状态提示。

### 阳光商城

幼儿奖励按“小奖励 / 开心奖励 / 亲子奖励 / 特别奖励”分层展示。余额、下一层差额、领取幂等和收藏事件继续使用现有成长快照及奖励 API，不另建账本。

### 兼容迁移

新增 `preschoolDayPlanVersion: 2`。旧幼儿快照首次读取时，只补齐缺失的 3 项新任务，不覆盖已有完成状态、阳光、收藏或防守状态；迁移后版本号写回快照。

## 验收清单

- 新鲜幼儿快照默认显示 6 项今日任务。
- 旧的 3 项幼儿快照加载后补齐新任务且原有状态不变，重复加载不重复追加。
- 奖励页显示四个层级，仍能正常领取和防重复领取。
- 防守区有 3 路/6 列棋盘；入侵者出现、豌豆能量、命中和生命值都有可访问状态。
- 任务完成、入侵者召唤、豌豆发射和奖励领取均有文字反馈，`prefers-reduced-motion` 下仍可用。
- 成人版、儿童版、账号/同步、本地导入导出和 Android/Pages 发布入口不受影响。
