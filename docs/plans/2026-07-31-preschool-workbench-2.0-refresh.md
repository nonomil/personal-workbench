# 幼儿暑期作业台 2.0 刷新方案

日期：2026-07-31
范围：幼儿学习工作台；成人版、儿童版保持隔离。

## 复审结论

当前幼儿版已经落地源笔记中的 2.0 体验重点：六项暑期小任务、完成后的阳光与语音反馈、可选 BGM、页面切换动效，以及把任务结果接到原创植物防守场。参考帧的紫色路线栏和浅紫工作区也已作为幼儿版首页主题，花园场景仍保持原创素材与 HTML/CSS 棋盘。

本轮复审发现项目中已生成一套更完整的 `published-gpt-v2` 原创像素素材。本轮将它作为 UI 组件包落地：导航按钮、任务图标、地图地标、草地平台、能量条和连续奖励条进入实际页面；参考视频截图只保留为离线证据，不再作为首页背景素材。

## 本轮设计决策

### 首页信息架构

首页顺序固定为：顶部 HUD -> 六项成长状态 -> 紧凑三路六列花园防守 -> 今日任务 -> 宝箱/收集 -> 语数英课程/家长互动。首页防守卡保留生命值、豌豆按钮和三路棋盘，把路线节点与陪伴信息留给成长页，避免防守卡挤出首屏任务。桌面端通过 `map / quest / side` 网格区域让防守区位于左侧、任务区位于左下、宝箱与收集位于右侧；窄屏改为防守、任务、侧栏纵向排列。任务卡为三列两行，窄屏保持两列；侧栏在窄屏固定为约 152px 的单列路线栏，贴近参考帧的移动工作台结构。

### 视觉方向

幼儿版使用紫色路线栏、浅紫主工作区、白色信息面板和绿色原创像素花园。任务文字、状态卡、完成态和交互反馈由 HTML/CSS 渲染；素材只使用本项目已有原创像素图，不复制参考视频、WorkBuddy 或植物大战僵尸的角色、字体、商标和音效。

### 新素材落地方式

- 侧栏使用 `nav-*` 和 `settings-gear` 图标，保留文字标签和键盘顺序，图像只承担识别作用。
- 防守场使用 `castle-gate`、`river-bridge`、`grass-patch`、`grass-platform`、`fence`、`small-tree` 组合为原创花园背景，参考帧不进入运行时背景。
- 六项任务优先使用 `task-book-icon`、`task-sun-icon`、`task-water-icon`、`flower-pot` 和 `cat-helper`，让语数英、创意和生活任务在图像上有区别。
- 能量 HUD 使用 `player-energy-bars`，连续状态使用 `streak-stars`，动态数值仍由 HTML 文本呈现，避免把不可读文字烘焙进图片。

### 防守场

防守棋盘固定为 3 路、6 列：左侧是植物列，中间是四个路径格，右侧是原创云朵小怪列。每次发射豌豆只消耗 1 点防守能量，短动画展示豌豆飞行和命中闪光；减少动效时保留生命值、按钮文案和状态提示。完成任务、课程、浇水、奖励和连续行动会通过唯一事件增加防守能量或解锁收藏，不另建积分账本。

### 阳光商城

幼儿奖励按“小奖励 / 开心奖励 / 亲子奖励 / 特别奖励”分层展示。余额、下一层差额、领取幂等和收藏事件继续使用现有成长快照及奖励 API，不另建账本。

### 2.0 交互与兼容迁移

- 顶部状态条同步显示阳光、植物、豌豆能量、等级、连续天数和收藏进度。
- 今日六张大图任务卡都支持直接点击完成/取消，每张卡显示学科图标、阳光奖励和完成态；完成后即时更新阳光、任务状态、花园防守能量和反馈浮层。
- 奖励页在四层奖励上方显示当前阳光、下一份未领取奖励、动态进度条和差额提示，进度仍来自成长快照，不另建账本。
- 设置页提供花园音乐、动效和语音夸奖开关；BGM 只在用户操作后启动，关闭动效时业务仍正常结算。
- 页面切换使用短入场反馈，`prefers-reduced-motion` 下自动关闭动画。
- 侧栏仍保留导入/导出、本地优先和自托管账号同步入口。

### 兼容迁移

新增 `preschoolDayPlanVersion: 2`。旧幼儿快照首次读取时，只补齐缺失的 3 项新任务，不覆盖已有完成状态、阳光、收藏或防守状态；迁移后版本号写回快照。

## 验收清单

- 新鲜幼儿快照默认显示 6 项今日任务。
- 旧的 3 项幼儿快照加载后补齐新任务且原有状态不变，重复加载不重复追加。
- 奖励页显示四个层级，仍能正常领取和防重复领取。
- 首页显示六项成长状态；首页顺序为 HUD、状态条、防守区、任务、宝箱/收集和课程/家长入口。
- 防守区有 3 路/6 列棋盘；入侵者出现、豌豆能量、命中和生命值都有可访问状态。
- 首页侧栏、任务卡、地图地标和防守 HUD 能加载 `published-gpt-v2` 素材，参考截图只存在于 `docs/design-references/`。
- 任务完成、入侵者召唤、豌豆发射和奖励领取均有文字反馈，`prefers-reduced-motion` 下仍可用。
- 平板/桌面任务卡使用三列或两列；390px/320px 窄屏改为单列大卡，侧栏保持单列紫色路线且页面没有横向滚动，标题与完成框不重叠。
- 成人版、儿童版、账号/同步、本地导入导出和 Android/Pages 发布入口不受影响。

- 顶部豌豆 HUD 和成长状态条统一使用 player-energy-bars，并保持像素图的清晰渲染；任务结算、豌豆命中和奖励反馈仍由 HTML 状态与短动画表达。

## 参考帧对照后的 v2.1 优化

最新复核的 6 张参考帧仍与 `docs/design-references/source-workbench-2.0/` 同名文件 SHA-256 一致，未出现需要重新复制的图片资产。参考帧的关键差异在于“植物大战/花园战场”是明确的主入口，而不是只藏在首页卡片里；441px 手机画布也保持两列任务卡，320px/390px 才切换为单列大卡。

本轮执行：

- 幼儿版新增 `battle` 路由和侧栏“战场”入口，使用同一份 `garden` 状态、三路棋盘、召唤/发射动作，不新增第二套积分或数据库字段。
- 战场页补充三步玩法说明、波次/能量/发射/击退记录和植物伙伴选择，任务卡仍由现有本地奖励路径结算。
- 441px 参考宽度的首页防守卡压缩为更接近视频画面的首屏比例，任务卡恢复两列；390px 和 320px 保持单列，保证标题、图标和完成框不重叠。

## 浏览器复核后的移动端调整

实际检查了 441px、390px 和 320px 的同源嵌入视口：三种视口的 `documentWidth` 均与视口宽度一致；441px 使用两列任务卡，390px/320px 使用单列任务卡。紫色路线栏在手机上保持固定单列，保留参考设计的路线入口和像素导航图标，同时给任务、战场和 HUD 留出完整宽度。

桌面端使用固定紫色侧栏；v2.2 根据最新参考帧将移动端也调整为固定的 152px 单列路线栏，设置入口留在路线栏与设置页中，顶部保留必要的页面上下文和成长 HUD。

## v2.2 参考帧对齐

复核参考目录后确认六张截图与 `docs/design-references/source-workbench-2.0/` 的离线副本哈希一致，本轮不重复复制截图，也不把参考图作为运行时背景。根据截图的实际密度继续调整幼儿版壳层：

- 主色从森林绿壳层调整为紫色固定路线栏与浅紫工作区，花园棋盘仍保持绿色，形成“路线栏 / 学习区 / 防守场”的清晰分层。
- 首页新增轻量“今日提示”卡，顶部状态保留阳光、豌豆、连续和设置入口，成长状态压缩为六格，贴近参考帧的首屏节奏。
- 441px 维持两列任务卡，390px 与 320px 使用单列；320px 额外将状态卡网格子项设为可收缩并隐藏内部溢出，发布前以浏览器 `documentWidth` 校验无横向滚动。
- 战场页使用紧凑防守棋盘，把“分层奖励 / 每日挑战 / 植物伙伴 / 守护记录”接在棋盘后面，避免窄屏先看到一大片空的路线地图。
