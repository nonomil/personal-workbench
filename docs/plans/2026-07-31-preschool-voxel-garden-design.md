# 幼儿方块花园工作台设计

日期：2026-07-31  
范围：`preschool-workbench/` 入口及共享幼儿版运行逻辑；成人版、儿童版不改。

## 目标

把“给娃手搓个暑期作业台 2.0”的信息结构和反馈节奏落到幼儿学习工作台中，并形成原创的方块花园防守主题：孩子完成一项学习或生活任务后获得阳光，阳光用于种植、浇灌和解锁植物伙伴；花园出现友好的云朵入侵者时，任务奖励转化为豌豆能量，点击防守按钮完成一轮即时互动。

参考的是功能结构和交互节奏，不复制参考项目或游戏的官方素材、角色、字体和商标视觉。所有画面继续使用本项目已有的原创像素素材与 CSS 方块几何；缺少素材时使用可访问的 CSS/图标降级。

## 用户流程

1. 首次进入幼儿版，进入“今天的冒险”总览。页面首屏直接呈现阳光、连续天数、今日任务、花园状态和奖励宝箱。
2. 孩子点击大尺寸任务卡完成任务。任务只能成功结算一次，阳光、连续天数和任务完成状态沿用现有存储与奖励服务。
3. 完成反馈包含阳光飞入 HUD、任务卡点亮、植物轻微成长、可选语音鼓励和短时 toast；关闭动画或系统减少动效时仍显示明确的状态变化。
4. 当花园出现入侵者时，孩子可以完成任务获得防守能量，再点击“发射豌豆”进行一轮防守。防守只影响幼儿版花园状态，不创建第二套积分账本。
5. 阳光达到植物解锁条件后，孩子在“成长”中解锁/切换植物；连续奖励、收集册和奖励中心提供长期反馈。
6. 家长在设置/家长入口中配置任务、奖励、语音和动效偏好；导入导出、localStorage 本地优先和现有账号/同步适配器继续保留。

## 页面结构

### 幼儿版总览

- 方块天空背景和低对比度网格地面，避免大面积渐变和复杂装饰。
- 顶部 HUD：当前阳光、今日完成数、连续天数、花园安全/警报状态，以及设置入口。
- 主花园战区：固定比例的植物槽位、阳光轨迹、入侵者轨道和状态标签。
- 今日任务：用图标、短标题、学科颜色和大按钮展示任务；完成后变成点亮的方块。
- 右侧/下方奖励区：今日宝箱、收集册、下一株植物和连续奖励。
- 移动端改为纵向顺序，主任务和“发射豌豆”按钮保持首屏可触达；桌面端采用工作台式两列布局。

### 成长/阳光花园

- 显示当前植物、等级、阳光进度、浇水动作、植物伙伴和造型解锁。
- 植物卡片是可点击的大方框，锁定项清楚显示所需阳光；不能用模糊的空白占位。
- 花园战况与总览共享同一 `garden` 视图模型，避免两个页面状态不一致。

### 原有功能入口

课程、改错、奖励、家长、账号和设置继续由现有幼儿版页面处理。重做只替换幼儿版的呈现层和交互反馈，不删除现有内容，也不改变成人/儿童版的共用默认样式。

## 状态与兼容

继续使用 `petbank_huchuliang_preschool_workbench_state_v1`，优先通过 `storage.js` 和 `preschool-garden.js` 的公开 API 读写。新增状态只允许追加在幼儿版状态的 `garden` 下，并由归一化逻辑提供默认值：

```text
garden.defenseEnergy        当前可发射能量
garden.defenseShots         已完成防守次数
garden.invader.health       当前入侵者生命值
garden.invader.wave         当前波次
garden.lastDefenseDate      最近一次防守日期
garden.feedbackPreferences  voice / motion / music 偏好
```

任务奖励仍走现有 `completePlan`/奖励事件路径，不能直接改共享积分 key。重复点击、重复完成和重复发射必须幂等。旧快照缺少上述字段时按默认值恢复，旧的 `zombieActive`/`invaderActive` 字段继续可读。

## 视觉与交互规则

- 主题色：草地绿、阳光黄、天空蓝、土壤棕和警报红；紫色只作为非幼儿版历史界面兼容色，不作为幼儿版主色。
- 方块风格来自边缘、阴影、网格、像素素材和硬朗 2-6px 圆角，不依赖官方游戏素材。
- 幼儿按钮最小触控区域 48px；图标配短文字和 `aria-label`，避免只有图形没有含义。
- 用 CSS 动画实现阳光飞行、完成闪光、植物呼吸、入侵者退场；`prefers-reduced-motion: reduce` 时关闭位移动画，只保留颜色/文本状态。
- 音效/BGM 使用现有可选设置和浏览器用户手势限制，不自动播放；失败时不影响任务完成。
- 图片加载失败时隐藏图片并显示 CSS/图标降级，深层 GitHub Pages 路径继续走相对资源基址。

## 验收标准

- 总览首屏能看到任务、阳光、花园状态和奖励；桌面与移动布局均不溢出。
- 完成一项任务后只增加一次阳光，任务卡、HUD、花园和反馈同步更新。
- 入侵者出现时可发射豌豆；防守成功后能看到入侵者退场/波次更新，重复点击不会重复结算。
- 植物解锁、种植、浇水、连续奖励和收集册保留并能刷新后恢复。
- 课程、错题本、奖励中心、家长互动、导入导出和账号/同步入口仍可进入。
- 成人版和儿童版截图/契约测试不因幼儿版样式重做而改变。
- `npm test`、静态服务入口检查、移动端准备脚本和 Pages/APK 自动构建门禁通过。
