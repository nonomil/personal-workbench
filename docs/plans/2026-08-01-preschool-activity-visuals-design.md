# 幼儿课程练习卡图形化设计

## 背景

`v0.3.0` 已经把幼儿课程从“点击即完成”改成了可答题的练习闭环，但选项仍主要是文字按钮。幼儿版的目标是少文字、大图形、大方框，因此需要让孩子先通过视觉识别，再阅读短文字。

## 设计决策

1. 每个静态课程活动增加 `optionIcons`，继续放在 `config.js`，不进入 localStorage。
2. 练习面板每个选项显示 Lucide 图形、字母标记和短文本；图形不是唯一信息，文字和答对/答错状态仍保留。
3. 面板顶部增加当前课程内的练习进度，例如“第 2 张 · 已完成 1/3”，帮助孩子知道下一步，不增加额外任务账本。
4. 继续使用现有 `lessonSession` 临时状态和 `completeCourseLesson()` 奖励路径；错误选择不写快照。
5. 图形优先使用项目离线可用的 Lucide 图标，避免新增网络字体或运行时图片依赖；`prefers-reduced-motion` 继续关闭弹簧动画。

## 验收标准

- 21 个幼儿活动都提供与选项数量一致的 `optionIcons`。
- 练习弹窗每个选项同时有图标和文字，图标缺失时仍能正常显示文字。
- 练习进度在桌面和 320/375/390/441px 视口中不换出弹窗边界。
- 答错、答对、完成奖励和 localStorage 课程进度行为与 `v0.3.0` 保持一致。
- 全量测试、浏览器交互、APK 构建和 MuMu 启动检查继续通过。
