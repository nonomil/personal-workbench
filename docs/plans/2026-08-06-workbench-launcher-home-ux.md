## 1. 背景与当前事实

当前根入口已经有五张入口卡，但用户的选择模型是“两类入口”而不是“三套工作台”：

1. 幼儿端共用一套运行时和一份本地成长快照，只切换视觉主题：植物大战僵尸式花园、我的世界式方块探险、马里奥式横版闯关。
2. 成人端和少儿端是另外两个独立的通用工作台。
3. 已记住工作台时，根入口会自动进入上次选择；需要通过 `?choose=1` 回到选择页。

根入口的页面顺序必须表达这个模型：

```text
根入口
├─ 幼儿游戏世界（上方）
│  ├─ 植物大战僵尸式花园
│  ├─ 我的世界式方块探险
│  └─ 马里奥式横版闯关
└─ 成人与少儿工作台（下方）
   ├─ 成人成长工作台
   └─ 儿童学习工作台
```

## 2. 设计决策

### 2.1 首屏层级

- 页面标题先说“选择今天的工作台”，避免把五个入口误解成五份互相独立的数据。
- 第一分组命名为“幼儿游戏世界”，明确三张卡是同一幼儿工作台的视觉入口。
- 第二分组命名为“成人与少儿工作台”，与幼儿世界之间使用独立的分组标题和间距。
- 最近使用状态只做辅助信息，不改变五张卡的顺序；自动跳转仍允许通过 `?choose=1` 复看全部入口。

### 2.2 视觉策略

- 幼儿世界卡：使用已有主题主图作为视觉主角，保持三种高辨识度的主题色——草坪绿、方块蓝、平台天空蓝/红色点缀。
- 成人/少儿卡：保留已有工作台主图，但降低视觉饱和度和卡片高度，让它们成为稳定入口而不是幼儿游戏卡的竞争对象。
- 使用 CSS Grid 表达“上三下二”：宽屏三列 + 两列；中屏两列并让第三张幼儿卡独占下一行；竖屏单列。
- 不使用 emoji 代替导航图标；入口图像、文字标签和颜色共同表达主题，颜色不是唯一状态线索。

### 2.3 交互与可访问性

- 每张卡仍是一个完整链接，避免卡片内部嵌套按钮造成点击冲突。
- 链接最小触控区域保持 44px；卡片本身提供 hover、focus-visible 和按压反馈，但不因缩放造成布局跳动。
- 图片保留准确中文 `alt`；分组使用 `aria-labelledby`；键盘 tab 顺序与页面视觉顺序一致。
- 记住幼儿主题时只保存 `preschool` 变体和主题 ID，不创建第四个幼儿运行时变体。
