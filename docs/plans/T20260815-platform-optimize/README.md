| # | 缺口 | 级别 |
|---|---|---|
| 1 | 碰撞债（当前状态 3.13 在案）：水平击退死代码、全宽地面碰撞缺保护 | P0 债 |

| 4 | `bestTime` 静默存储孩子看不见；结算无长线进度；星芒零出场 | P0 |

S2（二期）：P4 时间挑战外显、P5 检查点反馈、P6 关卡减肥复查——见分册 `01-玩法优化方案.md` §4/§5 与 `04-落地路线与验收.md`。
