## 一页结论

1. **Echo Loop 的精华不是代码，是方法论产品化**：把「盲听→精听→跟读→复述→间隔复习」做成自动推进的阶段机 + 今日任务队列，用户零决策。这套思路可以整体平移到方块传奇（关卡=材料、复习副本=复习轮）和工作台英语专区（今日词队列）。
2. **AGPL 边界（已确认口径）**：参考、阅读、提炼参数都允许；唯一纪律是**不复制粘贴代码和资源文件**，以保留将来发布/自选协议开源的自由。`Echo-Loop-main/` 已 gitignore（zip 被既有规则覆盖），本地保留作参考（见 01 §4）。
3. **最高性价比的三件事**（P0）：
   - 跟读评测引擎：ASR 文本 + 词形还原 + LCS 覆盖率 + 分级阈值，替换/加强 blocklegend `speech-input.js` 的判定，同时给 Boss「说」通道一个可信的过关判据；
   - 复习之门：把 Echo Loop 的固定 7 轮复习课表（6h/1d/2d/4d/7d/14d/28d）做成方块传奇的「关卡复习副本」，并统一工作台 mastery 的 `[1,3,7,14]` 间隔口径；
   - 今日任务队列：到期复习 > 未到期复习 > 新学，游戏首页与工作台英语专区共用同一排序。
4. **刻意不抄**：完整 FSRS、波形对齐、云端发音打分、Anki 全功能、订阅体系。先用最小机制跑通闭环。
