# 02 · 方块传奇借鉴方案（E1–E4 分期）

前提：方块传奇已落地到 P3.7（战斗词卡阶梯、Boss 破罩、同关复习、597 词闭环、跨日 mastery 回流）。
本方案回答：**Echo Loop 的哪些机制能让它的英语闭环更完整**，以及怎么改。

## 0. 现状与 Echo Loop 的对照

| 维度 | 方块传奇现状 | Echo Loop 对应机制 | 差距 |
| --- | --- | --- | --- |
| 学习推进 | 玩家自己选关，词卡随战斗出现 | 阶段机自动推进 + 今日任务队列 | 无「今天该干什么」的入口 |
| 复习调度 | 同关会话复习（`sessionReviewKeys`）+ 工作台 mastery `[1,3,7,14]` 天 | 固定 7 轮课表（6h→28d）+ 宽限窗口 + 到期优先 | 缺 6h/当日轮；到期词只是混进 `focusPool`，无专门复习场景 |
| 说的训练 | `speech-input.js` Web Speech（国内易失败）、判定粗 | ASR 三档降级 + lemma + LCS 覆盖率 + 分级阈值 | 评测不可信 → Boss「说」通道体验差 |
| 难词处理 | `missByWord` 同关重绑金色词块；通关写 `progress.reviewWords` | 难句自动归档 → 复习轮专项补练 | 跨日难词没有专属玩法出口 |
| 词卡语境 | catalog 词均有中英例句，但图鉴/词卡未充分用 | 语境闪卡：翻面播原句 | 例句资产闲置 |
| 统计 | 家长三指标、图鉴阶段 | 输入/输出词数、唯一词形 | 缺听说输入输出比 |

## 1. E1（P0）：跟读评测引擎「说得算数」

**目标**：给「说」一个可信的过关判据，让 Boss 破罩的 speak 通道和「练一句」场景真正可玩。

设计（借鉴 Echo Loop §2.2，全部重写实现）：

1. 新建纯函数模块 `data/speech-match.js`（可 `node --test`）：
   - `tokenize(text)`：只取英文词、小写化；
   - `lemma(word)`：轻量词形还原——先查不规则表（幼儿词表规模下 ~100 条足够），再退规则后缀剥离（`-ies/-es/-s/-ed/-ing`）；不引第三方库；
   - `lcsCoverage(refTokens, hypTokens)`：LCS 对齐，返回覆盖率 + 两侧命中标记；
   - `rate(coverage, scene)`：分场景阈值——单词跟读（1 词，命中即过）、短句跟读（Perfect 0.95 / Good 0.75 / Pass 0.5）、复述型（Pass 0.4，更宽）。
2. `speech-input.js` 改为「引擎 + 判定」分离：ASR 拿到什么文本都交给 `speech-match`，不再做内联字符串比较；
   - ASR 三档降级保留现有方向：网关 faster-whisper > Web Speech > 纯录音（录了就给基础分，不阻断闭环）——这是 Echo Loop「评测不阻断主环」的原则。
3. 接入点：Boss speak 通道、`scenes.js` 练一句、词卡 `enpick`/跟读题型；UI 显示逐词命中高亮（答对的词亮色）。

**验收**：`node --test` 覆盖 lemma/LCS/阈值边界；手玩 Boss speak 通道，说对 3/4 词能过、说无关话不能过。

## 2. E2（P0）：复习之门 + 今日任务队列

**目标**：把 Echo Loop 的固定复习课表变成游戏内玩法，解决「通关了就再也不复习」。

设计：

1. **关卡复习课表**：每关通关时记 `completedAt`，按课表生成复习点：`6h → 1d → 2d → 4d → 7d → 14d → 28d`（相对上一轮完成时间链式推进，同 Echo Loop）；存于 `progress.levelReview[levelId] = { round, dueAt, overdueAt }`；
   - 宽限窗口：到期后 24h 内不算逾期；逾期只标记不惩罚（可做可不做，同 Echo Loop 哲学）。
2. **复习之门（玩法载体）**：主界面/关卡选择处出现发光传送门，进入 = 该关的縮短版复习波（2–3 波 + 小 Boss）：
   - 出题池 = 该关 `reviewWords` ∪ mastery 中 `due` 的该关词 ∪ 上轮 `missByWord`；
   - 题型阶梯上移一档（上次 choice 的这次出 spell/speak）——对应 Echo Loop「复习轮比首学难」；
   - 奖励：金币 + 少量阳光（口径低于首次通关，防刷）。
3. **今日任务队列**：进游戏首屏显示「今日冒险」三条，排序 = **到期复习之门 > 即将到期 > 推进新关**。这就是 Echo Loop「决策外包」的游戏化版本——孩子不用想今天干什么。
4. **进度 schema 版本快照**（借鉴 plan versioning）：`progress.reviewPlanVersion = 1`；将来改课表时存量关卡沿用旧表，避免炸已有进度。

**验收**：假时钟单测课表推进/宽限/逾期；手玩一关通关后 6h（调试面板可快进）出现复习之门。

## 3. E3（P1）：语境词卡 + 难词本 + 听说统计

1. **图鉴语境化**：图鉴词卡翻面时显示例句（catalog 已有中英例句）并 TTS 朗读英文例句；已有 33 条包装音频的词优先播真人音频。零新增素材成本，激活闲置例句资产。
2. **跨日难词本**：`missByWord` 通关时合入持久化 `progress.hardWords`（词 + 错误次数 + 最近错误时间）；复习之门出题池优先抽难词；连续答对 2 轮从难词本移除——对应 Echo Loop「难句归档→补练→毕业」。
3. **听说输入/输出统计**：记录 `inputWords`（听音题+盯物卡听到的词次）与 `outputWords`（spell/speak 产出的词次），家长报告加一行「听说比」；唯一词形量用 E1 的 `lemma` 去重统计。

## 4. E4（P2）：句子跟读关（把 scenes.js 升级为迷你 Echo Loop）

现有 `scenes.js`（4 情景 × 3 句）升级为「句子跟读挑战」：

1. 每句走 Echo Loop 跟读引擎的节奏：**播句 → 倒计时录音 → 覆盖率评分 → 间隔 → 下一句**（纯逻辑引擎 + UI 分离，方便单测）；
2. 句子完成度用 E1 覆盖率分级星级（1–3 星）；
3. 场景完成进 mastery 的句级记录（新 namespace，不与词混存）；
4. 素材扩展预留：句子按「文本 + TTS/录音音频」两件套管理，暂不做词级时间戳（无场景，见 01 §3）。
