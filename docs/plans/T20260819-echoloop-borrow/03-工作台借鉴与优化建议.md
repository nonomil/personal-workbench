# 03 · 工作台借鉴与优化建议

范围：工作台英语体系（幼儿英语专区、`preschool-english-vocab.js` mastery 引擎、词库包、家长报告）。
原则：不推翻现有 localStorage + JSON 词库架构，只做机制升级。

## 1. 今日任务队列：英语专区首页「决策外包」（P0）

Echo Loop 最强的产品思路是用户零决策。工作台英语专区现在是「功能菜单」（今日词/我的词库/错词/打 BOSS），孩子和家长仍要自己选。改造：

1. 专区首屏置顶一张「今天练这个」卡片，内容由统一排序器生成：
   - **到期复习词**（mastery `nextReview` 已到）> **快到期词** > **新词引入**（按当日新词配额）；
   - 卡片直接给动作按钮：「复习 8 个词（约 3 分钟）」→ 一键进对应练习，而不是进菜单；
2. 排序器做成纯函数（`selectTodayTasks(masteryState, now, quota)`），blocklegend 的今日冒险（02 §2.3）复用同一份逻辑——**工作台和游戏共享一个「今天该学什么」的事实来源**；
3. 完成后卡片翻转为「今日已完成 + streak」，对应 Echo Loop 的 streak 反馈。

## 2. mastery 复习调度升级（P0，需拍板）

现状：`DEFAULT_INTERVALS = [1,3,7,14]` 天，状态机 `introduced→practicing→ready→maintenance`。

借鉴 Echo Loop 固定课表的两个改进：

1. **加当日轮**：新词引入当天 +6h 一次微复习（哪怕只是听音选图一题）。艾宾浩斯最陡的遗忘发生在头几小时，Echo Loop 的 6h 首轮就是为此。落地：间隔表改为 `[0.25, 1, 2, 4, 7, 14, 28]` 天（0.25≈6h），或维持天级粒度但当天再见一次；
2. **宽限窗口与逾期语义**：`nextReview` 过后 48h 内算正常，超过只标 `overdue` 不降级——不惩罚孩子，只影响排序优先级（overdue 最优先）。

**决策点**：改间隔表影响存量 `nextReview` 数据。建议方案 A（推荐）：新词用新表、存量词沿用旧表自然过渡（即 Echo Loop 的 plan 版本快照思想，给每词记 `planVersion`）；方案 B：一次性迁移全部。

## 3. 复习事件日志：为未来算法升级留门（P1）

借鉴 Echo Loop FSRS 基建的架构方法（只抄架构不上 FSRS）：

1. mastery 每次答题追加一条事件：`{ wordId, ts, mode, correct, source }`（source = workbench / blocklegend / wordboss）——**只追加不修改**；
2. 当前 mastery 状态视为「快照」，事件流是事实来源；
3. 收益：
   - 家长报告可算真实曲线（现在只有当前状态，看不到历史）；
   - 将来想换调度算法（含 FSRS），重放事件流即可迁移，无需猜；
   - 排查「为什么这个词又出现了」有据可查。
4. 体量控制：localStorage 下每词保留最近 N=20 条事件即可，或按月归档到导出文件。

## 4. 跟读评测共享模块（P1，随方块传奇 E1 落地）

02 §1 的 `speech-match.js`（tokenize + lemma + LCS 覆盖率 + 分级阈值）放在共享位置（如 `prj/games/shared/` 或 `prj/lib/`），工作台英语专区的跟读题、自然拼读的读音练习复用同一评测器。收益：全家桶「说」的判定口径一致，单测一份。

## 5. 听说输入/输出统计进家长报告（P2）

借鉴 Echo Loop 的统计哲学——抓输入/输出比而非虚荣指标：

- `inputWords`：听音题、例句播放听到的词次；
- `outputWords`：拼写、跟读产出的词次；
- 唯一词形量：lemma 去重后的「真·认识的词」数量（比「学过 N 词」诚实）；
- 家长报告展示三条：本周听说比、唯一词形增量、streak。

## 6. 内容素材的「三件套」思路（P2，做减法采纳）

Echo Loop 素材 = 音频 + 句时间轴 + 词时间轴。我们词表规模下不需要时间轴，但可采纳其**同名配套 + 校验**的纪律：

- 词条素材统一为「词 + 例句文本 + 例句音频（可选）」三件套，catalog 校验脚本检查配套完整性；
- 新增音频沿用 `T20260815-vocab-unify` 的统一媒体接口，不另起炉灶。

## 7. 提醒机制（P3，Capacitor 侧）

Echo Loop 用固定时刻本地通知（默认 20:00）+ 点击深链到任务。工作台 APK（Capacitor 8）可用 `@capacitor/local-notifications` 做同款：每天固定时刻推「今日复习词 N 个」，点击直达英语专区今日卡。纯 Web 端跳过此项。

## 8. 明确不做

| 项 | 原因 |
| --- | --- |
| SQLite / Drift 迁移 | localStorage + 事件日志在当前体量够用；迁移是纯成本 |
| FSRS 接入 | Echo Loop 自己都没接入业务；先把事件日志铺好 |
| 音频导入/转录管线 | 面向长音频材料的功能，与幼儿词表场景无关 |
| 订阅/账号体系借鉴 | 与本仓库目标无关 |

## 9. 优先级汇总（工作台侧）

| 优先级 | 项 | 依赖 |
| --- | --- | --- |
| P0 | 今日任务队列（§1） | 无 |
| P0 | mastery 间隔升级 + 版本快照（§2） | 需拍板方案 A/B |
| P1 | 复习事件日志（§3） | 无，建议先于 §2 落地 |
| P1 | 共享跟读评测器（§4） | 方块传奇 E1 |
| P2 | 听说统计（§5）、素材三件套纪律（§6） | §3 |
| P3 | 本地通知（§7） | APK 渠道 |
