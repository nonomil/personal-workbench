## 3. W1 工作台手玩

入口：§1 英语专区地址。先点进「英语」专区，不要先点课程菜单。

### 3.1 今日卡三种态（W1-A3）

1. **空库：** 若本机几乎没学过词，置顶卡「今天练这个」应写「先认识几个词」，按钮「开始认识」，点进 `preschool-english-words-1`，**不经过中间菜单**。
2. **有任务：** 卡文案「复习 N 个词（约 M 分钟）」。`M = ceil(N × 25 / 60)`。例：3 词 → 约 2 分钟。点「开始练习」同样直进 words-1。
3. **做完：** 把今日卡点进去的词练完，回专区。卡应翻成「今日已完成 · 连续 X 天」。X 复用现有连续学习天数，不是新账本。

390px / 320px 窗口看一眼：专区**无横向溢出**。控制台无 error。

### 3.2 新词走 v2（W1-A1 前半）

1. 认识一个**以前没记录**的词（或 DevTools 里确认该词无 `planVersion`）。
2. 打开 Application → Local Storage → `petbank_huchuliang_preschool_workbench_state_v1`。
3. 在 `courseProgress.english.mastery.<word>`（或刚练的那科）确认：
   - `planVersion` 为 `2`

   - `events` 至少 1 条：`{ ts, mode, correct, source }`，`source` 为 `workbench`
4. 刷新英语专区。该词会进今日队列的「24 小时内到期 / soon」档（首页 `now` 是本地日期，新词首轮 +6h 当天就会出现在卡上）。**不必真等 6 小时。**

### 3.3 存量走 v1（W1-A2）

3. 再读快照：`planVersion` **仍应缺省或仍为 1**，不得变成 2；间隔仍按 1/3/7/14 天推进（新写入可能变成 ISO，但间隔天数仍是旧表）。

## 4. E1 跟读手玩（方块传奇）

入口：§1 方块传奇地址。允许麦克风。控制台保持打开。

### 4.1 单词跟读 / lemma（E1-A3）

准星对着一只怪或词卡，走「说」通道。目标若是 `apple`，说 **`apples`** 应判对（lemma）。说完全无关词应判错。

### 4.2 Boss 破罩（E1-A1）

打到带罩 Boss。目标短语约 4 词时：

- 说对其中 3 词（可用变形，如 `runs` 对 `run`）→ **破罩**
- 念一句毫不相关的中文或英文 → **不破罩**，界面能看出哪些词没命中

### 4.3 练一句星级与高亮（E1-A2）

顶栏「练一句」。整句复述：

- 覆盖率大约 ≥0.80 → **3 星**（Perfect / Excellent）
- 大约漏一半 → **1 星**（Fair 档）
- 未过关时目标词有 `<em class="bl-hit">` 亮色

阈值备忘（跟读列）：Perfect≥0.95 / Excellent≥0.80 / Good≥0.60 / Fair≥0.40；流程通过 ≥0.5。

### 4.4 无英文 / 无 ASR（E1-A4）

- 只说中文、或完全静音：toast「记下了，没有听清词」，**不判负、不掉血、不破流程**。
- 断开麦克风权限后再说一次：同样降级，不卡死。

### 4.5 既有玩法不回归（E1-A5）

四选一词卡、砍树、挖方块、金币、触屏键位各点一次。控制台无 error。

## 5. E2 复习之门 / 今日冒险手玩

同一方块传奇页。假时钟：

```js
__blDebug.skipHours(6)   // 返回新的 ISO；同时刷新门列表和今日列表
__blDebug.now()          // 看当前假时间
```

`skipHours` **只改本页内存**，刷新页面会回到真实时间。要看「门」或「今日」，快进后不要刷新，直接点顶栏按钮。

### 5.1 首通盖章（E2-A8 前半）

1. 通关第 1 关（或任意未通关）。结算标题「通关啦」，阳光走原 `L.eventKey`。
2. 不要刷新。在 Console：`__blDebug.progress.levelReview`。该关应有 `{ round: 0, lastCompletedAt, reviewPlanVersion: 1 }`。
3. `clearedLevels` 含该关。**没有**新的 localStorage key。

### 5.2 到期发光进门（E2-A1）

1. `__blDebug.skipHours(6)`。
2. 点顶栏「门」。第 1 关按钮应发光，文案「复习之门」，可点。
3. 进门：波数 2–3，Boss 血/罩大约一半（下限 20 / 1）。
4. 结算标题「复习完成」。本局金币增量大约减半。阳光 eventKey 形如 `bl-review-1-0`。
5. **再进同一轮再打完**：阳光不应再发（幂等）。`levelReview[1].round` 变成 `1`，`lastCompletedAt` 更新为假时钟时刻。

### 5.3 题型上移（E2-A2）

复习局里，上次只做过四选一 / 听音 / 看图的词，应更常出拼写或开口。对照：choice/enpick/listen/picture → spell；spell/fill/letters/speak → speak。

### 5.4 逾期仍可进（E2-A3）

1. 一扇门处于 waiting 时 `__blDebug.skipHours(24)` 或更多，直到超过宽限（第 1 轮宽限 6h，其后 24h）。
2. 门上角标「待复习」，**仍可进**，无扣血、无扣金币惩罚。
3. `round` **不变**，只是 status 变 overdue。

未到期门：按钮 disabled，文案「还要 N 小时」。

### 5.5 今日冒险（E2-A4）

1. 进游戏约 1 秒后应自动弹出「今日冒险」（仅首次；关掉后点顶栏「今日」可再开）。
2. 有到期 / 逾期门时，**第一条是门**。
3. 把门都推到未到期（刚复习完，或 `round: 3` 且刚写完 `lastCompletedAt`）：第一条应是 **「推进新关」**，点进去开当前 `unlockedLevel`。
4. 点门卡 = 进复习副本；点关闭「先去探险」= 只关层，世界继续。

### 5.6 图鉴翻卡（E2-A5）

1. 顶栏「图鉴」。文案含「看自己收过的词」。
2. 点一条有例句的词：展开中英例句。
3. 有 `media.audio` 播文件；没有则 `speechSynthesis` 读英文例句。出声即可，不要求音质。

### 5.7 难词本（E2-A6）

同一词**故意答错 2 次**（普通词卡，不是石碑）。

```js
__blDebug.progress.hardWords
```

第一次错：`hardTally` 有计数，`hardWords.length === 0`。第二次错：数组出现 `{ word, misses: 2, lastAt, reviewHits: 0 }`。

进该关复习门，把该词答对 **2 次**（复习局里）。再看：该词从 `hardWords` 消失，`hardTally` 对应键被删。复习里答错会把 `reviewHits` 清零。

### 5.8 听说比（E2-A7）

1. 做几道听音 / 四选一（input）和几道拼写 / 开口（output）。
2. 顶栏「给家长看」。应有一行 `听说比 output/input`，例如听 2 道、说/拼 2 道 → `听说比 2/2`。
3. 全 0 时是「听说比 还没开始」。
4. 数字只增不另开 key：看 `growth.worldGames.blocklegend.stats`。

### 5.9 首通口径不被复习污染（E2-A8）

再通一关**新关**（非复习）：阳光、金币、解锁价与改复习门之前一致。`awardSunlight` 的首通 key 仍是关卡原 key，不是 `bl-review-...`。

## 6. 数据对照（手玩时开着 DevTools）

### 6.1 禁止出现的新 key

手玩前后对比 Local Storage 名称。允许改**值**，不允许新名字。尤其不要有：

- `bl-review-*` 作为 **localStorage key**（它只是阳光 `eventKey` 字符串，活在既有 `growth.awardedIds`）

## 10. E4 练一句跟读（手玩）

入口仍是 `?v=20260819-e4s1`。

1. 点顶栏「练一句」。应先听到原句，状态「听原句」，随后变「该你说」。
2. 跟读或打关键词。评分低也会进遍间停顿（「听下一遍」），不卡死。
3. 同一句走满 3 遍才换下一句。右上可看「第 n/3 遍」。
4. 「再来一遍」可以超过 3/3。「跳过等待」把倒计时压到约 1 秒。
5. 无麦克风：停在「没听清，再点听我说」，打字仍能算一遍。
