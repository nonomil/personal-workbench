# WorkBuddy 幼儿工作台视觉重构

日期：2026-07-31

## 目标

将幼儿版首页从“完整战斗面板”调整为更接近 WorkBuddy 的个人工作台：孩子进入后先看到今天要做的事、已获得的阳光、花园状态和下一份奖励，同时仍能快速进入植物大战与课程模块。

## 设计

### 外壳

保留现有固定侧栏、顶部栏、路由和导入/导出工具。侧栏采用奶油白背景、清晰的激活态和大尺寸植物入口图；顶部只承载面包屑、开始学习动作、阳光和身份信息。

### 首页

首页采用 12 列响应式布局：

- 第一行是短标题、完成进度和阳光/豌豆能量状态。
- 主列是“今天的任务”大卡片，六个任务使用两列网格，卡片图像比说明更大，完成后变为绿色点亮态。
- 次列是“花园状态”预览，显示当前植物、花园安全/入侵状态、成长进度和进入植物大战按钮。
- 第二行是奖励梯子、连续打卡和收集预览。

### 视觉

颜色使用 `#fff8ed` 奶油背景、`#f5fff8` 白绿卡片、`#2f7553` 叶绿、`#ffc83d` 阳光黄、`#73c7d8` 天空蓝和 `#ef896b` 珊瑚橙。主要卡片使用 16-22px 圆角和轻阴影，减少深色边框和紫色像素面板。

### 互动

保留任务点击、阳光增长、植物状态、豌豆能量、奖励入口和现有动效。新的视觉层只负责布局与状态呈现，所有状态变更继续通过现有公开 API 完成。

## 不变边界

- 不改 `petbank_huchuliang_preschool_workbench_state_v1` 的根 key。
- 不新增第二套积分或奖励账本。
- 不修改成人版、儿童版的入口和 CSS。
- 不复制 WorkBuddy 外部源码、图片、统计脚本或品牌视觉。

## 验收

- 首页第一视口同时看见今日任务、阳光、花园状态和奖励入口。
- 桌面版不再由战斗棋盘占满首屏；移动版任务卡和“去植物大战”按钮保持可见。
- 现有 PVZ 植物/僵尸动画、任务完成、导入导出和路由测试继续通过。
