# 幼儿首页行动主线 2.8 设计说明

## 目标

让幼儿首页回答一个问题：现在下一步做什么。首页以“今天打卡 → 继续学习 → 领取奖励/守护花园”为一条清晰的视觉路线，课程页则负责浏览全部学习专区和进度。

## 设计

首页在今日提示和状态卡之后增加三步行动带：

1. 今日打卡：显示已完成数量，按钮进入今日任务；任务全部完成时显示“已点亮”，入口改为查看宝箱。
2. 继续学习：显示当前课程、下一张练习卡和预计时间，直接打开已有的课程练习对话框；全部课程完成时改为“课程都点亮啦”，入口去花园。
3. 成长奖励：显示阳光、收藏和当前花园状态；入侵时进入植物大战，安全时进入奖励中心。

三步使用现有任务、课程进度、花园防守和奖励状态，不新增 localStorage key、不新增积分账本。课程完成仍由 `finishLesson()` / `completeCourseLesson()` 结算原有奖励。

课程目录增强为每个专区显示进度条、完成比例和“继续”状态；点击专区仍通过现有 `#courses?course=` 路由，卡片内练习仍使用 `openLessonDialog()`。

## 响应式与可访问性

- 桌面端三步并排，卡片内容保持固定最小高度。
- 768px 以下改为纵向路线，步骤间用连接线提示顺序。
- 390px / 320px 保持单列、大触控块，文字允许自然换行，不产生横向滚动。
- 行动带使用 `aria-label`、`role=progressbar` 和现有 `[data-action]` 事件委托。

## 验收

- 首页存在三个带明确状态的行动步骤，并能分别进入任务、练习、奖励/植物大战。
- 课程目录每项都有 `completed/total`、进度条和当前状态。
- 不改变现有课程奖励、豌豆能量、localStorage、成人版/儿童版行为。
- `npm test`、`node --check app.js`、`git diff --check` 通过；浏览器 320px/390px 无横向溢出。
