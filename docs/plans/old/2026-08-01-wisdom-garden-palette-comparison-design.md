# 智慧花园配色对比测试页设计

**状态：** 已确认

**目标：** 创建一个不接入主站的独立 HTML 测试页，用相同的幼儿学习工作台内容对比当前版视觉与提示词中的“液态玻璃精致 UI”配色方案。

## 设计范围

- 页面路径：`visual-tests/智慧花园配色对比测试.html`
- 不修改 `preschool-workbench/`、主站路由、localStorage 或 APK 入口。
- 使用现有幼儿版植物素材，避免为一次配色验证重复生成素材。
- 页面本身不依赖构建工具，静态服务或直接打开都可以查看。

## 对比结构

页面顶部提供测试标题、设计说明和视口切换按钮。主体使用双栏对比：

1. **当前版**：保留当前幼儿工作台的紫/暖色工作台层级、侧栏导航、任务卡、阳光状态和植物大战预览。
2. **新方案**：使用提示词定义的橙色品牌、薄荷绿辅助、金色奖励、草绿成功、奶油背景和暖灰文字；通过半透明玻璃卡片、边缘高光、分层阴影和更大的留白体现精致感。

两侧展示同一组内容：今日完成进度、阳光与豌豆能量、三项任务、植物伙伴、奖励入口和学习专区。每侧只改变视觉语言，不改变信息层级，便于直接比较。

## 视觉令牌

- 品牌橙：`#FF8C42`
- 薄荷绿：`#4ECDC4`
- 奖励金：`#FFD93D`
- 成功绿：`#6BCB77`
- 奶油背景：`#FFF8F0`
- 暖背景：`#FFF0E0`
- 主文字：`#2D2D3A`
- 次文字：`#6B6B7B`

新方案的卡片使用白色高不透明度玻璃层、细边框、暖灰阴影和局部橙/薄荷色光晕；不使用黑色阴影，不让渐变成为整页唯一视觉元素。

## 交互与响应式

- “桌面 / 手机”按钮切换测试画布宽度，便于在同一页观察 1440px 和 375px 关系。
- 点击任务卡可切换完成状态，更新进度条和阳光数字。
- 点击奖励按钮显示轻量反馈，不写入主站数据。
- 植物和阳光素材提供轻微呼吸/脉冲动画，支持 `prefers-reduced-motion`。
- 1440px 使用双栏，900px 以下上下排列，560px 以下每个预览内部改为单列，禁止横向滚动。
- 所有按钮提供焦点样式、最小触控尺寸和 `aria-label`；图标使用现有 SVG/Lucide 方案或 CSS 形状，不使用 emoji 作为界面图标。

## 验收标准

- 直接打开或通过本地静态服务可以加载页面和素材。
- 1440px 下两套视觉在同一屏可比较，375px 下不出现横向滚动。
- 任务点击、进度变化、奖励反馈和视口切换可操作。
- 页面不会新增或修改主站 localStorage 数据。
- 现有 `npm test` 不受影响。
