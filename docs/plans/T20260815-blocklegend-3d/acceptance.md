# T20260815-blocklegend-3d · 验收清单

> 用户手玩验收。建议路径：桌面浏览器先走一遍，再在 MuMu/平板上复走关键三步。
> 验收口径：每一项打勾需要能复现；打不了勾的如实标注原因。

## A. 核心学习循环（最重要）

- [ ] A1 进游戏 10 秒内遇到怪物，攻击弹出词卡（英文 + 四个中文选项 + 能听到发音）
- [ ] A2 答对后明显"打得更痛"（暴击数字/音效可感知）；答错或不答，打得慢——孩子能自己发现这个差别
- [ ] A3 左下角 已学/总词、答对/答错 实时跳动；**刷新页面后数字还在**
- [ ] A4 第 1 关 Boss 有蓝色防护罩；答对单词后罩变红（破防），之后伤害明显提高

## B. 关卡与经济

- [ ] B1 怪物掉金币，金币入账有反馈
- [ ] B2 通关第 1 关出现结算（阳光 + 三行），回工作台阳光余额增加
- [ ] B3 金币足够时可解锁第 2 关；**刷新后已解锁关卡保留**
- [ ] B4 第 2 关起的单词明显更难（MC-D2 词池），关卡词池按 README §2 切分

## C. 操作与体验

- [ ] C1 WASD/空格/鼠标视角顺手，Esc 能退出指针锁定，无卡墙卡地
- [ ] C2 右键魔法弹会自动转向追怪（不要求瞄准）
- [ ] C3 F 键商人交易能卖战利品；？ 帮助浮层展开是全英文说明
- [ ] C4 桌面 1280 宽、390px、320px 三档无横向溢出；游戏页 console 无 error

## D. 工作台接入

- [ ] D1 「方块探险」主题首页有「方块传奇」入口卡，点击进入
