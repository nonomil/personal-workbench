| # | 需求 | 裁决 | 依据 |
|---|---|---|---|
| R1 | 词级记忆状态用 Leitner 5 盒（非 FSRS） | 采纳 | FSRS 需 400+ 复习记录才能优化参数，幼儿场景过重；盒制可解释、可手玩验收（07 文档 §2.2） |

| R4 | 出词队列到期优先，替换盲抽 `reviewRatio` | 采纳 | ANKI 核心；`reviewRatio` 保留字段但改为复习占比上限语义 |
| R5 | 每波复习词占比上限 60% | 采纳 | 防"整关全是旧词"劝退；地下城"整局不打同一种怪"同理 |

| R7 | 重玩难度只做 3 档 | 采纳 | 25 级天启是长线运营产物，12 关体量 3 档够（07 §4 不做清单） |
| R8 | 天启解锁需 3 个不同 Boss 关 | 采纳 | 抄 Apocalypse Plus boss-mission 门槛，防刷最简单关（官方 Endgame 博客） |

| R10 | 冒险/天启档新词 0% | 采纳 | 重玩=消复习债的定位；新词只在推进新关时出现 |
| R11 | 卷轴条件 = 该关 `climateWords` 全部盒号≥3 | 采纳 | 把"学扎实"变成探索钥匙；盒 3=7 天间隔，代表真掌握 |
| R12 | 隐藏关用程序生成迷宫 | **拒绝** | 只用固定迷宫 seed；程序生成房间池投入产出不成比（07 §4 不做清单） |
| R13 | 营地做换装/宠物/装饰 | **拒绝** | Prodigy 反面教训：装饰玩法冲淡学习密度（官方评估报告） |
| R14 | 训练假人答题掉金币 | 采纳 | 无压力复习入口；掉落远低于关卡防替代主线 |
| R15 | 难词第 3 次见面降级题型 + 例句支架 | 采纳 | Prodigy 教训"反复错没人管"；Memdora：支架后再爬梯 |

| R17 | wordMemory 同步进 workbench mastery | **拒绝（本包）** | 跨轨对齐另开包，记门控债；本包只做游戏内闭环 |
