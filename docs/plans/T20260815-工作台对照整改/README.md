# T20260815-工作台对照整改

> 源头：`docs/01-方案/什么是真正的工作台/什么是真正的工作台.md`
> **本包只改三套工作台。不改 `prj/games/`。**

## 为什么另开一包

上一包 `T20260815-真正的工作台整改` 把 P1 做成了方块传奇词卡回流。那是游戏账本问题，不是文章批评的对象。文章说的是：工作台不能变成打卡网页，要成为日常工作/学习真正发生的地方，并自动沉淀数据。

对照对象是这三个入口：

| 工作台 | 入口 | 当前问题（对照文章） |
|---|---|---|
| 成人成长工作台 | `prj/成人成长工作台/index.html` | 首页主卡是「今天的习惯」+ `toggle-habit` 打勾；生活分区标题就是「习惯打卡」。这是文章反对的人为打卡。 |
| 儿童学习工作台 | `prj/儿童学习工作台/index.html` | `config.js` 文案「先打卡，再玩耍」；今日清单主按钮是 `toggle-plan` 勾选换阳光。 |
| 阳光成长工作台 | `prj/preschool-workbench/index.html` | 工作流卡已改成真实下一步（§3.11），但任务墙仍并列「点亮」勾选；设置页没有「用已有数据出总结」。 |

独立小游戏（花园/方块/闯关/方块传奇）不是本包范围。

## 三个子项（只动工作台）

| 子项 | 改什么 | 对应文章观点 |
|---|---|---|
| W1 成人：去掉打卡主路径 | 首页不再展示习惯勾选；生活页「习惯打卡」改为记录列表（无每日勾）。主 CTA 变成「写下一条生活记录 / 记一次阅读 / 写复盘」。习惯若保留，只作备忘，不进年度活跃天数。 | 不能反人性 |
| W2 儿童：今日页走真实学习 | 文案去掉「先打卡」；有 `practiceLessonId` / 课程映射的项，主按钮改 `open-plan-practice` 或进课程，勾选降为次要。 | 不能舍本逐末 |
| W3 工作台出总结 | 幼儿设置页 + 成人复盘页：一键把本周已有快照拼成 Markdown 下载（点亮日、完成课、错题、阅读、复盘草稿）。不调用任何模型。 | 工作台是数据库，可喂给 AI |

## 明确不做

- 不改 `prj/games/**`
- 不加新阳光/徽章/排行
- 不新增 localStorage 主 key
- 不在运行时内置联网 AI
- 不把 `docs/` 资料库塞进产品
