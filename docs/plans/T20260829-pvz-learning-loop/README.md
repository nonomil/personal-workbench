## 为什么有这个包

学习↔游戏的经济链已通，但"学习=打僵尸"的心智没建立：僵尸是纯装饰、首页无今日目标、
错题入侵状态机从未接通数据。本包把三个断点接上，让孩子看见努力的方向和意义。
