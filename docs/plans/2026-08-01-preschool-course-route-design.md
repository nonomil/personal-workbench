# 幼儿课程路线 2.0 设计说明

## 目标

把幼儿版课程页从“课程说明 + 文字练习列表”调整为可一眼理解的视觉学习路线：孩子先看到课程图形和步骤，再决定从哪一张练习卡开始。

## 交互结构

每门课程卡包含四层：

1. 课程标题、课程图形和短说明。
2. `completed / total` 课程进度条，以及“准备出发 / 正在进行 / 全部点亮”状态。
3. 参考资料徽章和少量样例，保留识字、拼音、古诗、数学、专注力、英语、运动的内容边界。
4. 三张视觉步骤卡：已点亮、现在来做、下一张。每张卡有序号、图形缩略图、短标题和短提示。

桌面端三张步骤卡并排显示，手机端变为单列大方框。下一张仍然可以直接打开，避免孩子因为路线装饰被强制阻塞；已点亮的步骤保持禁用，防止重复领取奖励。

## 数据边界

- 进度仍来自 `state.courseProgress.completedLessonIds`。
- 练习仍进入 `openLessonDialog()`，答对后才由 `completeCourseLesson()` 发放阳光和豌豆能量。
- 不新增 localStorage key，不改变奖励事件 ID，不改变成人版和儿童版课程行为。
- 步骤图形优先复用现有 `preschoolAssetForIcon()` 和离线生成素材，素材加载失败时回退到 Lucide 图标。

## 验收矩阵

| 视口 | 预期布局 | 关键检查 |
| --- | --- | --- |
| 1440px | 侧栏 + 双列课程卡，单卡内三列路线 | 进度、图形和按钮不重叠 |
| 768px | 单列课程卡，单卡内三列路线 | 内容保持可扫描 |
| 390px | 单列课程卡，单卡内单列路线 | 无横向滚动，步骤是大触控块 |
| 320px | 单列课程卡，单卡内单列路线 | 文本不溢出，进度摘要不换出卡片 |
