# 智慧花园工作台 WorkBuddy 精致 UI 设计

## 目标

将幼儿学习工作台的视觉与交互统一到 `智慧花园工作台-项目主提示词-workbuddy精致UI版.md`：温暖奶油背景、橙色主操作、薄荷绿成长反馈、金色奖励反馈、分层卡片和更清晰的移动端导航，同时保留当前工程的模块化 Vanilla JS、本地优先快照和自托管 API 边界。

## 设计决策

1. **保留现有架构**：不改造成单 HTML，不重新引入第二套 `sunBalance`、`tasks` 或 `calendar` 存储。所有视觉入口继续通过 `app.js`、`css/preschool-workbench.css` 和现有快照状态驱动。
2. **新增最终视觉层**：新增 `css/preschool/16-workbuddy-finish.css`，放置在幼儿版样式导入链末尾。它只负责最终令牌、卡片、按钮、页面背景、导航和响应式收口，不覆盖业务选择器的语义。
3. **桌面导航**：保留左侧 16 个栏目，但将其做成暖奶油侧栏、清晰分组、带橙色选中态；内容区使用宽松网格，避免把学习卡压成窄列。
4. **移动导航**：保留现有抽屉侧栏作为完整入口，新增固定底部浮动导航，提供首页、学习、植物大战、奖励和更多五个常用入口；“更多”打开侧栏，不复制业务状态。
5. **反馈语言**：完成任务、课程练习、花园防守和兑换奖励继续调用现有奖励/快照逻辑；视觉层只提供弹簧按压、卡片高光、金色反馈和减少动效降级。
6. **可访问性**：按钮保留现有 `data-action`、`aria-label` 和键盘焦点；底部导航使用真实按钮，不依赖颜色区分状态；`prefers-reduced-motion` 下关闭漂浮和扫光。

## 不纳入本轮

- 不重写 11 个课程模块的业务引擎。
- 不把 Emoji 作为新增 UI 图标；继续使用项目已有 Lucide 图标和生成图片素材。
- 不使用 Agnes，不重新接入 Supabase；仓库提交与发布由独立的交付流程处理。

## 验收标准

- 桌面端幼儿版首页、课程、日历和花园页面使用同一套 WorkBuddy 视觉令牌。
- 375px 视口无横向滚动；首页状态卡、课程目录、日历和底部导航均可读、可点击。
- 主要按钮具备 hover、active、focus-visible 和 reduced-motion 状态。
- 现有测试继续通过，并新增导航结构与响应式样式契约断言。
