# 素材复用方案

## 1. v1 不新增运行时素材

本版本没有素材生成任务、manifest、published 新目录或图片体积增量。复用项目中已经存在并已进入当前页面/APK 的花园背景：

```text
prj/assets/generated/preschool-pvz-2d/background/published/pvz-garden-lawn-bg.webp
```

它由 `44-child-game-world.css` 通过 `--child-scene-image` 提供给花园主题。51 CSS 只引用继承变量，不复制文件、不改 manifest、不调用外部图片接口。

学习伙伴继续使用 `prj/app.js` 的 `preschoolAsset()` 与既有主题资源。当前 `50-learning-companion-writing.css` 已对透明素材、错峰动画和 reduced-motion 做过处理，本版本不重新生成角色。

## 2. 为什么不生图

当前问题是页面比例和层级，不是缺一张新图。先用已存在的背景和伙伴验证：

- 背景是否能露出来；
- 手写板是否仍是主焦点；
- 字卡是否从“大框”变成紧凑墙；
- 伙伴是否在下方形成陪伴而不是抢焦点。

如果未来需要新美术，应另立素材计划，经过视觉循环和体积门禁后再接入；不把候选图顺手打进本次 v1。

## 3. 视觉门禁

浏览器检查时记录：

- 花园背景 URL 可加载，坏图为 0；
- 伙伴主体不是整体半透明、白底或矩形 matte；
- 背景不含新增文字、水印或品牌元素；
- 1280×720 截图中背景可见，且不遮挡目标字、Canvas 和 44px 控件。

这些是视觉检查，不把静态文件存在误写成“美术质量已证明”。

## 4. 体积结论

本次新增运行时图片为 `0 KiB`，不需要重新编译 APK 来证明素材增量。若后续编译，仅记录是否因 CSS/JS 改动产生正常包差异，不设生图素材预算。
