# 验收清单

按切片验收，全部勾完 + `npm test` 全绿才算包完成。

## S1 测评

- [ ] 识字专区能进「识字量测一测」，完整答完 25 题
- [ ] 题目字不重复、选项拼音无重复、正确答案在其中
- [ ] 连对会变难（级别上升）、连错会变简单，测试有断言
- [ ] 结果页显示估算量/置信度/阶段，估算量与手算样例一致
- [ ] 答错的字出现在错题本里

## S2 历史

- [ ] 测完一次，`assessments` 多一条；第 25 次测评后仍只有 24 条
- [ ] 置信度 <60% 的成绩标「参考值」，不刷新最高纪录
- [ ] 清空 assessments 字段后刷新页面不报错
- [ ] 家长摘要出现「识字量：最近 … · 最高 …」

## S3 错字本

- [ ] 识字错题显示为田字格字卡，错最多的排最前
- [ ] 专项复习只出识字错字；同一字连对 3 次后从待复习消失
- [ ] 打印预览：A4 单页 8 卡，含练写格与裁切线；非打印视图无样式泄漏
- [ ] 数学/英语错题条目外观与行为不变

## S4 档案

- [ ] 0 条历史：显示「先测一次」引导；1 条：只画点
- [ ] ≥2 条：折线 + 250/500/750 参考线 + 三 KPI 正确
- [ ] 证书打印页字段齐全，低置信测评不出证书按钮

## S5 首页

- [ ] 识字今日页顶部为 KPI 行 + 三大卡 + 周连续条
- [ ] 三大卡分别可达测评/错题本/档案
- [ ] 今日课时列表仍在卡片下方，原有课时全部可玩
- [ ] 手机宽度（390px）不横向溢出

## 总收尾

- [ ] `npm test` 全绿（记录数字进 test-report）
