# 需求核对清单

## 功能

- [ ] R1 识字量测评：25 题四选一（字→拼音），阶梯自适应 L1–L5
- [ ] R2 测评结果：估算识字量（取整到 10）+ 置信度 + 阶段名 + 错字清单
- [ ] R3 测评错字自动进错题本（subject=识字），走既有 1/3/7 复习
- [ ] R4 测评历史存 `courseProgress.literacy.assessments`（≤24 条），低置信不刷新最高纪录
- [ ] R5 阶段映射：0–250 字芽初萌 / 250–500 绘本启蒙期 / 500–750 自主阅读期 / 750+ 阅读进阶期
- [ ] R6 错题本识字条目字卡化（田字格 + 拼音 + 组词 + 错次），按错次倒序
- [ ] R7 专项复习只出错字，连对 3 次自动 mastered
- [ ] R8 A4 打印字卡（8 卡/页，含练写格与裁切线）
- [ ] R9 成长档案：识字量 SVG 曲线 + 阶段参考线 + 最近/最高/本月新增
- [ ] R10 证书打印页（有效测评才可打）
- [ ] R11 识字首页：KPI 行 + 三大卡 + 周连续条，原课时列表保留
- [ ] R12 家长学情摘要显示最近/最高识字量

## 红线

- [ ] N1 无新 localStorage key（只在既有 key 内扩字段，且留评审记录）
- [ ] N2 无小书虫商标/毛毛虫形象/App Store 元素
- [ ] N3 无新依赖（图表、打印、字体库都不加）
- [ ] N4 测评无惩罚、无时间压力文案；乱点只降置信不扣分
- [ ] N5 离线可用；打印即导出，无网络请求
- [ ] N6 阳光账本不变：测评不发新货币、不重复发放

## 质量

- [ ] Q1 新测试两个文件全绿，既有测试不回归
- [ ] Q2 缓存戳全链更新（index.html / css / js）
- [ ] Q3 旧存量状态（无 assessments 字段）加载兼容
- [ ] Q4 手玩走查记录 + 打印预览截图进 test-report
