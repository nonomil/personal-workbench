# 需求核对清单

## 功能

- [x] R1 识字量测评：25 题四选一（字→拼音），阶梯自适应 L1–L5
- [x] R2 测评结果：估算识字量（取整到 10）+ 置信度 + 阶段名 + 错字清单
- [x] R3 测评错字自动进错题本（subject=识字），走既有 1/3/7 复习
- [x] R4 测评历史存 `courseProgress.literacy.assessments`（≤24 条），低置信不刷新最高纪录
- [x] R5 阶段映射：0–250 字芽初萌 / 250–500 绘本启蒙期 / 500–750 自主阅读期 / 750+ 阅读进阶期
- [x] R6 错题本识字条目字卡化（田字格 + 拼音 + 组词 + 错次），按错次倒序
- [x] R7 专项复习只出错字，连对 3 次自动 mastered
- [x] R8 A4 打印字卡（8 卡/页，含练写格与裁切线）
- [x] R9 成长档案：识字量 SVG 曲线 + 阶段参考线 + 最近/最高/本月新增
- [x] R10 证书打印页（有效测评才可打）
- [x] R11 识字首页：KPI 行 + 三大卡 + 周连续条，原课时列表保留
- [x] R12 家长学情摘要显示最近/最高识字量
- [x] R13 视觉升级：主视觉 + 三大入口图标 + 四阶段徽章 + 证书角花均为本地原创透明 PNG，并有 manifest
- [x] R14 视觉接入：识字首页/结果/档案使用 `data-asset` 挂点，缺图时回退 emoji/CSS，不阻塞功能

## 红线

- [x] N1 无新 localStorage key（只在既有 key 内扩字段，且留评审记录）
- [x] N2 无小书虫商标/毛毛虫形象/App Store 元素
- [x] N3 无新依赖（图表、打印、字体库都不加）
- [x] N4 测评无惩罚、无时间压力文案；乱点只降置信不扣分
- [x] N5 离线可用；打印即导出，无网络请求
- [x] N6 阳光账本不变：测评不发新货币、不重复发放
- [x] N7 生图只在离线内容工厂发生；运行时不联网，图片不内嵌中文/品牌/水印
