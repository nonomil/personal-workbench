## 1. 核心理念（从两份参考提炼）

布鲁伊参考的本质不是某张卡片的样式，而是**三层构图 + 陪伴感**：

1. **上面是学习卡片**：识字计划/英语启蒙等功能以少量、大尺寸的卡片呈现在页面上半部，一屏只讲一件事。
2. **下面是动画场景与人物**：页面下半部（或右侧）是大面积卡通场景，主角一家在场景里活动。场景不是装饰，而是**情绪层**——它告诉孩子"这里很轻松"。
3. **人物即入口**：参考稿里点主图人物、点功能卡都能进入栏目。人物有轻微的待机动作（呼吸、摆动），点击有反馈。

工坊参考补充了**进度可视化的空间化**：等级、关卡、家园都"放"在场景里（Lv.2/Lv.3 的出生点广场），而不是列表里。

当前工作台的问题（对照）：学习负担重（每屏塞满按钮和选项）、人物只是三条静态提示、场景只有静态的太阳云朵形状。本方案把"场景 + 人物"从装饰升级为**导航层和情绪层**，把学习内容压缩为**上层少量大卡**。

## 2. 布局总纲：三层构图

所有幼儿版页面统一为三层（自下而上）：

```
┌──────────────────────────────────────────────┐
│  ③ 卡片学习层   大字卡 / 任务卡 / 奖励卡       │  ← 内容，占 55%~65% 高度
│──────────────────────────────────────────────│
│  ② 动画背景层   天空渐变 + 太阳/云 + 远景      │  ← 情绪，常驻
│──────────────────────────────────────────────│
│  ① 人物舞台层   草地前景 + 3~4 个可点角色      │  ← 导航，占 20%~28% 高度
└──────────────────────────────────────────────┘
```

- **首页**：舞台层最大（约 30%），角色可走动、可点击进栏目。
- **学习内容页**：舞台层收成 48~64px 的"场景条"（已在识字页实现），角色待机微动 + 答题联动。
- **奖励/家园页**：人物就是主角（喂食、收集），舞台与卡片融合。

## 3. 首页详细设计

### 3.1 结构

```
┌────────────────────────────────────────────────┐
│ 顶栏：问候 Hi 小探险家 · 日期 · 阳光/能量        │ 44px
├────────────────────────────────────────────────┤
│ ③ 今日卡片区（上半，flexible）                  │
│   ┌─────────────┐  ┌─────────────┐             │
│   │ 现在做：识字 │  │ 下一件小事  │  ← 1~2 张大卡 │
│   └─────────────┘  └─────────────┘             │
├────────────────────────────────────────────────┤
│ ②① 场景舞台（下半，约 110~130px）              │
│   ☁️☁️  ☀️          （天空渐变 + 飘动云）        │
│   🌻 →→ 🌰   🫛    （角色在草地上走动/待机）     │
│   [草地前景条，颜色随主题]                      │
└────────────────────────────────────────────────┘
```

现首页的"任务泳道（battlefield lanes）+ 伙伴提示条 + 世界出口"三段折叠为：**一张"现在做什么"主卡**（取第一条未完成任务，大按钮直达对应课程）+ **舞台**。其余任务列表、打卡摘要等放入第二横屏分页（保留现有分页器）。

### 3.2 人物即导航（点击映射表）

把现有三个学习伙伴升级为**可点击的角色导航**，点击效果 = 跳一下 + 冒气泡 + 进入栏目：

| 角色（花园主题资产） | 点击进入 | 气泡文案示例 | 微动效果 |
|---|---|---|---|
| 向日葵 `pvz-sunflower` | 识字专区 | "认字去咯！" | 待机摇摆（rotate ±3°），点击后跳起撒 2~3 枚小阳光 |
| 豌豆射手 `pvz-peashooter` | 拼音/英语专区 | "跟我读！" | 待机点头，点击后"发射"一颗豌豆（translateX 飞出） |
| 坚果墙 `pvz-wallnut` | 数学专区 | "算一算！" | 待机呼吸（scale 1→1.04），点击后左右滚一下 |
| 小僵尸 `garden-walker-v5` | 植物大战（游戏） | "来抓我呀～" | 慢速左右走动，点击后吓一跳（后退 + 抖动） |

方块世界主题换用：小晶体/方块树/紫晶体（已有 `voxel-companion` 等资产）；马里奥主题换用：小探险家/金币/终点旗。映射表做成 `config.js` 内的主题配置，随主题自动切换（现有 `assetMap` 机制直接扩展）。

**气泡**：角色头顶白色圆角气泡 + 主题色描边，默认显示栏目名；点击后短暂放大 + 显示鼓励语，600ms 后跳转。

### 3.3 动画背景

复用现有 `.child-game-scene`（已在 `44-child-game-world.css`，含 sun/cloud DOM），从静态形状升级：

- **太阳**：原地脉动（scale 1→1.06，4s 循环）+ 光芒旋转（伪元素 rotate，20s）。
- **云 ×2**：横向漂移（translateX 从 -20% 到 120vw，60s/90s 两速视差），透明度 0.8。
- **天空**：主题渐变常驻（花园=晨间蓝绿→暖黄；方块=像素天蓝；闯关=黄昏橙紫），顶部到底部渐变进入舞台的草地色。
- **草地前景**：舞台底边一条 12px 深绿条 + 2~3 丛小草（伪元素 repeating-gradient），整条缓慢左右平移 4px 呼吸（避免每根草单独动画）。

**总动画元素预算 ≤ 8 个**，全部只用 `transform`/`opacity`，旧 WebView 可 GPU 合成，不触发布局。

## 4. 学习内容页详细设计（识字/拼音/古诗/数学/英语 通用模板）

- 识字页沉浸式：外框、顶部选项行、等级行全部移除；字卡三重嵌套盒拆平，田字格直接坐在背景上；工具只留"听 + 会了"；底部场景条（气泡 + 三角色）。
- 页面级纵向滚动兜底（超出整屏可滚）。

### 4.2 通用模板（其余学科套用）

```
┌──────────────────────────────────────────────┐
│ 顶栏：学科名（唯一保留的 chrome）+ 翻页器      │
├──────────────────────────────────────────────┤
│ ③ 学习卡片区（大，去框）                       │
│   - 识字：田字格大字 + 拼音 + 听/会了          │
│   - 拼音：声母韵母大卡 + 拼读按钮              │
│   - 数学：大数字/算式 + 选项大按钮             │
│   - 英语：大单词 + 图 + 听读                   │
├──────────────────────────────────────────────┤
│ ① 场景条 48~64px：气泡进度语 + 3 角色 + 草地   │
└──────────────────────────────────────────────┘
```

- 卡片区规则：**每屏最多 4 张可点卡或 1 张主卡**；按钮每卡 ≤ 2 个；点击卡片本体 = 展开详情（渐进披露），不放"看提示"之类的次按钮。
- 场景条进度语：`{已会}/{总数} · 再认 {n} 个就升级`，与现有 `bank-levels` 进度数据打通。

### 4.3 人物与学习联动（本方案的灵魂）

- **答对**：场景条三角色集体跳一下（stagger 80ms），气泡切换为夸奖语（"太棒了！""再来一个！"，随机池）；阳光币从卡片飞向阳光 HUD（一次 transform 位移动画）。
- **答错/还不会**：坚果原地滚半圈，气泡换安慰语（"没关系，再看看"），**不出现红色错误样式**（保护积极性）。
- **连续答对 3 个**：触发"阳光雨"——舞台层短暂落下 5~6 枚小阳光粒子（2s，一次性），配合现有音效开关。
- **完成一页**：角色挥手 + 气泡"这一页完成啦！"，1s 后出现下一页大按钮。

联动实现点：在 `app.js` 的 `flashcard-mark` / `lesson-answer` 处理器里派发自定义事件（`preschool:answer`，带 `correct` 布尔值），场景条组件监听并切换 CSS class（`is-cheer` / `is-comfort` / `is-sunrain`），动画全部由 CSS keyframes 驱动。**不引入任何 JS 动画库。**

## 5. 奖励页 / 家园页设计

- 顶部：下一站奖励卡（进度条 + 小图）——保持现紧凑版。
- 中部：兑换分层卡（单列滚动，已实现）。

## 6. 动画技术方案

### 6.1 原则

1. **只用 `transform` 和 `opacity`** 做动画（`translate/scale/rotate`），禁止动画 `box-shadow/top/left/width/height`——旧 WebView（Chromium 8x~10x）也能合成线程跑，不卡顿。
2. **CSS keyframes 优先，JS 只切 class**：状态机（待机/点击/欢呼/走动）全部是 class 切换，动画本身零 JS。
3. **尊重现有动效开关**：`body.preschool-no-motion`（已有 `motionEnabled` 偏好）下，所有舞台动画降级为静态；`@media (prefers-reduced-motion: reduce)` 同样处理。
4. **数量预算**：每屏同时运行的动画元素 ≤ 8；粒子（阳光雨）≤ 6，且只触发 2s。

### 6.2 待机与点击动画（现有静态素材即可做）

| 动画 | 实现 | 参数 |
|---|---|---|
| 待机呼吸 | `scale(1→1.04)` 往复 | 2.4s ease-in-out infinite，角色间 delay 错开 |
| 待机摇摆 | `rotate(-3°→3°)`，transform-origin 底部中心 | 3s |
| 点击跳起 | `translateY(0→-10px→0)` + 落地压扁 `scaleY(.92)` | 450ms 一次性 |
| 点击发射（豌豆） | 伪元素小球 `translateX(0→40px)` + 渐隐 | 500ms 一次性 |
| 阳光飞向 HUD | 克隆小图 `translate` 到 HUD 坐标（JS 取终点，CSS 过渡） | 600ms 一次性 |

### 6.3 走动（分两档实现）

- **P3-a 零素材版**：角色整图 `translateX` 在舞台范围内往返（12~20s 慢速），朝向用 `scaleX(-1)` 翻转；走动时轻微 `translateY` 上下颠簸（steps 感）。现有静态 PNG 即可，效果已接近参考稿。
- **P3-b 序列帧版**（需新素材）：每个角色画 2~4 帧走路序列（AI 生成，风格对齐现有 pvz 卡通资产），`steps(N)` 切换 `background-position`。素材清单见 §7。

### 6.4 背景视差

云、太阳、前景草三条速度（1x / 0.6x / 1.4x）形成轻视差；所有层 `position: absolute` 于 `.child-game-scene`，`will-change: transform` 慎用（只在动画期间加 class）。

## 8. 交互与无障碍

- 角色按钮 ≥ 48×48px 命中区（视觉图可以更大），`aria-label` 带栏目名（"向日葵，去识字专区"）。
- 气泡文字 ≥ 12px，与背景对比度 ≥ 4.5:1。
- 点击角色 → 600ms 动画后跳转，期间禁止重复点击（防连点跳丢动画）。
- 所有点击有 `:active` 压下反馈（`transform: translateY(1px)`）。

## 10. 风险与对策

| 风险 | 对策 |

## 11. 与现状的差异对照（一句话版）

- 首页：任务泳道 + 三条静态提示 → **一张主卡 + 会动的角色舞台，点角色进栏目**。
