# 学习卡片墙舒展布局实施计划

> **给 Claude:** 必需子技能：使用 superpowers:executing-plans 来逐任务实施此计划。

**目标：** 让学习页在 1080、1440/MuMu 横屏中展示更多学习栏目，同时拉开卡片间距并压缩卡片内部无效留白。

**架构：** 保留网页端和竖屏的自然滚动；Android 横屏继续使用左右分页。高分辨率横屏把 10 个学习专区作为一张完整目录墙，1080 横屏采用可读的紧凑网格与分页兜底。课程卡片继续复用现有图片、状态和点击行为，只调整布局层和分页策略。

**技术栈：** 原生 HTML、CSS Grid、现有 `app.js` 横屏分页逻辑、Node.js 测试、Chrome CDP 视觉回归。
