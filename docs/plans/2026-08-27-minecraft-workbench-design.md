**参考的闭环本质**：做作业赚积分 → 积分喂宠物/买装备/修家园 → 不做作业怪物出现威胁家园 → 游戏也是作业的一部分。所有消费和风险都**发生在虚拟世界**，且每一步都有事件日志记录，孩子能看到自己的一天。

## 2. 与本项目现状的映射（关键决策）

| 参考概念 | 本项目对应物 | 结论 |
|---|---|---|
| 积分 💎 | **阳光 sunlight**（`awardSunlight`，app.js:8552），voxel 主题 HUD 已显示为绿宝石 | 直接复用，不新增货币 |
| 每日作业 + 完成奖励 | dailyPlans 任务清单（`toggle-plan` 时 `task:${id}` 记账防重） | 复用；工坊页是任务清单的"主题化视图" |
| 饱食度 hunger | `growth.hunger` **字段已存在但无 UI**（child-growth.js:102，默认 80） | M1 激活它 |
| 宠物 Lv/EXP/造型 | `growth.unicorn`（xp/level/unlockedStyleIds）+ `preschool-pet.js` 孵蛋 | 复用，投喂给 XP |
| 怪物来袭 | `growth.zombieActive`（漏打卡出现，child-growth.js:268）+ `zombieDefeated` | 语义一致，攻城夜直接读它 |
| 家园快照 mosaic | `renderPreschoolVoxelHomeCard`（app.js:678，方块世界拍照快照） | 工坊页"我的家园"区直接放它 |
| 记忆配对游戏 | `play-memory` 皮肤（app.js:2371，lesson dialog 内） | M4 把它提为独立可打卡入口 |
| 冒险日志 | 无现成事件流 | 新增当日内存日志 + 当日落盘（复用 growth 快照，不新建 key，见 §4） |

### 决策 D1 — 惩罚口径（重要，与参考的差异）

参考的"未完成每科 -5 积分"是真实扣分。**本项目不做真实扣分**（与既有的测评无惩罚、错题不扣分原则一致）。替代：

- 未完成任务 → 当晚攻城演出更热闹（怪物多来一只），只掉**虚拟家园耐久**，不动阳光；
- 阳光只加不减；修复家园便宜（10 阳光）且有免费途径（完成任一任务顺手修复 5 点）；
- 文案用幽默化解："苦力怕只是想找你玩，做完一件事它就走了"。

### 决策 D2 — 页面载体

不重映射现有底部导航，**新增一个 `workshop` 工坊页**（仅 voxel 主题显示入口，挂在侧边栏"守护与奖励"组顶部），页内五个 sub-tab：`作业 / 宠物 / 战斗 / 商店 / 游戏`（就是参考的五屏）。理由：零风险、不打散现有 IA、其他主题不受影响。若后续验证孩子高频使用，再考虑提升为底部导航第二项（列入 P2 可选项）。

### 决策 D3 — 状态存放

`growth.voxelWorkshop = { homeDurability: 100, homeUpdatedAt, weaponId: 'none', armorId: 'none', log: [{t, text}] (封顶 24 条) }`——在 `child-growth.js` normalize 处补默认值，随既有快照落盘，**不新建 storage key**。

## 3. 工坊页信息架构（五 tab）

```
┌──────────────────────────────────────────┐
│ 方块工坊   💎阳光数          [日期]       │ 44px 顶栏
├──────────────────────────────────────────┤
│                                          │
│           （五 tab 内容区）               │
│                                          │
├──────────────────────────────────────────┤
│ [🔨作业] [🐾宠物] [⚔️战斗] [🛡️商店] [🎮游戏] │ 56px 底部 sub-tab（像素风）
└──────────────────────────────────────────┘
```

### Tab1 作业（默认）
- 顶部"我的家园"卡：房屋像素图 + 耐久条（颜色 100~60 绿 / 59~30 黄 / <30 红）+ 一句话状态（"家园很结实"/"昨晚被啃了几口，修一修吧"）。
- 中部：今日任务清单（复用 `renderPreschoolPlanRows` 数据源，渲染成参考样式的绿色行卡：左勾选圆钮、中间标题+科目色块、右侧"+N 阳光"绿色方块）。完成动作复用 `toggle-plan`。
- 底部：全清进度条 + "结算今天"大按钮（见 M5）。

### Tab2 宠物
- 像素场景框：宠物立绘（用 `preschool-pet` 当前造型 art）+ 名牌。
- 状态双条：Lv/EXP（现有数据）+ 饱食度（`growth.hunger`）。
- 投喂三档按钮（M1 定价表）+ 宠物造型切换入口（跳现有衣橱/孵蛋逻辑，不在工坊重复实现）。

### Tab3 战斗
- 夜色场景框：无怪 → "今晚很平静…" + 一只悠闲小怪；有怪（zombieActive 或当天有未完成）→ 怪物立绘 + 血条。
- "出击"按钮：按当前武器伤害演一段驱赶动画（CSS steps 帧 + transform），胜利文案随机池；同时调用现有的"驱散"记账路径。
- 当前装备摘要（武器名 + 伤害、护甲名 + 减免）。
- 冒险日志：时间戳事件流（喂食/游戏/结算/攻城/购买），当日为内存态，跨次启动保留最近 24 条（growth.voxelWorkshop.log）。

### Tab4 商店
- 武器 4 档 + 护甲 3 档 + 修家园，卡片网格（像素金边按钮），价格表进 `config.js` 的 voxel 主题配置。
- 已购装备"点击装备"；卖出不做（参考也无）。
- 修家园：25 阳光 → 耐久 100；任务完成时免费 +5（上限 100）。

### Tab5 游戏
- 复用 `play-memory` 记忆配对引擎独立开局（4×4，步数/配对计数沿用）。
- 一局完成 = 触发一次特殊记账 `voxel-memory-game:${date}`（+10 阳光，每日一次），并在当日任务清单尾部自动出现的"趣味游戏·消消乐"选做任务上打勾（若存在该 plan；不存在则只在日志+阳光生效）。

## 5. 视觉规范

- 沿用 31 号 `voxel-workshop.css` 与 26/27 号皮肤的方块世界 token（`--vw-sky/--vw-dirt/--vw-grass` 等）：深板岩面板 + 金边按钮 + 像素字重。
- 所有装饰图取自现有资产：方块类用 `voxel-*` companion 资产；怪物用 `garden-walker-v5`（僵尸）等 garden 资产按主题措辞复用；食物用 emoji 起步（🥕🍎🎂），正式贴图后置。
- 动画遵守 scene-immersion 包同款红线：transform/opacity only，no-motion 降级，旧 WebView 兼容（禁 `:has()`/裸 dvh/color-mix）。
- 手机竖屏为第一目标（参考图即手机竖屏）；平板横屏在分页器内整页呈现。

## 7. 风险与红线

- 不扣真实阳光、不影响 garden/platform 主题任何行为（workshop 页与 voxelWorkshop 状态仅 voxel 主题读写）。
- 不新建 storage key；增长字段一律走 child-growth normalize。
- 怪物形象可爱化、数量 ≤2、无血腥恐怖元素；文案避免恐吓（"怪物来抓你"禁用，用"来捣乱/找你玩"）。
- 消消乐每日限一次奖励，防止刷币；商店不可退款但对账清楚（日志记录）。
