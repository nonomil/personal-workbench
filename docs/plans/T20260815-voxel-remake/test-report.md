## 修复轮（2026-08-15 晚）— 用户反馈「主角卡住动不了 + 主角形象用参考项目资源」

- **卡死根因**：`spawnCell` 固定出生在第 3 列，而世界生成按 C++ 技巧在**第 3 列必种一棵树**，
  主角出生即嵌入树干（碰撞双向锁死）。旧测试「spawn is safe」恰因树干而误绿。
  修复：出生点扫描 4–15 列找脚/头两格皆空气的干净列（seed 3 → 第 4 列，已 node 推演确认）；
  测试改为断言站立格空气 + 地表实地 + 头顶无树
- **旧档修复**：localStorage 里的旧存档可能保存着嵌在方块里的坐标，加载时用
  `rectHitsSolid` 校验，嵌入即重置到安全出生点并提示
- **主角**：换成参考项目主角的 8×7 帧、每帧 24×24 精灵表（待机/走路 8 帧/跳落选帧，
  对齐 C++ physicsSystem 逻辑），按 1:1 比例 2.25 倍最近邻放大渲染；
  原文件名含商标词触发 release-asset-allowlist 门禁（与 mario/creeper 同表），
  **改名 `player.png`** 引入，README 已更新署名与拍板记录
- **健壮性**：主循环 rAF 停摆 >500ms 时自动降级 setInterval 驱动（嵌入式 webview 场景）
- **验证受限说明**：嵌入式浏览器面板被遮挡时整页计时器冻结（rAF/setInterval/键盘注入全部停摆），
  无法自动化复现移动；修复正确性由单元测试（11/11 绿）+ seed 3 世界推演 + 前台目检交接用户确认
- 戳：craft-v11
