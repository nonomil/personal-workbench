# 个人工作台下一轮优化方案

## 目标

继续保持三套工作台独立运行、localStorage 本地优先、JSON 导入导出和现有自托管 API 边界；本轮重点提升“进入后马上知道做什么、手机上每个入口都能点到、幼儿版反馈不被固定导航遮住”。

## 现状判断

- 成人版的主任务、指标卡和行动区已完成窄屏单列收口，继续保持安静、密集、偏工作流的成人视觉。
- 儿童版已经形成“今天一件事 + 课程/错题/奖励”的学习路线，暂不改变业务结构。
- 幼儿版首页已具备任务、阳光、植物、豌豆能量、收集、奖励和花园防守，但移动端仍需要对固定导航和入口文案做最后的可达性收口。
- 根入口在手机顶部同时展示 03 MODES、分隔线和 LOCAL FIRST，可用宽度不足时会裁掉右侧状态，影响首次选择的完整感。

## 本轮决策

1. **启动器优先级**：桌面保留 03 MODES / LOCAL FIRST 信息组合；640px 以下隐藏装饰分隔线和次要英文状态，只保留不换行的 03 MODES，不改变入口卡与记忆选择逻辑。
2. **幼儿固定导航**：五个快捷入口都保留至少 44px 触控目标；底部位置和页面底部留白同时叠加 safe-area-inset-bottom，确保 iOS/Android 全屏模式下最后一张任务卡可以滚到导航上方。
3. **文案可理解性**：移动端战斗入口显示“花园战”，同时保留 aria-label/title="植物大战"，让幼儿看得懂、辅助技术仍能识别完整功能。
4. **不新增状态账本**：本轮不新增阳光、任务、用户或同步字段，不改变任何现有快照 key。

## 验收矩阵

| 范围 | 视口 | 必须验证 |
| --- | --- | --- |
| 根入口 | 375 / 768 / 1440 | 顶部状态不裁切，三张入口卡可访问 |
| 成人/儿童 | 375 / 1440 | 主任务与指标不横向溢出，侧栏/菜单可用 |
| 幼儿首页 | 320 / 375 / 390 / 441 / 768 / 1440 | scrollWidth <= clientWidth，HUD/状态卡/五项底部导航完整 |
| 幼儿战斗 | 375 / 768 | 植物、僵尸、主按钮可见，固定导航不遮挡主操作 |
| APK | GitHub Actions + MuMu | 推送自动构建，安装后可启动并进入幼儿首页/花园基地 |

## 后续候选，不在本轮强行扩张

- 课程页继续补充更具体的题目内容和逐题完成反馈。
- 成人版增加周复盘的可视化摘要，但保持目前的低干扰信息密度。
- 只有完成真实云端快照合并策略后，才扩展多设备冲突解决，不把“登录成功”描述成“数据已同步”。
