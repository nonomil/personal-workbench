# M5 — 结算仪式（全清 bonus + 结算今天）

## 目标

参考图1 的收口：今日任务全清 → tasks tab 底部出现金色"结算今天"大按钮 → 点击播放结算动画 + 全清 bonus +30 阳光 + 结算弹窗（今日战报）。

## 实施步骤

1. **全清判定**：复用 derived（app.js 1073 todayPlans/`todayCorePlans`）：`todayPlans.length > 0 && 全部 done`（选做也计入，与参考一致；无任务日不显示按钮）。
2. **bonus**：点击 `workshop-settle` → `awardSunlight(next, 'voxel-all-done:' + localDate(), 30)` + 日志"全部任务完成！额外奖励 +30 阳光" → 结算弹窗（lesson dialog 复用）显示：
   - 标题"今日战报"
   - 三行统计：完成 N 项任务 / 获得阳光 X（今日 task 记账合计，从 growth 快照当日 award 遍历或简化为"今日共完成 N 项"）/ 家园状态（耐久 + 怪物情况）
   - 宠物今日变化一句（喂了 n 次）
   - 大按钮"收下了"关闭
3. **动画**：点击后按钮 `is-settling`：金色粒子 ≤6（transform 上浮渐隐 1.2s）+ 按钮变"已结算"；no-motion 直接弹窗。
4. **防重**：bonus awardId 天级防重（awardSunlight 内建）；已结算日按钮显示"今日已结算 ✓"（禁用态，不重复弹窗；再次点击可回看战报弹窗，无二次奖励）。
5. **测试**：bonus 防重、无任务日不出现、部分完成不出现、已结算态渲染。
6. **缓存戳**：`&workshop=v6`。

## 边界

- 战报统计仅展示，不新增存储（当日完成数从内存 state 算，历史日不支持回看——日志里已有事件流）。
- 不与现有"连续奖励/补签"耦合。

## 验收

- [ ] 勾完所有任务 → 金按钮出现 → 点击 +30、弹窗战报、日志入账
- [ ] 刷新再点：按钮"已结算"，无重复加分
- [ ] 有未完成任务时按钮不出现；空任务日不出现
- [ ] no-motion 直接弹窗；测试绿；截图结算弹窗
