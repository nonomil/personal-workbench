# M3 — 装备商店（武器 / 护甲 / 修家园）

## 目标

参考图4 商店页：武器四档、护甲三档的网格卡片（价格 + 说明 + 像素金边购买按钮），已购"点击装备"，修家园按钮。

## 数值（方案 §4，进 `renderWorkshopPage` 同文件的常量 `WORKSHOP_GEAR`）

- 武器：`none 空手伤3`（初始拥有）/ 木剑 50·伤8 / 石剑 120·伤14 / 铁剑 260·伤22 / 钻石剑 320·伤38
- 护甲：`none`（初始）/ 皮革 50·减免3 / 铁甲 220·减免7 / 钻石甲 450·减免12
- 修家园：25 阳光 → `homeDurability = 100`（耐久满时按钮禁用）

## 实施步骤

1. **数据**：`growth.voxelWorkshop.weaponId/armorId`（M0 已建）+ 新增 `ownedWeaponIds: ['none']`、`ownedArmorIds: ['none']`（normalize 补默认；`none` 恒在）。购买 = push id + 扣阳光 + 日志"购入了{名称}！"。
2. **渲染**（shop tab）：两组网格（竖屏 2 列、≥768 横屏 4 列）：
   - 卡片：像素图标（emoji 🗡️🛡️ 起步，或现有 `voxel-*` 资产对味就用）+ 名称 + 说明一句 + 伤害/减免值 + 价格
   - 状态三态：未拥有（购买按钮，阳光不足禁用"还差 N"）/ 已拥有未装备（"装备"按钮）/ 装备中（金边高亮 + "使用中"角标）
   - 装备切换免费即时生效
3. **修家园卡**：单独一张宽卡放两组之间或底部：当前耐久 + 修复按钮（满血禁用）。
4. **动作**：`workshop-buy`（data-gear-type/ id）/ `workshop-equip` / `workshop-repair-home`，全部走 commit + 防重校验（已拥有不可再购）。日志：购买/装备/修家园各一条。
5. **联动显示**：battle tab 的"当前装备"摘要（M2 已渲染结构，本片接真数据）；耐久公式里的护甲减免从 armorId 查表（M2 预留）。
6. **测试**：购买扣费与 owned 列表、重复购买拒绝、装备切换、修复满血禁用、减免查表。
7. **缓存戳**：`&workshop=v4`。

## 边界

- 不做卖出/退款/升级；数值改动只动 `WORKSHOP_GEAR` 常量一处。
- 武器/护甲只影响工坊演出数值，**不得**影响学习任务奖励或任何主题外状态。
