# M6 — 皮肤打磨 + 双端验收 + APK

## 目标

五 tab 视觉统一到参考的 MC 像素质感，双档布局打磨，跑全套验收，出 APK。

## 实施步骤

1. **视觉统一**（57 号文件收口）：
   - 面板：深板岩底（`--vw-dirt/--vw-wood` 系）+ 2px 亮边 + 4px 暗角，模拟 MC 按钮浮雕
   - 数字/价格：金色（参考的积分金色）；完成态：绿色块 +N
   - tab 图标：emoji 起步，若 `pixel refresh` 资产有对味再替换
   - 饱食度/耐久/血条：统一分格像素条组件 `.workshop-meter`
2. **布局打磨**：412×915 单列舒适；800×360 横屏双列（作业+宠物同屏可切）；1463×616 面板加宽居中；检查 safe-area。
3. **对照走查**：与参考 5 图逐屏比对（布局骨架像，不必像素级复刻 IP 素材）。
4. **全套验收**：跑 `acceptance.md` 全清单（含三主题隔离、no-motion、红线复查、测试基线）。
5. **发布**：`npm run android:sync` → `gradlew assembleDebug` → 真机抽查（投喂/攻城/结算三关键路径）→ 截图回填 `screenshots/`。
6. **收尾**：README 状态表 M0~M6 全标 landed；整包状态 `review`。

## 边界

- 不引入外部像素字体/贴图；一切装饰走现有 token + emoji + CSS。
