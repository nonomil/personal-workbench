# 01 样式与资源治理方案

## 1. CSS 当前问题

`prj/css/preschool-workbench.css` 依次导入 28 个幼儿样式文件。文件名中的 `legacy`、`correction`、`final`、`restore`、`override` 表明样式依赖覆盖顺序，而不是组件职责。

不允许再通过新增 `29-final-final.css` 修问题。

## 2. 目标六层

```text
prj/css/
├─ base.css
├─ shell.css
└─ preschool/
   ├─ tokens.css
   ├─ workbench.css
   ├─ game-entry.css
   └─ themes.css
```

| 层 | 内容 |
| --- | --- |
| `base.css` | reset、排版、按钮基础、focus、reduced-motion |
| `shell.css` | 侧栏、顶部栏、底部导航、dialog、toast |
| `tokens.css` | 颜色、间距、圆角、阴影、字号、层级 |
| `workbench.css` | 今天、学习、奖励、我的等工作台组件 |
| `game-entry.css` | 游戏选择、进度摘要，不含独立游戏 Canvas/棋盘 |
| `themes.css` | 花园、方块、横版的 token/背景/素材变量 |

## 3. 迁移方法

1. 冻结新增覆盖文件。
2. 为 390×844、844×390、1280×720 建立截图基线。
3. 先迁 tokens 和 shell，不改变视觉。
4. 按页面迁移 today、learning、games、rewards、profile。
5. 使用浏览器 computed style 和合同测试确认旧层已无消费者。
6. 每次只从 manifest 删除一组旧 import。
7. 旧文件无引用、测试通过、截图无关键差异后才能删除。

## 4. 幼儿视觉约束

- 正文字号移动端不低于 16px，核心任务标题建议 18–22px。
- 触控区域最小 44×44px，主要动作建议不低于 52px 高。
- 每屏最多 1–2 个持续动画主体。
- `prefers-reduced-motion: reduce` 下取消摇摆、漂浮、视差和连续粒子。
- 状态不能只靠颜色；完成、待做、错误必须同时有文字或图标。
- UI 图标统一 SVG；角色/场景使用优化后的 WebP/PNG。
- 不把中文文字烘焙到生图背景。

## 5. 素材分层

### 运行时

```text
prj/assets/runtime/
├─ launcher/
├─ shared/
├─ preschool/
├─ garden/
├─ voxel/
└─ platform/
```

### 研究和生产

```text
docs/参考设计/
docs/pvz-visual-research/
docs/design-references/
tmp/image-generation/
```

以下目录或文件类型不得进入 APK/Pages 制品：

- `raw/`
- `reference/`
- `split/`
- `clean/`
- 生图响应 JSON、HTTP 错误、prompt 文本
- 调试网格和裁切中间图
- 未审核的商业素材

## 6. 发布白名单

新增一个机器可读清单，例如：

```json
{
  "version": 1,
  "files": [
    "assets/runtime/launcher/adult.webp",
    "assets/runtime/launcher/child.webp",
    "assets/runtime/garden/sun-token.webp"
  ],
  "directories": [
    "assets/runtime/shared",
    "assets/runtime/garden"
  ]
}
```

`scripts/prepare-mobile.mjs` 和后续 Pages artifact 脚本共用该清单。复制前验证来源存在，复制后拒绝 raw/reference 路径。

## 7. 体积门禁

建议初始门限：

- Web 运行时素材目标小于 20MB。
- APK Debug 目标小于 30MB；如果 Capacitor 基础体积导致无法达到，应记录分项证据再调整。
- 首屏不得预加载完整课程数据和所有游戏背景。
- 大图提供 WebP 和实际显示尺寸；避免 2000px 图片显示在 200px 卡片中。

体积门禁需要报告“代码、素材、Capacitor/原生壳”三部分，不能只看最终 APK。
