# 02 发布素材清单规范

## 清单字段

每项运行素材至少记录：

```json
{
  "id": "garden-sun-token",
  "path": "assets/runtime/garden/sun-token.webp",
  "consumer": ["preschool-shell", "garden-game"],
  "license": "project-original",
  "source": "generated-and-reviewed",
  "sha256": "...",
  "width": 256,
  "height": 256
}
```

## 状态

- `approved-runtime`：可发布。
- `research-only`：仅调研。
- `production-intermediate`：裁切、抠图或压缩中间物。
- `rejected`：失败/不使用。
- `unknown-license`：禁止发布。

## 组装规则

- artifact 只接收 `approved-runtime`。
- consumer 为空的素材不能进入制品。
- 路径含 raw/reference/split/clean 时测试失败。
- 清单路径不存在或哈希不符时构建失败。
- 同一视觉只保留实际使用尺寸和格式，不同时发布 raw PNG 与 WebP。

## 清理边界

第一阶段只把中间物排除出 artifact；是否移动或删除原始文件必须另过 GATE-4。
