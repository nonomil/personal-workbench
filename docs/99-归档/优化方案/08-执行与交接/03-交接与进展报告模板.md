# 03 交接与进展报告模板

## 单卡交接

```text
任务卡：
状态：
目标：
实际修改：
测试：
浏览器/设备：
未执行：
数据和奖励影响：
范围漂移：
未提交改动：
下一张 READY：
需要用户决定：
```

## 会话续接

下一执行者必须先读：专项索引、进度看板、当前任务卡、对应分计划和最近验收报告，然后运行 `git status --short`。不得只依赖上一代理的自然语言总结。

## 审查结论

主控审查后只允许三种结果：

- `ACCEPT`：DoD 和证据满足，更新看板。
- `REWORK`：列出具体失败项，继续同一任务卡。
- `STOP`：范围、数据或迁移风险不可接受，回到用户门。
