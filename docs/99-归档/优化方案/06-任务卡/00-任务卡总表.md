# 00 任务卡总表

## 使用规则

- 每次只领取一张 `READY` 卡。
- 代码卡遵循：失败测试 → 最小实现 → 定向测试 → 全量测试 → diff 审查。
- 每张卡必须报告修改文件、命令、真实结果、未验收项。
- `USER-GATE` 未通过不得继续。
