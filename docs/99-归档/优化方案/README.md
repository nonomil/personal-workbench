## 总完成定义

专项只有同时满足以下条件才算完成：

1. 根入口只有成人、少儿、幼儿三张主卡，幼儿主题进入后选择并记住。
2. 幼儿主导航只有今天、学习、游戏、奖励、我的。
3. 首页只保留任务闭环，不渲染课程目录、月历、完整游戏和家长后台。
4. 成人、少儿、幼儿不再同步执行彼此的页面渲染代码。
5. 幼儿课程资料按需加载，首页不加载完整暑假资料。
6. 幼儿 CSS 从 28 层历史级联收敛为最多 6 个稳定入口层。
7. APK/Pages artifact 不包含 raw/reference/split/失败响应和生图中间产物。
8. 三套业务 key、幼儿共享快照、奖励幂等和 JSON 导入导出保持兼容。
9. Node、浏览器、Pages、APK、MuMu 的对应验收都有真实证据。
10. 旧根迁移和 306MB 清理副本经过核验后处理，不误删用户成果。
