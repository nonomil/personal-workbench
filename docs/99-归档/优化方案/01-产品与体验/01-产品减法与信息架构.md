# 01 产品减法与信息架构

## 1. 产品定位

个人工作台不是孩子真正学习内容的唯一场所，它的核心作用是：

```text
看见今天的安排
→ 完成打卡或一个轻量测试
→ 留下完成证据
→ 获得阳光/能量
→ 去游戏或兑换奖励
```

丰富教材保留在资料库和课程页；趣味玩法保留在独立游戏；家长配置保留在受控二级入口。

## 2. 根入口改造

### 当前

```text
花园主题 / 方块主题 / 横版主题 / 成人 / 少儿
```

### 目标

```text
成人工作台 / 少儿工作台 / 幼儿工作台
```

进入幼儿工作台时：

1. 如果 `personal_workbench_selected_preschool_theme_v1` 有合法值，直接采用该主题。
2. 如果没有合法值，显示一次主题选择：阳光花园、方块探险、彩虹闯关。
3. 选择后调用现有 `PersonalWorkbenchLauncher.rememberTheme(theme)`。
4. 设置页始终可切换主题。
5. 三主题继续共用 `petbank_huchuliang_preschool_workbench_state_v1`。

根入口仍可显示“上次使用”，但不把主题冒充成独立产品。

## 3. 幼儿五主导航

| 主入口 | 内容 | 不再单独占一级导航的内容 |
| --- | --- | --- |
| 今天 | 伙伴、资源、3 个核心任务、选做任务、今日完成、出口 | 日历、学习任务 |
| 学习 | 学科目录、当前练习、错题复习 | 暑假、识字、拼音、古诗、数学、专注、自然拼读、运动八个侧栏按钮 |
| 游戏 | 当前主题游戏、三个世界选择、植物/关卡收藏 | 花园基地、植物大战 |
| 奖励 | 可兑换奖励、待家长确认、历史记录 | 奖励商城 |
| 我的 | 日历、成长、错题、家长互动、设置、导入导出 | 原守护与奖励分组 |

PC 可以使用侧栏，但仍只显示五个主入口；二级栏目在主内容区内部显示。移动端与 PC 使用同一信息架构，不维护两套语义不同的导航。

## 4. 幼儿首页结构

首页最多四块：

### A. 状态头

- 伙伴头像/角色。
- 今日日期。
- 阳光余额、豌豆能量、连续完成天数。
- 不重复显示累计成长、三世界进度和多组资源。

### B. 今日任务

- 默认显示 3 个核心任务。
- 选做任务最多 3 个，默认折叠。
- 卡片只保留标题、预计时间、完成/去练习按钮、奖励预览。
- 植物和僵尸只做一处视觉反馈，不占据任务文案空间。

### C. 今日反馈

- `已完成 n/3`。
- 最近一条真实练习或阅读证据。
- 若无证据，显示下一步提示，不造假数据。

### D. 两个出口

- 主按钮：去当前主题游戏。
- 次按钮：去奖励中心。

以下内容移出首页：完整周报、三世界详细进度、课程目录、月历、完整错题、家长表单、账号同步、导入导出。

## 5. 学习页

学习页不是课程平台，采用二段结构：

1. **继续今天**：显示今日任务映射的 1–3 个轻量练习。
2. **更多内容**：按语文、数学、英语、运动与专注分组；展开后才显示具体课程。

自然拼读属于英语二级入口。暑假学习属于计划集合，不再和学科并列。

统一练习节奏：

```text
30–60 秒热身
→ 1–3 个轻量问题
→ 立即反馈
→ 错题进入复习
→ 同一 eventId 只奖励一次
```

## 6. 游戏页

游戏页负责选择和进入三个独立世界：

- 花园保卫：`prj/games/garden-defense/`
- 方块探险：`prj/games/voxel-adventure/`
- 横版闯关：`prj/games/platform-quest/`

工作台只显示摘要和“进入游戏”；完整棋盘、Canvas、敌人、计时器和关卡逻辑不能回到首页。

游戏可以读取和消费阳光/能量，并通过既有 bridge 发放有上限且幂等的奖励；不能修改课程完成状态。

## 7. 成人和少儿减法

### 成人一级导航建议

- 今天
- 项目与目标
- 阅读与记录
- 复盘
- 我的

生活分区、归档统计、家庭互动、账号同步、设置进入二级页。

### 少儿一级导航建议

- 今天
- 学习
- 成长
- 奖励
- 我的

错题、阅读、目标、家长互动、日记、同步进入相应二级页。

成人和少儿的减法在幼儿 P0 稳定后执行，避免一次改三套产品。

## 8. 文案原则

- 给孩子：短句、动作导向、不给失败贴标签。
- 给家长：显示真实状态、待确认和可恢复方式。
- 不使用“漏卡惩罚、奖励减半、僵尸扣分”。
- 僵尸只表示待处理目标或游戏挑战。
- 不宣称复制商业游戏；产品文案使用“花园保卫、方块探险、横版闯关”。
