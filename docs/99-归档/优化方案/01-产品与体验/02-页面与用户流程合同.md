# 02 页面与用户流程合同

## 根入口

- 输入：最近模式、幼儿主题记忆。
- 输出：三张主卡和最近使用提示。
- 禁止：加载课程、工作台状态和游戏资源。

## 幼儿今天页

- 必须：日期、伙伴、阳光/能量/连续、3 核心、折叠选做、进度、游戏和奖励出口。
- 可选：最近一条证据。
- 禁止：月历、完整周报、三游戏完整进度、课程目录、棋盘、家长设置。

## 学习页

- 首屏：继续今天、错题复习。
- 二级：语文、数学、英语、运动与专注。
- 每次练习：最多 1–3 题或一个活动。
- 完成：先保存完成事实，再通过幂等事件发奖。

## 游戏页

- 显示三个世界的摘要和进入按钮。
- 游戏在独立 HTML 中运行并拥有自己的生命周期。
- 返回工作台后不得残留 timer。

## 奖励页

- 显示余额、可兑换、待家长确认、历史。
- 兑换失败不能只改 UI。
- 游戏奖励和学习奖励均显示来源，但不建立第二余额。

## 我的页

- 子入口：成长、日历、错题、家长互动、设置、备份、账号。
- 儿童默认看成长；账号和导入导出放家长区域。

## 核心旅程

```text
根三卡 → 幼儿主题 → 今天 → 完成/练习任务
→ 阳光和证据更新 → 游戏 → 返回 → 奖励 → 冷启动保持
```

从今天到开始任务不超过一次主要点击；从今天到进入当前游戏不超过一次点击。
