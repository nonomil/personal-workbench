# 04 总路线图与里程碑

| 里程碑 | 目标 | 主要任务 | 退出节点 |
| --- | --- | --- | --- |
| M0 基线 | 让当前迁移可解释、可恢复 | GOV-001～003 | NODE-0 |
| M1 产品骨架 | 三卡入口、主题选择、五导航 | IA-001～005 | NODE-1 |
| M2 幼儿闭环 | 首页四块、学习/游戏/奖励/我的归并 | UX-001～004 | NODE-2 |
| M3 模块化 | runtime adapter、幼儿页面、按需数据、成人少儿 adapter | ARC-001～006 | NODE-3 |
| M4 样式与制品 | CSS 六层、素材 manifest、APK/Pages artifact | UI/AST-001～006 | NODE-4 |
| M5 发布候选 | 全回归、浏览器、Pages、APK、MuMu | QA/REL-001～005 | NODE-5 |

## 关键路径

```text
M0 可恢复基线
→ M1 产品减法
→ M2 幼儿真实闭环
→ M3 模块化
→ M4 CSS/素材清理
→ M5 发布
```

不能并行：`prj/app.js` 页面抽取与同页面产品重构；CSS 删除与页面结构重写；移动 artifact 和素材路径迁移。

可以并行：只读素材清单审计、验收脚本设计、文档和测试夹具准备，但不能同时写共享入口文件。

## 参考节奏

- M0：半天到 1 天。
- M1：1–2 天。
- M2：2–3 天，加一次孩子/家长实际使用。
- M3：3–6 天，按页面小步提交。
- M4：3–5 天，重点在证明旧规则/素材无消费者。
- M5：1–2 天。

这是参考切片，不是承诺工期；退出门优先于日期。
