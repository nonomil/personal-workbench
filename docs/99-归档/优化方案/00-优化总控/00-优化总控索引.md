# 00 优化总控索引

## 1. 专项目标

本专项只解决“工作台过于臃肿”的问题：减少一级入口和首页信息，拆开三模式运行代码，收敛 CSS 历史级联，建立运行素材白名单。它不负责新增课程、题库、游戏关卡和云端能力。

## 5. 状态词

- `BLOCKED`：依赖或用户门未满足。
- `READY`：输入和文件边界明确，可以领取。
- `IN_PROGRESS`：正在执行，不能并行修改相同文件。
- `REVIEW`：代码完成，等待 diff、测试或用户审查。
- `DONE`：DoD 和验收证据都满足。
- `DROPPED`：经决策明确取消，保留原因。
