# 花园保卫战问题与优化清单

> 优先级从高到低；P0/P1 为本轮 MVP 已完成项，P2 和发布门禁中的未勾选项是后续工作。

## P0：先修复用户可见故障

- [x] 让种子卡片选中状态与 `garden.activePlantId` 一致。
- [x] 用选中的植物或已放置植物渲染战场，不再使用固定五路植物数组。
- [x] 把植物行为拆成产阳光、射击、阻挡、减速射击、一次性范围清除等最小规则。
- [x] 坚果墙不进入发射豌豆路径，并显示阻挡/生命值状态。
- [x] 把单个 `invader` 改为可容纳多实体的 `defense.zombies`，支持同屏 3 只、不同路线。
- [x] 增加路、列、速度/移动节奏、生命、攻击冷却和稳定实体 ID。
- [x] 归一化时保留显式 `health=0`，清除死亡实体，避免刷新或结算时复活。

## P1：形成可玩的短局

- [x] 加入 5×6 格子点击放置，覆盖空格/已占用/阳光不足/未解锁反馈。
- [x] 增加简化游戏循环，页面离开 battle 和重新渲染时停止 timer。
- [x] 增加普通、路障、铁桶三种可辨认僵尸，并让波次组成可预测地升级。
- [x] 把发射、命中、减速、阻挡和清波结果拆成可测试的纯规则函数。
- [x] MVP 不在战斗重复发放阳光/奖励；任务奖励仍沿用现有幂等成长逻辑。

## P2：体验和可维护性

- [x] 统一命名为“阳光成长工作台 / 花园保卫战”，删除季节性“暑假”文案。
- [ ] 增加暂停、重试、降低动效和键盘/触屏最小可用状态。
- [x] 为状态迁移补 `schemaVersion`，保留旧 `garden.invader` 的兼容读取。
- [ ] 给调试模式增加实体快照、波次、路和命中日志，默认不显示给孩子。

- [ ] 不使用原版 Logo、截图、音效、原始关卡数据或直接嵌入商业游戏。
- [ ] 发布前检查深层路由、移动端 320/390/441px、刷新恢复和导入导出。
