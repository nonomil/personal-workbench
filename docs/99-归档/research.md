# 个人工作台调研整理

> 调研时间：2026-07-29（Asia/Shanghai）
>
> 这份资料服务于本仓库个人工作台的设计与实现。外部案例只用于提炼信息架构和交互方法，不复制作者内容、截图或受限素材。

## 已核实事实

### 用户提供的胡楚靓案例脉络

用户提供的笔记介绍了一个以 WorkBuddy 为例的个人学习工作台：左侧导航、首页总览、每日计划、学习任务、阅读记录、长期规划；纯本地方案使用浏览器 `localStorage`，云端方案另有账号和数据库提示词。笔记同时强调，要把布局、颜色、数据结构和按钮行为写成具体规格，生成结果才不会依赖 AI 自由猜测。

### 小红书案例：暑假学习工作台

用户提供的小红书公开分享页描述了一个为孩子制作的暑假学习工作台：计划和玩法可定制，语数英任务可以调整；完成任务获得阳光并培育植物，不完成会触发僵尸入侵；成功打卡有语音鼓励；另有错题本、奖励中心、打卡统计和亲子互动模块。

### 公开模板与效率产品

- Notion 个人模板目录把 Personal Dashboards、Reading List & Book Tracker、Planner、Habit Tracker 等作为高频个人模板类别。
- Todoist 的效率方法目录把 GTD、Kanban、Time Blocking、Pomodoro、Weekly Review、SMART Goals、PARA 等拆成可探索的方法入口。
- AFFiNE 的个人生产力仪表盘文章建议先定义结果和 KPI，再建立 Tasks、Habits、Events、Time Logs 等可扩展实体；同时提醒没有决策价值的指标应被删除。

## 设计推断

1. 个人工作台的核心不是“有很多卡片”，而是打开后立即回答：今天做什么、正在推进什么、最近有没有形成稳定节奏。
2. 对学习场景，完成反馈需要同时有即时奖励和长期可见的成长痕迹；儿童版现在用阳光、植物阶段、独角兽 XP、连续奖励和奖励中心形成完整闭环。
3. 小红书案例的可迁移点是“把规则和反馈做成可配置系统”，而不是下载或复制植物大战僵尸素材；本项目以原创的阳光花园、僵尸状态、星芒造型和语音夸奖表达同类闭环。
4. “离开电脑就打不开”和“后台提醒难”等公开反馈说明，首版应优先保证本地数据、导入导出、移动端布局和无网络可用，再扩展云端能力。

## 本项目采用

- 独立中文项目目录 `G:\StudyCode\个人工作台\`。
- 三个独立入口：成人成长工作台、儿童学习工作台、幼儿学习工作台；共享 Vanilla JS 引擎，但使用不同 localStorage key。
- 成人版使用深色、低干扰工作台外壳：侧栏、顶部上下文、今日主线、家庭互动、账号连接和少量高信号数据。
- 成人版继续吸收 Life OS 单 HTML 案例的信息架构：生活分区、习惯、DDL/考试节点、完成项归档、年度时间进度和语言偏好；它们放在成人专属 `adult` 快照命名空间，不扩散到儿童/幼儿玩法。
- 儿童版使用明亮、鼓励式工作台外壳：今日打卡、成长地图、语数英课程、独立错题本、阅读记录、阳光奖励中心、家长互动和成长日记。
- 幼儿版进一步采用少文字、大图卡、大触控目标：入口压缩为今天、成长、打卡、课程、改错、奖励、家长、设置，卡片标题使用短词，图标作为主要识别线索。
- 幼儿版视觉重做采用原创阳光花园、植物伙伴、星星和友好小怪的 clay / paper-cut 语言；主视觉与 7 个无文字图标来自本地生图流程，字母和数字误生成素材不进入页面，所有中文仍由 HTML/CSS 渲染。
- localStorage 本地快照，成人版、儿童版和幼儿版分别使用独立 key，均不混入主站业务和 Profile 快照。
- 远端 adapter 已接入现有自托管 API 的注册、登录、refresh、家庭/档案和快照 push/pull；未填写地址时显示“本地模式”，冲突时保留本地数据并提示人工恢复。
- Vercel 只作为静态前端部署目标，自托管服务继续负责 JWT、SQLite 和快照授权；不重新引入 Supabase。
- 成人版使用一张无文字本地学习桌面图，儿童版使用明亮学习桌面图；幼儿版使用独立阳光花园主视觉和语义图标资产，缺失时仍使用 CSS fallback。
