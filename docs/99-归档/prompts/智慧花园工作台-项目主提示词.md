## 1. 产品定位

项目名：智慧花园工作台。

目标用户：3-8 岁儿童与家长，重点覆盖幼小衔接和小学低年级。

核心闭环：

```text
选择学习入口 → 完成一张小练习 → 获得阳光/豌豆能量
→ 植物成长或防守花园 → 解锁收藏/奖励 → 家长看到反馈
```

幼儿版的优先级是：图像识别、少量短文字、大触控目标、立即反馈、可重复练习、家长可回看。不要用大量说明文字替代可操作内容。

## 2. 当前工程技术边界

- 当前工程是模块化 Vanilla JS 静态 SPA，不是单 HTML 原型。
- 入口是 `preschool-workbench/index.html`。
- 业务编排在 `app.js`，配置和课程内容在 `config.js`，状态和迁移在 `storage.js`。
- 样式通过 `css/preschool-workbench.css` 的 import 图加载；幼儿视觉增量优先放在 `css/preschool/15-workbuddy-overview.css` 或新增明确版本层。
- 业务数据使用当前工程的 `petbank_huchuliang_preschool_workbench_state_v1` 快照，不得另造 `sunBalance`、`tasks`、`calendar` 等第二套账本。
- 页面必须支持无网络运行。静态资源使用相对路径，并保留缺图 fallback。
- 远端能力只接现有自托管 API adapter；不重新引入 Supabase，不把“未来方案”写成已上线。
- 生图只使用 GPT Image 路线；不使用 Agnes，也不把 Agnes 输出作为验收素材。
- 所有新增业务 key、路由、资源和数据字段要有测试或契约说明。

课程入口可以共享课程页，但点击“识字专区”等入口时必须聚焦对应专区，并在 URL hash 中保留当前课程，便于刷新和分享，例如：`#courses?course=preschool-literacy`。

移动端优先：

- 顶部状态栏保留阳光、连续天数和学习入口。
- 侧栏折叠后，主要入口应能在打开菜单中按组阅读；不能把 16 个入口挤成横向小按钮。
- 课程卡在 375px 宽度下单列显示，触控目标至少 44px 高，相邻目标至少 8px 间距。
- 不允许横向滚动，不允许标题、按钮或题目被父容器裁切。

## 4. 首页与任务闭环

首页只负责回答“今天做什么”和“花园现在怎么样”，不要把所有课程正文塞进首页。

首页应保留：

- 今日任务进度和完成数量
- 当前阳光、豌豆能量、连续天数、植物收藏
- 花园预览和僵尸状态
- 今日宝箱/奖励进度
- 进入完整课程资源的明确入口

每日任务默认包含参考网页中已核实的 6 项：

- 完成今日识字
- 朗读一首古诗
- 数学闯关一关
- 学习今日英语
- 做一项运动
- 专注力训练一题

完成任务必须通过现有状态提交逻辑，不能只修改 DOM。重复点击不得重复发放阳光、豌豆能量或收藏奖励。

## 5. 11 个学习模块的内容契约

### 日历打卡

- 月历网格显示日期、已打卡、未完成和未来日期。
- 统计本月点亮天数、出勤率、当前连续天数、今日完成进度。
- 优先使用已有 `dailyPlans`、专注记录和阅读记录推导状态，不新增重复日历账本。

### 花园基地

- 展示 4 行防守路线、植物、阳光、僵尸和花园安全状态。
- 继续支持植物伙伴、收藏、花园成长和防守入口。
- 画面要以场景和角色为主，文字只标识状态。

### 识字专区

- 每日 10 个字，支持自然、植物、动物、身体、数字、颜色等分类。
- 卡片至少显示汉字、拼音、分类和“学会”动作。
- 点击可调用 Web Speech API 中文发音；不可用时显示可见降级提示。
- 当前课程卡中的 `684 字启蒙字库` 等参考站数据属于内容说明，未接入真实字库前不得冒充完整可测字库。

### 拼音专区

- 覆盖 23 个声母、24 个韵母、16 个整体认读音节的内容规划。
- 先展示声母跟读、顺口溜和发音小游戏，再逐步扩充数据。

### 古诗专区

- 每关 10 首，首关从《静夜思》开始。
- 支持朗读、跟读、白话解释和“我学会了”。
- 诗句内容和插图分开管理，不能把长诗塞进狭窄卡片。

### 数学专区

- 首版支持 10 以内加减，逐步扩展到 20 以内进退位。
- 题目配水果计数辅助、大数字按钮、确认和换一题。
- 答错应进入错题本，不能静默丢失。

### 专注力训练

- 支持找不同、迷宫、数数、规律、逻辑五类入口。
- 首版每类提供一题可操作样例，后续再扩展题库。

### 每日英语

- 每日 5 词，区分新词和复习词。
- 展示图片、英文、中文、例句和英文发音入口。
- 发音优先 `en-US`，不可用时不阻塞页面。

### 每日运动

- 保留 10 个居家动作的内容规划。
- 每个动作有开始、倒计时、进度和完成反馈。
- 完成运动通过统一奖励入口发放阳光。

### 错题本

- 数学答错自动记录题目、错误答案、正确答案和复习状态。
- 支持重新练习、标记掌握和家长查看。

### 奖励商城

- 参考网页的植物商店 + 家长自定义奖励结构。
- 使用现有奖励、阳光和植物成长数据，不另造余额。
- 兑换前校验余额，成功后记录一次性奖励事件并播放可关闭的反馈动画。

## 6. 视觉与交互约束

- 幼儿版使用明亮的花园纸张、草地绿、向日葵黄、珊瑚橙和天空蓝；保持文字对比度。
- 卡片留白优先于信息堆叠；课程资源页默认两列，窄屏单列。
- 使用 Lucide 图标或本地生成图片作为 UI 图形；不要用 Emoji 代替所有操作图标。
- 角色图片应有透明背景、稳定尺寸和 `alt` 文本；图片加载失败时保留 CSS/文字 fallback。
- 植物轻微呼吸、角色左右摆动和阳光脉动都要支持 `prefers-reduced-motion`。
- 所有按钮、卡片和课程入口有 hover/focus/active 状态；点击后必须有状态变化或 toast。
- Web Speech API、震动、音效均为渐进增强，浏览器不支持时不报错、不阻塞学习。
