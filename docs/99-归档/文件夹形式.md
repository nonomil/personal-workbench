## 维护原则

1. `docs/00-总控/` 是项目状态唯一来源；不要在 worktree 下建立第二套总控。
2. `幼儿课程方案/00-总控/` 只管幼儿课程，不负责成人版、儿童版和发布全局状态。
3. `research/raw/`、`tmp/`、生成原图和截图不能直接进入 Pages/APK。
4. 任何标记为“完成”的内容，都必须能指向代码、数据、测试或验收证据。
