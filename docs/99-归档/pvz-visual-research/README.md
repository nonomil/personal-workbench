# 幼儿版植物大战僵尸视觉调研

这份资料用于幼儿学习工作台的视觉改造。目标是借鉴经典横向塔防的可读性和反馈节奏，把学习任务映射成原创的阳光、植物、豌豆和僵尸玩法；外部页面中的角色、截图和图鉴素材只做研究参考，不进入网站发布制品。

## 资料结构

- `research.md`：已核实事实、设计推断、本项目采用和待补证据。
- `sources.md`：来源、抓取时间、证据用途和版权边界。
- `assets/screenshots/`：搜索结果证据截图，仅供设计复盘。
- `prompts/`：原创参考图和透明素材爆炸图提示词。

## 本轮设计结论

幼儿首页必须首先像一个“正在玩的草坪关卡”，而不是普通成长仪表盘：顶部是种子卡槽和阳光；中间是 5 路横向草坪，左侧是植物，右侧是正在靠近的整身僵尸；任务卡、学习进度和奖励放在战场下方或侧边。中文标题与按钮由 HTML/CSS 绘制，生成图片不包含文字。

## 发布边界

调研截图、来源图片 URL、原始生成图和拆解中间产物不得进入 GitHub Pages 发布目录。发布目录只保留经过透明度检查、语义命名并被页面引用的自有素材。
