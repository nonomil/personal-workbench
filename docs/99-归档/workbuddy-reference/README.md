# WorkBuddy 幼儿工作台参考

调研日期：2026-07-31

本资料包记录对用户提供的 WorkBuddy 幼儿工作台页面的结构观察，以及本项目幼儿版的采用边界。外部页面只作为交互与信息架构参考，不复制源码、品牌、角色或图片素材。

## 参考页面

- 页面：[幼儿工作台 WorkBuddy 参考](https://a8a2a214b0bfc8b89.sh4.agentos-app.net/)
- 读取方式：静态 HTML/CSS/JavaScript 页面结构核对
- 本地素材：无外部产品素材进入发布制品

## 本项目采用

- 固定左侧导航，导航名称短、图像入口明确。
- 顶部只保留当前页面、阳光状态和孩子身份，减少首屏干扰。
- 首页优先展示今天任务，再展示花园状态、奖励和连续打卡。
- 页面内容采用白色/奶油色大卡片，给幼儿留下足够的点击与阅读空间。
- PVZ 植物、僵尸、阳光和发射豌豆仍使用本项目已有素材和状态逻辑。

## 不采用

- 不复制 WorkBuddy 的源码、品牌名、统计脚本或第三方图片。
- 不把外部页面的 emoji 当成产品图标；产品入口继续使用项目内 SVG/Lucide 和透明 PNG 素材。
- 不把首页做成营销型 Hero；首页必须直接进入今日任务与花园反馈。
