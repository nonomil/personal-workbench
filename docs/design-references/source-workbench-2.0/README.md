# 暑期作业台 2.0 参考帧

来源：`G:\UserCode\跨平台采集器\notes\AI\工作台\给娃手搓个暑期作业台2.0版本`

这些图片是本项目的离线设计研究资料，不是线上产品素材。它们用于核对工作台的信息架构、任务密度、动画反馈和植物防守场景；页面中的文字、图标、数值和交互仍由 HTML/CSS/JS 渲染。

## 关键观察

- 首屏同时出现紫色单列路线栏、浅紫工作区、顶部阳光/等级/连续状态、六项成长状态和花园防守区。
- 首页任务不是 3 张装饰卡，而是 6 项左右的可完成小任务；桌面端三列两行，窄屏两列，完成状态和奖励在卡面直接反馈。
- 植物防守区使用绿色多行网格、植物列、路径格和入侵者列，孩子能立即看懂“完成任务 -> 收集资源 -> 防守”。
- 阳光商城按奖励层级组织，连续签到、每日自检、收藏和分层奖励形成长期节奏。
- 任务完成、页面切换、召唤入侵者、豌豆命中都有短反馈；BGM 是可选增强，不应阻塞业务结算。
