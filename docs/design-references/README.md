# 幼儿工作台视觉参考生成

这组提示词只用于生成网页视觉参考图，不直接作为页面资源发布。先比较两种方向，再决定是否替换幼儿版现有视觉。

## 方向 A：阳光花园版

- 参考方法：WorkBuddy 案例的今日任务、阳光、花园、奖励闭环
- 视觉语言：原创纸雕 / clay / 软 3D，适合低年级幼儿
- 优点：亲和、识别成本低，和当前幼儿版素材兼容
- 风险：如果卡片层级过多，容易继续像普通工作台

提示词见 `workbench-reference-garden.md`。

## 方向 B：原创像素方块世界版

- 参考方法：宠物积分项目现有像素冒险、地图、战斗和宠物素材的结构感
- 视觉语言：原创 16-bit / 32-bit 像素美术，方块地形、像素宠物、任务牌、地图节点
- 优点：游戏感最强，孩子更容易把打卡理解为“闯关”
- 风险：像素细节容易抢过学习任务，需要保持任务入口足够大、文字足够少

提示词见 `workbench-reference-pixel.md`。

方向 B 已作为幼儿版当前视觉方向落地：像素参考图的中央地图区域被裁切为首页花园的装饰背景，任务节点、中文标题、状态、按钮和数值仍由 HTML/CSS/JS 渲染，避免把交互做成一张静态图。
