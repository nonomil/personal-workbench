# 资料生产与版权规范

## 允许进入运行数据

- 项目原创词条、短句、题目、中文解释和打印页。
- 已确认许可证、署名和修改条件的外部资源，并逐项写入 manifest。
- 使用 GPT 生成的原创无文字角色/背景，经过人工筛选、透明处理和发布清单登记。

## 只作研究

UFLI、Reading Rockets、British Council、Open Source Phonics 的课件、词卡、音频、绘本页面；商业教材；来源不明的 GitHub 图片/音频；搜索结果截图。它们只能放 `research/` 或作为家长外链。

## 内容 QA

- 短句按已教规则计算可解码比例，不能凭感觉标记“简单”。
- 所有图片不得包含模型生成的中文、英文、字母、数字或 Logo。
- 课程条目必须有 `source.kind/license`；unknown 不可发布。
- `assets/generated/preschool/phonics/manifest.json` 只登记最终被页面引用的素材。
