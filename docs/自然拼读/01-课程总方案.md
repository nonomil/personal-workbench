# 自然拼读课程总方案

## 教学闭环

基础字音热身 → 新音/字母组合示范 → 合成/分解/词族练习 → 可解码短句和意义应用。每节 8-15 分钟，至少一半时间用于旧内容或混合复习。

## 60 日阶段

| 阶段 | 天数 | 目标 | 进入下一阶段的证据 |
| --- | --- | --- | --- |
| 音素意识 | 1-5 | 词、音节、押韵、首尾音、口头合成 | 3 个听音活动中至少 2 个可完成 |
| 第一组字音 | 6-12 | `s a t p i n m d` | 字母-音匹配和口头听辨均有记录 |
| CVC | 13-20 | 短 a/i、首中尾音 | 能合成/分解 3 音词 |
| 词族 | 21-28 | 短 o/e/u 与常见词族 | 能替换首音并区分中间音 |
| 常见组合 | 29-36 | `sh/ch/th/ck/ng` | 能在词中定位组合 |
| 连缀 | 37-44 | `st/sp/sl/sk/nd/nt/mp/ft` | 读词时不插入额外元音 |
| 短句应用 | 45-52 | 2-4 句可解码短文 | 能读/跟读并回答意义题 |
| 迁移复习 | 53-60 | 混合规则、易错音、亲子朗读 | 能将规则迁移到新词或短句 |

## 掌握状态

`introduced` 表示见过，`practicing` 表示正在练，`ready` 表示至少两个不同日期、两种活动且约 80% 正确，`maintenance` 表示进入长期复习。错题回退到 `practicing`，不扣阳光。
