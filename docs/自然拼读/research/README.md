# 自然拼读外部资料研究

本目录只保存研究证据和外部链接，不是运行时内容目录。

## 资源分层

- `reference-only`：教学原则、教材目录、外部文章，仅引用和外链。
- `open-licensed`：许可证明确的内容，仍需逐项记录署名和修改条件。
- `project-original`：个人工作台自行编写、绘制或录制的内容。
- `unknown`：授权不清，只能留在研究目录，不能进入发布制品。

## 下载规则

原始 PDF、网页快照、截图和未审核音频放在 `tmp/phonics-downloads/`，不进入 `data/`、`assets/` 或发布制品。每一项若要长期保留，必须在本文档体系中登记原始 URL、作者、许可证、访问日期和用途。
