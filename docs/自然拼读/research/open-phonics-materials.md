# 权威开放自然拼读资源核验

更新时间：2026-08-03

## 使用边界

目标不是把个人工作台做成完整教材，而是找到可以支撑“已教规则 -> 简单测验 -> 复习”的公开课程资料。以下资源按原始页面或 OER 目录的许可证证据核验；没有下载商业教材，也没有把任何外部内容写入运行时课程数据。

许可证允许使用，不等于可以无条件打包。进入发布制品前仍需逐文件登记作者、来源、许可证、修改说明和署名，并确认个人工作台的发布方式符合 `NC`、`SA` 等限制。

## 可进入发布包的候选

这里的“可进入”表示许可证方向明确、技术上可以进入审核队列；当前均未下载或导入。

### 1. Open Source Phonics：首选主参考

- [官方主页](https://www.opensourcephonics.org/)
- [120 Lessons](https://www.opensourcephonics.org/120-lessons/)
- [Decodable Stories](https://www.opensourcephonics.org/decodable-stories/)
- [官方 Terms of Use](https://www.opensourcephonics.org/terms-of-use/)
- [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)

官方页面明确提供 120 节课程，从字母和字母音开始，逐步进入 CVC、辅音组合、词缀、多音节词和高级拼写模式；课程页面同时提供分组可解码故事。官网说明活动包含音素意识、读词、听写和重复朗读，特别适合作为“规则、读词、听写、短句/短文复核”的来源框架。

官方 Terms of Use 明确写明：材料可补充、改编和再发布；采用 Attribution-NonCommercial-ShareAlike 4.0 Creative Commons 条款，需要署名、说明修改，并以相同方式共享改编版本。

对工作台的用法：只提取技能顺序和测验类型，或在许可证合规后纳入经过改编的少量词/句；不把官网整套页面镜像进项目，不把 120 节原文直接复制成另一套课程数据库。

### 2. EL Education K-2 Reading Foundations Skills Block：结构化拼读参考

- [EL Education K-2 课程概览](https://www.eleducation.org/resources/k-5-language-arts-curriculum-k-2-overview/)
- [OER Commons：Grade K Module 1](https://oercommons.org/courses/grade-k-reading-foundations-skills-block-module-1)
- [OER Commons：phonics 资源集合](https://oercommons.org/browse?f.keyword=phonics)
- [OER 记录中的官方课程链接](https://curriculum.eleducation.org/curriculum/ela/grade-k/skillsblock-1)
- [课程条款链接](https://curriculum.eleducation.org/terms-of-use)

OER Commons 的资源记录标明提供方为 EL Education、内容为 Kindergarten Reading Foundations Skills Block Module 1，描述为每天一小时的结构化自然拼读课程，并标注 `Creative Commons Attribution`。同一资源集合还列出 Grade K、Grade 1、Grade 2 的多个 Reading Foundations Skills Block 模块，标签包含 Assessment、Decoding、Phonics、Reading、Spelling。

对工作台的用法：参考其“技能模块 + 形成性评估 + 解码/拼写”组织方式。它面向学校年级课堂，资料量和课时明显大于家庭短测，不直接照搬到幼儿每日任务。实际导入前必须检查下载文件中的版权页和当前 EL Education 条款，保留 CC BY 署名。

### 3. Core Knowledge Language Arts（CKLA）Skills / Decoding Supplement：系统序列参考

- [CKLA 免费课程入口](https://www.coreknowledge.org/download-free-curriculum/)
- [CKLA K-5 FAQ（官方 PDF）](https://www.coreknowledge.org/wp-content/uploads/2017/08/FAQs_CKLA_K5.pdf)
- [Decoding and Encoding Remediation Supplement（官方 PDF）](https://www.coreknowledge.org/wp-content/uploads/2017/01/CKLA_DecodingEncodingSupp_Web_Oct_2016.pdf)
- [示例 Unit Reader（官方 PDF）](https://www.coreknowledge.org/wp-content/uploads/2017/01/CKLA_G1_U4_RDR_web.pdf)
- [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/)

官方 FAQ 说明 CKLA PreK-3 可免费下载、使用和改编；Skills strand 以显性、系统的字母-音素和拼写模式教学为主，包含解码、编码、形成性评估和可解码读本。FAQ 明确写出 CKLA 使用 `Creative Commons Attribution-NonCommercial-ShareAlike 3.0 Unported License`，改编和再发布需要署名、相同方式共享，不能销售原作或改编版。

对工作台的用法：适合核对课程顺序、测验点和“可解码文本必须围绕已教规则”的边界。完整 CKLA 体量很大，官方 FAQ 描述 K-2 每天约 120 分钟，不适合直接作为个人工作台的简短每日材料。只考虑提取结构，或在明确遵守 CC BY-NC-SA 3.0 的前提下选取少量适配内容。

### 4. FreeReading：早期解码练习参考

- [FreeReading 官方入口](https://freereading.net/)
- [OER Commons：Reading Connected Text Fluency](https://oercommons.org/courses/reading-connect-text-activities)
- [OER Commons phonics 目录](https://oercommons.org/browse?f.keyword=phonics)
- [Creative Commons 许可说明](https://creativecommons.org/share-your-work/cclicenses/)

OER Commons 资源记录将 `Reading Connected Text Fluency` 标为 FreeReading 项目内容，提供方为 Wireless Generation，适用 Lower Primary，内容包含 sequential/supplemental activities，帮助学生解码第一批印刷短句；记录标注 `Creative Commons Attribution Share Alike`，并关联 K/1、Phonics、Decoding 和 Common Core RF.K.3。该记录没有在摘要中显示具体版本，不能把 OER Commons 站点页脚默认许可误当成 FreeReading 文件的许可证，必须逐文件核验。

对工作台的用法：可参考“从首批可解码短句开始”的测试形式和 40 周早期阅读结构。由于原站较老、资源页面和视频可用性不稳定，不能把 OER 目录的一条记录当成所有文件都已授权；导入前逐文件核验许可证。

## 仅参考，不进入发布包

### UFLI Foundations

[官方课程入口](https://ufli.education.ufl.edu/foundations) 和 [版权说明](https://ufli.education.ufl.edu/copyright) 对技能顺序、显性教学和活动设计很有价值，但其课件、词表、故事和音频受版权边界约束。只作为教学参考，不复制资源。

### EEF、Reading Universe、Reading Rockets

这些机构资料可用于确认系统、显性、渐进教学和可解码文本原则，但不是本项目可直接打包的教材许可证。只引用观点和链接，不复制正文或图表。

### Antura、GCompris

两者是开源教育项目，可以参考离线活动、无障碍和练习交互；但它们不是本项目需要的自然拼读教材序列。代码和图片/音频许可证也需分开核验，暂不导入。

## 推荐采用方式

当前不需要再设计复杂课程，也不需要同时接入四套资料：

1. 将 `Open Source Phonics` 作为首选的开放课程参考，优先使用其技能顺序和“读词/听写/可解码文本”测验思想。
2. 用 EL Education 和 CKLA 交叉检查顺序、形成性评估和解码边界，不把它们变成第二套运行时课程。
3. 用 FreeReading 参考最早期的短句解码测试。
4. 个人工作台继续保留现有原创 60 节、94 词、36 短句数据；外部资源只做 `sourceTrace` 和研究引用，不覆盖当前数据。
5. 前台只做“今日任务、快速测验、错题复习、完成记录”，不制作完整教材阅读器。

## 发布审核门槛

任何资源真正进入 `Data` 或 `assets` 前，必须满足：

- 文件级许可证证据可访问，不能只依据搜索摘要或项目首页口号；
- 保存作者/组织、来源 URL、许可证 URL、访问日期和署名文本；
- 记录是否翻译、改写、裁剪或重新排版；
- 对 `CC BY-NC-SA` / `CC BY-SA` 改编内容保留相同许可，且不把它混入声称可商业使用的独立素材；
- 不下载或纳入未经许可的外部音频、字体、插图、角色和视频；
- 发布前运行资源清单和专项课程测试。
