# 家长执行手册

## 每天怎么做

1. 只安排 8-15 分钟，孩子疲倦时停在“尝试过”。
2. 先让孩子听和看，再让孩子说/拖/读；不要一开始就告诉答案。
3. 读短句时先遮住图片读词，再打开图片确认意思，避免只靠猜图。
4. 记录“自己读、跟读、需要示范”，不把语音识别失败算作孩子失败。
5. 错了就回到上一张会的卡，下一次先复习，不扣阳光。

## 家长只需要观察

| 观察项 | 选择 |
| --- | --- |
| 听音 | 能分辨 / 需要再听 |
| 字音 | 能匹配 / 需要示范 |
| 合成 | 能连起来 / 逐音跟读 |
| 应用 | 能读或跟读 / 只看图讲意思 |

家长页面提供建议，不要求家长掌握专业术语；页面中文解释和英文示范可以分开。
