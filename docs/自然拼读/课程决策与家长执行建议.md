# 自然拼读课程决策与家长执行建议

## 先给结论

目前不建议为了“有课程才有效”直接报一个长期班。现有大纲已经足够搭建一套低成本、可观察、可调整的家庭课程；更适合先执行 4 周，再根据孩子的状态决定是否购买短期专项课或一对一纠音。

报班的价值主要是固定节奏、老师即时纠音、同伴环境和家长省时间，不是因为商业课程拥有自然拼读的唯一内容。家长能稳定每天陪伴 8-15 分钟，并愿意记录孩子的听音、合成和阅读表现时，自研更适合当前目标。

## 什么时候优先自研

- 孩子愿意玩声音、模仿发音，尚未出现持续抵触。
- 家长每天能提供固定的短时段，而不是周末一次补一小时。
- 目标是建立音素意识和自主解码，不急着冲刺证书或校内排名。
- 家庭希望课程和现有英语专区、每日任务、阳光奖励保持一致。

## 什么时候考虑报课

- 家长连续两周无法稳定执行，课程需要外部节奏来维持。
- 孩子在同一音素上反复混淆，家长无法判断是听辨、口型还是字母对应的问题。
- 孩子需要同伴互动，独自在家练习明显缺乏动力。
- 课程提供真实的个别反馈、可试听的教师示范和清晰的退费/版权边界，而不只是大量录播和资料包。

不建议仅凭“词汇量爆炸”“超过在校一两年”等宣传语购买。试听时重点看：是否先听音再看字、是否显性示范合成/分解、是否让孩子读已教规则的可解码文本、是否纠正错误而不是让孩子看图猜词、是否给出可验证的家庭练习。

## 四周家庭试运行

每周 5 天，每天 8-15 分钟：

| 时间 | 做什么 | 观察什么 |
| --- | --- | --- |
| 第 1 周 | 听音、押韵、首音、口头合成 | 能否听出相同/不同和首音 |
| 第 2 周 | `s a t p i n m d` 字音匹配 | 能否把音和字母稳定对应 |
| 第 3 周 | 短 `a`、短 `i` 的 CVC 合成/分解 | 是否能从左到右读，不靠猜图 |
| 第 4 周 | 混合复习、原创短句、亲子共读 | 能否读已学规则并说出大意 |

每次只记录三件事：孩子独立完成的词/句、最常错的音、第二天需要复习的项目。连续两次卡住就退回前一个熟悉活动，不增加惩罚，也不把奖励和正确率绑定。

## 与个人工作台的合并边界

- 课程是英语专区的一条子路线，不新增顶层导航。
- 每天自然拼读占 1 个核心任务位；3 个可选任务可放复习卡、开放绘本和打印活动。
- 完成记录写入既有 `courseProgress.completedLessonIds`，奖励继续走现有唯一奖励链路。
- 不新增自然拼读积分、阳光或课程账本。
- 数据和素材都必须按 Profile 隔离，家长查看的是学习证据和卡点，不是额外排行榜。
