做预览时发现的两点（如实告知）

1. 插图重复：按现有 preschoolAssetForIcon 映射，识字 / 拼音 / 古诗 / 英语四科共用同一张"故事书"插图，专注 / 拼读 / 运动共用"星芒"插图。卡片墙上区分学科主要靠底色 + 两个字标题。若希望每科一张专属插图，需要另开一轮生图。

2. 运动专区是 green 色：方案只定义了 orange / blue / lime / pink / gold 五种底色，tone-green 没有对应样式，上面最后一张"运动"卡显示为默认白底。要么补一条 tone-green 样式，要么把运动的 tone 改成已有色（如 lime）。
