# 样式模块

工作台样式现在按版本和历史级联层拆开，页面不再直接依赖 4000 多行的单文件级联。

- `base.css`：成人、儿童、幼儿共用的工作台壳层和通用组件。
- `adult-workbench.css`：成人版清单，加载公共层和成人扩展。
- `child-workbench.css`：儿童版清单，加载公共层和儿童扩展。
- `preschool-workbench.css`：幼儿版清单，按编号顺序加载幼儿历史层和最终 PVZ 主题。
- `styles.css`：兼容入口，按旧顺序聚合全部模块；新页面优先使用对应版本清单。

`css/preschool/` 下的编号文件保留原有追加顺序。暂时不要只按文件名重排它们，因为后面的规则可能覆盖前面的历史规则。新增幼儿视觉修正应放在最终主题文件或新的末级文件，并同步做桌面端和窄屏回归。

嵌套目录中的资源路径相对对应 CSS 文件解析，图片资源统一回到项目根目录的 `../../assets/`。测试使用 `tests/helpers/css-graph.mjs` 展开 `@import` 后检查最终样式内容。
